## §2 Agent Track 逐系统机制摘录（全部可得信息，逐字为据）

### §2.0 赛制规则（Track 2 定义，§3.3）—— 规则面比系统面更重要

> *"Participants design an audio reasoning agent that may orchestrate multiple open-source
> models and tools (e.g., ASR, separation, beat tracking, captioner, planner) to produce a
> CoT path and a final answer. … Agents can be implemented with explicit planning
> (plan–execute–reflect), structured memory for intermediate artifacts (e.g.,
> transcriptions, stems, captions), and self-verification or cross-checking. The goal is to
> evaluate **system-level reasoning** ability to break down high-level auditory questions
> into executable sub-tasks, **actively seek evidence**, and perform self-correction."*

对照 Track 1 规则（§3.3）：

> *"Systems must perform intrinsic reasoning within one forward without delegating to
> **external tools, APIs, search engines, or separate controllers**."*

**规则面的三条读数（对 R2 承重）**：
1. Track 1 的禁止清单里**明写 "search engines"**——说明组织者把"外部搜索"视为一个
   **在场的、需要明令禁止的能力类别**；Track 2 未复述该禁令，因此外部搜索在 Agent Track
   **规则上不被禁止**（但也未被明确许可；"open-source models and tools" 的措辞偏向本地工具）。
2. Track 2 的工具例举**全部是音频重表达算子**（ASR / separation / beat tracking /
   captioner / planner），**零外部知识源**。组织者对"agent 能做什么"的想象本身就限定在
   感知轴。
3. "structured memory for intermediate artifacts (transcriptions, stems, captions)" =
   **回合内感知产物记忆**，不是外部知识组织；与 R2 §3 组织轴无交集。

## §3 专项判定二：Agent Track 横截面 —— 外部知识检索动作 = **零，但证据覆盖率只有 3/16**

**结论（须按此精确措辞进入 R2，不得放大）**：

> **在 Interspeech 2026 ARC Agent Track 决赛 16 支队伍中，论文描述了前 3 名共 3 个系统；
> 这 3 个系统的动作空间全部由音频重表达算子构成（工具重查音频 / 频谱图跨模态重呈现 /
> 多代理辩论），无一使用 web 搜索、知识库检索或任何外部知识源。赛制的 Track 2 定义在
> 工具例举中也只列举音频处理算子，而 Track 1 的禁止清单明写 "search engines"——
> 说明该能力类别在组织者视野内，却在 Agent Track 的所有已描述方案中未被使用。**

**加固强度评估（必须如实降级，这是本次深读最重要的一条纪律性发现）**：

1. **覆盖率**：3/16 = 18.75%，且是**按分数选取的有偏样本**（top-3）。156 队注册、47 队
   初赛提交、30 队决赛提交中，我们只看到 3 个系统的一句话描述。
   → **不能声称"156 队的横截面"**；只能声称"Agent Track 前 3 名的横截面"。
2. **载体的构造性解释（对 R2 是反向证据，必须写进 R2）**：**MMAR 的答案由音频决定**——
   它是"deep reasoning in speech, audio, music, and their mix"的推理基准，
   题目问的是从音频能推出什么。**在一个外部知识对实例级答案几乎没有边际价值的载体上，
   没有队伍使用外部检索，不是"语音域缺失外部知识调度能力"的证据，而是"任务不需要"的
   合理响应。** R2 若把这条当作"缺席"的加固，会被隔离评审直接击穿。
   - 唯一的部分反向读数：ARC §2.2 描述 MMAR 的分类体系为
     *"a hierarchical taxonomy spanning signal, perception, semantic, and **cultural**
     reasoning … utilizing real-world internet videos"*——**cultural reasoning 层
     在原理上是需要世界知识的**。即便如此仍无队伍引入外部检索。这条把结论从
     "任务完全不需要"弱化为"任务的一小部分可能需要但无人尝试"，但**该层的题量、
     以及外部知识在该层上的实际边际价值，本篇均未给出，不可据此推断**。
3. **可辩护的最强表述**（建议原样进 R2 §4.3 或 §4.4 的脚注）：
   > 语音/音频 agentic 的**建制化竞赛**（Interspeech 2026 ARC，156 队注册，Agent Track
   > 30 队决赛提交）在其 Track 2 规则的工具例举与全部三个被描述的获奖系统中，动作空间
   > 均限于音频重表达；外部知识获取动作在该竞赛的公开记录中零出现。**该观察的证据覆盖
   > 为 3/16 支决赛队伍，且其载体 MMAR 的答案主要由音频决定，因此它证明的是"该社区当前
   > 把 agentic 能力全部投在感知轴"，不证明"外部知识调度在语音域不可行或未被需要"。**

## §4 专项判定三：MMAR-Rubrics 过程质量协议 → R2 §6.5 合理性层可借什么

### §4.1 协议全貌（§3.1–§3.2 逐式）

**任务形式化**：$(\hat Y_{\mathrm{CoT}}, \hat Y_{\mathrm{Answer}}) = \mathcal F(A, Q)$。
**评分函数**（关键，见下 §4.3 的反面教材判定）：

$$S = \begin{cases}\mathcal E(\hat Y_{\mathrm{CoT}}) & \hat Y_{\mathrm{Answer}} = Y_{\mathrm{Answer}}\\ 0 & \text{otherwise}\end{cases}$$

**实例级 rubric 分解**：由**人工标注的参考推理链** $Y_{\mathrm{CoT}}$ 出发，用
**Gemini-2.5-Pro 自动生成 $k=5$ 条可核查的原子准则**；再用 **GPT-4o 作 rater**，
对每条准则输出**二元 True/False + 一段简短文字理由**；
$\mathcal E(\hat Y_{\mathrm{CoT}}) = \frac1k\sum_i \mathbb I[\text{criterion}_i]$。

**图 1 实例（`arc-example.pdf`，逐字摘录）**——题目"根据向井里投石时听到的声音估计井深"，
选项 0-100 / 100-200 / 200-300 / 300-400 m；5 条准则：
- **C1** 正确识别回声与落水声为关键听觉线索；
- **C2** 正确识别投石动作与回声返回之间的时间间隔（**八秒**）为计算关键；
- **C3** 认识并应用自由落体公式 $H=\frac12 gT_1^2$；
- **C4** 正确应用声速 340 m/s 计算 $T_2$ 并纳入深度计算；
- **C5** 联立两式求解 $H$ 并准确选出正确深度区间。
预测链把时延估成 2–2.5 s（真值 8 s）、选了 200–300 m，**Rubric score = 0.4**（5 条中满足 2 条）。
→ **该图本身是"表面合理的推理链在关键量上错、但仍拿到部分过程分"的样例**，对 R2 §6.5
"合理性层不得与有效性层合成总分"是一条有力的第三方论据。

### §4.2 协议的自证可靠性（Table 1，逐格）

| 协议 | Inter-rater $\alpha$ | Intra-rater $\alpha$ | 人类对齐 $C>R$ | $C<R$ | $C=R$ |
|---|---|---|---|---|---|
| System-level（单一 5 分制通用量表） | 0.7459 | 0.9081 | 15 | 8 | 27 |
| **Instance-level（MMAR-Rubrics）** | **0.7921** | **0.9216** | **17** | **2** | 31 |

口径：inter-rater = 三个 LLM rater（GPT-4o / Gemini-2.5-Flash / GPT-5-mini）对
**Qwen3-Omni-Thinking 产出的 664 条终答正确的推理链**打分；intra-rater = GPT-4o
**temperature=1.0 跑五次**；人类对齐 = 50 对（人类偏好 $C$ / 拒绝 $R$）来自
Qwen3-Omni-Thinking 与 Single Model Track 前三名的输出。

**可自算的派生读数（论文未给）**：在**有判别的对**上，instance-level 的人类一致率
= 17/19 = **89.5%**，system-level = 15/23 = **65.2%**；但 instance-level 的**平局率
从 54% 升到 62%**——即它买到高一致率的代价之一是**分辨力更低**（$k=5$ ⇒ 单实例分数
粒度只有 0.2）。**这条必须与 $\alpha$ 提升并列引用，否则是选择性汇报。**

### §4.3 对 R2 §6.5 的可借与不可借（逐条）

**可借（三件，均为报告形式与设计教训，非效果外推）**：

1. **"度量本身的可靠性必须自证"这一报告行。** R2 §6.5 合理性层目前列了
   retrieve-skip / continue-stop / admit-reject 三个混淆矩阵 + $\hat V$ 分量标定，
   **但没有任何一处报告"这些离线诊断量自身的评判可靠性"**。ARC 给出现成模板：
   **inter-rater $\alpha$（≥3 个异源 judge）+ intra-rater $\alpha$（同 judge、
   temperature>0、≥5 次重复）+ 人类偏好对的三分类计数（$C>R$ / $C<R$ / $C=R$）**。
   建议直接搬进 R2 §6.5 合理性层作为**新增报告行**（frozen judge 已在 R2 §1.4 工具白名单内，
   红线合规；judge 版本必须 pin 并入九维成本的 `judge calls` 维）。
2. **"实例级原子准则优于全局量表"的设计教训。** 0.7459→0.7921 / 0.9081→0.9216 /
   人类逆转 8→2。R2 若在 §6.5 引入任何"推理链/证据链质量"的判官打分，
   **应采用实例级二元准则分解 + 强制文字理由，而非 1–5 分通用量表**。
3. **"准则由人工参考链派生"的锚定纪律。** ARC 的准则不是凭空生成，是从
   **人工标注的 $Y_{\mathrm{CoT}}$** 派生的（LLM 只做分解，不做发明）。对应到 R2：
   任何"证据链是否被正确使用"的自动判定，其准则应锚在**载体自带的 gold 资产**
   （Omni-DeepSearch 的 `golden_path` / gold entity）上，而不是让判官自由发挥。

**不可借 / 反面教材（两条，同样承重）**：

4. **`S = 0 if answer wrong` 的门控式合成 —— R2 必须显式拒绝。** 这个设计把过程分乘进
   正确性门，导致 Rubrics 列与 Acc 列**结构性强耦合**：可从两列直接算出条件过程质量
   $\mathbb E[\mathcal E\mid\text{correct}] = \text{Rubrics}/\text{Acc}$（见 §5.2 的
   派生表）。**R2 §6.5 明写"四层评价、不合成总分"，照搬 MMAR-Rubrics 会直接违反自己的
   合同。** 建议 R2 若采用过程质量度量，**分列报告二元组
   $(\text{Acc},\ \mathbb E[\mathcal E\mid\text{correct}])$ 并同报 coverage**，
   不报乘积。
5. **分辨力与判官成本的双重代价。** $k=5$ ⇒ 粒度 0.2 ⇒ 62% 平局；每实例需
   1 次生成调用（Gemini-2.5-Pro）+ 1 次判定调用（GPT-4o）+ 人工参考链。
   R2 若引入同类度量，**必须把它计入九维成本的 `judge calls` 维并在 §6.5 的
   "含/不含探针开销"双读数中显式区分**，否则合理性层会变成一个隐藏的成本黑洞。

**边界声明**：MMAR / MMAR-Rubrics **不可作 R2 载体**——MMAR 的答案由音频决定，
外部新信息对实例级答案无边际价值，落在 R2 §1.3 信息角色边界之外。本节借的是
**协议形状**，不是载体，也不外推任何效果数字。

## §6 R2 威胁面判定（本篇作为总览论文的定位）

**总判定：本篇对 R2 不构成方法层威胁面（它不是方法论文，不提出机制），但它是本批
对 R2 的"空位断言量词"影响最大的一篇——因为它是一份建制化的横截面记录。**

### (a) 对 R2 §4.3 / §4.4 空位断言的影响

1. **§4.3 定位结论"文本/视觉域 2023–2026 的整个'自适应→定价'跃迁在语音域尚未发生"**
   —— 在**外部知识轴**上，本篇**加固**该断言（Agent Track 全部已描述系统零外部知识动作）；
   在**感知轴**上，本篇**削弱**该断言（冠军方案已做"低置信度→重查音频"的自适应触发）。
   **必须按轴限定**，与 NAP 条目 §5a-3 的建议一致、方向相同、证据独立。
2. **§4.4 机制位表**须在 M1–M8 之外**新增一条脚注**：语音域**感知轴**的自适应触发已在
   Interspeech 2026 ARC Agent Track 冠军方案中出现（机制细节 `INSUFFICIENT_DETAIL`）。
3. **§1.2 的方法位占据声明**（NAP 条目 §6-⑤ 已建议加）**须改写为更强的版本**：
   > 「不确定性触发的音频重听」这一方法位已被占据：**NAP/OmniAgent（2606.19341，训练态、
   > 自报置信度 0.9 阈值、纯感知动作空间）**与 **Interspeech 2026 ARC Agent Track 冠军
   > 方案（2602.14224 §4.2：低置信度→换工具重查音频，机制细节未公开，训练态未声明）**；
   > 另有具名但全文未获取的 **CoFi-Agent**（*Coarse-to-Fine Uncertainty-Triggered
   > Re-Analysis for Audio Reasoning*，同届 ARC 参赛系统，仅见于 EChO-Agent 的占位式 bib）。
   > R2 的新颖性主张不挂在该动作原语或其触发形态的存在性上。

### (b) 对 R2 "外部知识调度在语音域缺席"断言的影响 —— **净加固，但幅度有限且须带限定**

按 §3 的三条：加固方向成立（一个 156 队规模的建制化竞赛，Agent Track 的规则例举与
全部已描述获奖系统均无外部知识动作），但**证据覆盖 3/16、且载体 MMAR 的答案由音频决定**。

### (c) 红线关系

本篇不含可搬方法。三个 Agent Track 系统的**红线态全部 `UNSTATED`**（训练与否、作答权

### (d) 是否提供新载体/基线数字

- **MMAR（1000 题全集）不可作 R2 载体**（信息角色边界外），但**可作 R2 §5.4 回退梯的
  "感知侧能力体检"参照**：本核家族（Qwen3-Omni）在该基准上，单模型 SOTA Acc **74.00**、
  agentic SOTA Acc **77.40**。这是目前读集内**最新、最可信的 MMAR 头部读数**。
- **口径警告（必须随数字同行）**：ARC 的 MMAR 数字口径 = **完整 1000 题**；

- 无成本记账：本篇对参赛系统的算力/调用/时延**零报告**（40+ 工具的冠军系统与
  单前向的 Single Model 直接同榜比较，无任何等成本对照）。**这是 ARC 协议本身的一个
  缺陷，R2 §6.5 的九维记账相对它是净进步**，可在 R2 §4.4 或 §6.5 引作"语音域评测协议
  尚未把成本纳入报告面"的证据。
