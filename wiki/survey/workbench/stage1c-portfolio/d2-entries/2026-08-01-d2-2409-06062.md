## 2. 方法本质

RAC 把稀有命名实体的 ASR 错误纠正重构成 RAG：**不动识别器，只在文本假设上做检索增强重写**。
第 68 行给出四步管线（矩阵目前只记了三步，见 §6 格 4）：

> "our approach consists of four steps, as illustrated in Figure 1: Query Generation, Entity
> Retrieval, Context Construction and LLM Application."

核心洞见在第 54 行——检索的 key/query 编码必须捕获**声学**而非语义：

> "Importantly for correcting ASR errors, the encodings used as queries and database keys capture
> information about the likely acoustics of the corresponding text strings."

### 2.1 查询生成三策略（§II-A，第 73–79 行）

不用整句查库，而是从（可能带错的）假设里切出查询串，三条路各有代价：

- **All N-grams**（第 75 行）：假设里所有长度 ≤ `N_max` 的子词序列全部当查询。优点是
  "requires no separate model or set of rules"；缺点是 "it will over-generate, which may make the
  task of using the retrieved entities for correction more difficult"。`N_max=5`（第 136 行）。
- **Template Matching**（第 77 行）：手工整理的域启发正则抽实体区，例文 `/play (.*)/`。查询数少于
  All N-grams，但 "requires the manual creation of a set of regular expressions, and these regular
  expressions will inevitably miss some edge cases"。
- **NE Tagging**（第 79 行）：另训一个命名实体区域标注器。查询数同样少，且 "more likely to
  generalize to edge cases"，代价是 "requires the training and application of a separate tagging
  model, which introduces complexity and increases inference time"。该标注器实现为**另一组
  LoRA**：第 132 行 "we separately adapt the OpenLLaMA model using LoRA adapters with rank 16"。

**承重事实**：三策略中**最优臂是 Template Matching（纯手写正则、零训练）**，不是 n-gram、也不是
训练出来的 tagger——见 §5 与 §6 格 4 的复算。

### 2.2 向量库检索：BM25 / T5 / Acoustic Neighbor Embeddings 的对比与选型（§II-B、§V）

三种 key/query 生成法（第 84 行）：`Okapi BM25`（词法）、`T5 Semantic Embeddings`（语义）、
`Acoustic Neighbor Embeddings`（ANE，声学词嵌入，Jeon 2020 / arXiv:2007.10329，见 `main.bbl`
第 62–64 行）。ANE 的训练目标（第 130 行）是让**同一短语的声学/音素/正字法三路嵌入的欧氏距离最小**，
其副作用正是"发音相近的短语彼此靠近"；本篇用 **40 维**嵌入。ANE 可从**正字法**或**音素**两路生成，
两路都评。

选型结论（第 144 行）："using orthography or phoneme *Acoustic Neighbor Embeddings* achieves much
higher recall than either using *T5 Semantic Embeddings* or *Okapi BM25*. This is consistent with
the intuition that in this task we are interested in acoustic similarity rather than semantic
similarity."

最终**选正字法 ANE**（第 164 行）："using phonemes achieves less than 1% higher recall while having
the additional requirement of a G2P model or lexicon. Based on these results, we chose
orthography-based *Acoustic Neighbor Embeddings*"——即**不需要 G2P/发音词典也能拿到近似全部收益**。
同段还给出 top-k 的边际结论：top-1→top-5 recall 大涨，top-5→top-10 "less than 2% increase"。

### 2.3 上下文构造：一道确定性准入门（§II-C，第 88–90 行）

检索结果**不直接进上下文**，先过两道阈值再构 hint：

> "we use a two-step context generation process. We first filter the retrieved entities and then
> construct a *hint* for each of the remaining entities. To filter, we apply two thresholds,
> 1. $D_{max}$, as a Euclidean distance threshold for keeping the most relevant candidates and a
> count threshold, 2. $R_{max}$ to limit the overall candidate counts."

超参（第 136 行）：`D_max=1.0`（全实验固定）、`R_max∈{1,5}`。hint 格式两种（只含实体 / 实体+检索
用的查询串），LLM 输入 = hint 串 + ASR 假设，用 `[H]`/`[A]`/`[P]` 标签分隔（第 64 行图注）。
**这一步在结构上就是 R2 §1.6 双门里的"准入门"，且是固定阈值版**——矩阵目前漏记（见 §6 格 4）。

### 2.4 LoRA 适配 OpenLLaMA-7B（§IV-B、§V）

作答模型 = OpenLLaMA 7B（第 132 行；`main.bbl` 第 146–150 行，Geng & Liu 2023，LLaMA 家族开源复现）。
适配策略横扫 LoRA rank ∈ {4,8,16,32} 与全参微调，结论（第 167 行）：

> "We see that LoRA at all ranks and full fine-tuning achieve similar WERs. We also experimented
> with in-context learning (ICL), but this strategy resulted in large WER regressions. As rank 4
> LoRA requires the fewest task-specific parameters of the best performing strategies, we use it for
> the remainder of our experiments."

训练超参（第 138 行）：AdamW，`α=0.001`、`β1=0.9`、`β2=0.999`、`ε=1e-8`、`λ=0.001`；余弦调度 +
100 步线性 warmup；LoRA 2000 步 / 全参微调 4000 步；有效 batch 128；推理用 greedy、最大 1000 token。

## 3. 训练态与信息访问边界

### 3.1 何处训练、何处免训练（逐件点名）

| 组件 | 训练态 | 出处 |
|---|---|---|
| 纠错作答 LLM（OpenLLaMA-7B） | **训练**：LoRA rank 4，2000 步 | 第 132/136/138/167 行 |
| NE tagger（查询生成三策略之一） | **训练**：另一组 LoRA rank 16，同超参 | 第 132 行 |
| Acoustic Neighbor 编码器（声学/音素/正字法三路） | **训练**（外部既有方法，本篇复用，非任务特定） | 第 84/130 行 |
| Template Matching 查询生成 | **免训练**（手写正则） | 第 77 行 |
| All N-grams 查询生成 | **免训练**（"requires no separate model or set of rules"） | 第 75 行 |
| 上下文过滤（`D_max`/`R_max`） | **免训练**（固定常数阈值） | 第 88/136 行 |
| 识别器（in-house CTC E2E ASR + 两个词级外部 LM） | 既有系统，本篇不调 | 第 108 行 |

**唯一被试过的 training-free 作答路径是 ICL，且失败**：第 167 行 "We also experimented with
in-context learning (ICL), but this strategy resulted in large WER regressions."——**论文未给任何
数字**（无表、无百分比、无附录）。用法约束见 §6 格 6。

### 3.2 纯文本后处理、不接收音频输入（承重，三重证据）

**证据一（自述边界，Related Work，第 96 行——最强）**：

> "While our approach starts from a textual ASR hypothesis, both [zhang2023knowledge] and [ragdst]
> requre the input audio, which means they cannot be applied in scenarios where only the textual ASR
> hypothesis is available."

这是作者**主动把"不需要音频"当作卖点**来划界，不是外部推断。

**证据二（管线入口）**：第 40 行摘要 "database queries are generated from possibly errorful
**textual** ASR hypotheses"；第 54 行同句复述；第 68 行四步管线入口即 "the ASR hypothesis"。

**证据三（数据流闭合）**：第 108 行 "All datasets are decoded using an in-house Connectionist
Temporal Classification (CTC)-based end-to-end ASR system"——音频在进入本方法**之前**就已被外部
识别器消费掉；第 144 行的评测口径 "quantifying the discrepancy between the fine-tuned LLM output
and reference transcriptions" 也只涉及文本。全文无任何"重解码/重跑识别/回读音频"的动作。

**必须附带的限定：「不回音频」≠「无声学信息」**。第 54 行明说 key/query 编码"capture information
about the likely acoustics of the corresponding text strings"，即**声学相似度是从正字法重建的先验
期望发音**（AN-Ortho），全程不碰波形。R2 若用"只有重听才能拿到声学证据"作 delta 论证，会被这一格
直接反驳；正确表述是：**重听拿到的是该次发音的实际声学，ANE 拿到的是文本串的先验期望声学**——
这是本次深读对 R2 论证形状的最实质修正（详见 §6 格 3）。

### 3.3 与 R2 信息边界的关系

RAC 落在 R2 incumbent 分组合同的**第④组（retrieval-GER）**，且是该组信息边界最干净的锚：它既不
读模型内部状态（区别于 PRISM/WCTC 的白盒），也不要求识别器暴露 context-list 接口（区别于 Siskos），
只要求"拿得到一条文本假设"。**代价**是它把 R2 视为核心的第二信息通道（该次发音的实际声学）整个
放弃掉了——这正是 R2 delta 的支点，也是 RAC 自身能力天花板的成因（见 §5 局限 iii）。

   "primarily due to correction of non-music-related words"。**33–39% 的头条完全由自建合成集承载。**

8. **多候选反而变差（第 193 行 + Table IV）**：`R_max` 从 1 提到 5，All N-grams 恶化
   （head 4.68→4.83、torso 5.02→5.08、tail 4.97→5.02、STOP 4.27→4.31），Template/NE 几乎持平。
   作者的解释是能力性的、不是超参性的：

   > "The lack of significant improvement when using multiple matches suggests that the adapted LLM
   > lacks any intelligence that would help distinguish between acoustically similar entities, making
   > the best strategy to consider only the most acoustically similar entity for any particular query."

9. **hint 里带不带查询串几乎无差（Table V，`table:cc`，第 221–237 行）**：`R_max=1` 时
   4.68/5.02/4.97/4.27 vs 带查询 4.69/5.01/4.94/4.29；`R_max=5` 时 4.83/5.08/5.02/4.31 vs
   4.81/5.08/4.98/4.33。第 218 行结论："the model is able to easily infer the spans in the ASR
   hypothesis for which the retrieved entities are relevant."

## 5. DFS 四问

**方法**：在**不动识别器、不碰音频**的前提下，把稀有实体 ASR 错误纠正做成 RAG——从带错文本假设生成
查询（三策略），到 260 万条实体的向量库里用**声学近邻嵌入**检索（key 捕获文本串的期望发音而非语义），
用两道固定阈值（`D_max=1.0`、`R_max`）过滤后构造 hint 上下文，交给 **LoRA rank-4 适配过的
OpenLLaMA-7B** 重写转写。机制新意集中在"检索 key 必须是声学的"这一条，以及"用任务无关编码器 +
小 LoRA 替代任务特定架构"的简化（第 96 行与 KG-ECO 的对比自述）。

**局限**：
(i) **训练是承重前提，且其反面无量化**——纠错 LLM（LoRA-4）+ NE tagger（LoRA-16）+ ANE 三编码器；
唯一 training-free 作答变体 ICL 被试过并 "resulted in large WER regressions"（第 167 行），**但零
数字**，无法进任何定量比较。
(ii) **头条增益的载体全为自建自评**——head/torso/tail 由模板+实体表合成、内部神经 TTS 合音、内部 CTC
ASR 解码（第 106/108 行）；唯一公开集 STOP 上检索的边际贡献 ≈0（All N-grams 4.27→4.27），且作者自承
STOP 改善主要来自非音乐词。**33–39% 与 7.7% 不是同一类证据**，矩阵与提案不得并列引用。
(iii) **没有候选裁决能力，且这是能力天花板不是超参问题**——`R_max=5` 对 All N-grams 净负，作者归因于
"the adapted LLM lacks any intelligence that would help distinguish between acoustically similar
entities"（第 193 行）。纯文本核在"两个发音几乎相同的实体里选一个"这件事上**结构性缺信息**。
(iv) **对照臂结构缺一角**——有 `No correction` 与 `No hints` 两个参照（这点已优于多数近邻），但**没有
random-entity hint 臂**（对照 MementoGUI `tab:em_retrieval_ablation` 的 random 臂），因此"检索到的是
对的实体"与"上下文里有实体这件事本身"没有被分离。
(v) **零成本记账**——All N-grams 在 `N_max=5` 下每句产生 O(L×5) 条查询、全部打 2.6M 库，论文只定性说
"increasing computational overhead during inference"（第 193 行），无延迟/吞吐/查询次数任何数字。
(vi) **单域单语单识别器**——音乐实体、英文、一个内部 CTC ASR；`D_max=1.0` 是全实验固定的全局手工常数，
未随域/说话人/信噪比标定。
(vii) **无 oracle 上界**——Table II 的检索 recall（top-1 84.8%）与 Table IV 的最终 WER 之间的传导率
从未被量化（没有"直接给 gold 实体 hint"的上界臂），因此无法判断剩余误差里多少是检索失败、多少是纠错
失败。

**改进空间**：
- **`R_max>1` 的失败是一个现成的空位**：RAC 已经把"需要在声学近邻候选间裁决"的场景构造好了
  （2.6M 库、top-5 召回 91.6%、纠错器分不出），缺的只是裁决所需的信号通道。一个**能重听该次发音**的
  裁决者恰好在这个位置有 RAC 结构性拿不到的信息——这不是"再调一次 `R_max`"能补的。
- **固定阈值 → 可标定标量门**：`D_max=1.0` 是最朴素版准入门（全局常数、无置信度、无按样本自适应）。
  把它换成可标定标量 + 外显阈值是直接的、可测的升级路径。
- **补两条臂**：random-hint 反事实臂（分离"有实体上下文"与"有对的实体上下文"）+ oracle-hint 上界臂
  （量化检索→WER 传导率）。这两条 RAC 都没做，且做起来不贵。
- **ANE（2020）作为 key 的时代前提待重审**：Table II 的选型结论建立在 2020 年的声学词嵌入与 2020-2023
  代文本编码器之间，2025 代语音表征是否翻转该结论未知。

**对 R2 可借鉴**：
(a) **"声学 key 优于语义 key" 有干净的一手比较表**（Table II：AN-Ortho 84.8/91.6/92.8 vs T5
80.7/86.9/88.4 vs BM25 53.5/71.2/74.6，head 列）。R2 §2.3 发音库的 key 建模可直接引此作选型依据；
更实用的是 **AN-Ortho ≈ AN-Phoneme（差 <1%）**，即**不需要 G2P/发音词典**，且 ANE 只吃文本、
不读模型内部状态——**在 API-only 黑盒约束下可运行**，是 R2 少数几个"能照搬进黑盒"的 key 通道候选
（40 维，第 130 行）。
(b) **两参照臂协议（`No correction` / `No hints`）应照搬并加第三臂**。RAC 自身的数据证明这个分离是
决定性的：不做分离就会把 STOP 上 5.7% 的"纠错器自带增益"误记成"检索增益"。R2 §6.2 臂族应固化
`无纠错 / 有纠错无检索 / 有检索随机 / 有检索真值 / 完整系统` 五臂。
(c) **RAC 是 incumbent 第④组（retrieval-GER）的最强锚**，其信息边界（纯文本、不要求识别器接口、
不读内部状态）比 Siskos 更松，故是"最容易被指为已占据"的对手；R2 与它的差分必须落在**信息通道**
而非"是否检索"。
(d) **反面样本**：RAC 的 33–39% 头条建立在自建合成集上、公开集上检索边际收益≈0。R2 §5.3 载体风险与
§9 的"载体自建自评 COI"条款应把 RAC 列为**不得复制的报数形态**——R2 若在自建先导集上报同型头条，
面对的是同一记反驳。

### 6.1 R2 增量变量核验（三个 delta 逐个引证）

**delta ①「回音频重解析动作」——在 RAC 内 CONFIRMED 缺席，但在 RAC 的引文邻域内 NOT 缺席（承重警告）**

RAC 自身确认缺席：第 96 行 "our approach starts from a textual ASR hypothesis"；全文无重解码动作。

**但 RAC 自己点名了做这件事的先例**，同在第 96 行：

> "The approach described in [zhang2023knowledge] is also similar to ours, but rather than an
> employing a adapted LLM for error correction, **ASR is rerun with the generated context**, making
> it more computationally costly."

其中 `zhang2023knowledge` = M. Zhang, X. Qiao, Y. Zhao, C. Su, Y. Li, Y. Li, M. Zhu, M. Piao,
S. Peng, S. Tao et al., "Knowledge prompt for Whisper: An ASR entity correction approach with
knowledge base," in *2023 IEEE International Conference on Big Data*, IEEE, 2023（`main.bbl`
第 98–103 行）；同段并列的 `ragdst` = M. Wang, I. Shafran, H. Soltau, W. Han, Y. Cao, D. Yu,
L. El Shafey, "Retrieval augmented end-to-end spoken dialog models," in *ICASSP 2024*, IEEE, 2024,
pp. 12056–12060（`main.bbl` 第 105–109 行），RAC 说这两者 "requre the input audio"。

**处置（对 R2 独立性主张的直接约束）**：「检索到知识后回音频重跑识别」这一**动作本身**在 2023–2024
已有先例，且 RAC 是**明确知情、以计算成本为由主动回避**的。因此：
- R2 **不得**把"回音频重解析动作"作为独立的新增变量单独主张；
- R2 的独立性只能落在**合取**（training-free + API-only 黑盒 + 双源同尺度门控选择 + 冻结核裁决），
  这与 §8 现有的"组合格结论"一致，但**该结论的量词自限（"上表十篇+读集"）现在有了一个被本篇一手
  指认的域外缺口**；
- **K-NB 补扫清单必须新增两篇**：Zhang et al. IEEE BigData 2023（Knowledge prompt for Whisper）与
  Wang et al. ICASSP 2024（Retrieval augmented end-to-end spoken dialog models）。前者尤其承重——
  "retrieval → re-run ASR with context" 在结构上就是 R2 重解析动作的最近先例，只是它非 training-free
  且非黑盒（须重跑 Whisper）。在这两篇被 D2 核验前，R2 §8 关于重解析动作的任何"无先例"措辞都不成立。

**delta ②「training-free」——CONFIRMED 缺席，且带一条一手负结果（仅定性可用）**

作答侧必须训练：LoRA rank 4、2000 步（第 136/167 行）。**本篇唯一的 training-free 作答变体是 ICL，
被试过且失败**：第 167 行 "We also experimented with in-context learning (ICL), but this strategy
resulted in large WER regressions."

**用法约束**：这是继 RAG-Boost（自报 raw RAG 使 WER 13.83→32.98）之后**第二条"TF plug-in 在
retrieval-GER 上非平凡"的一手证据**，可与之并列引入 R2 §4.1/§6.1 的动机论证；但**论文零数字**
（无表、无百分比、无附录），**只能引作定性陈述，不得赋任何数值**，且须注明"论文未量化"。
同时它也是 R2 的**风险证据**而非只是动机证据：R2 的 training-free 路线在同类任务上有一次已知失败，
门一（能力预检电池）必须先证明冻结 omni 核在此配置下不重演 ICL 回退。

**delta ③「冻结核作答」——CONFIRMED 缺席，但须防一处口径误读**

作答者是 LoRA rank-4 适配过的 OpenLLaMA-7B；第 167 行 "As rank 4 LoRA requires the fewest
task-specific parameters of the best performing strategies, we use it for the remainder of our
experiments."

**口径警告（建议在 §8 矩阵下方加脚注）**：LoRA 在**权重意义**上确实冻结基座、只训低秩增量，因此
若按"基座权重是否被改"的口径读，RAC 会被误判为"冻结核"。R2 的"冻结核作答"口径是**零任务特定参数 /
API-only 即可运行**——RAC 需要一组任务特定 LoRA 参数（且第 167 行自述 ICL 无参数路径失败），按 R2
口径确认缺席。不写这条脚注，评审可用权重口径直接反驳该格。

### 6.2 2026 重审条款预置

按 §8 现有"2026 重审条款"体例（draft 第 674–677 行），本篇的**两条承重前提均带时代限定**，登记为
Stage-2A 复现先行的重审对象：

## 7. 深读后新增的、R2 应该知道的事实

1. **头条与公开集是两类证据，不可并列**：33–39% 全部来自自建合成集；唯一公开集 STOP 上，
   `All N-grams` 臂的检索边际收益**恰为零**（4.27 → 4.27，Table IV 两行同值），最优臂也只有
   4.27→4.18，且作者自承 STOP 改善"primarily due to correction of non-music-related words"
   （第 191 行）。**R2 §8 引用 RAC 战力时必须报 STOP 数而非头条数。**
2. **"best system" 身份是复算出来的，论文未点名**：唯一匹配 32.6/35.3/39.0/7.7 的是
   `R_max=1 / Template Matching`——即**手写正则 + 单候选**。这意味着 RAC 的最强配置里，查询生成是
   零训练规则，而它训出来的 NE tagger 并不在最优路径上。引用时不应把 RAC 描述成"全链学习系统"。
3. **RAC 内部已有一道固定阈值准入门**（`D_max=1.0` + `R_max`，第 88/136 行）——R2 §1.6/§4.4 的准入门
   在语音域**已有先例**，R2 的差分应落在"可标定标量 + 外显阈值 + 按样本自适应"，而非"是否有准入门"。
4. **"回音频重跑识别"在 RAC 的引文里已有两篇先例**（Zhang et al. BigData 2023 / Wang et al. ICASSP
   2024，见 §6.1），且 RAC 明确知情并以成本为由回避。**这两篇未进读集，是 §8 组合格结论量词之外被
   一手指认的缺口，须补扫。**
5. **ANE 是黑盒可运行的声学 key 通道**：只吃文本正字法、40 维、不需 G2P、不读模型内部状态
   （第 84/130/164 行）。这是本次深读对 R2 §2.3 最直接可用的工程输入——它给出一个**不需要重听也能
   拿到期望发音相似度**的便宜通道，因此既是 R2 可用的组件，**也是 R2 必须超过的基线**：R2 要证明
   "实际声学"比"期望声学"多带信息，就得在同一检索管线上把 ANE 当对照臂跑。
