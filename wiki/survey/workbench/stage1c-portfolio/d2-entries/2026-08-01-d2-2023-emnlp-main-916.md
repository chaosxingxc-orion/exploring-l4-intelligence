## 2. 方法本质（memory 构造式 + 检索/插值机制）

PRISM 把「推理期把词典喂给 ASR」重构为**在冻结模型的 beam-search 内部挂一个 trie 结构的
声学-语言双 key 记忆，并在每个解码步改写 token 分布**。摘要原句（p.14820）：

> "a list of rare entities is indexed in a memory by synthesizing speech for each entry, and
> then storing the internal acoustic and language model states obtained from the best possible
> alignment on the ASR model. The memory is organized as a trie which we harness to perform a
> stateful lookup during inference."

**（a）memory 构造**。给定推理期文本词表 D̃ = {ỹ₁,…,ỹₖ}，先用 TTS（Coqui 的 VITS，p.14824）
为每条合成音频，得到 D̃_T = {…,(x̃ᵢ, ỹᵢ),…}——作者自陈这是**首次把合成语音用于 contextual
biasing**（p.14820："To the best of our knowledge, we are the first to use synthetic speech for
contextual biasing"）。key 的取法**按架构分岔**：

- **Transducer**（§3.1, p.14822）:
  > "For Transducers, the internal representations to index are audio encoder M_S state h_t and
  > the text encoder M_L state g_u for each non-blank prediction y_u as they describe both the
  > acoustic state and contextual language model state for the predicted token."

  h_t/g_u 从**受约束的 beam-search 对齐**里取：对每条 x̃ᵢ「trace the lattice of the highest
  probability beam to find the best valid alignment Aᵢ」，输出词表被钉死为目标序列 + blank，
  并且「To further nudge the model to predict the character 't', we incrementally add extra
  probability to the constrained token over ∅」。作者明说这比在输出格上跑 Viterbi 给出更好的
  对齐（p.14823）。
- **encoder-decoder（Whisper）**（§3.1, p.14823）:
  > "We use teacher forcing to constrain the predicted output to the ground truth. For each
  > inference step the memory is the output d after the last cross-attention block in the decoder.
  > The value for the memory consists of the next token as per the ground truth."

value 一律是**下一个 token id**（字符/BPE 级），不是实体身份。整个 memory 组织为 **trie**，
而不是扁平 kNN datastore——这是与 kNN-LM（Khandelwal et al. 2019）谱系的关键结构分岔，动机是
避免子串误触：「a dictionary entry for "Intuit" could spurious matches to the "In" or "it"
tokens of this word」（p.14822）。

**（b）检索**。每个解码步 i，beam 上除常规 (y, d, s) 外额外携带**两个状态**：已匹配 trie 节点
N（其深度 δ 对应已匹配后缀 z_u）与**回退分数 s̄**。以解码态构造 query q_i，在 N 的**子节点集内**
取 K 近邻 NN(N,q_i)={(k_r,v_r)}（K=4，p.14824）；距离带阈值，且
> "We use thresholds on the distances and it is possible for the neighbor set to be empty."（p.14823）

Transducer 走**双索引**：附录 B（p.14831）"PRISM uses separate indexes for audio and text
embeddings. In the implementation, both indexes are queried separately with their respective
thresholds. The common values obtained from the indexes are combined to form a single output over
which KNN probabilities are computed."——即**声学索引与文本索引各自过阈值后取交集**。索引用
FAISS（Johnson et al. 2019）。

**（c）插值**（§3.2, p.14823，式 1–3）：

- 式 1：`P_knn(y|q_i, N) ∝ Σ_{(k_r,y)∈NN(N,q_i)} exp(−dist(q_i, k_r))`
- 式 2：`P̃(y|·) = (1−λ_i)·P(y|·) + λ_i·P_knn(y|·)`，**仅当 y ∈ N 时**；否则 `P̃(y|·) = P(y|·)`
- 式 3（动态系数）：`λ_i = 1 − min_{(k_r,v_r)∈NN(N,q_i)} dist(q_i, k_r)`
  > "This function has the effect of increasing KNN weight when there is a good match in the
  > dictionary."（p.14823）

**（d）词级准入不变量（本篇真原创点）**。beam 上维护 s̄「that tracks the model score of the
suffix if the current suffix z_u of y_u were not to match the trie」；若下一 token 不是 N 的子节点
则 **s ← s̄**（丢弃所有已累积的 knn 加分），若走到 trie 末端（整词匹配完成）则 **s̄ ← s**（落袋）。
动机是图 3 的反例：
> "when the actual word deviates from the dictionary word after a prefix match, the hypothesis
> still carries the extra probability and can lead to spurious recognition (e.g, twin becomes
> twen, if the dictionary has the word twente as shown in Figure 3)"（p.14823）

作者点明该特性 "is absent from all prior trie-based biasing techniques (Sun et al., 2021;
Le et al., 2021a; Sun et al., 2023b)"（p.14827）。**注意术语碰撞**：本篇里的 "Rescore at false
Trie exit" 指的就是这个**模型内部 beam 分数回退**，与 R2 语境下的「世界知识 rescore」毫无关系
（详见 §8）。

## 3. 训练态与信息访问边界

**训练态：零梯度更新，零可训参数。** 三处直证：

1. §1（p.14821）："PRISM can be used with any existing pretrained encoder-decoder or Transducer
   ASR model **without any retraining** and incurs close to no delays during inference."
2. §1（p.14820）："adapt to predefined dictionaries at test-time **with no additional training**"
3. §4 Models（p.14824，最干净的一句）："**We do not do any finetuning of the Whisper model, and
   only alter the beam-search decoder to incorporate PRISM.**"

对照：作者自己指出 TCPGen 与 Deep Contextual RNN-T "both require a joint training of biasing
modules with the ASR models"（p.14824–14825）。**建库过程本身也无梯度**——它是一次
受约束的前向 beam-search / teacher-forcing 解码。故 training-free 判定**无保留成立**。

代价转嫁到**手工超参**：音频匹配阈值 0.4、文本匹配阈值 0.05、K=4；Whisper 走**未归一化**嵌入
距离，阈值 base=250 / small=1000（p.14824）。作者强调阈值的跨集稳定性——"Note that the same
threshold is used across all datasets spanning 9 different dictionary lists"（p.14824）——但同一
模型族的两个规模（base/250 vs small/1000）阈值就差 4 倍，**跨骨干不可移植**这一点是自证的。

**信息访问边界：白盒读 + 白盒写，两层侵入。** 精确清单：

| 架构 | 必须**读取**的内部状态 | 必须**写入/改写**的部件 |
|---|---|---|
| Transducer (RNN-T) | ① 音频编码器 M_S 的逐帧隐状态 **h_t**；② 文本编码器 M_L 的前缀隐状态 **g_u**（附录 A：两者各经独立投影层降到 **256 维**）；③ 联合网络后的 token 分布 P(y\|g_u,h_t) | ① 每步 token 分布（式 2 插值）；② beam 结构本体（额外携带 trie 节点 N 与回退分数 s̄）；③ 解码算法本体——PRISM 是对 ALSD（Saon et al. 2020）的扩展，附录 B 算法 2 第 13–15 行为新增 |
| encoder-decoder (Whisper) | **最后一个 cross-attention block 之后的 decoder 输出 d**（§3.1）；建库时叠加 teacher forcing 通道 | 同上；beam width=10（p.14824） |

即：R2 §8 现行措辞「白盒（encoder/decoder 隐状态）」**只覆盖了读的一半**。PRISM 还要求
**改写 beam-search 算法**（token 分布 + beam 状态 + 解码循环）。在 API-only 冻结 omni 核上，
这两项**都**不可得——即便某个 API 未来开放 hidden-state 读出，只要不开放解码循环，PRISM
仍不可运行。此为 R2 信息边界主张的**加强项**，不是削弱项。

**规模口径**（附录 A, p.14831 与 §4, p.14824）：Transducer 56M 参数，训练于 56K 小时私有
标注语音，声学编码器为 **6 层双向 LSTM**（hidden 640）、文本编码器为单层单向 768 维 LSTM，
联合网络为逐元素积 + tanh，输出 45 个英文字符 + blank；输入 240 维 log-Mel + delta/double-delta，
20ms 段。Whisper-base 74M / Whisper-small 244M。**内部矛盾一处**：§1/§2.1 反复以「streaming、
低时延」为动机（"Transducers … popular when low latency and streaming are important"，p.14821），
但其自建 Transducer 的声学编码器是**双向** LSTM，结构上不可流式。

## 5. DFS 四问

**方法**：用 TTS 为词典每条目造声学证据，把冻结 ASR 在该证据上的**内部对齐状态**（Transducer
的 h_t+g_u、encoder-decoder 的末层 cross-attention 后 decoder 态）作为 key、下一 token 作为
value，组织成 **trie**；解码时在 trie 当前节点的子节点内做 kNN，用距离软最大得 P_knn，与模型
分布做**动态系数线性插值**（λ 由最近邻距离决定），并用**回退分数 s̄ 强制「只有整词匹配才落袋」**。
全程零梯度、零新增参数，代价是白盒读隐状态 + 改写 beam-search。

**局限**（按对 R2 的杀伤力排序）：
(i) **双层白盒**——不仅读隐状态，还要改解码循环；API-only 下彻底不可运行（§3）。
(ii) **手工阈值是效果的承重件且不可移植**——0.4/0.05/250/1000，同族两个规模阈值差 4 倍；
     Table 6 显示去掉动态 λ 后 Location(Big) 从 29.0/45.1 退到 36.4/63.5，说明系数设计本身高敏。
(iii) **E-WER 与 WER 可以反向且无联合目标**——Table 6 的 Audio-only 行是自家论文里的反例。
(iv) **TTS 发音正确性是单点故障，作者自认**（§6 Limitations, p.14828）：
     > "For many rare words, TTS might not provide the correct pronunciation which can lead to
     > mismatches with the actual words during inference. In ASR settings involving **accented
     > speech and low-resource languages**, this difference can be further exacerbated due to the
     > lack of robust TTS engines."
(v) **骨干规模与时代**——56M/74M/244M，对手是 TCPGen(2021)/Deep Contextual RNN-T(2021)/
     Peng et al.(2023)；且自建 Transducer 用双向 LSTM，与其 streaming 动机自相矛盾。
(vi) **企业集样本极小且不公开**——Category-4 仅 20 条；WER 125.0/116.7 > 100 说明插入错误主导，
     该量级下的「减半」不构成稳健效应量。
(vii) **主力公开载体是全合成**——entity-rich 基准的实体与句子均为 VITS 生成，与真实语音差距未测。
(viii) **缺两条对照臂**：① 没有与 shallow fusion / 外部 LM rescoring 的直接头对头（虽然 §2 用它
     作动机）；② 没有「保留 trie 词级约束但关掉 kNN 插值（λ=0）」的臂，故**无法分离「检索带来的
     信息」与「trie 词级硬约束带来的搜索空间收紧」**两份贡献。
(ix) **Table 1 是跨论文拼接**（TCPGen 侧数字转引），非同一复现下的对照。

**改进空间**：
(1) **key 的来源从内部状态外置**——PRISM 从未尝试用外部冻结编码器产 key；其 Audio-only 消融
    恰恰给出了外置路线的**必要伴生条件**：纯声学 key 必须配一个语言/世界侧的裁决器，否则
    E-WER 涨而 WER 崩。
(2) **λ 从「距离的线性函数」换成「信息价值/决策改变概率」**——现行 λ 只回答「匹配得像不像」，
    从不回答「插值会不会改变最终答案」。这是 reward-guided 估计量的空位。
(3) **补 in-context dictionary 基线**——Peng et al.(2023) 只在企业集上、只对 Whisper 出现了一次，
    却在 Category-1 赢了 PRISM；缺一条随词典规模扫描的 in-context 对照曲线。
(4) **口音/发音变体 key 族**——作者自己把它列为未解限制（§6）。
(5) **E-WER/WER 帕累托报告**替代单指标头条。

**对 R2 可借鉴**（四条，按可移植性排序）：
(a) **Table 6 Audio-only 消融 = R2「冻结声学 key 必须配世界知识裁决」的一手他域反面证据。**
    这是本篇给 R2 最有价值的东西，且是**正面机制论证**而不只是 prior-difference：R2 §2.3 的
    两段式（声学 key 检回候选 → 世界知识 rescore 裁定）在本篇里被证明**缺第二段就会幻觉**
    （E-WER 43.9 更好 / WER 53.3 崩坏，作者归因 "lack of language model context"）。
    建议 R2 §2.3 引此表做**必要性论证**，不要只在 §8 当 prior 引。
(b) **词级 trie + 回退分数 = 可移植的准入门不变量**：「部分证据不得累积奖励，整词匹配才落袋」。
    R2 的准入门可以直接继承这条不变量（把「整词」推广为「整实体/整证据单元」），且作者已声明
    该特性为其相对全部先前 trie-biasing 工作的原创点。
(c) **距离阈值 → 空邻居集 = 现成的 naive gate 对照臂**。PRISM 的固定阈值虽是手工的，但它就是
    「不触发」的最简实现，且带 9 个词典的跨集稳定性声明。R2 §5.1「触发以不触发为正确」那一行
    应把它列为 naive gate 基线，用来证明学习/奖励驱动的门比固定阈值门更好。
(d) **载体与成本记账形状**：entity-rich 基准已公开（四档 1000/2818/4348/2874）+ 图 4 的
    distractor 0→3000 扫描 = 现成的「词典规模轴」协议，R2 的 K-PS 可照搬轴设计；
    Table 7（内存）+ O((c+p)BUT)（复杂度）+ RTF 图 三件套是可直接复用的预算报告模板。
    **但必须声明其为全合成 TTS 语音**（见 §6 第 5 格）。

## 7. 2026 重审条款预置

R2 §8 已挂「2026 重审条款」，本节把它对本篇**具体化为可执行的重验项**。PRISM 的下列前提是
**时代绑定**的：

**T1. 「模型无法在上下文原生消费词典，须把 key 打进内部状态」——本篇内部即已只条件成立。**
作者自己引入了反例并给出边界条件（§4.2, p.14826）：
> "Whisper supports the use of prompts with the decoder state to bias the predictions towards the
> dictionary entries during decoding. Note that this method is **applicable in settings where the
> number of contextual entities is small**, as the decoder state is prompted on these entities."

而 Table 3 Category-1（6 个关键词）上 **Peng et al. 19.2/13.1 胜过 PRISM 26.0/15.8**。
即：2023 年该前提的真正约束是**词典规模**，不是模型能力。**2026 冻结 omni 核（30B 级、10⁵ token
上下文）上必须重验**：(a) 以 prompt 注入实体清单的 in-context baseline，在 k = 6 / 30 / 1000 /
2818 四档（可直接对齐 PRISM 的四档词典）测 WER 与 E-WER，找**交叉点**；(b) 该 in-context
baseline 必须进 R2 §8 incumbent 分组作为**真对手**（v15 已列组②——本条建议已被采纳），
不得当 strawman。若交叉点在 R2 目标词典规模之上，PRISM 谱系的原初动机在 2026 已失效，
R2 的立论必须从「模型消费不了词典」改为「词典规模/干扰项密度超出上下文有效工作区」。

**T2. 「效果空间存在」这一隐含前提随基线变强而蒸发。** Table 5 显示增益与 headroom 强相关：
Drugs（基线 E-WER 93.5）大幅改善，Person Names（基线 E-WER 19.0）WER 只从 24.7 到 24.3。
2026 冻结 omni 核在同类实体上的基线 E-WER 大概率远低于 93.5。**重验项**：在动手前先测
2026 核在目标实体族上的基线 E-WER，若已进入 Person Names 量级（≈20），本谱系可达增益上限
须重新估算，K-PS 的效应量预注册必须据此重设。

**T3. 「E-WER 是可单独优化的目标」被自家 Table 6 证伪。** Audio-only 索引 E-WER 更好
（43.9 vs 45.1）而 WER 崩坏（53.3 vs 29.0）。**2026 版重验**：在冻结 omni 核上，「实体正确率」
与「下游答案质量」是否同样可以反向？R2 必须**预注册双指标（实体面 + 全局/下游面）与帕累托
报告**，禁止只报实体面增益。这条不是 2026 才成立——它在 2023 就成立且被作者写在表注里，
只是 R2 必须把它从「他人的消融」升级为「自己的验收合同」。

**T4. 「TTS 是逐实体声学证据的可行来源」在罕见词/口音上作者自认脆弱**（§6 Limitations）。
2026 的零样本/多说话人 TTS 显著更强，故**脆弱程度须重测**；同时这条正是 R2「口音变体族」的
来源合法性所在——**重验项**：口音变体 key 究竟是提升召回还是只增加干扰项，须以 K-PS 三臂
（无变体 / 单一标准音 / 变体族）在同预算下分离。

**T5. 「白盒可得」——非能力问题而是部署问题，无需重验，须固定为参照上界。**
R2 §8 incumbent 分组③（v15 六组编号）已把 PRISM 列为「retraining-free 白盒——参照上界、非同边界对手」，
本件确认该定位准确：PRISM 的不可运行性来自 API 契约而非模型能力，因此 2026 不会「自动解锁」。
R2 的正确用法是**同预算下报 PRISM 式白盒上界与黑盒实现的差距**，并把该差距作为公开代价申报。

**T6. 阈值可跨集移植（"the same threshold is used across all datasets spanning 9 different
dictionary lists"）在跨编码器时已自证失效**（base 250 vs small 1000）。R2 若声称门参数稳定，
须在**至少两个不同冻结编码器**上验证同一参数，否则继承本篇同样的可移植性缺陷。

**T7. 对照面全部为 2021–2023 方法**（TCPGen 2021、Deep Contextual RNN-T 2021、Peng et al. 2023），
骨干 56M–244M。按 agent-era recency 纪律，本篇的**数字**只能用于机制论证与协议借鉴，
**不得**作为 2026 效果基线；R2 §8 引用本篇的所有数字应随行标注该限制。

## 8. R2 增量变量核验（四项 delta 在本篇是否确实缺席）

| delta 变量 | 缺席判定 | 逐项引证 |
|---|---|---|
| **API-only 黑盒 key** | **确实缺席（结构性不可能）** | key 按定义就是内部状态：摘要 "storing the **internal** acoustic and language model states"（p.14820）；§3.1 "the **internal representations** to index are audio encoder M_S state h_t and the text encoder M_L state g_u"（p.14822）；encoder-decoder "the memory is the output **d after the last cross-attention block in the decoder**"（p.14823）。全篇**零次**提及外部/独立编码器产 key，也**零次**讨论无隐状态访问时的退化方案。故这不是「作者没做」，而是「该方法的 key 定义与黑盒互斥」。**delta 成立，且是四项中最硬的一项。** |
| **世界知识 rescore** | **确实缺席（且须防术语碰撞）** | 候选排序**纯由嵌入距离**决定：式 1 `P_knn ∝ exp(−dist)`，式 3 `λ_i = 1 − min dist`。全篇无任何外部知识源、无 LLM 参与、无「该候选在世界中是否真实存在/语境是否相符」的判断。**术语碰撞警告**：本篇 Table 6 有一行叫 "− Rescore at false Trie exit"，且 §3.2/图 3 反复用 "rescoring"——那**只是 beam 内部把分数回退到 s̄**，是模型自身分数的复原，与世界知识无关。R2 在 §8 引用时**必须显式区分**，否则易被质疑为「PRISM 已有 rescore」。**正面证据**：Table 6 的 Audio-only 行（E-WER 改善 / WER 崩坏，作者归因 "lack of language model context"）恰好说明**缺一个语言/世界侧裁决器**是纯声学检索的固有失效模式——这既证明 delta 缺席，又证明该 delta 是**必要的**而非装饰性的。 |
| **口音/个性化族** | **确实缺席，且被作者列为未解限制** | 每条词典项只合成**一份**音频（§3.1 "we use a TTS engine to create audio for the corresponding phrases"，p.14822）；entity-rich 基准里唯一的说话人处理是"different speakers for the dictionary entities and the test utterances"（p.14826）——那是**避免说话人泄漏的实验卫生**，不是变体族。全篇无口音变体、无 G2P 多发音、无 N-best 音素假设、无个性化/说话人自适应轴。§6 Limitations 明写这是弱点："In ASR settings involving **accented speech** and low-resource languages, this difference can be further exacerbated"（p.14828）。**delta 成立，且作者自己指了门。** |
| **门控动作空间** | **在「动作空间/策略/奖励」意义上确实缺席；但 R2 措辞须改述** | 缺席证据：单一信息源（就一个词典），无源选择；无「查/不查」的显式动作，插值在**每个解码步**都尝试；无策略、无奖励、无学习到的门；唯一的「不触发」是被动的——"We use thresholds on the distances and it is possible for the neighbor set to be empty"（p.14823）；以及 trie 失配时的硬回退。**须改述的理由**：PRISM **确有**两个手工门——(i) 固定距离阈值（0.4/0.05/250/1000）、(ii) 动态 λ_i 软门（式 3），且后者被 Table 6 证明承重（去掉退 29.0/45.1→36.4/63.5）。因此 R2 **不能**写成「PRISM 无门控」或「R2 首次门控检索」，只能写成「**奖励驱动的、动作级的、跨源的**门控动作空间」——门的**存在**不是 delta，门的**形态与驱动信号**才是。此项与既有的 MementoGUI/NAP「训练态门先例」记账同构：独立性挂在合取上，不挂在「有没有门」上。 |

**合取结论**：四项 delta 全部缺席，其中前三项为「结构性缺席」（本方法定义上做不到或作者自认
未解），第四项为「形态性缺席」（有原始形态、缺 R2 主张的形态）。R2 §8 的
「十篇无一同时满足 API-only + training-free + 双源动作 + 世界知识 rescore」在本篇上
**逐项核实成立**——PRISM 满足 training-free，**不**满足 API-only、**不**满足双源动作、
**不**满足世界知识 rescore。

### 深读后新增的、R2 应该知道的事实

1. **Table 6 Audio-only 行应从 §8（prior-difference）提升到 §2.3（机制必要性）**：这是他域一手
   证据，证明「冻结声学 key 单独使用会把实体指标做好而把全局指标做坏」，正是 R2 两段式设计的
   反面论证。当前 R2 只把 PRISM 当 prior 引，浪费了这条正面弹药。
2. **Table 3 Category-1 的 in-context prompting 胜出（19.2/13.1 vs 26.0/15.8）必须进 R2 的
   incumbent 分组**。本件撰写时 R2 §8 尚无「in-context 词典注入」组，而这恰恰是
   2026 冻结 omni 核上最自然、最便宜、审稿人最先想到的对手。**建议新增该组：
   in-context dictionary injection（Peng et al. 2023 谱系；2026 版=直接把实体清单写进
   prompt）**——v15 已采纳为六组编号中的组②（词典规模扫描含 crossover 读数），
   并按词典规模扫描出交叉点。不补这一组，R2 的「2026 重审条款」就没有落地的实验载体。
3. **信息边界比 R2 现行措辞更严**：PRISM 需要的不止隐状态读出，还有 beam-search 改写权
   （§3 表）。这使 R2「API-only 下不可运行」的论断对**未来可能开放 logits/hidden state 的 API**
   仍然成立——是加强项，应写进 §8 第 3 格。
4. **PRISM 的公开 entity-rich 基准是全合成语音**（实体与句子均由 VITS 生成，p.14826）。
