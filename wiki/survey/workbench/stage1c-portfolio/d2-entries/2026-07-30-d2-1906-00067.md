## 1. 数据集本质

OK-VQA（Outside Knowledge VQA）是**第一个把"图像内容不足以回答"作为纳入条件**的自然图像 VQA 基准：
14,055 问 / 14,031 图（COCO 图像，沿用 80k-40k 官方 train/val 划分作 train/test），答案为**开放式短答**
（平均 1.3 词），每问 **5 份**人工答案标注。它相对前作 FVQA/KB-VQA 的关键位移是**不从固定知识库出发
造题**——论文明说 FVQA 是"从固定 KB 里挑一条三元组（如 dog is mammal）再标问题"，因此只测"把给定 KB
接进 VQA 的能力"；OK-VQA 则要求方法"从 web、数据库或**任何未被用于造题的知识源**"检索事实，且论文
断言"三元组不足以表达一般知识"。全部问题另被 5 名标注者归入 **10 类知识 + Other**（取众数，故类别互斥）。
配套提出的知识基线 **ArticleNet** 是一条完全**确定性、无端到端检索训练**的管线：问题非停用词 ∪
（ImageNet 物体分类器 + Places2 场景分类器 + COCO 物体检测器的 top 分类标签）→ 枚举**所有单词与所有
两词组合**作 query → Wikipedia search API 取每 query top-1 文章（每问约 **100 篇**）→ 用三级确定性
规则（唯一 query 词数 → query 词总数含重复 → 句在文中的顺序）抽每篇 **T=5** 句。

## 2. 定位：任务构造法、知识必要性保证、判定协议，与 Omni-DeepSearch-640 对照

### 2.1 构造漏斗（§3，逐数字取自正文）

1. **第一轮**：MTurk 工人看图写问题，提示语要求"骗过一个 smart robot"、须与图像内容相关、
   **须需要一些外部知识**，并**明确禁止**问"图里有什么"和"有几个"。
2. **第二轮**：另 5 名工人各标一个答案。
3. **人工知识过滤**：从 **86,700** 问池人工筛到 **34,921** 问（"manually filtered to get only questions
   requiring knowledge"）。
4. **答案分布去偏**：train/test 各自"若某答案作为最高频答案出现 **超过 5 次** 则删该问"，使答案分布趋近
   均匀；论文明说这**同时**降低偏置**并抬高难度**（算法见到同一答案的次数被限，外部信息更重要）。
5. **一致性过滤**：删除**标注者间零一致**的问题。
6. 终局：**9,009 train + 5,046 test = 14,055**。

### 2.2 知识必要性靠什么保证——判定：**人工判断 + 负向证据，无对抗模型过滤**

- **正向保证只有人的判断**：第 1 步的提示语约束 + 第 3 步的人工筛选。论文**没有**为任何一题标注
  "所需的那条外部事实是什么"，也**没有**用任何模型把"不需要外部知识就能答对"的题剔掉。
  → 不存在实例级的"外部知识确实必要"的机器可验证证据。
- **负向证据有三条，且相当扎实**：(a) SOTA VQA 模型崩塌——MUTAN 26.41 / BAN 25.17，对照 VQAv2 2018 年
  最佳开放式 **72.41**（§5）；(b) **Q-Only 14.93** 远低于含图基线，说明去偏有效、题目确实视觉接地；
  (c) 视觉特征消融（Table 3）ResNet152 26.41 → ResNet50 24.74 → ResNet18 23.64 → Q-Only 14.93，
  即**换更强视觉特征几乎不涨**、但去掉图像暴跌——论文由此推断瓶颈"在检索相关知识与所需推理"，不在感知。
- **论文自承的一条收窄，R2 必须知道**：§5 原句"**the major portion of our dataset requires knowledge
  outside Wikipedia such as commonsense or visual knowledge**"。即 OK-VQA 的多数题目**并非
  Wikipedia 可检索**的 factoid；把 OK-VQA 读作"可检索外部知识必要性"的基座会**过度**，它保证的是
  "**图像之外**的知识必要"，不是"**可检索的外部文档**必要"。这两件事在 R2 的 T1/T2 分型下不是一回事。

### 2.3 判定协议

标准 VQA accuracy（Antol et al. 2015 的软投票式指标），但因 OK-VQA 每问只有 **5** 份答案（VQAv2 为 10），
论文**把每份标注用两次**以套用原公式；并对答案做 **Porter stemming** 以合并单复数/词形变化（沿用 FVQA
做法）。无 MC 协议、无 abstain、无出处/引用判定。另设两条 **oracle 行**（Table 2）：`MUTAN/AN oracle`
与 `BAN/AN oracle` = 取 ArticleNet 与 VQA 模型两者中**对着 gold 更好的那个答案**——即 pre-2024 就已有
"gold 指导的组合上界"报告行。

### 2.4 与 R2 主载体 Omni-DeepSearch-640 对照：谁的"必须外部知识"保证更强

| 维度 | OK-VQA (2019) | Omni-DeepSearch-640（R2 §5.1 转述） | 判 |
|---|---|---|---|
| 剔除"不需外部信息即可答"的机制 | **纯人工**（提示语 + 86,700→34,921 人工筛） | **四道 GPT-5 过滤**（纯问题推理过滤、first-hop 实体泄漏过滤、视觉必要性过滤等）+ 人工唯一性复核 | **Omni-DeepSearch-640 更强**：过滤器是强模型，"过滤模型答得出的题被删"这一保证的强度随过滤模型能力上升 |
| 结构性必要性约束 | 无 | Wikipedia 知识图谱路径 **k≥5**；一个非根节点绑近期新闻以抗参数捷径 | **Omni-DeepSearch-640 更强**（OK-VQA 无任何跳数/图结构约束） |
| 答案分布去偏 | **有**（最高频答案 >5 次即删该问）+ 删零一致题 | R2 未记载任何答案分布去偏 | **OK-VQA 更强**（且这是 R2 载体的一个未登记缺口） |
| 单模态捷径地板值实测 | **有**：Q-Only 14.93、视觉特征三档消融（Table 3） | R2 §5.1 明记"**无 no-tool 直读行**"（须自行补） | **OK-VQA 更强**（R2 已把补该行列为贡献，方向正确） |
| 语料快照纪律 | **部分有**：文章*选取*走 live Wikipedia search API，但原文*抽取*用 DrQA (`chen2017reading`) 的检索模型"**to achieve a consistent snapshot**"（附录 B.1 原句） | R2 §5.1/§5.2 明记"**无冻结检索快照（结果随时间漂移）**" | **OK-VQA 更强**——一个 2019 基线的语料快照意识强于 R2 2026 主载体 |
| 规模与统计分辨率 | 14,055 问（test 5,046） | 640 题、15 细类每类约 43 题、温度 0 单样本 | **OK-VQA 强得多** |
| 知识类型标注 | **全量** 5 标注者众数归入 10 类 + Other | 15 类（检索目标×音频内容两维），R2 未记标注者数/一致性 | 大致相当，OK-VQA 的一致性程序更明确 |
| 负类（"该学会不搜"） | **无**（按构造全部需知识） | **无**（R2 已如实声明"按构造不存在"） | 并列缺口 |

**综合判定**：在"**剔除无需外部知识者**"这一条主轴上，**Omni-DeepSearch-640 的保证更强**（GPT-5 级
对抗过滤 + k≥5 图路径 + 抗参数捷径的新闻绑定 vs 纯人工判断）。但在 **答案分布去偏、单模态地板值、
语料快照、统计分辨率** 四条上 **OK-VQA 明显更强**，且这四条中有三条正是 R2 §5.1 自列的阻断项。
→ 对 R2 有用的结论不是"我们更强"，而是：**这四条 2019 年就已存在的构造纪律是 R2 主载体的现存缺口**，
其中"最高频答案 >5 次即删"与"语料快照"两条是 R2 报告里目前完全没有对应物的。

## 4. DFS 四问

**① 方法是什么？** 数据集侧：COCO 图 + 两轮众包 + 人工知识筛 + 答案均匀化去偏 + 零一致剔除，得
14,055 问 5 答，全量标 10 类知识。方法侧：ArticleNet——一条**完全确定性、免训练检索**的
"视觉分类器标签 ∪ 问题内容词 → 枚举 1/2-gram query → Wikipedia top-1 文章 → 规则抽 5 句"管线，
其句/词打分头才是唯一被训练的部分（预测答案是否/在何处出现）。

**② 局限是什么？** (a) 知识必要性**无机器可验证保证**、无实例级 gold 证据标注；(b) 论文自承多数题需
Wikipedia **之外**的常识/视觉知识 → 它不是"可检索文档必要性"的干净基座；(c) ArticleNet 单独只 5.28、
组合增益 +1.43、oracle 上界仅 +0.63，说明其检索路径太弱，测不出"更好的知识组织能带来多少"；
(d) 只有 5 份答案（VQAv2 有 10），论文靠"每份用两次"套指标，是一个未讨论方差影响的将就；
(e) 单一 train/test 划分、无 dev，无负类（"不需要检索"的题按构造不存在）。

**③ 改进空间在哪？** 论文自己指路："oracle 数字表明**更聪明的知识检索方法**能拿到更强性能"，且
ArticleNet 提供的信息与 VQA 模型是**互补的**（oracle > 两者各自）。缺口清单是现成的：实例级 gold 证据
标注、更强检索器、Wikipedia 之外的常识源、以及"检索质量→任务效用"的显式链路度量（论文只给 Recall@K
曲线与最终 accuracy，两者之间没有接起来）。

**④ 可借鉴什么？**（对 R2 最实质）**(a) 答案分布均匀化去偏是一条低成本、强效果的构造纪律**——
"最高频答案出现 >5 次即删该问"配 Q-Only 地板值实测（14.93）形成闭环：去偏做了、也**量出来**了。
R2 主载体两项皆缺。**(b) 语料快照意识**：文章选取用 live API 但原文抽取绑 DrQA 固定 dump
"to achieve a consistent snapshot"——R2 §5.1 把"无冻结快照"列为 Omni-DeepSearch-640 的阻断项，
这里有一个 2019 年的最低可行做法可引。**(c) query 构造的确定性配方**（详见 §5 新增事实第 3 条）。
**(d) "换更强感知主干几乎不涨、去掉感知暴跌"的三档消融**，是把"瓶颈不在感知、在知识"论证成立的
最小实验设计——R2 §6.1 要分离"映射损失 vs 使用损失"时，这个形状可直接移植成"换更强 ASR/音频编码器
几乎不涨 vs 去掉音频暴跌"。

   R2 的研究对象是 **T1（value 在开放 web/文本）**，OK-VQA 只有一部分落在这型上——引用时
   必须带这句收窄，否则基座与对象错位。
2. **两条 2019 年就有、R2 主载体没有的构造纪律**：**答案分布均匀化**（最高频答案 >5 次即删该问）+
   **零一致剔除**；以及 **Q-Only 地板值实测 14.93**（R2 §5.1 明记 Omni-DeepSearch-640 缺 no-tool
   直读行）。前者是 R2 报告里完全没有对应物的一条，建议在 §5.1/§5.2 的缺口清单里补记。
3. **query 构造的确定性配方可直接移植到 R2 §2.4。** R2 判定 T1 型下"key 空间归搜索引擎所有，
   key 侧的杠杆只剩 query 构造"。OK-VQA 的 ArticleNet 给了最早的具体配方：**问题非停用词 ∪
   {ImageNet 物体分类 top-k, Places2 场景分类 top-k, COCO 检测器 top-k} → 枚举全部单词与全部
   两词组合作 query → 每 query 取 top-1 文章（每问约 100 篇）→ 三级确定性规则抽 T=5 句**。
   语音域的同构映射是现成的：**ASR 内容词 ∪ {emotion2vec 情感标签, AST 声音事件标签, 音乐属性标签}
   → 同样枚举 1/2-gram**。这是一条 pre-2024 的**跨域借鉴设计**（按 memory 中 owner 的方向判据，
   属"(b) 型跨域借鉴"），且完全在 R2 的红线内（无新训练、确定性规则、冻结现成分类器）。
4. **语料快照的最低可行做法**：文章*选取*可以走 live API，但**原文抽取绑定固定 dump**即可获得
   "consistent snapshot"（附录 B.1 原句）。R2 若无法冻结整条检索链，这是一个可引的降级方案。
5. **oracle 行不是 2024 后的新习惯**：Table 2 的 `MUTAN/AN oracle` / `BAN/AN oracle` = 对 gold 取
   两模型中更优者。R2 §4 的 M7"oracle/headroom 报告行"矩阵里把它记作只有 Omni-DeepSearch 实体分解
   一处；实际 OK-VQA 2019 就有，且其数字给了警示：**oracle 上界只比最佳组合高 +0.63**——
   oracle 行也可能是**紧的**，紧的 oracle 意味着该杠杆已近饱和，不能一律当"headroom 很大"读。
6. **"更强感知几乎不涨"的三档消融**（26.41/24.74/23.64 vs Q-Only 14.93）是把"瓶颈在知识不在感知"
   坐实的最小设计，可移植为 R2 §6.1 分离映射损失/使用损失的一个补充臂。
7. **指标口径的一个小陷阱**：OK-VQA 只有 5 份答案却套用 VQAv2 的 10 答案软投票公式（做法是每份用
   两次），且答案做了 Porter stemming。任何跨数据集比较 OK-VQA 与 VQAv2 绝对分数的说法都须带这个口径注。
