## 1. 方法本质

Speech-Hands 把「omni 模型该不该采信外部音频系统的假设」**从隐式融合重构为一次显式的、
可读出的反思决策**，并把这个决策做成解码序列的第一个 token。

**决策原语**：给定音频 $A$、可选问题 $Q$、模型自产假设 $H_\text{omni}$、外部模型假设
$H_\text{ext}$，agent **先**从 $\{\texttt{<internal>}, \texttt{<external>}, \texttt{<rewrite>}\}$
中发射一个动作 token，**再**在该动作条件下生成最终输出（§3.1 任务表述；§3.5「Agentic
Inference via Action Tokens」：*"The model performs a two-stage decoding process: it first emits
an action token … and then generates the final output accordingly."*）。原语的语义正是摘要
所称的那一件事：*"knowing when to trust itself versus when to consult external audio
perception."*（Abstract）。

**注意这是三元不是二元**：`<rewrite>` 是第三个、结构上不同的动作——它既不信自己也不信外部，
而是在音频+两路证据上**重新生成**（GER）。三元中前两个是**选择**，第三个是**合成**，因此
该系统的上界并非候选集 oracle（AMI 上 15.03 低于其两个源的 19.77/16.88 即由 `<rewrite>`
贡献）。R2 若把它简化为「二选一门」会读错机制。

**agentic action 机制的接口形状**：不是外挂控制器、不是 logits 后处理，而是**扩词表**——
「We extend its tokenizer to include three special action tokens」（§5.1 Training Details）。
动作因此与内容共享同一自回归解码路径与同一 loss。

**如何训练该反思原语（按源，逐条）**：
- **监督信号=oracle 标签，由 ground truth 反推**。ASR 侧（§3.2）：对每条样本分别求
  $T_\text{int}$/$T_\text{ext}$/$T_\text{ger}$ 与 $T_\text{gt}$ 的 WER，谁最低标谁；且显式
  写入「若 $T_\text{int}$ 与 $T_\text{gt}$ 相同（WER=0）或 WER 最低则标 `<internal>`，
  *this is to encourage the model to trust itself when it can successfully solve the problem*」。
  Audio QA 侧（§3.3）：$c_\text{int}=c^*$ → `<internal>`；$c_\text{int}$ 错而 $c_\text{ext}=c^*$
  → `<external>`；两者皆错 → `<rewrite>`。
- **标签稳定化**：因外部预测随机（*"External predictions can be stochastic … makes the decision
  boundary between `<external>` and `<rewrite>` inherently less robust"*，§3.3），改为**对外部
  模型采样 5 次取多数**决定 `<external>` 还是 `<rewrite>`。这一步就是 Table 4
  (`tab:audioqa_results`) 里 `+ majority sampling` 行的来源。
- **训练目标=纯 SFT，无 RL**。§3.4：训练串为「决策 token + 最终目标串」拼接，
  *"we optimize a single cross-entropy loss over the concatenated target sequence, which jointly
  supervises the action token and the subsequent prediction"*。§5.1：Qwen2.5-Omni、5 epochs、
  fp16、batch 64、lr 1e-4 cosine decay、greedy decoding。**全文没有为 Speech-Hands 本身使用
  任何 RL/偏好优化**；GRPO 只作为对照基线出现（Table 4 的 `+ GRPO with official training
  data` 与 `+ GRPO with external audio data` 两行）。任务书中「SFT/RL 细节」的正确回答是：
  **SFT-only；RL 仅在基线侧**。
- **附录扩展的工具动作**：附录 C 把动作空间扩为再加 `<tool:bnr>`（NVIDIA BNR 降噪微服务）与
  `<tool:studio>`（NVIDIA Studio Voice / Maxine，48 kHz 生成式上采样）。但正文明说
  *"leaving the tool calling action in future work"*（§1），附录只给触发逻辑的**散文描述**
  （「when the internal audio embedding suggests high background entropy or when the initial
  decode contains disfluency markers」），**未给该触发器的训练方式、标签构造或消融**。

## 2. 训练态与信息访问边界（承重）

**trained / learnable 确认 —— CONFIRMED，四条互相独立的证据**：

1. 摘要自称：*"This **learnable** reflection primitive proves effective…"*（Abstract）；
   *"we introduce Speech-Hands, a **learnable** framework that instantiates self-reflection as a
   core control primitive."*（§1）。
2. **改核参数**：§5.1「All experiments are conducted using the Qwen2.5-Omni model. We extend its
   tokenizer to include three special action tokens … Models are trained using the standard
   supervised fine-tuning (SFT) objective with a cross-entropy loss.」——扩词表 + SFT，
   **决策原语存在于权重里**。件内**未声明 LoRA/PEFT**，措辞为 standard SFT（lr 1e-4）。
3. **监督数据规模**：Table 8 (`subset`) 每集 20,000 条（GigaSpeech 仅 9,389 条通过过滤）；
   Table 9 (`tab:audioqa_stats`) audio QA 三子集训练 0.7K/1.0K/6.4K。
4. **训练必须消耗 gold**：动作标签由 $T_\text{gt}$ / $c^*$ 反推（§3.2/§3.3）。这条对 R2 是
   **信息边界事实而非风格差异**：Speech-Hands 的门在**训练集**上使用了答案；R2 的门在任何
   阶段都不得触碰部署时不存在的信息。两者的可用信息集合不同，任何效果比较必须带这一声明。

**「外部」的确切外延 —— 仅为音频感知工具/候选，不含外部世界知识（CONFIRMED，证据四条）**：

1. **形式定义就是「另一个模型的成品答案」**：§3.1 *"the agent first generates its own response
   $H_\text{omni}$, and then combined with an external response $H_\text{ext}$ **provided by an
   external model**."* ——不是检索结果，不是文档，不是知识库条目。
2. **实例枚举全是感知系统**：§5.2「External ASR models」= Whisper-v2-large / Canary-1B-v2 /
   Parakeet-TDT-0.6B-v3，明说 *"These systems operate in a closed transcription setting and
   provide non-generative references."*；「External audio QA model」= Audio Flamingo 3
   （*"a speech-language model with audio frontend capabilities"*）。**无检索器、无向量库、
   无 web、无实体词典**。
3. **prompt 模板把外部限定为假设/候选**：ASR 模板（§3.4）三路输入是「(1) 原始音频；(2) 另一
   ASR 系统的五条转写假设（external）；(3) 你自己的首遍转写（internal）」；AudioQA 模板
   （附录 B）是「(2) 另一模型生成的一个答案候选」。
4. **附录工具动作仍在感知侧**：`<tool:bnr>` / `<tool:studio>` 是 DSP 降噪与带宽重建，作者自
   名为 *"Active Perception"*，即「clean its ears before transcription」（附录 C）；这是**改善
   自身听觉输入**，不是引入世界知识。

**反向证据（作者自己划清界线）**：§2.1 相关工作评论既有 voice retrieval 路线时说
*"even in these agentic frameworks, retrieval is often treated as an auxiliary enhancer, rather
than as a distinct source of information."* ——他们把「检索作为独立信息源」列为**未解决问题**
而非自己的做法。故「其外部仅音频感知」在件内是**作者自陈的范围**，不是我的推断。

**信息访问边界的完整刻画（R2 矩阵应写入的那一格）**：白盒权重级（扩词表+SFT 改核参数）；
**原始音频始终在上下文**（与纯文本 GER 相反，附录图 `fig:extension` 即以此对比）；外部为
**单一**外部系统的成品假设（Limitations 明记 *"our current system only accepts a single
external prediction"*）；无检索语料；训练标签消耗 gold。

## 3. 关键数字（LaTeX 源核对）

**头条数字必须先做两处口径更正——这是本次深读最重要的两条数字发现。**

1. **「OpenASR 12.1% WER」不是 WER 值，是相对降幅，且全文只在摘要出现、正文从不推导。**
   摘要原句：*"Across the OpenASR leaderboard, Speech-Hands consistently outperforms strong
   baselines **by 12.1% WER** on seven benchmarks."* 正文 §5.1 与 Table 3 (`tab:wer_results`)
   给出的是**绝对平均 WER**，最低为 5.69。**复算推定**：三组配对的相对 WER 降幅
   whisper (7.17→6.67) = 6.97%、canary (7.22→6.17) = 14.54%、parakeet (6.68→5.69) = 14.82%，
   **三者均值 = 12.11% ≈ 12.1%**——即头条是「对各自外部 ASR 的相对降幅的算术平均」。
   该推导**件内没有任何一处写出**，引用时必须标为复算推定。
2. **「77.37%」是任务平均准确率，不是「决策准确率」。** Table 4 (`tab:audioqa_results`) 中
   `Speech-Hands ⇌ (parallel agentic) + majority sampling` 行：Bio-acoustic **81.25** /
   Soundscape **59.4** / Complex QA **85.7** / avg. Acc. **77.37**。摘要把它写成
   *"77.37% accuracy and high F1 on audio QA decisions"*，**把答案准确率与动作 token 的决策
   质量并置在同一句里**；后者的实测证据在 Table 5 (`tab:special_token_f1`，只有 ASR 设定)
   与三张混淆矩阵图（`fig:cm-all`）。**R2 引用时不得称 77.37% 为决策准确率。**

**ASR 主表 Table 3 (`tab:wer_results`)，avg. WER（%），↓**：
- 外部/基线：Whisper-v2-large 7.17、Canary-1b-v2 7.22、Parakeet-tdt-0.6b-v3 6.68；
  Qwen2.5-Omni（内部核）7.33、Phi-4-MM **6.14**、Gemini-2-Flash 8.56、GPT-4o-voice 15.76。
- 级联 GER 基线（Qwen2.5-Omni）：⇒Whisper 8.44、⇒canary 8.74、⇒parakeet 8.33——**三者全部
  劣于两个源**。
- Speech-Hands（并行 agentic）：⇌whisper-v2 **6.67**、⇌canary **6.17**、⇌parakeet **5.69**。

**由主表推出的三条件内未讨论的事实（承重）**：
- **(a) §5.1 断言(1)「Speech-Hands outperforms all baselines」在平均列上只对 parakeet 配置成立。**
  SH⇌whisper 6.67 与 SH⇌canary 6.17 **均劣于 Phi-4-MM 的 6.14**；SH⇌whisper 6.67 与
  parakeet 基线 6.68 实为持平（0.01）。
- **(b) 增益随外部候选质量走，而非随门的存在走**：相对各自外部 −0.50 / −1.05 / −0.99；
  相对内部核 Qwen2.5-Omni（7.33）−0.66 / −1.16 / −1.64。门是**分配器**，其收益上界被候选集
  决定。
- **(c) 21 个「数据集 × 配置」格里有 2 个负格，全部集中在 whisper 配置**：GigaSpeech
  SH⇌whisper **12.37**，而其两个源分别是 Qwen2.5-Omni 11.26 与 whisper 11.45——**门控系统
  劣于它自己的两个候选源**；Tedlium SH⇌whisper 4.45 劣于外部 whisper 4.32。canary 与
  parakeet 两配置的全部 14 格均优于各自 min(内部, 外部)。**注意 whisper 恰是 prompt 模板里
  写明「五条假设」的配置，而正文 §3.2 描述外部时用单数 $T_\text{ext}$——外部候选基数在正文
  未逐配置固定**，这削弱了对负格成因的归因能力。

**决策读出质量 Table 5 (`tab:special_token_f1`，仅 Action Tokens + Whisper 配置)**：
- 标签分布极度倾斜：训练集 `<internal>` 占 67.95%(AMI) – 98.96%(Libri-clean/other)；
  `<external>` 0.96% – 31.01%；`<rewrite>` 0.1% – 2.34%。测试分布同型。

- 作者结论：*"precision consistently exceeds recall, indicating that when the model does emit

- **本次深读新增的同址观察**：`<internal>` F1 最低列 = Tedlium (0.67)，`<rewrite>` 非零 F1

## 4. DFS 四问

**方法**：在一个 omni 核上，把「信自身 / 咨询外部音频感知 / 自行重写」做成扩词表后的三个
动作 token，用 gold 反推的 oracle 标签做 SFT，使动作与内容共享同一自回归解码与同一交叉熵
loss；推理期两段解码——先出动作、再在动作条件下出答案，从而把仲裁从隐式融合变成**可读出、
可评分（F1/混淆矩阵）的显式决策**，并在 ASR 与 audio QA 两族任务上用同一原语。

**局限**（逐条带出处）：
- (i) **不是 training-free**：扩词表 + standard SFT（§5.1），标签消耗 gold（§3.2/§3.3）。
- (ii) **反思决策的三种失败形态**，件内可证：
  **①稀有动作坍塌**——`<rewrite>` F1 在 Libri-clean/other 为 **0.0**、GigaSpeech 0.08，
  precision>recall 即系统性**欠触发**（Table 5、§6.1）；
  **②源势均力敌时判别力最低**——§6.2 解释 Soundscape 上 `<internal>/<external>` 混淆升高的
  理由是「两个源本身表现接近（Qwen 56.32 vs Flamingo 57.31），导致 `<external>` 集合远小」。
  **门在最需要它的地方（两源接近）信噪比最差**，这是可移植的机制律；
  **③被外部误导仍是最强破坏源**——§6.3 三类失败模式中 *"External-induced Misguidance … This
  is the most damaging failure mode"*，附录 A.1 给出 internal 正确（"insane"）却被 Whisper
  5-best 噪声牵走的整句幻觉案例。
- (iii) **端到端负格**：见 §3 (c)，whisper 配置在 GigaSpeech 上劣于自己的两个源。
- (iv) **无迁移与多源实验**：Limitations 明记未研究「换一个外部 ASR 测试」，且**只接受单一
  外部预测**。→ 训练出来的门与**具体外部提供方**耦合，可移植性未测。
- (v) **工具门未被隔离**：附录 C 缺「无条件施加 DSP」臂（同上）。
- (vi) **决策质量与最佳性能来自不同配置**：Table 5 的 F1 只报 whisper 配置，而最佳 WER 出自
  parakeet 配置——**门的读出质量在最优配置上没有测量**。
- (vii) 聚合口径不可复算（Table 4 avg. 列，见 §3）；头条 12.1% 无件内推导。

**改进空间**：
- 缺失的三臂对照是现成空位：固定候选集，比较「总是信内部 / 总是信外部 / 门控」，并报**oracle
  余量捕获率**（本文只给了 5% oracle 与端到端值，没有把二者接成一个读数）。
- `<rewrite>` 的欠触发在本文被归为数据稀疏，但更可能是**目标错配**：标签问的是「哪一路
  WER 最低」，而不是「重写会不会改变答案」。把门控信号从「谁更好」换成「这次介入会不会改变
  最终答案」即 value-of-information 形状，本文完全没有触碰。
- 「势均力敌时判别力最差」提示门应当接受**弃权/双出**，本文的三元动作空间无弃权项。

**可借鉴 / 须规避（对 R2 触发电池设计）**：
- **可借鉴 (a)——prompt 基线为何不够，这里有两张现成的、方向一致的表**：Table 1 证明
  「换 prompt 措辞（强调内部/外部/音频/平衡）× 换输入格式」七种实测组合（表内一格为空）**无一恢复到基线**
  （8.44–9.05 vs 7.17/7.33）；Table 2 证明零样本仲裁**跟着 prompt 措辞走而不是跟着真值走**
  （internal-biased 下 oracle=external 仍 0.71 判 internal）。R2 的触发电池必须包含这两个
  臂——**prompt 措辞扫描**与**oracle-vs-预测混淆矩阵**——否则无法回应「你的门是不是只是
  prompt 敏感性的另一种包装」。
- **可借鉴 (b)——决策层要有独立读数**：本文把动作 token 的 P/R/F1 与混淆矩阵与端到端指标
  并列上报（Table 5、`fig:cm-all`）。R2 的外显标量门天然更容易做到这一点（阈值可扫），
  应当直接采用「决策层 F1 + 端到端指标」双读数的上报形状。
- **可借鉴 (c)——标签/信号的稳定化协议**：对随机的外部源采样 5 次取多数（§3.3），把
  `<external>`/`<rewrite>` 的边界稳住，Table 4 上换来 75.75→77.37。R2 的触发信号若依赖
  采样式估计量，同一稳定化步骤可直接移植，并且**必须报告它贡献了多少**（本文报了）。
- **须规避 (a)——单臂工具实验**：附录 C 的形状（只有「有门」与「没门」）**不能**用来支持
  「门有用」，因为缺「无条件施加」臂。R2 触发电池的每个动作都必须自带 always-on 臂。
- **须规避 (b)——把决策质量与最佳配置分离上报**：R2 必须在**同一配置**上同时报门的读出质量
  与端到端效果。
- **须规避 (c)——单一外部提供方**：R2 若只用一个重听/知识源，就会复制本文 Limitations 里
  自认的迁移盲区；触发电池应至少含两个异质外部源，并报告门在换源后的稳定性。
- **须规避 (d)——用 gold 反推阈值**：本文的标签合法（训练集内），但 R2 的**外显阈值标定
  不得以任何形式使用部署时不存在的信息**；本篇是「合法使用 gold 训练」与「非法使用 gold
  标定」之间最容易被混淆的一条边界，须在 R2 红线节点名引用。

## 6. 2026 重审条款预置

本篇为 **2026 同期工作**（v2 2026-05-18，ACL 2026 oral），不适用「2023 时代前提是否仍成立」
那一类重审。按任务书指定，重审焦点是：**其 trained 反思与 R2 training-free 外显门的效果差距
是否可归因于训练本身。** 预置条款如下（在 Stage-2A 复现先行阶段执行，结论回填本条目）：

**RC-SH-1（可归因性的前置条件）**：只有在**候选集、外部提供方、载体、成本口径四项全部对齐**
时，二者的差值才允许被讨论。本文的候选集是「omni 首遍 + 单一外部 ASR/AF3」，R2 若引入知识源
就已改变候选集——此时差值**不可归因于训练**，只能作为不同问题的并列报告。

**RC-SH-2（把差距分解到可归因的读数上）**：主读数不用端到端指标之差，而用**oracle 余量捕获率**
$\rho = (\text{基线}-\text{系统})/(\text{基线}-\text{oracle})$。本文侧已有全部输入：oracle 5%
WER（`fig:2:wer` 标题）、基线 6.68（parakeet）、系统 5.69 → $\rho \approx 59\%$（复算推定）。
R2 在同一候选集上算同一 $\rho$。**若 R2 的 $\rho$ 显著低于 59% 而候选集与载体已对齐，则差距
可归因于训练；若 $\rho$ 接近而端到端有差，差距归因于候选集质量而非门。**

**RC-SH-3（把「训练」拆成两个可分离的因子）**：本文的训练同时提供了 ①**判别力**（学出哪路更
可信）与 ②**输出成形**（`<rewrite>` 的合成能力）。二者对效果的贡献必须分开：把 R2 的
training-free 门接在**同一个 `<rewrite>` 生成器**上（或双方都禁用 rewrite，只留二选一），
再比较。**未做这一拆分前，任何「训练带来 X 点」的说法都不成立**——因为本文最优格（AMI
15.03 优于其两源）恰恰来自因子 ②，与门的判别力无关。

**RC-SH-4（对称的失败面检查）**：重审须同时检验 R2 的门是否复现本文的三种失败形态——稀有
动作坍塌、势均力敌时判别力塌陷（Soundscape 型）、被强噪声外部候选牵走。**外显标量门在第二种
上有结构性优势（阈值可扫、可弃权），这一点应作为独立主张单独取证，而不是混入总效果差。**

**RC-SH-5（迁移面，本文的公开盲区）**：本文自认未测「换外部提供方」。重审必须报告 R2 的门在
换源后的稳定性，并在本条目回填；**若 R2 亦不测，则不得以「trained 门与提供方耦合」作为独立性
论据**（那将是用对方未测的项做己方优势）。

**RC-SH-6（复现可得性）**：代码与项目页公开（comment 字段 GitHub 链接；正文脚注项目页）。
本篇因此是少数**可实际复现的 trained 对照**——重审时若仍只做纸面对比，须在治理节声明理由。

## 7. R2 增量变量核验（两个 delta 逐个引证）

**Delta 1 —— training-free 外显标量门：确实缺席，但缺席的形态需要被准确记账。**

- **缺席（门是训练出来的）**：§5.1「We extend its tokenizer to include three special action
  tokens … trained using the standard supervised fine-tuning (SFT) objective」；§3.4 决策 token
  与内容共用一条交叉熵。**没有任何 training-free 变体被作为方法提出。**
- **缺席（门不是标量，也没有外显阈值）**：决策是**离散 token 的解码结果**（§3.5 两段解码），
  件内**从未出现**可标定的连续信号、阈值参数、阈值扫描或工作点选择；唯一的连续读数是**事后**
  的 P/R/F1（Table 5），不是**驱动**决策的量。R2 的「可标定标量 + 外显阈值」在本篇**结构上
  不存在**。
- **但必须写进 prior-difference 记账的一条**：本文**确实测过一种 training-free 门并证伪之**
  ——零样本 prompt 仲裁。Table 1 八种 prompt×格式组合平均 WER 8.44–9.05，全部劣于基线
  7.17/7.33；Table 2 显示决策跟随措辞而非真值（*"highly sensitive to prompt wording rather
  than the ground truth correctness"*）；§5.1 断言(2) 进一步总结 *"This underscores the
  importance of explicit control via action tokens rather than relying solely on natural-language
  prompts."* **被证伪的对象是「让模型用自然语言自己裁决」，不是「在模型之外计算一个标定过的
  标量再阈值化」。** 这两者的差别恰恰是「有没有可读出、可标定的量」——而本文自己的证据
  （零样本决策无校准、只跟措辞走）**正是 R2 把信号外置并标定的动机**。故：Delta 1 成立，
  但 R2 的表述必须收窄为「**外算可标定标量 + 外显阈值**」，并**主动引用本文的负结果作为
  设计动机**；同时接受它抬高的门槛——R2 必须至少显著优于零样本 prompt 仲裁，才谈得上与
  trained 门比较。

**Delta 2 —— 外部源含世界知识：确实缺席，证据密度高且含作者自陈。**

- **定义层**：§3.1 外部 = *"an external response $H_\text{ext}$ provided by an external model"*。
- **实例层**：§5.2 外部 ASR = Whisper-v2-large / Canary-1B-v2 / Parakeet-TDT-0.6B-v3
  （*"operate in a closed transcription setting and provide non-generative references"*）；
  外部 audio QA = Audio Flamingo 3。全部是**音频感知/推理模型**。
- **接口层**：ASR prompt 模板三路输入只有「音频 / 另一 ASR 的五条假设 / 自己的首遍」（§3.4）；
  AudioQA 模板只有「音频 / 另一模型的一个答案候选 / 自己的预测」（附录 B）。**没有第四路**。
- **扩展层**：附录 C 的两个工具是 DSP 降噪与带宽重建，作者归类为 *"Active Perception"*
  （「clean its ears」）——**仍在感知侧**。
- **作者自陈层（最强的一条）**：§2.1 *"even in these agentic frameworks, retrieval is often
  treated as an auxiliary enhancer, rather than as a distinct source of information. When the
  retrieved content diverges from the internal prediction of the model, current systems lack
  principled mechanisms for arbitration."* ——作者把「检索内容作为独立信息源并被仲裁」列为
  **他人未解决的问题**，而非自己的做法。
- **须同时声明的边界**：Bio-acoustic 子集是**知识密集**的（31 种海洋哺乳类的物种分类与事实
  检索，附录 D.1），且 §1 把 omni 模型的能力面写为含 *"knowledge-heavy question answering"*。
  但那部分知识来自**参数内部或 AF3 内部**，**不是外部世界知识源**。R2 的 delta 因此应精确写
  为「**外部源含可检索的世界知识载体**」，而不是「涉及世界知识」——后者会被本篇的
  Bio-acoustic 子集正面反驳。

**结论**：两个 delta 均**确实缺席**；Delta 1 的表述须收窄为「外算可标定标量 + 外显阈值」并
主动引用本文的 prompt 负结果，Delta 2 的表述须收窄为「外部源为**可检索的世界知识载体**」。
未做这两处收窄前，第 670 行的 delta 单元格在敌意审读下**可被证伪**。

### 深读后新增的、R2 应该知道的事实

1. **「势均力敌时门最弱」是可移植的机制律**（§6.2 对 Soundscape 的解释）：两个源基础表现接近
   时，稀有类样本变少、混淆升高。R2 的重听/知识双源在很多样本上正是势均力敌——**触发电池
   必须专门取一个「两源接近」分桶单独报读数**，而不是只报总体。
2. **门的读出质量与端到端负格同址**（Tedlium `<internal>` F1 0.67 最低 + Tedlium 负格；
   GigaSpeech `<rewrite>` F1 0.08 + GigaSpeech 双负格）。这条件内未提，但它给 R2 一个便宜的
   **早期预警指标**：决策层 F1 塌陷的桶就是端到端会翻车的桶。
3. **级联 GER 三行（8.44/8.74/8.33）全部劣于其两个源**——「把候选无条件喂进强模型」在**音频域
   的独立数据点**，与视觉域 MementoGUI Table 4 的「无条件检索是净负」同型。R2 §4.1「无条件
   检索是默认失效模式」可再加一条音频域引用。
