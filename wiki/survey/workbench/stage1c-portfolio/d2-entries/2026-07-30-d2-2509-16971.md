## §1 方法本质

AGR 的两条自陈创新：**(i) 范式转换**——把音频深度推理**整体转成文本理解任务**，用一个
ALLM 把原始音频 $A$ 一次性转成粗粒度文本文档 $D_0 = \mathcal F_{\text{caption}}(A)$，
从此**感知与认知解耦**（感知归 ALLM，认知归 LLM 代理），"优雅地绕开"音频推理训练数据的缺乏；
**(ii) 主动迭代文档精化环（Proactive Iterative Document Refinement Loop）**——四个专职
agent 在环内把 $D_0$ 逐步富化成"演进的证据链"：

- **Planning Agent**：$(s, H_{i+1}) = \mathcal F_{\text{plan}}(Q, L, D_i, H_i)$，
  $Q$=问题、$L$=选项列表、$D_i$=当前文档、$H_i$=分析历史；输出
  **$s \in \{\text{Sufficient},\ \text{Insufficient}\}$ 的二元状态 flag**；
  若 Insufficient 则把"信息缺口分析"写进 $H_{i+1}$。
- **Interaction Agent**：$P = \mathcal F_{\text{interact}}(D_i, H_{i+1})$，产出结构化增强
  计划 $P$，**从三个工具动作中选一**：*audio question-answering* / *guided re-captioning*
  / *automatic speech recognition*。
- **Augmentation Agent**：$E_{\text{new}} = \mathcal F_{\text{Aug}}(P)$，
  $D_{i+1} = D_i \oplus E_{\text{new}}$（$\oplus$ 的具体实现**论文未定义**——拼接还是
  LLM 改写重组，未写）。
- **Answering Agent**：环终止（$s=$ Sufficient 或达最大迭代数）后
  $(A^{*}, S_c, R) = \mathcal F_{\text{answer}}(D_f, Q, L)$ —— 答案 + **置信度 $S_c$** +
  文字理由 $R$。图 2（`sup/network.pdf`）的示例输出逐字为
  `Answer: On a plane, Confidence: 0.9, Reason: The sound....`

实现：ALLM = **MiDashengLM-7B**，LLM = **GPT-4o-2024-08-06**（同时充当 planning /
interaction / answering 三个 agent），转录工具 = **Whisper-Turbo**，
**最大迭代数 = 3**。

**最关键的一处结构读数**：**唯一的标量（$S_c$）由链条末端的 Answering Agent 产出，
而触发再分析的是链条开端 Planning Agent 的二元 flag。$S_c$ 不回流、不参与任何决策。**
即本篇**有置信度输出但没有置信度控制**。

## §2 六字段方法卡（对齐 R2 §2.1 格式）

| 字段 | 内容 |
|---|---|
| **组织** | **无外部知识组织。**核心状态是**单实例、单回合的演进式文本证据文档** $D_i$（$D_0$=ALLM caption，之后 $D_{i+1}=D_i\oplus E_{\text{new}}$）+ **分析历史** $H_i$（累积的信息缺口分析）。跨题即弃：无语料库、无 chunk/schema、无索引、无快照、无版本、无跨实例记忆。**无出处 schema**——$\oplus$ 之后无法区分某句证据来自 $D_0$ 的 caption、audio-QA、re-caption 还是 ASR（论文未定义 $\oplus$，也未给任何证据 ID/来源标记约定；对比 NAP 的 Full Evidence ID 前缀，本篇**倒退一步**）。无冲突标记、无来源质量分级、无 abstain 支持。$H_i$ 是本篇唯一的"结构化中间产物记忆"，但只记缺口分析、不记证据出处。 |
| **供给** | **LLM 自由生成的二元充分性判定 + 硬迭代上限，无任何标量价值估计。** 触发：Planning Agent（GPT-4o）每轮输出 $s\in\{$Sufficient, Insufficient$\}$——**二元 flag，非标量、无阈值、无标定、无 dev 选型**。动作选择：Insufficient 时由 Interaction Agent（同一个 GPT-4o）**自由 prompt 生成**增强计划，从 audio-QA / guided re-captioning / ASR 三者中挑一——**论文对"凭什么挑这个工具"零描述、零判据、零消融**。停止：$s=$ Sufficient **或**达到 max iterations = 3。**无预算分维**（无 core calls / search calls / audio seconds 的分维余额）、**无 per-action 价值比较**（三个动作之间没有任何可比的量）、**无外部知识动作**（三个动作全部作用在同一段原始音频上）。 |
| **使用** | **无准入门，零使用机制。** $E_{\text{new}}$ **无条件** $\oplus$ 进 $D$；无冲突处理、无来源质量、无归因、无 abstain、无"这次动作是否改变了答案"的度量。唯一的"使用"侧机制是**评测期的 GPT-4o-2024-08-06 答案格式后处理**（把自由文本映射到选项列表），论文以 raw / post-processed 双列报告——**这是评测规范化，不是证据使用机制**。$S_c$（置信度）与 $R$（理由）是输出元数据，**不被任何下游消费**。 |
| **changed vs held-constant** | **changed：零参数。**全 training-free（红线 1、红线 2 **合规**）；被改变的只有编排结构与 prompt。**held-constant**：MiDashengLM-7B（ALLM）/ GPT-4o-2024-08-06（LLM）/ Whisper-Turbo 全为已发布冻结检查点，无微调、无蒸馏、无奖励模型。**红线 3：硬违反。**最终答案 $A^{*}$ 由 **GPT-4o（Answering Agent）**发出；冻结 ALLM 只做感知（captioning / audio-QA / re-captioning）。**且本篇的消融自己把这一违反量化了**：只换作答 LLM（GPT-3.5-turbo → GPT-4o）在 MMAR 上 **49.72 → 58.85（+9.13）**、MMAU 上 **67.30 → 72.60（+5.30）**，而换 ALLM 只造成小波动（MMAR 55.80 / 56.35 / 58.85）；正文自陈 *"the LLM serves as the planning, interaction, and answering agent, its reasoning capability is a **decisive factor** in the final performance"*。**即增益的主要归因在文本 LLM，不在音频侧**——与 R2 §1.4 对 AudioRAG 的批评（"+9.2pt 无法归因到外部知识还是多了一个模型"）是**同一缺陷、同一量级，且本篇自己给出了证据**。 |
| **runtime-visible vs gold-only** | **runtime-visible 且进控制**：Planning Agent 的二元 $s$（LLM 自由生成的**离散标签**，不可标定、不可作阈值输入）、迭代计数 $i$（硬上限 3）、分析历史 $H_i$。**runtime-visible 但不进控制（关键）**：Answering Agent 的置信度 $S_c$、理由 $R$——**本篇唯一的部署可见标量被浪费掉了**。**gold-only**：MMAU/MMAR 正确性（仅离线评测）。**一处口径耦合风险须记录**：评测期的答案格式后处理用的是**与推理期同一个模型同一版本**（GPT-4o-2024-08-06）；论文把它作为公平措施，但它使"作答者"与"答案规范化者"同源。可验证的后果：AGR 的 raw 与 post-processed 两列**完全相同**（58.85/58.85、72.60/72.60，即 AGR 输出本就规范、后处理对它零增益），而对基线增益巨大（Audio-Reasoner MMAR **26.30 → 40.55，+14.25**；MMAU **35.80 → 62.60，+26.80**）。**该后处理对基线的贴补远大于对 AGR 的贴补，方向上不利于 AGR，因此不构成夸大；但引用任何一列时必须标明口径。** |

   MMAR **+1.44**。→ **"加一个更强的感知工具"不保证更好**，这是感知轴上的
   "更多≠更好"的一条直接证据，可与 R2 §4.1 的 M6（"更相关≠更好"）并列引用。

### §3.4 loop 的净贡献 —— **含一条论文未指出的自证负结果（本次深读最高价值发现）**

**(A) 干净的 loop 消融（唯一一对同 ALLM、同 LLM、同为无 Whisper）**：
AF3+GPT-4o 无 Whisper，**w/ loop 69.40 / 55.36 vs w/o loop 68.90 / 44.09**
→ **MMAU 仅 +0.50、MMAR +11.27**。
**这是唯一不混入 ASR 收益的 loop 净贡献读数：MMAU 上 loop 近乎无效（+0.50），
MMAR 上才显著（+11.27）。**

**(B) 不干净的对照（w/ loop 带 Whisper-Turbo vs w/o loop 无 Whisper，把 ASR 收益记进了
loop 头上）**：MiDashengLM +9.20 / **+16.97**；AF3 +5.20 / +11.71；
Qwen2.5-Omni-3B +3.94 / +10.94。**论文用的是这一组（"the removal of our iterative
document refinement loop causes a consistent performance drop"），因此其对 loop 的
效果归因偏高**——正确读数应取 (A)。

**(C) 论文未指出的自证负结果：符号桥接（audio → text → LLM）单独为负。**
把 *w/o loop* 行（= caption 一次 + GPT-4o 作答，无迭代、无 ASR）与**同一 ALLM 的直答
基线**对比：

| ALLM | w/o loop（桥接单遍） | ALLM 直答（raw / post） | MMAR 差 |
|---|---|---|---|
| MiDashengLM-7B | 41.88 | 46.19 / 46.30 | **−4.31 / −4.42** |
| Audio Flamingo 3 | 44.09 | 45.97 / 46.74 | **−1.88 / −2.65** |
| Qwen2.5-Omni-3B | 45.41 | 50.06 / 50.06 | **−4.65** |

**在 MMAR 上，三个 ALLM 全部因"被转成文本再让 GPT-4o 作答"而变差（−1.9 ~ −4.7pt，
符号对 raw/post 两口径都稳健）。** MMAU-mini 上则接近零或小正

## §4 DFS 四问

**方法**：把音频深度推理整体转成文本理解——ALLM 一次性 caption 出粗粒度文档 $D_0$，
再由**同一个 GPT-4o** 分饰 planning / interaction / answering 三角，在
"diagnose–plan–act" 环内以三个音频重表达工具（audio-QA / guided re-captioning / ASR）
迭代补齐 $D_i$ 的信息缺口，直到 planning agent 判 Sufficient 或达到硬上限 3 轮，
最后由 GPT-4o 从 $D_f$ 产出答案 + 置信度 + 理由。全程零训练、零参数改动。

**局限**（按对 R2 的相关度排序）：
(a) **触发量是 LLM 自由生成的二元 flag，不是可标定标量**——无阈值、无 dev 选型、
无灵敏度分析、无"该停没停"的混淆矩阵；而**唯一的标量 $S_c$ 被产出后丢弃**，
是本篇最刺眼的设计浪费；
(b) **动作选择完全无判据**——三个工具之间凭什么挑，论文零描述、零消融
（**没有"随机挑工具"或"固定顺序跑全部工具"的对照臂**，因此"Interaction Agent 的规划有
价值"这一主张未被识别）；
(c) **红线 3 硬违反且归因被自己的消融击穿**——+9.13pt 来自换作答 LLM，音频侧跨度仅 3pt；
(d) **零成本记账**（连 GPU 一句都在源里被注释掉），~10+ 次调用直接与单次前向基线比 accuracy，
**无任何等成本/等调用对照**；
(e) **无 CI、无 seed、无显著性**；"胜过闭源"只靠 MMAU Avg 的 +0.40pt；
(f) **无准入门、无出处、无冲突处理**——$\oplus$ 未定义，证据来源在文档里不可分辨，
比 NAP 的 Evidence-ID 约定倒退；
(g) **载体口径**：MMAR 只用 905/1000（失效链接过滤），与 ARC 的全 1000 口径不可比；
So-Mu（$n=11$）与 Sn-Mu-Sp（$n=22$）两列的 $\Delta$ 无统计意义；
(h) **无 Related Work 章、22 条参考文献里零条 agentic/多代理/检索文献**，
却主张 "first exploration of MAS in audio deep reasoning"；
(i) **消融把 ASR 收益记进 loop 头上**（§3.4-B），loop 的效果归因偏高；
(j) 符号桥接单独为负（§3.4-C）、最优轮数跨基准不一致却统一封顶（§3.5-1）、
迭代表配置与主表不同且未声明（§3.5）——三处论文自证但未指出的问题。

**改进空间**：把二元 flag 换成可标定的标量估计量（把已有的 $S_c$ 回流即是最小改动）；
给三个工具动作一个可比的价值量并做 argmax（本篇整条空缺）；补"随机选工具"与
"固定顺序跑全部工具"的归因对照；实现作者自己承认应有的**条件激活**
（不是每题都进环）；把作答权还给冻结 omni 核以恢复归因（红线 3）；
补等调用成本对照与九维记账；补 CI/seed；把 $\oplus$ 定义为带出处标记的结构化合并；
把最优轮数做成按任务分层的自适应而非统一封顶 3。

**可借鉴**：
- **三个动作原语的具体形态**，尤其 **guided re-captioning（带 query 引导的重述）**——
  这是 R2 `RE_RESOLVE_AUDIO` 的一个**在纯黑盒 API 设定下就能实现**的子类型：
  不需要区间切分、不需要白盒、不需要 ffmpeg，只需给冻结核换一个引导 prompt 重述同一段音频。
  **比 NAP 的 $a_{\text{audio}}(s,e)$ 更贴 R2 的黑盒设定**，建议作为 R2 `RE_RESOLVE` 的
  **第一实现档**（NAP 的区间重取作为第二档）。
- **"演进式文本证据文档 $D_i$ + 分析历史 $H_i$"的状态表示**——$H_i$ 只记"信息缺口分析"，
  是 R2 `gapCorr` 项的一个自然语言版前身；R2 的确定性版本（槽值重叠率）相对它是净进步，
  可在 §6.2 引作对照。
- **干净的 loop 开关消融设计**（同 ALLM、同 LLM、只开关环）→ 与 R2 A4a/A4b 差分同形；
  但**本篇踩的坑（w/ loop 带 Whisper、w/o loop 不带，把工具收益混进机制收益）正是
  R2 §6.2 探针仪器声明要防的东西**，建议在 R2 §6.2 加一句反例注释。
- **轮数-效果曲线的报告形式**（Iter 0…4 单调性 + 峰值 + 转负点）→ R2 §5.3 固定档阶梯的
  呈现模板（与 NAP 的 test-time scaling 曲线互补：NAP 报"上限扫描 + 实际消耗饱和"，
  本篇报"固定轮数逐档 + 转负点"，R2 §5.3 应同时具备两种读数）。
- **作者自陈的"条件激活"缺口**（§3.6-1）→ R2 §4.5 动机段的第三方论据。
- **信号层缺证据生成器的自陈**（§3.6-3）→ R2 §6.2 对 `RE_RESOLVE_AUDIO` 可实现范围的限定依据。

## §5 R2 威胁面判定（专项五问）

### (a) "training-free 多代理粗到细"具体怎么触发再分析 —— **不确定性信号：否；规则：部分**

**判定：AGR 不占据 R2 的"不确定性触发"位。**

| 维度 | AGR 事实 | 与 R2 的关系 |
|---|---|---|
| 触发量的类型 | **GPT-4o 自由生成的二元标签** $s\in\{$Sufficient, Insufficient$\}$ | R2 的 $\hat V(a\mid s_t)$ 是**连续标量**、per-action、可离线标定；二元标签无法 argmax、无法标定、无法给校准曲线 |
| 是否不确定性信号 | **否**。$s$ 是"证据是否足够"的**LLM 主观判定**，不是任何离散度/一致度/熵/自一致性计数 | R2 的 `disp(H_t)`/`maxAgree`/`audCons` 在本篇**无对应物** |
| 唯一的标量在哪 | Answering Agent 输出的 $S_c$（图 2 示例 `Confidence: 0.9`） | **该标量不进任何控制回路**——本篇有置信度输出、无置信度控制 |
| 确定性规则的部分 | 硬迭代上限 = 3；`s=Sufficient` 即停 | 仅工程护栏级，与 R2 的 $\tau$ 阈值不同类 |
| 动作选择的判据 | **无**（Interaction Agent 自由 prompt 生成，零描述、零消融） | R2 的 argmax 有显式估计量族 |

→ **AGR 属于 R2 §4.3 第 1 点批评的形态（"每个采集决策=LLM 自由生成，每个数量=硬编码常数"），
只是发生在感知轴而非检索轴。它是 R2 的对照面（自由生成 controller），不是竞争者。**
**这是对 R2 有利的判定：本篇把"感知轴上也存在同一失效面"补全了，使 R2 §4.3 的批评
从"检索轴"扩到"感知+检索双轴"，论证面反而更宽。**

**与 CoFi-Agent / NAP 的三点谱定位**（建议整段进 R2 §4.3 或 §4.5）：

| 系统 | 触发量 | 训练态 | 动作空间 | 作答权 |
|---|---|---|---|---|
| **AGR**（本篇） | LLM 自由生成二元 flag | **training-free** | 3 个音频重表达工具 | **文本 LLM**（红线 3 违反） |
| **NAP/OmniAgent**（2606.19341） | **自报置信度标量 + 阈值 0.9** | **训练态**（红线 1/2 违反） | 4 个原语（帧/音频/clip/答） | **同一 omni 核**（合规） |
| **ARC Agent Track 冠军**（2602.14224 §4.2） | "initial confidence was low"（细节未公开） | 未声明 | 40+ 音频工具 | 未声明 |
| **R2 主张的格子** | **确定性可标定标量估计量 + dev 标定阈值** | **training-free** | **感知 + 外部知识双源** | **冻结 omni 核** |

→ **四行一起看，R2 的格子仍然空着**：没有任何一个已知系统同时做到
"training-free + 可标定标量 + 双源动作 + 作答权在核内"。**这是本次两篇深读对 R2 独立性
论证的最大正面贡献。**

### (b) 有无外部知识动作 —— **零，且结构上不可能**

三个动作（audio-QA / guided re-captioning / ASR）**全部作用在同一段原始音频上**，
属 R2 §1.3 的第②类信息作用（对已有观测的重表达），不引入任何外部新信息。
`refs.bib` 22 条**零条**检索 / RAG / 知识库 / web / 工具调用文献
（已 grep `retriev|search|knowledge|web|rag` 确认零命中）。
→ **R2 的"外部知识获取调度在语音域缺席"断言在本篇上成立且被加固**：
这是一篇以"主动探索与迭代精化"为核心卖点的 2025/2026 音频 agentic 论文，
其动作空间里**连一个外部知识动作都没有**，作者也**从未把"去外部查"当作候选动作讨论过**。
**该加固的证据强度高于 ARC 的横截面**（ARC 是竞赛规则+3 队一句话，本篇是完整方法论文的
动作空间定义），**但同样受载体制约**：MMAU/MMAR 的答案由音频决定，
外部知识对实例级答案无边际价值——**须与 ARC 条目 §3 的同一条限定并列声明，不得单独放大**。

### (c) 作答权归属（红线 3）—— **硬违反，且被自己的消融量化**

最终答案 $A^{*}$ 由 **GPT-4o（Answering Agent）**发出；冻结 ALLM 只做感知。
红线 1（不改参数）**合规**、红线 2（不为任务新训练）**合规**、红线 3 **硬违反**。
**关键增量**：本篇的消融给出了读集内**最干净的一条"新增 LLM 代答吃掉归因"的量化证据**
——只换作答 LLM（GPT-3.5→GPT-4o，其余全同）MMAR **+9.13**、MMAU **+5.30**；
而换 ALLM（音频侧）只带来 3pt 级波动。
→ **建议 R2 §1.4 把本篇与 AudioRAG 并列作为红线 3 的双证据**（R2 现在只引 AudioRAG 的
+9.2pt；本篇的 +9.13 是**同量级、且对照更干净**的第二条独立证据，两条一起使
"不新增 LLM 代答"从设计偏好升级为**由证据支撑的方法学要求**）。
→ 同时须如实注明：**本篇的效果数字（MMAR 58.85、MMAU 72.60）不可作为 R2 的可达目标或臂**
（红线 3 不合规），只能作**上界参照与归因反例**。

### (d) 与 R2 双源动作调度的差异与可借鉴

**差异（五处，全部对 R2 有利）**：
1. **单源 vs 双源**：AGR 只有感知一侧，无外部知识动作，因此"在两类动作之间分配预算"
   这一决策类别**结构上不存在**；
2. **二元 flag vs 连续标量**：不可标定、不可 argmax、无校准曲线；
3. **无 per-action 价值**：三个工具之间无任何可比量（连"选哪个工具"都没有判据与消融）；
4. **无预算分维**：只有一个全局轮数上限 3，无 core calls / search calls / audio seconds
   的分维余额；
5. **无准入门、无出处**：$E_{\text{new}}$ 无条件 $\oplus$ 进 $D$，$\oplus$ 未定义，
   来源不可分辨。

**可借鉴（四件，全部为红线内的确定性/工程层或报告形式）**：
1. **guided re-captioning 作为 `RE_RESOLVE_AUDIO` 的黑盒第一实现档**（见 §4"可借鉴"）；
2. **$H_i$（信息缺口分析历史）→ R2 `gapCorr` 的自然语言前身**，可在 §6.2 引作对照；
3. **loop 开关消融的对照形状 + 其踩的坑**（把 Whisper 收益混进 loop 收益）→
   R2 §6.2 探针仪器声明的反例注释；
4. **Iter 0…4 逐档曲线 + 峰值 + 转负点**的报告形式 → R2 §5.3 固定档阶梯模板
   （与 NAP 的上限扫描+饱和值互补）。

**不可搬**：GPT-4o 三角作答架构（红线 3）；任何效果数字作 R2 目标；
"多代理"这一组织形态本身（R2 的控制面是确定性规则，不新增 LLM）。
