## 2. 方法本质：三段管线

论文把"个性化实体上下文化"从**把整个实体库塞进 prompt** 重构为**先听一遍、再按音检索、
再听一遍**。动机是成本而非精度——原文（`01-introduction.tex` L31–35）：

> "In practical applications such as voice assistant, however, users can have hundreds or thousands
> of named entities of different categories. Using a prompt with all personal named entities can lead
> to a significant increase in computational complexity and memory footprint, especially for on-device
> applications."

作者自陈灵感来自 RAG，但点明**三条语音特有的 RAG 落差**（`02-methodology.tex` L24–28，逐字）：
(1) "The input query is speech, while the named entity database is text."；(2) "The named entities do
not carry significant semantic differences and **differ only in phonetics**."；(3) "The correct span
in the speech input signal has to be identified as the query." ——这三条正是 R2 §1.5 问题二/问题三
（key 用什么表示、什么装进 key）的语音域最早期表述之一，值得原样引用。

### 2.1 第一段：无上下文实体检测（detection）

音频嵌入喂进 LLM，跑**context-free ASR decoding**。检测能力靠训练数据里给实体打标签实现：
训练转写形如 `Call <contact> Thomson </contact>`（`02-methodology.tex` L38）。解码时假设里被标签
包裹的 span 即候选实体，"so they can be extracted by **simply parsing the hypothesis**"。
**若未检出实体，解码直接结束**——这是一道朴素但真实存在的**触发门**（见 §8 第 3 变量的限定说明）。

### 2.2 第二段：NPD 音素编辑距离检索（retrieval）

库结构：每个类别（contact / app name / playlist）一张**扁平表**，每条含实体文本与其**音素表示**；
音素表示"obtained either from a **pronunciation lexicon** or a **grapheme-to-phoneme (G2P) model**"
（`02-methodology.tex` L38）——即 G2P 是词典缺失时的兜底，不是唯一通路。

**NPD 定义式**（`02-methodology.tex` L40 逐字："To compute NPD, we first compute the edit distance
between phonetic representations of the query and database entry, then divide by the number of
phonemes in the query pronunciation."）：

    NPD(q, e) = EditDistance( P(q), P(e) ) / |P(q)|

其中 `P(·)` 为音素序列，分母是**查询侧**音素数（不是被检条目侧、也不是二者最大值——这条不对称性
是可移植实现细节）。

**准入规则（两支取并集，再截断）**：
- 相对支：`NPD(q,e) ≤ 1.2 × min_{e'} NPD(q,e')`
- 绝对支：`NPD(q,e) < 0.2`
- 上限：按 NPD 升序**最多保留 10 条**。

原文（`02-methodology.tex` L40–41）："the NPD is no greater than 1.2 times the best NDP or it is lower
than 0.2. We keep a maximum of 10 candidate names in the prompt, sorted by NPD."（源文两处把 NPD 误写
作 "NDP"，`03-experiments.tex` L25 复现同一笔误；不影响语义。）

**一条作者未讨论的规则退化**：当最佳候选是音素精确匹配（best NPD = 0）时，相对支 `≤ 1.2 × 0 = 0`
只放行同样精确匹配者，准入集实际由绝对支 `<0.2` 单独决定；两支的主导关系随最佳距离静默切换。
R2 若把此规则当阶梯基线实现，须显式登记这一分段行为。

### 2.3 第三段：上下文化解码（generation）

把检回的候选实体作为 prompt 喂回**同一个** LLM，跑 context-aware ASR decoding。关键在于**音频仍在
上下文里**——第三段是"假设 × 音候选 × 原始声学"三者上的重裁决，不是纯文本改写。

**三个管线变体**（`tab:method` = Table I）：

| 模型 | detection（context-free） | generation（context-aware） |
|---|---|---|
| `full-full` | ASR decoding | ASR re-decoding |
| `ne-full` | NE detection（只吐实体，不吐整句） | ASR decoding |
| `full-ne` | ASR decoding | NE rewriting（只重写实体，再回填） |

`full-full` 是主方法（"full ASR decoding is run **twice**"，`02-methodology.tex` L49）；另两个是省算力
变体。三者的**推理期共性**：未检出实体时全部退化为普通 ASR，无需上下文 prompt；检出时只灌回检回的
少量实体而非全库，"requiring a much shorter KV cache"（L58）。

## 3. 训练态与信息访问边界

这是本篇对 R2 最承重、也最容易被一句"有训练"糊过去的部分。**逐件枚举全部训练组件**：

**(T0) 音频编码器——唯一冻结件。** Conformer + CTC，4× 下采样卷积块 + 12 层 Conformer（每层 512
输出单元），**82M 参数**，25 帧/秒输出。先在 **300k 小时机器转写数据**上预训练，再在 **45k 小时
有监督数据**上微调（`03-experiments.tex` L11）。在 LLM 微调阶段它被冻结——原文 L13 逐字："We
**freeze the audio encoder** in LLM finetuning"。注意：它冻结，但它本身是这条链上训练成本最高的部件，
只是在**本文的实验之前**训完的。

**(T1) 投影层 + LoRA = 每个 LLM 模型 46M 可训参数。** 原文 L13 逐字："we use a subsampling of 12x for
the audio embeddings, and a LoRA adapter with **rank=8 and alpha=16**. As a result, all LLM models we
trained have **46M trainable parameters**, with **21M parameters from the LoRA adapter** and **25M
parameters from the projection layer**."
> **口径更正（对上游任务书表述）**：46M 是**总量**，不是 LoRA 单项。正确拆分是 **21M LoRA + 25M
> projection = 46M**。任何写成"LoRA 46M / projection 25M"的行都会把总量重复计一次。

底座 LLM 为 **Mistral 7B**（`03-experiments.tex` L13）。优化：交叉熵 + Adam + warmup 线性升降，
峰值 **2e-4**（L15）。

**(T2) 独立检测模型（两个，不是一个）。** `03-experiments.tex` L15：先训一个 baseline LLM（在打标签
转写上），"This model **also serves as the standalone detection model** for `full-full` and `full-ne`"；
再"train **another model** on tagged named entities to prepare training data for `ne-full`"。
其存在理由在 `02-methodology.tex` L94 说得很直白——**不能用参考实体当训练期的检测输出**：
> "If we used the tagged reference as the detection output ... this would create a **severe
> training/inference mismatch**. In fact, it is exactly the cases where the detection output does not
> match the reference where we expect to benefit from retrieval and generation."

这是本篇最好的一条工程纪律，也与 R2 的信息边界纪律同构（用 gold 造训练态 = 制造不存在的容易情形）。

**(T3) 三个任务模式模型。** "Then, we **train three models** following Section II-C"（L15）——
`full-full` / `ne-full` / `full-ne` 各训一个。

**训练总账**：1（baseline/检测）+ 1（`ne-full` 的数据准备检测模型）+ 3（三个模式模型）= **5 次 LLM
训练**，每次 46M 可训参数，训练集 31k 小时英文。

**(T4) 合成个人库训练数据。** 训练音频**没有**配套个人库，作者整套合成（`03-experiments.tex` L5）：
从训练数据抽取各类实体池 `NE(c)` 及其分布；从**有真实库的开发集**估计每类实体条数分布 `N(c)`；
逐条音频按 `n(c) ~ N(c)` 从 `NE(c)` 无重复抽样；最后——"if the transcript of the audio contains a
named entity, **we add it to the synthesized database**"。即训练期**按构造保证 gold 实体在库内**
（召回上界 = 1）。这不是测试期泄漏（测试用真实个人库），但它意味着**检索召回失败这一失效模式在训练
分布里被系统性抹掉了**，且全文从未报告测试期的检索召回率。

**信息访问边界的准确刻画（比"白盒+训练"更细）**：
- **架构级白盒**：需要把音频嵌入下采样 12× 后**投影进 LLM 的嵌入空间**、需要往权重里插 LoRA。
  这两件在 API-only 冻结核上都做不了。**这是白盒判定的真正来源。**
- **但推理期的上下文化回路本身是 prompt 级的**：检索 key 是**解码出来的音素串**（文本域），不是
  encoder/decoder 隐状态；检回的候选以**普通文本 prompt** 灌回。这与 PRISM（以声学/语言隐状态为 key、
  推理期 kNN）**不是同一种白盒**。本篇的白盒性来自训练与架构改装，不来自机制回路——这一区分对 R2
  §8 的 incumbent 分组直接有后果（见 §7 第 3 格与 §9 前提 B）。

## 4. 关键数字（全部取自 LaTeX 表体）

**主结果（Table II，`tab:results`；WER / NER，NER = entity error rate，计 WER 时忽略实体标签）**：

| 模型 | 无上下文 WER | 无上下文 NER | 带上下文 WER | 带上下文 NER |
|---|---|---|---|---|
| Conformer-CTC（82M，beam 50） | 8.30 | 44.86 | – | – |
| Baseline LLM（beam 10） | 6.36 | 37.52 | – | – |
| `full-full` | 6.34 | 37.58 | **4.44** | **9.90** |
| `ne-full` | 6.53 | 38.46 | 4.99 | 15.20 |
| `full-ne` | 6.35 | 37.61 | 4.46 | 11.09 |
| ` - Simple replacement` | – | – | 4.84 | 12.60 |

1. **头条相对增益（摘要 + 结论 + 引言三处一致）**：`full-full` 相对 Baseline LLM 达 **30.2% 相对 WER
   下降、73.6% 相对 NER 下降**。本次逐位复算：(6.36−4.44)/6.36 = **30.19%**；(37.52−9.90)/37.52 =
   **73.61%**。**算术核对通过，且基线确为 Baseline LLM 而非 Conformer-CTC**（若以 CTC 8.30/44.86 为基
   则分别是 46.5%/77.9%，作者未取此口径）。
2. **绝对水位仍高**：即使最优臂，**NER 仍为 9.90**——约十分之一实体仍错。上下文化把 37.52 打到 9.90，
   但没有把问题关掉。
3. **裁决步的独立价值（Simple replacement 消融）**：`full-ne` 若跳过 LLM 重裁决、直接把假设里的实体
   替换成 **top-1 检回项**，退化为 4.84 / 12.60，相对最优 `full-ne`（4.46 / 11.09）**WER 差 7.85%、
   NER 差 11.98%**。原文 `03-experiments.tex` L25 的定性表述："This comparison verifies the
   effectiveness of the LLM in generating the correct name entities given the context-free hypothesis
   and the retrieved context." ——**这是"检索出候选 ≠ 裁决完成"的一手证据**，且裁决方拥有原始音频。
4. **检索条数非单调，拐点在 10（Table IV，`tab:results_by_context_length`，固定条数）**：

   | 模型 | k=1 | k=5 | k=10 | k=20 |
   |---|---|---|---|---|
   | `full-full` | 4.57 / 12.15 | 4.44 / 10.52 | **4.42 / 10.28** | 4.45 / 10.57 |
   | `ne-full` | 5.09 / 16.77 | 5.00 / 15.35 | **5.00 / 15.30** | 5.03 / 15.72 |
   | `full-ne` | 4.60 / 12.93 | 4.50 / 11.49 | **4.48 / 11.30** | 4.50 / 11.50 |

   **三个模型全部在 k=20 回退**（NER 相对恶化 2.82% / 2.75% / 1.77%）。作者归因（L97）："When even
   more (=20) named entities are fed to the LLM, WER and NER start to increase **due to noisier
   contextual prompt**." ——**这是语音域"更多证据 ≠ 更好"的现成 n=3 复现**。
5. **本文内部一组现成的"准入门 vs 无准入门"对照（作者从未指出）**：Table II 用的是**自适应 NPD 规则**
   （1.2×best 或 <0.2，上限 10），Table IV 的 k=10 列用的是**固定 10 条**（L97 逐字："a **fixed
   number** (=1, 5, 10, 20)"）。同源、同上限，只差一道准入判据，三个模型的 NER 全部是自适应更优：
   `full-full` 9.90 vs 10.28（相对 −3.70%）、`ne-full` 15.20 vs 15.30、`full-ne` 11.09 vs 11.30；
   WER 上自适应在 `ne-full`/`full-ne` 更优、在 `full-full` 微劣（4.44 vs 4.42）。
   **这是 R2 §6.2 中 A2（检索+无条件拼接）vs A3（同证据集+准入）臂对的现成语音域实例，方向一致地
   支持准入门为正。**
6. **检测质量主导整条链（Table III + 交叉实验）**：参考侧实体 **12.7k**；`full-full` 检出 12.0k、
   `full-ne` 12.0k、`ne-full` 仅 **10.7k**。作者把 `ne-full` 的全面劣化归因于检测欠佳，并做了直接
   交叉：用 `full-ne` 的检测结果生成上下文、仍用 `ne-full` 做 ASR 解码，"WER decreased from 4.99 to
   **4.61**, and NER from 15.20 to **10.2**"（L93）——**只换检测源，NER 相对改善 32.9%**。
   这是"查询构造/映射瓶颈"量级的一手测量，直接对应 R2 §2.2 与 A1/A1′ 臂的动机。
7. **载体规模与构成**：训练 **31k 小时**英文；测试 **37k 条 query**，每条配真实个人库（含 contact /
   music playlist / app name）；**12k contacts 出现在 11.2k 条 query 中**；"On average, each contact
   list has **hundreds of contacts**"；**实验只考虑 contact 一类实体**（"We only consider contact
   entities during our experiments."，L7）。
   **一处低危内部不一致**：正文写 "12k contacts"，Table III 参考侧写 "12.7k"——12.7k 常规四舍五入为
   13k。二者口径可能不同（query 内出现数 vs 参考转写标注数），论文未说明；引用时以表体 12.7k 为准并
   标注口径未定。
8. **零成本数字**：全文**没有任何延迟、token 数、内存占用的实测值**。效率主张（"highly efficient"、
   "much shorter KV cache"、"reducing the number of tokens to generate"）**全部是设计论证，无测量**。

## 5. DFS 四问

**方法**：在一条 LoRA 微调过的 LLM-ASR 链上，用**同一个模型跑两遍**——第一遍无上下文解码并借训练时
注入的标签能力吐出实体 span，以该 span 的音素串为 query 在个人实体库上做**归一化编辑距离**近邻检索，
第二遍带着少量候选与原始音频重解码。核心工程主张是"**按需、按音、按条数上限**地把上下文化成本从
O(库大小) 压到 O(10)"。

**局限**：
1. **不是 training-free，且训练面比"LoRA"一词大得多**——5 次 LLM 训练 + 一整套个人库合成流程 +
   一个前置的 82M CTC 编码器（300k h 预训练 + 45k h 微调）。冻结的**只有** audio encoder。
2. **载体完全不公开**：Apple 内部语音助手数据（31k h 训练 / 37k query 测试），个人库训练侧为合成、
   测试侧为内部真实库；无公开数据集、无公开实体库、无代码发布。**本篇不可复现，因而不能作为可运行
   对手**，只能作结构最近邻。
3. **检索层零读数**：从不报告 recall@k、同音候选命中率、检索失败率。全部证据都是端到端 WER/NER，
   检索与裁决的贡献无法分离（Simple replacement 只切了裁决一侧）。
4. **训练分布按构造保证 gold 在库**（`03-experiments.tex` L5），故模型可能从未在"gold 不在库"的
   分布上被优化过；测试期该比例未报。
5. **单类实体、单语言**：只评 contact，只有英文。而 NPD 的行为高度依赖音素库与同音密度。
6. **距离函数是纯编辑距离**，作者自陈为主要局限（`04-conclusions.tex`）：
   > "One main limitation of the current approach is that we use edit distance to measure the phonetic
   > distance between two pronunciations and **do not take into account similarities between two
   > phonemes**."
7. **零成本测量**（见 §4 第 8 条）——一篇以效率为主要动机的论文没有报任何效率数字。
8. **无 training-free 对照臂**：没有"不微调、只 prompt 一个通用 LLM 跑同样三段管线"的臂，因此**训练
   在多大程度上是必需的，本文没有回答**。这一空缺恰是 R2 的作业面（见 §9 前提 B）。
9. **k 的选择与准入规则未被联合搜索**：Table IV 只扫固定 k，自适应规则的两个常数（1.2 与 0.2）从未
   消融，出处仅为 "Empirically, we use a simple rule"（`02-methodology.tex` L40）。

**改进空间**：
- 把 NPD 从**均匀代价编辑距离**换成**音素混淆矩阵加权距离**或发音嵌入——作者自己指的方向，且是
  R2 §2.3 阶梯"朴素语音学基线 → 冻结声学 key"之间最自然的中间台阶；R2 应把它实现为阶梯的**上界侧
  朴素基线**，避免用未加权 NPD 这一弱实现去衬托自家方案（§8 incumbent 分组合同"不得挑弱实现称胜"）。
- **准入门与触发门都可标量化**：现有触发是布尔的（检出实体就查），现有准入是启发式两支规则。把两者
  换成条件于核不确定性的可标定标量 + 外显阈值，是本篇结构上留下的直接空位。
- **检测侧才是瓶颈**（NER 15.20 → 10.2 仅靠换检测源），所以**多假设 query**（R2 §2.2）在此有明确
  收益预期：本篇的 query 是单条 1-best span，没有 N-best/lattice 输入检索。
- **k=10 的拐点提示准入而非扩容**：与其扩大 k，不如在 k 之上加一道基于原始音频的准入判据——本文
  Table II vs Table IV 的差已经给了这个方向的弱信号。

**对 R2 可借鉴（分四条，含指定项）**：
- **(a) 作为 R2 §2.3「检索层对照阶梯」第二级的实现参考——本条为本次深读的指定用途。** R2 §2.3 的
  阶梯为"字面/别名匹配 → **G2P/音素编辑距离** → PRISM 式合成语音记忆（白盒参照上界）→ 冻结声学 key
  （本方案）"，且立有硬条件："冻结声学 key 须在同预算下超过朴素语音学基线才立机制主张"。本篇提供了
  该第二级**唯一一份完整可复刻的规格**：音素来源（发音词典优先、G2P 兜底）、距离式（编辑距离 ÷ 查询
  音素数）、准入两支（≤1.2×best ∪ <0.2）、条数上限（10）、排序键（NPD 升序）。R2 实现该级基线时**应
  逐项照抄并在方法合同里注明出处**，同时按上文"规则退化"与"未加权代价"两条做显式登记——否则阶梯第
  二级会被实现成一个稻草人，K-PS 的机制主张随之作废。**同时它给出了一个可移植的超参先验：k*≈10，
  k=20 已经变差**（但见 §9 前提 D，k* 不得跨核沿用）。
- **(b) 训练/推理失配纪律的现成措辞**：不得用 gold 实体当检索 query 去造训练/校准数据，因为"正是
  检测输出与参考不一致的那些样本才是检索与生成起作用的地方"。R2 的 dev 标定（阈值、基率表、
  §6.1 预检电池）面临同一陷阱的镜像形态，可直接引此段作为纪律出处。
- **(c) 三条语音-RAG 落差的原文表述**（query 是语音、库是文本；实体只在音上有别、语义上无别；正确
  span 须先被定位）可直接作为 R2 §1.5「问题二/问题三」的领域先行表述引用，说明这不是 R2 自造的问题
  框架。
- **(d) 两组本文未自觉、但对 R2 承重的读数**：①Table II（自适应准入）vs Table IV k=10（无准入）
  三模型一致的 NER 方向 → 语音域的 A2/A3 弱证据；②Table IV k=10→20 三模型一致回退 → "更多证据 ≠
  更好"的语音域复现。二者都应以"本文未讨论、由本次深读从表体推出"的措辞引用，不得写成作者结论。

## 8. R2 增量变量核验（四项 delta 是否确在本篇缺席）

**delta ①「零训练」——确实缺席，CONFIRMED，强度：最高。**
证据：5 次 LLM 训练，每次 46M 可训参数（`03-experiments.tex` L13、L15）；训练数据需整套合成个人库
（L5）；前置 82M Conformer-CTC 编码器另需 300k h 预训练 + 45k h 有监督微调（L11）。全文**没有任何
不经微调即运行的臂**。**限定**：唯一冻结件是 audio encoder，故"training-free"在本篇里连局部都不成立。

**delta ②「黑盒 / API-only」——确实缺席，CONFIRMED，强度：高，但须带一条对 R2 不利的限定。**
证据：需要把音频嵌入 12× 下采样后**投影进 LLM 嵌入空间**并插入 LoRA（L13）——这两件在 API-only 冻结
核上不可执行。**不利限定（必须写进 prior-difference 记账）**：本篇的**机制回路**（1-best 实体 span →
音素串 → 库检索 → 文本 prompt 回灌 → 带音频重解码）**全部是 prompt 级的**，一旦前提 B 被 2026 的核
满足，该回路可原样搬到 API-only。因此 R2 的"黑盒"delta 是**对本篇实现的 delta，不是对本篇机制的
delta**；R2 不得据此主张"首次在黑盒下实现该机制类"，只能主张"首次在不改架构、不训权重的条件下
达成同等或更强效果"。

**delta ③「双源动作」——确实缺席，CONFIRMED，但须削弱为"缺席的是动作选择，不是缺席一切门"。**
证据（缺席侧）：动作源**唯一**——个人实体库；**没有重听/重加工动作**（第二遍解码是对同一音频的固定
重解码，不是被信号触发的定向重听）；**没有源间选择**，管线是确定性的"检出即查"。全文无任何调度、
路由或成本比价。
**证据（须承认的已有门）**：①**布尔触发门**——"If no named entities are detected, decoding stops"
（`02-methodology.tex` L38），即未检出实体就不付检索与二次解码的代价，这在结构上是一道**采集门**；
②**外显阈值准入门**——NPD ≤ 1.2×best ∪ NPD < 0.2，再截 top-10（L40–41），这是**已有外显阈值的准入
规则**。故 R2 §8 的 delta 措辞若停在"双源动作"是安全的，但 R2 §0/§4.4 中任何"门控化的 agent 环即
空位"式全称句在本篇面前须加限定：**空位的是"可标定标量门 + 感知信号驱动 + 多源动作选择"，不是
"任何形式的门"**。请 orchestrator 据此复查 §4.4 的表述强度。

**delta ④「裁决由世界知识而非微调承载」——确实缺席，CONFIRMED，强度：高。**
证据：候选**全部来自个人实体库**，无任何外部/世界知识源，无 rescore 环节；裁决由**微调过的 LLM 的
上下文感知解码**完成（`02-methodology.tex` L41、`03-experiments.tex` L25）。Simple replacement 消融
（4.84/12.60 → 4.46/11.09）证明裁决确实由模型承担而非由检索排名承担，但**承担者是被微调的模型 +
仍在上下文里的原始声学**，不是世界知识。**限定**：本篇的裁决**用到了声学证据**（音频仍在 generation
的上下文里），这一点与"纯文本后处理"的 RAC/DARAG 不同，R2 在写"回不到信号"一类概括时**不得把本篇
并入**——本篇是回得到信号的。
