## 1 方法本质

M³-VQA **不是方法论文，是 benchmark + 评测协议论文**。它构造 13,125 条 (I, Q, A) 三元组
（10,565 张唯一图、7,611 条唯一问题、4,645 个唯一实体、平均 3.1 跳 / 2.8 实体 / 3.1 条证据），
每条都带**可溯源的黄金证据链**（每个子问题链到一篇维基文章，标注**恰好含答案的那一句**，并记录
支撑句所在 **section 索引**），配一个从 ~2M 实体维基快照（2022-08-13）构建的多模态 KB。任务分
**并行多跳**（多实体各自独立检索后聚合）与**串行多跳**（bridging entity 逐跳传递）两个子任务。
论文用 **6 个"信息可得性"分层协议**评测 16 个 MLLM，并把 KB 协议实现为**启发式检索**与
**agentic 检索**两条管道。全程**无任何训练**（附录 Compute Resources 原文："No large-scale model
training was performed during the course of this study"，~2000 A800 GPU-hours 全部用于数据构建
与推理，vLLM 部署）。

## 2 key-value 与三轴定位

| 维度 | 事实（LaTeX 源核） |
|---|---|
| **key 用什么构建** | **KB 双语料双 key。** 文本语料：每个实体页取**至少 3 个 section**（必含含黄金证据的那个），用 `bge-large-en-v1.5` 编码，Faiss 索引，query 侧加指令前缀 `"Represent this sentence for searching relevant passages:"`。图像语料：每页**首图**，用 `clip-vit-large` 编码，并与**文章摘要的文本嵌入相加**构成 **entity embedding**（作者明说：摘要+图像求和优于任一单独，也优于"实体名+图像"）——即 **key 本身是双面相加融合**。 |
| **检索几跳** | **启发式=固定 2 阶段一次性**（问题整句检文本 top-10；整图检实体 top-10 再用问题在这 10 篇内检 10 个 section）；**agentic=Planner 迭代不定跳**（"runs iteratively until the system determines that sufficient knowledge has been gathered"）。停止判据是 **Planner LLM 的自由生成判断**——"Before each call to the executor, the planner must assess whether sufficient information has already been acquired"——**没有 scalar reward，没有硬预算，没有显式停止规则**。 |
| **证据怎么进上下文** | 启发式：文本检索与图像检索的结果**直接 concat** 作为 context。agentic：Solver 把工具输出**去掉执行轨迹、只留检索内容**，组织成 evidence list 后与图、问一起推理。 |
| **有无准入** | **没有。** 两条管道都无阈值、无拒绝、无冲突处理、无引用归因入答、无 abstain 通道。 |
| **KB 难度控制（对 R2 有用）** | 不在全 2M 文章上检索：保留 M³-VQA 全部实体页，并为**每个实体采 ~5 个 hard negative**（用 `all-mpnet-base-v2` 编码摘要，Faiss 取 top-20 最相似实体，随机选 5）。检索必须在**整个构造后的 KB** 上做，而非仅在正例+hard negative 之间。 |

**三轴读数**：组织轴 = 双语料 + 图文相加式融合 key + section 级 value + **逐句 gold 标注与 section
索引**（读集内证据溯源最完整的一篇）；供给轴 = 启发式固定 / agentic 自由生成停止（**与 R2 §4.3
批评语音域 AudioRAG 的失效形态同型**）；使用轴 = 无条件接纳。

## 4 DFS 四问

**方法（做了什么）**：把"知识型 VQA"从单实体两跳推到**多实体 × 多跳（并行/串行）**，并把评测本身
做成**一条按信息可得性单调排列的协议阶梯**（Q-Only → Original → Entity-Name → Section →
Sentence，旁挂 KB 的 Heuristic/Agentic 两实现），每一级的差分都对应一个可解释的能力项。
逐子问题的 gold 句 + section 索引标注使**检索归因**（检对页/检对段）可以直接量。

**局限**：(a) 是 benchmark，无新机制——两条检索管道都是"设计给评测用的通用算法"，本身不含准入、
定价、停止规则；(b) **agentic 臂的 Planner 恒为 GPT-4o**，被测 MLLM 只当 Solver，因此
"agentic > heuristic" 混杂了"外部注入了 GPT-4o 的规划能力"这一混淆项，论文未做 Planner 消融；
(c) 对象检测器固定 Qwen2.5-VL-7B（也是被测模型之一），存在自评风险；(d) KB 检索被限制在
"M³-VQA 实体 + 5 hard negatives"构造集上，不是全 2M，绝对召回数字不可外推到真实开放库；
(e) agentic 臂的迭代成本（跳数、token、时延）**完全未记账**，所以"agentic 更好"是无预算约束下的
结论；(f) 无 abstain / 拒答分析（GPT-4o 的拒答只用一个脚注 `*` 处理）。

**改进空间**：(i) Planner 消融（把 Planner 换成被测模型自身）以拆掉能力注入混淆；(ii) 给 agentic
臂加成本记账与预算档，看 20 点 gap 里多少能在固定预算下拿到；(iii) 加准入门（Tab.14/15 已给出
per-hop 的检索正确率，天然的门控标签源）；(iv) 1-hop 上 agentic 反而更差（分割噪声）说明
**动作应按任务分层选择而非一律执行**——这是现成的自适应空位。

**可借鉴（形状，H5 withheld）**：**(1) "信息可得性单调阶梯"这个协议骨架**（Tab.9 那张
I/Q/实体名/证据 的 ✓✗ 矩阵）是 R2 A0–A6 阶梯最直接的跨域模板：每一臂只改**一个**信息通道的
可得性，相邻臂差分即一项能力/机制的归因值。**(2) gold 臂的三级粒度 + Gold@k 覆盖度双轴**
（粒度 × 覆盖比例）比单一 oracle 行信息量高一个数量级。**(3) 检索归因表**（检对 page / 检对
section 的准确率，对着 gold 标注算）是"证据要审计"的最小可执行实现。**(4) hard-negative 构造的
KB 缩放法**（保留正例 + 每实体 5 个语义近邻负例）——让检索难度可控又不必扫全库，R2 §9 的
"数据集 lock 与检索服务 pin"可以直接抄这个构造法。

### 深读后新增的、R2 应该知道的事实

**F1 — 四臂协议的确切构造（R2 的 A1′ 能否直抄：能抄骨架，但要抄的是"5 级 + 双轴"而非"四臂"）**

- **no-evidence 是两条臂，不是一条。** `Q-Only` = 只给问题（**去掉图像**），`Original` = 图+问。
  两者差 8.9 点，作用是**证明任务确实依赖那个模态**。**这对 R2 是承重的**：R2 若主张"音频先产出
  语义假设"，A0 之下应补一条"**去掉音频、只给文本问题**"的臂，否则无法排除"答案可由问题文本
  独立猜出"（本篇 Q-Only 平均仍有 15.6，作者归因于问题里的文本实体 + IoU 部分给分 + 事实/计数题
  可猜中）。R2 现在的 A0（no-evidence）**缺这一条模态必要性臂**。
- **gold-evidence 是三级粒度，且第一级不含证据。**
  `Entity-Name` = 给 gold **实体身份**、不给任何证据文本（Tab.9 证据列 ✗）；
  `Section` = 给含证据的整个维基 section；`Sentence` = 给**恰好支撑答案的那一句**。
  三级差分把 headroom 拆成可归因段：**+10.2（认对实体/key）**、**+10.4（section 级 value）**、
  **+4.8（句级精度）**。**R2 的 A1′ 可以直接抄这三级映射**：`Entity-Name` ↦ **gold 语义假设/转写
  作为 key**（不给知识）；`Section` ↦ 给 gold 知识文档；`Sentence` ↦ 给 gold 答案句。抄的是
  **"每级只放开一个信息通道"**这条规则，不是数字（H5 withheld）。
- **第二轴是覆盖度而非粒度：Gold@k。** 固定题目复杂度（4 实体并行 / 3 跳串行），只改**有多少个
  推理步拿到 gold 证据**（0 / 1 / 2 / 3 / All）。Tab.6（主文）+ Tab.17（附录全桶）。
  **这正是 R2 A0–A6 阶梯的跨域出处**——R2 的阶梯应当声明自己借的是"**覆盖度阶梯**"这一形状。
  两个可直接迁移的性质：(i) **按复杂度桶饱和**——1-hop 桶在 Gold@1 就饱和（71.78 恒定），4+ hop
  桶到 Gold@All 才 45.01，所以**阶梯必须分桶报**，聚合曲线会掩盖饱和点；(ii) **串行 vs 并行的
  增益结构不同**（Qwen-7B：串行 25.9→59.0 = **+33.1**，并行 21.7→39.5 = **+17.8**），R2 若有
  "链式假设依赖"与"并列多假设"两类音频任务，须分开建臂。
- **heuristic 与 agentic 是**同工具、不同调度**的受控对照。** 两臂共用 `bge-large-en-v1.5`（文本，
  top-10，带指令前缀）与 `clip-vit-large`（图像，top-10，且 key = 摘要嵌入 + 图像嵌入相加），
  差异只在：agentic 多一个 Planner 做**问题分解 + 图像分割（对象检测）+ 迭代充分性判断**。
  R2 若要一条"已发表 agentic 基线"臂，这是**工具面对齐的正确做法**（不要换检索器再比调度）。
- ⚠ **但有一个必须处理的混淆项**：**Planner 恒为 GPT-4o，被测 MLLM 只当 Solver**；object detection
  恒为 Qwen2.5-VL-7B。所以 Tab.5 的 agentic 增益里混着"外部强模型的规划能力注入"，论文未做
  Planner 消融。R2 若照抄，要么把 planner 固定为**同一个被测冻结系统**，要么把"planner 模型"
  作为显式消融轴——否则 R2 自己的 agentic 对照臂会继承同一处可攻击点。

**F2 — 训练环节（红线相关）：本篇是三篇里唯一完全 training-free 的一篇。**
附录 Compute Resources 原文："**No large-scale model training was performed during the course of
this study**"；~2000 A800 GPU-hours 全部用于数据构建与推理，用 vLLM 部署。所有 16 个 MLLM 都是
现成 checkpoint 直接评测，检索侧也全是现成冻结编码器（`bge-large-en-v1.5`、`clip-vit-large`、
构建 hard negative 用的 `all-mpnet-base-v2`）。**对 R2 §1.4 红线的含义**：M³-VQA 的整套协议
（6 臂 + Gold@k + 检索归因）**可以在完全冻结、无训练的条件下实施**——这是 R2 借用该协议时最
关键的一条"可行性证据"，也把它与 Wiki-LLaVA（LoRA 微调）、EchoSight（reranker 全参微调
40 A100-h）区分开。R2 若在 §4.2 并列三篇，须注明**只有 M³-VQA 是零训练**。

**F3 — 其余对 R2 承重的新事实**

1. **"gold key 只值 +10.2 点"这个量级在两篇上一致**（本篇 Entity-Name − Original = 10.2；
   EchoSight KB Title 29.4 vs vanilla 21.0 = +8.4）。R2 若把 A1′ 设计成"只给 gold 语义假设"
   一臂，据此形状**预期效应量偏小**，功效分析（§9 K1–K5 待办）必须按小效应量算样本；
   更稳的做法是同时建 gold-key 与 gold-value 两臂。
2. **检索准确率沿跳数强非均匀且两模态方向相反**（Tab.14 heuristic top-10）：文本检索 Page
   1-hop **2.38** → 4-hop **48.02**；图像检索 Page 1-hop **55.22** → 4-hop **17.96**。
   即"哪个动作有用"随任务结构**反号**。这是 R2 §4.4 M8（按类别再分配预算）与 §4.5 主杠杆
   （**选对动作比多做动作重要**）在视觉域的直接实测出处，且强度高于 R2 现引的 AdaCompute。
3. **agentic 在最简子集上净有害**：1-hop 图像检索 agentic **劣于** heuristic，论文归因为
   "单实体图不需要分割，分割引入额外噪声"。这是"更多机制 ≠ 更好"的干净反例，可与 R2 §4.3
   第 3 条（Omni-DeepSearch 预算档在 VIDEO/AMBIENT 上**下降**）并列成"跨域一致：一律执行的
   动作会在部分分层上净负"。
4. **agentic 臂的成本完全未记账**（跳数/token/时延零报告）。R2 §4.3 批评语音域 agentic 线
   "无界 hops、无显式停止"时，可以指出**视觉域 2026 的 benchmark 级 agentic 管道同样如此**——
   这不是语音域独有缺陷，而是 agentic 评测的普遍缺口；R2 的"成本全程记账但不设限"因此是
   **跨域新增的报告项**，而不是补语音域的落后。
5. **KB 难度控制的可抄构造**：保留全部目标实体页 + 每实体 5 个 hard negative（`all-mpnet-base-v2`
   编码摘要 → Faiss top-20 → 随机取 5），检索在**整个构造 KB** 上做。反面含义：**该 KB 的绝对
   召回数字不能当作开放库上限**（论文自陈此法是为了避免扫全 2M）。R2 若引 Tab.14/15/16 的
   召回数字，必须带这个范围限定。
6. **可交叉校验的一致性**：Tab.17 Gold@All（Qwen-72B All = 58.41）与 Tab.4 Sentence（58.4）
   一致；Tab.17 Gold@0 = 32.55 与 Tab.3/Tab.4 Original（32.6）一致。→ 本篇主表内部自洽，
   数字可直接引用。
7. **纯文本模型 + 图像描述始终劣于 MLLM**（Llama-3.1-8B *text* 在每一臂都低于同尺寸 MLLM：
