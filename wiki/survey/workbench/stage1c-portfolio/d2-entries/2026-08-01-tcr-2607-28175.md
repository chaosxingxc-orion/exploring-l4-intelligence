## 4. 本篇实际做的事

### 4.1 任务定义：audio → clean text

摘要逐字（PDF 第 1 页）：

> "We therefore formulate Agentic Speech Recognition (AgenticSR), an **audio-to-clean-text task that removes disfluencies, resolves self-corrections, and normalizes written form while preserving the speaker's final intent**."

§Method / AASR-Bench / Task Formulation（PDF 第 2 页）给出四条合法输出要求，逐字：

> "A valid AgenticSR output should:
> • remove semantically empty fillers and smooth repetitions or stuttering;
> • apply ITN to expressions such as numbers and dates, and render entities in conventional written forms;
> • resolve false starts and self-corrections, retaining only the speaker's final intended content;
> • use contextual spelling or explanatory cues to recover uncommon entities, for example mapping ``Mary, ends with ie'' to ``Marie.''"

并附一条**恒等约束**：

> "For an utterance that is already suitable for writing, AgenticSR should return the input unchanged."

即：任务是**口语形式 → 书面形式**的转写净化，而不是知识补全、不是意图识别、不是对话。

### 4.2 架构：ASR–Refiner 两级

§Method / AgenticASR / AgenticASR System 首句（PDF 第 4 页）：

> "AgenticASR uses a **two-stage ASR--Refiner architecture**. The ASR front end produces a spoken-form hypothesis, and the LM-based Refiner transforms a text string derived from that hypothesis into clean written text that preserves final intent. **The Refiner is post-trained on pairs generated by the preceding pipeline and can be shared across ASR front ends.**"

- **离线推理**：`H = F_ASR(A)`，`Y = F_R(H)`，Refiner 在整句结束后一次性变换。
- **在线推理**：见 §4.3。

### 4.3 核心机制：有界 active context 的重复变换 + 输出跨度替换（流式修订）

摘要逐字（PDF 第 1 页）——**核心机制引用之一**：

> "AgenticASR implements this task through an ASR--Refiner architecture that **repeatedly transforms a bounded active context and replaces its corresponding output span as audio arrives**. This enables continual emission and revision over streams of arbitrary duration."

§AgenticASR System / Online inference 逐字（PDF 第 4–5 页）——**核心机制引用之二**：

> "At update $t$, the manager selects the current source span $C_t$ and up to $K-1$ preceding spans, concatenates their ASR text, and sends the resulting ordinary text string to the Refiner: $W_t = C_{\max(1,t-K+1)} \Vert \cdots \Vert C_t$, $\widehat{Y}_t = F_{\mathrm{R}}(W_t)$ … **The system replaces the previously emitted clean-text span associated with the selected source window by $\widehat{Y}_t$. When a later source span enters the window, the system repeats this operation on the shifted window, so new right context can revise an earlier local output.**"

补充的工程约束（同节逐字）：

> "A Chunk Manager uses these signals and sentence-final punctuation to identify stable source-text spans. To bound the text processed at each update, it **limits each span to $L=80$ characters**. If the limit is reached, the manager closes the span at the nearest preceding punctuation or at the limit when none is available."

> "**The chunks are scheduling units, not separate Refiner input or output slots.**"

> "We use $K=3$ by default. **The fixed window bounds the context and computation of each Refiner call rather than the duration of the audio stream.** … Text outside the selected source window is retained in the emitted transcript."

**机制要点归纳（三条，均有上引逐字支撑）**：

1. **有界**：每次 Refiner 调用的输入 = 至多 K 个源跨度（默认 K=3），每跨度至多 L=80 字符 → 计算量与音频总时长解耦。
2. **重复变换**：窗口右移即重跑，**同一段文本会被多次重新变换**，不是一次性提交。
3. **跨度替换**：新输出**覆盖**上一次为该窗口发出的 clean-text 跨度 → 已发出的文本**可被后到的右侧证据推翻**
   （teaser 图题注给的实例：`"Mary"` 在听到 `"ends with R-I-E"` 之后被改写为 `"Marie"`）。

这三条合起来即"流式修订"：**不是等整句说完再净化，而是边发边改**。论文对既有工作的划界句（PDF 第 1 页摘要）：

> "Existing spoken-to-written methods process completed audio or transcripts but **cannot revise emitted text when later speech changes how preceding content should be interpreted**."

## 5. 论文中的 "intent" 究竟指什么

`intent` 在 `arxiv.tex` 全文出现 **10 次**。逐条归类：

- **9 次为 "final intent" / "speaker's final intent" / "final intended message" / "final-intent-preserving"**，
  指**说话人在自我修正之后的最终意图内容**，是 AgenticSR 任务的正确性判据，而非可路由的离散类别。
- **1 次（第 182 行）为下游背景陈述**：`"In interactive agents, such artifacts can also propagate into intent detection and dialogue decisions"`
  ——这是在说"口语杂质会污染下游的意图检测"，**下游意图检测不是本系统的组件**。

逐字取一处（贡献列表，PDF 第 2 页）：

> "We define Agentic Speech Recognition (AgenticSR) as a **final-intent-preserving** audio-to-clean-text recognition task. Valid outputs **retain the semantic content of the final intended message**, make only evidence-supported edits, and pass clean input through unchanged."

再取一处（§AgenticASR System，PDF 第 4 页）：

> "…the LM-based Refiner transforms a text string derived from that hypothesis into clean written text that **preserves final intent**."

**结论**：本篇的 `intent` = **"说话人自我修正后要表达的最终内容"**，是一个**保真目标**；
它**不是**待分类的意图类别，因而本篇也不存在对它做分类或分派的环节。
（对照：2605.29430 中的 `intent` 是显式的三类离散标签 `{confirmation, new input, correction}`，并据此路由。两篇同词异义。）

### 6.3 关键消融

**在线窗口 K**（表 `tab:online-comparison`，PDF 第 7 页；前端固定 Qwen3-ASR-1.7B）：

| 设置 | Rephrase↑ | Latency (s)↓ | Explanation↑ |
|---|---|---|---|
| Offline（整句一次过） | 72.83 | 9.59 | 75.20 |
| Window K=1 | 36.17 | 11.28 | 19.43 |
| Window K=2 | 65.08 | 11.70 | 55.06 |
| Window K=3（默认） | 70.47 | 12.15 | 74.00 |

> "Moving from $K{=}1$ to $K{=}3$ raises Rephrase from 36.17 to 70.47 (offline: 72.83) and Explanation from 19.43 to 74.00 (offline: 75.20), while latency grows by just 0.87 s… **At $K{=}3$, the gaps to offline scores shrink to 2.36 (Rephrase) and 1.20 (Explanation).**"

机制解释逐字（同页）：

> "When VAD places a boundary inside a correction such as ``I want to go to Beijing <VAD> oh no, Shanghai,'' a single-chunk window processes the two fragments independently and **cannot retroactively revise the already emitted ``Beijing''**. With $K{=}2$, the prior chunk is concatenated before refinement, so the model recognizes the repair pair and correctly outputs ``Shanghai''."

**这段是本篇机制的最强自证**：K=1（无跨块右上下文）时 Rephrase 崩到 36.17，
说明其增益**主要来自跨块的回溯改写能力**，而非单纯的 LM 改写能力。

**Refiner 容量**（表 `tab:refiner-size-ablation`，PDF 第 7 页；前端固定 Qwen3-ASR-1.7B）：
Qwen2.5-0.5B-Instruct 78.76 → MiniCPM-5-1B 79.95 → Qwen2.5-4B-Instruct **83.42**（延迟 9.21 → 9.59 → 10.77 s）。
最大增益在 Format（+11.03）与 Rephrase（+5.83）。

**裁判可信度**：双盲、两位领域专家逐题对照，与 Gemma-4-31B-IT 的答案级一致性：
Spearman ρ = 0.8222 / 0.8064，二次加权 κ = 0.8313 / 0.7918（Qwen3-ASR-0.6B / 1.7B 两组）。

## 7. 训练 vs 冻结的分层（承重，防"training-free 先例"误记）

逐组件核定（依据 §Experimental Setup 与 §AgenticASR System 逐字）：

| 组件 | 具体模型 | 状态 | 逐字依据 |
|---|---|---|---|
| **Refiner** | MiniCPM-5-1B（默认） | **训练（全参数 SFT）** | "The Refiner was initialized from MiniCPM-5-1B… We used **full-parameter supervised fine-tuning for five epochs** with AdamW, a learning rate of $2\times10^{-5}$…"（PDF 第 5 页） |
| ASR 前端 | Qwen3-ASR-0.6B/1.7B、Whisper Base/Small/Large | **未训练**（直接使用） | "Qwen3-ASR-1.7B served as the default ASR front end"；架构节："The Refiner is post-trained… and **can be shared across ASR front ends**"；相关工作节把 FormalASR 划为对立面："FormalASR instead **fine-tunes Qwen3-ASR** to generate formal text directly from speech" |
| 数据生成 LLM | Gemma-4-31B-IT | 未训练（按阶段提示词调用） | "All LLM-based generation and quality-control operations use Gemma-4-31B-IT with stage-specific prompts." |
| 裁判 LLM | Gemma-4-31B-IT | 未训练 | "Gemma-4-31B-IT serves as the judge and selects one option for each rubric question." |
| rubric 生成 | Qwen3.7-Plus | 未训练 | "we evaluate each output using atomic multiple-choice rubrics generated by Qwen3.7-Plus" |

训练细节（PDF 第 5 页逐字）：

> "Using the data generation pipeline described above, we constructed **100,000 input--target pairs**, using **85% for training and 15% for validation**… On four NVIDIA H100 GPUs, training used BF16, gradient checkpointing, packed sequences, and a maximum sequence length of 1,024 tokens, with **loss applied only to target tokens**."

**判定（三条，须逐条随行下游）**：

1. **本篇不是 training-free 方法**。其核心组件 Refiner 经过 10 万对合成数据的**全参数监督微调**，
   任何把本篇登记为"免训练推理时控制"先例的写法都是口径夸大。
2. **但"冻结"确实成立于 ASR 前端一侧**：论文的分层主张是"Refiner 与前端解耦、可跨前端共享"，
   并以五个不同前端（两族、三个尺度）的表格作为该主张的证据。这是**部署层的骨干无关性**，不是训练层的免训。
3. **对照点**：论文自己把 FormalASR（微调 Qwen3-ASR 端到端产书面文本）设为对立面——
   两篇都训练，差别在**训练谁**（Refiner vs ASR 骨干）。论文在 §Main Results 给出的论据逐字（PDF 第 6 页）：

   > "Notably, both FormalASR variants scored lower on Pass-through than the API and AgenticASR systems at the corresponding scale. This result suggests that **directly post-training an ASR model for correction can bias it toward rewriting already clean utterances, thereby weakening transcription faithfulness and increasing the risk of hallucinated edits.**"

   该论据与表中 FormalASR 的 Filter/Rephrase 崩塌（36.51/13.29 与 40.59/15.70）互相印证。
   **注意其证据面是 pass-through 控制臂**——即 §6.1 记的那 129 条"本已书面化、正确行为是原样返回"的样本。
