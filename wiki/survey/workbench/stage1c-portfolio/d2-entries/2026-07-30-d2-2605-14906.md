## 1. 方法本质

构造 **789 题的多模态多轮会话长期记忆基准**，第一次在**同一批数据、同一套长度控制**下把
"长上下文 LVLM" 与 "记忆增强 agent" 两条路线并排评测。核心构造手段是**实体抽象**：先选图，再让
LVLM 写含具名实体的背景段，然后把段落里的实体替换成上位概念（"Golden Gate Bridge" →
"the bridge shown in `<image>`"），使**只有证据图能解引用**——由此关掉了 LoCoMo/Mem-Gallery 那类
"纯文本捷径"。证据事实被包进一个**与干扰会话同管线、同风格生成的完整证据会话**（而非直接插入裸事实），
再按时间戳随机插入干扰会话序列，用 MMLongBench 的跨模态计数方案物化成 32K/64K/128K/256K 四档。
五种记忆能力：IE / MSR / TR / KU / AR。20k 候选经自动过滤+三轮人评压到 789 题。
**本篇不提出任何 key-value 设计**——它测的是别人的 key-value 设计。

## 2. key-value 定位（本篇是"测量者"，不是"设计者"）

### 2.1 论文自己不建 key

MemLens 是评测集，没有索引、没有 key、没有 value schema。它的贡献是**给 key-value 装载失真提供了一把尺子**。

### 2.2 但它给出了读集内最干净的 key-value 保真度词汇：**写入期视觉形态 vs 作答期视觉形态**（Table 5）

| Agent | 骨干 | **写入期视觉**（进入 store 的形态） | **作答期视觉**（骨干能拿到的形态） |
|---|---|---|---|
| M3-Agent | Video LVLM (Qwen2-VL-7B) | 每会话一张**合成拼图** | 检回的会话拼图 |
| M2A | Native LVLM (Qwen3-VL-8B) | 原图 | **只有存下的 embedding** |
| M3C | Native LVLM (Qwen2-VL-2B) | 原图 | **只有存下的 embedding** |
| Mem0 / MemOS / MemAgent-7B / Memory-T1 | 文本 LLM | **只有 BLIP-2 caption** | 只有 caption |
| 直接 LVLM（对照） | — | — | **原会话逐像素** |

这张表把 R2 §2 的"问题三：什么装进 key、什么装进 value"变成了可测量的两栏。
**七个被评 agent 全部在作答期拿不到原像素**——这就是论文所说 "storage-time compression" 的物理含义。
**注意论文自己的诚实声明**：'Reported deficits relative to direct LVLMs therefore **conflate
adapter-induced visual information loss with retrieval and reading quality**.' 即"保真度损失"这条
归因在本篇是**被承认为混淆的**，只有两条隔离手段（M2A vs 同权重直推 Qwen3-VL-8B；Mem0/MemOS 骨干消融）。

### 2.3 单面 key 的能力选择性——本篇提供了读集内最强的一条经验证据（R2 未持有）

- **Memory-T1 = BM25 日期匹配的单面（词法/时间面）key**：TR 全场最高（62.50@32K，Table 13；
  正文另引 63.46），IE 却只有 18.03——论文原话："reaches high TR accuracy through BM25 date matching
  but falls well below direct LVLMs on IE, **substituting keyword retrieval for the visual grounding
  that IE demands**"。
- **M3C = LoRA 会话检索器**：78.1% 的错误发生在证据从未被检回（平均 recall 0.26）；
  **Mem0 / Memory-T1** 反之：recall 0.82–0.89，但 87–95% 的错误发生在检回之后。
  两种失败模式要求两种不同干预。
- **五种能力之间的 Spearman 相关低**（32K，34 个系统）：IE–KU 最强（共享"先定位证据图"），
  MSR 与 IE / AR 在所有长度上都弱相关。论文由此提出"证据检索轴（IE, KU）"与"聚合轴（MSR）"两条独立难度轴。
- **合起来 = "一个检索面只能服务一部分 query 类型"的直接读数**。这是 R2 §3.4 多面 key 假设
  最有力的间接支撑，而且它不是 R2 现有引文里已有的说法。

## 3. 主实验数字 —— 重点核"代价曲线"的度量

### 3.0 先定性：R2 说的"代价曲线"在本篇是**两条互相正交的失真轴，且成本轴不存在**

| 轴 | 自变量 | 是否被扫成曲线 | 因变量 |
|---|---|---|---|
| **长上下文退化轴** | 输入长度 32K / 64K / 128K（LVLM）、+256K（agent），MMLongBench 跨模态计数 | **是**，3–4 个点 | LLM-as-Judge 二值准确率（%） |
| **存储压缩失真轴** | 无自变量。压缩比/caption 器/嵌入维度**均未被扫**，只是"agent 的 adapter 是什么样就什么样" | **否**，是一次**水平比较** | 同上 |
| **成本轴（算力/延迟/费用）** | **不存在** | **否** | 全文唯一的成本数字：M2A 每题耗时约 **60×** 于直推（附录 `app:canonical195`）；API 总花费约 **4,500 USD**；判官调用约 **73,784** 次；8×A100-80GB + vLLM 0.17–0.18 | 

论文自己的结论句是 **"The two failure modes are orthogonal"**（§4.3），并明确说
"Because each architecture covers only one axis, scaling along that axis leaves the other failure mode
untreated"。**这是一张 2×2 的失效模式表，不是一条保真度/成本权衡曲线。**

### 3.1 因变量（y 轴）的度量定义

- **主指标 LLM-as-Judge (J)**：单一正典判官 **Qwen3-VL-235B-A22B-Instruct（thinking 关闭）**，
  读"题+参考答案+原始输出"出二值判定，按题型附加评判准则。
  防退化处理：>6,000 字符尾截断、>500 解析词自动判零、提示判官拒绝循环论证。
  可靠性：与 GPT-5.4-mini 在分层 800 题上 item 级一致 **96.40%，Cohen κ=0.93，模型级 Spearman ρ=0.97**；
  与三标注人共识在 484 题上一致 **93.60%，κ=0.86**。判官对 1–3 词短答有**宽松偏置**，
  附录用确定性规则重打分：**LLM 判官把闭式题准确率绝对高估约 5%**，但榜单 top 不重排
  （34 个 roster 的 ρ=0.78，top-10 重叠 7/10，LLM-top-10 内 ρ=0.82，top-5 两种度量下一致）。
- **辅助度量**：Substring Exact Match（SE，宽松）；**Coverage**（在 699 道可答题中尝试作答的比例）；
  **Per-Answer Accuracy（PA，只在尝试作答的题上算）**；三者关系
  `J ≈ (Cov × PA × 699 + AR_correct) / 789`（本件复算 GPT-5.4@32K：(0.6395×0.7315×699+88)/789 = 52.58%
  vs 报告 52.72%，差 0.14 pp，四舍五入内自洽）。
- 生成预算：直答模型 2,048 token，thinking 模型 16,384 token。

### 3.2 退化轴的具体读数（LaTeX 表体核对）

1. **Table 12（27 LVLM，n=789）**：32K 时 **top-8 落在 6.34 pp 带内**（58.68 Qwen3.5-122B-A10B
   → 52.34 GLM-4.6V，复算 ✓）——短上下文已不区分前沿系统。128K 时格局反转：
   **Qwen3.5-122B-A10B 58.68→45.50（−13.18）**、GLM-4.6V 52.34→39.04（−13.30）、
   Qwen3.5-9B 50.32→32.57（−17.75）；**Gemini-3.1-Pro 54.10→51.99（−2.11，全 LVLM 最小）**，
   Kimi-K2.5 54.88→51.99（−2.89）。**全场最强 LVLM 在 32K 也只有 58.68。**
2. **AR（拒答/幻觉控制）是最脆的能力**：GLM-4.6V AR 93.33@32K → 30.00@128K。
   **Table 19** 给 Qwen3-VL 全尺寸：235B-Instruct 97.8→92.2（−5.6）；**2B-Thinking 87.8→14.4（−73.3）**
   （截断的推理轨迹变成实质回答而不是拒答）。
3. **Table 13（7 agent，32K→256K，195 题子集）**：Mem0 31.79→30.77；MemOS 30.26→29.74；
   Memory-T1 28.72→29.23；M3-Agent 19.49→**23.59（反升）**；M3C 18.46→16.92；M2A 15.38→16.41；
   **MemAgent-7B 32.82→24.62（−8.20，正文"六之七在 ±7% 内"的唯一例外，复算 ✓）**。
   **长度不变性成立**，但绝对水平低。
4. **Table 15（同 195 题子集对照）**：Qwen3.5-122B 63.59@32K vs 最好的 agent 32.82 —— 约 31 pp 落差；
   同骨干对照 **M2A 14.21 vs 直推 Qwen3-VL-8B-Instruct 49.18 = 34.97 pp 赤字**。
5. **Table 3（跨模态消融，n=634 image-essential+supportive）**：给全证据时 GPT-5.4 **93.13**、
   Gemini-3.1-Pro **89.42**；**抽掉证据图后分别塌到 1.74 / 1.89（Δ −91.39 / −87.53）**。
   同表 MSR 在给全证据时达 **100.00 / 90.21**——即 **oracle 检索把 MSR 从 <45% 抬到 90–100%**，
   证明 MSR 的天花板是 **retrieval-bounded 而非 reasoning-bounded**。
6. **Table 20（骨干消融，32K，195 题）**：Mem0 架构内 Qwen3-8B 32.50 / gpt-4.1-mini 43.15 /
   Qwen2.5-7B 28.50（**Δ=14.65**）；MemOS 内 Qwen3-8B 34.00 / Qwen2.5-7B **36.50**（Δ=2.50，换旧骨干反升）。
   两个 Δ 都远小于 M2A 的 34.97 pp 架构赤字 → **管线架构主导，骨干次要**。
   同表另一条：Mem0+Qwen2.5-7B 的 AR 达 **100.00**，而 Qwen3-8B 只有 77.27 —— 骨干的拒答校准直接穿透管线。
7. **Table 16（Coverage/PA 分解）**：GPT-5.4 Cov 63.95 / PA **73.15**（拒答 252 题）；
   Qwen3.5-122B Cov **87.70** / PA 62.32（拒答 86）；Claude Sonnet 4.5 Cov 49.50 / PA 57.51（拒答 353，
   总榜第 23 但 PA 尚可）。**关键动力学：128K 时多数模型 Coverage 反而上升而准确率下降**
   ——"长上下文下占主导的是虚假自信，不是更谨慎"。
8. **错误分解（128K）**：IE 与 KU 近 **90% 的错误落在 Visual 类**（没找到/没读到证据图）；
   TR 的错误在 Mixed 与 Reasoning 之间；**MSR 唯一以 Reasoning 为主（73%）**，但结合第 5 条的 oracle
   诊断，论文判定这些"聚合错误"多是上游检索缺失的下游后果（"当模型只找到 6 个必需会话中的 4 个，
   它的计数必然错"）。
9. **RL/LoRA 记忆后训练毁掉拒答（R2 高相关）**：**冻结骨干**的 Mem0 AR 77.27、MemOS 68.18；
   五个对骨干做 RL/LoRA 记忆后训练的（M2A / M3-Agent / M3C / MemAgent-7B / Memory-T1）**塌到 9–22%**；
   **M2A 在与直推同一份 Qwen3-VL-8B 权重上 AR 只有 22.73，直推为 81.82**（Table 15 复算 ✓）。
   论文归因：现有记忆管线的 RL/SFT 奖励只优化答对与检索成功，**没有任何"拒答不可答问题也是对的"信号**。
10. **规模/家族对退化的影响**：22 个有完整 32K–128K 数据的开源 LVLM 上，参数量与
    32K→128K 保留率的 Spearman **ρ=0.62（p=0.002）**；Qwen3-VL Instruct 家族保留率 8B 0.71 → 235B 0.90；
    Qwen3.5 dense 4B 0.57 / 9B 0.65 / 27B 0.77。同等规模下家族差两倍
    （Qwen3.5-122B-A10B −13.18 vs Qwen3-VL-235B-A22B −5.57）。
11. **难题不随长度解锁**：32K 上被 <20% 模型解出的 280 道题，32K 平均 9.07%、128K 平均 8.52%。

### 3.3 本篇最值得学的三段"曲线可信性"审计（R2 可直接照搬）

- **单调性审计**：扫全部 27 LVLM × 7 agent × 5 题型 × 2 个长度跃迁，共 **72 处名义上升**
  （38 LVLM + 34 agent）；**Bonferroni α/72 = 0.0007 下无一存活**。唯一 p<0.05（未校正）的
  Qwen3-VL-2B-Thinking MSR 64K→128K（+5.59%, p=0.022, 9 翻正 vs 1 翻负）被追查为**退化输出假象**
  ——9 道翻正题里 8 道在 64K 撞了 2,048 token 生成上限。34 处 agent 异常全部归因于小样本（n=22–61，
  一题翻转 = 2–5% 摆幅）。
- **双向抖动**：21 个有三档判官数据的 LVLM 上，每一步长度跃迁同时**丢 60–150 题、得 30–80 题**；
  32K→64K 翻转的题里 **38.7% 在 64K→128K 又翻回来**。Gemini-3.1-Pro 在 64K→128K 两个方向各翻约 71 题
  （≈18% 抖动率），净降只有 1 pp —— **"抗长上下文"是抖动被抵消，不是静态稳固**。
  ⚠ **对 R2 的直接教训：单模型的逐档 delta 不是信号。**
- **构造有效性（证据会话与干扰会话不可区分）**：balanced 698/698、题分组五折；
  TF-IDF+LR **56.71% ± 1.20（AUC 0.59）**，DeBERTa-v3-base **57.92% ± 0.85（AUC 0.55）**，
  Cohen's h < 0.16；再做词表消融（移除 top-K 判别 n-gram，K=20…1000）准确率始终 54.77–56.71%
  ——弱信号是弥散的，不集中在可识别的风格标记上。
- **子集不确定性**：195 题上 1000 次自助重采样，7 个 agent 的 95% CI 半宽 **[4.87, 6.67]，均值 5.93**；
  四个文本/caption 管线的区间互相重叠且整体高于三个多模态管线（区间不重叠）。

### 3.4 内部一致性存疑项（引用时须避开）

1. **同配置跨表不一致（最多 3.74 pp）**：Table 13 的 32K 行给 Mem0 **31.79** / MemOS **30.26** /
   M2A **15.38** / Memory-T1 **28.72**；而 Table 20 的 default 行与 `app:agent_underperformance` 正文
   给 Mem0 **32.50** / MemOS **34.00** / M2A **14.21** / Memory-T1 **29.50**。两处均标注为
   "32K、195 题 canonical 子集"，未说明差异来源。**引 agent 数字时须指明取自哪张表。**
2. **Table 2 的规模自洽性可疑**：`Tokens/image ≈ 2,000` × `Images/instance 20`（32K 档）= 约 40K token，

   无法从本篇自证。**需在引用长度档位时加"按 MMLongBench 计数口径"限定。**
3. `app:agent_underperformance` 首句称 "agents trail LVLMs by 18–34% overall"，但 Table 15 上
   最好 agent 32.82 vs 最好 LVLM 63.59 = 30.8 pp、最差 agent 15.38 = 48.2 pp，区间上界与下界都对不上
   ——该区间的取值基准未说明。

## 4. DFS 四问

**方法**：实体抽象 + 同管线证据会话包裹 + 时间戳随机插入 + 跨模态 token 计数四档长度，
构造 789 题图必要的多轮会话记忆基准；在同一批数据上并排评测 27 LVLM（32K/64K/128K）与
7 记忆 agent（+256K），主指标为单一正典 LLM 判官的二值准确率，配 Coverage/PA 分解、
错误模态分解、检索归因分解、oracle 检索诊断、单调性审计与不可区分性验证。

**局限**：(a) **无成本轴**——"组织的代价"在本篇只有一处 60× 的定性提及，没有延迟/token/费用曲线；
(b) **压缩比不是自变量**——"存储期压缩失真"是七个 released adapter 的水平比较，论文自承其归因
"conflates adapter-induced visual information loss with retrieval and reading quality"；
(c) agent 只在 195 题子集上评（CI 半宽约 6 pp），且跨表同配置数字不一致（§3.4.1）；
(d) 全数据合成（GPT-5.1 演用户 / Gemini-3-Pro 演助手 / Gemini-3-Pro 生成 QA），
生成器与被测者同族（intra-family generator familiarity，论文自列为 limitation）；
(e) 文本 agent 一律吃 BLIP-2 caption，**caption 器质量成了视觉信息上界**，论文承认换更强 captioner
可能改变结论；(f) 单一判官，且已知对短答宽松（绝对高估约 5%）；(g) 每格只跑一次（无种子、
无逐格二项 CI，理由是判官调用总量已 73,784 次）。

**改进空间**：把压缩强度做成自变量（caption 长度 / embedding 维度 / 保留像素比例扫描），
才能把水平比较变成真曲线；把成本记账（延迟、token、$）与准确率并排报，才有 Pareto；
补一个"保留原像素的检索期回看"臂（论文明确说"a pipeline that retained pixel-level evidence at
retrieval time … might score higher"）——**这个臂正是 2605.16481 的 VAM 在视频域做的事，
两篇拼起来才构成完整对照，但没人做过跨两篇的统一实验**。

**可借鉴（对 R2）**：① Table 5 的**写入期/作答期两栏**——R2 §2 问题三的现成表达式；
② **oracle 检索臂**（只给必需会话，MSR 90–100%）与 R2 的 gold-evidence 臂同构，
且提供了"上界臂如何反证 reasoning 不是瓶颈"的论证模板；③ **检索归因分解**
（recall<0.5 判为检索失败，其余判为理解失败）——纯离线、可算，直接可用于 R2 的 K5-r 读数；
④ **Coverage/PA 分解**把"检索能力"与"校准"拆开，且给出 `J ≈ (Cov×PA×699+AR_correct)/789` 的
可复算恒等式；⑤ **单调性审计 + 双向抖动 + 不可区分性分类器 + 自助 CI** 四件套是曲线可信性的完整防线；
⑥ **一条对 R2 立论极有利的读数**：冻结骨干保住拒答（77.27 / 68.18），
RL/LoRA 记忆后训练把拒答打到 9–22%（同权重 22.73 vs 81.82）。

### 深读后新增、R2 应该知道的事实

1. **本篇的结论句是对 R2 方向的直接背书**：摘要与结论两处都写"These results motivate **hybrid
   architectures that combine long-context attention with structured multimodal retrieval**"，
   并把"visual-evidence retention and retrieval, rather than raw scaling of either context or memory"
   点为首要瓶颈。R2 §3.2 的轴结论可以直接引这句，比现在的转述更有力。
2. **单面 key 的能力选择性——R2 多面 key 假设的最强间接证据（R2 目前没有这条）**：
   Memory-T1 的 BM25 日期面 key 让 TR 登顶（62.50）而 IE 垫底（18.03），论文原话是
   "substituting keyword retrieval for the visual grounding that IE demands"；
   GLM-4.6V 领先 TR 而 KU 崩；五能力间 Spearman 相关低，论文据此提出"证据检索轴 vs 聚合轴"两条独立难度轴。
   **"一个检索面只能服务一部分 query 类型"在此有跨 34 个系统的读数支撑。** 建议提升为 §3.4 O2 的立论证据。
3. **训练环节：本篇零训练**（纯评测），但它测出了一条对 R2 TFRL 框架极有利的因果读数——
   **冻结骨干保住拒答、记忆后训练毁掉拒答**：Mem0 77.27 / MemOS 68.18（冻结）vs 五个 RL/LoRA 系统 9–22%；
   **同一份 Qwen3-VL-8B 权重上 M2A 22.73 vs 直推 81.82**。论文的机制解释是"奖励只优化答对与检索成功，
   没有'拒答不可答问题也是对的'信号"。这同时支撑 R2 的两件事：(i) 训练自由不是妥协而是保留了校准；
   (ii) R2 的 abstain support 必须进组织 schema（R2 §3.2 已列该字段"逐字段为零"，本篇给出了后果）。
4. **oracle 检索臂的论证模板**：给全证据时 MSR 达 100.00（GPT-5.4）/ 90.21（Gemini-3.1-Pro），
   而全基准上 <45% —— 论文由此判定天花板是 retrieval-bounded 而非 reasoning-bounded。
   这与 R2 已持有的 Omni-DeepSearch oracle 分解（gold-entity 50.00）是**同一论证形状在视觉域的复刻**，
   可作 R2"检索层 headroom 与推理层 headroom 可分离"的第二载体。
5. **Table 5 的"写入期/作答期"两栏**是读集内对 R2 §2 问题三最贴合的表达式，建议直接借用这对术语。
6. **R2 不能用本篇支撑成本/Pareto 类主张**（§3.0）。若 R2 需要"组织有代价"的量化，
   现有读集内最好的两个来源是：2605.16481 的能力重分配读数（Overall −2.07）与本篇的 60× 延迟提及。
7. **曲线可信性四件套**（单调性 Bonferroni 审计 / 双向抖动 / 不可区分性分类器 / 自助 CI）
   是 R2 O 臂读数报告可直接照搬的防线；其中**双向抖动**给出一条纪律性教训：
   单模型逐档 delta 不构成信号（38.7% 的翻转会翻回来）。
8. **一条待抓线索**：本篇评测的 M3-Agent 引自 `long2025seeinglisteningrememberingreasoning`，
   在相关工作里被描述为 **"entity-centric audio-visual memory"** —— 这是读集内最接近
   "含音频面的多面记忆" 的系统，且在本篇里位列最差档（19.49–23.59）。
