# R2 开题报告：语音任务中的知识系统——门控 agent 底盘上的 key/value 建模、组织与使用

## §0 一页摘要

**方向陈述（三层归位）**：**研究主题=知识**——语音任务中知识的 key/value 建模、组织、
供给与使用，及其基于任务效果的 training-free 端到端优化（TFRL）；**底盘=继承自文本域的
成熟 agent 架构**（ReAct/Reflexion/DeepAgents 谱系），我们的动作是把它**门控化**；
**战场=语音任务谱系**（从音频理解、口语问答到外部知识深搜，六族任务矩阵，§5.1）。

**核心主张（capability-first，三臂可判）**：在实体/知识密集的语音任务上，**"语音内容
知识 + 冻结 omni 核"的任务效果上界超过"专用 ASR + biasing/GER"管线**（主判据=效果绝对
提升；成本九维透明记账、不进主判据）——omni 核出原生语义能力，知识系统补核的三个已知
短板（实体：发音库+世界知识；副语言：面 key 联邦；长时程：T2 库），门控环把两者缝合。
判定=三臂对照：omni 裸核（下界）/ ASR+biasing-GER（incumbent，必须赢的对手——可运行组
正面交锋、不可运行组作结构对照；GER 支的可运行对照在组④/⑤载体侧、主载体上作结构对照，
边界与分组见 §5.1/§8）/ omni 核+知识系统（主张臂，
**运行时 ASR-free**：运行时不产生任何 ASR 转写、算子池 ASR 算子在主张臂配置下停用——
与 FC 参照臂的唯一差别即此；能力上界主张只能由该臂承载）。**主张级悬置一项**：双源
机制主张以核通过探针稳定性预检为前提（不过则记待定，§6.1/§7）。**载体身份已冻结**（主=
Earnings21 官方全集、复制=TED-LIUM3、诊断=PRISM 词典协议、组④对照=LibriSpeech+Rare5k，
§5.1；判据数值与效应量待 Stage-2A 第零步本核余量检定后 power 预注册——§7④ 与 §5.3
回退梯兜底，数值预注册前判据不判）。**主张级条件降级条款另有三处**（§6.1/§6.2/
§7）：裁决能力预检不过→架构主张暂停；核裸语义差距超阈→K-NB 降级理解任务限定；FC 参照臂或
组④ trained 上界对照下主张臂不及（不及口径统一见 §7 K-NB）→改判"增强"。**反向先验具名（两条）**：①同一检索候选下专用 ASR 核胜过 LLM 核（RECAST 载体；注入接口
不同，全口径见 §8 反向证据登记）；②主载体上强冻结核零上下文（Whisper large 7.98）双指标
优于弱核+oracle 偏置全谱〔规模差 21.7×；实体面 oracle 仍胜 6/8——如实成对引〕——知识层
可主张余量须在本核上重测（§5.1 第零步 gate 动机）——
能力上界主张为待验假设、载体限定，由 K-NB 在选定载体上行使判死权，Stage-2A 前不外推。**机制核前置检定**：冻结黑盒声学 key 在同预算
下不优于语音学检索基线→机制核改挂"语音学检索+世界知识 rescore"、声学 key 退可选（§2.3
阶梯首级=门控前实验，中止规则预注册）。**独立性现状如实**：合取前三分量（API-only/
training-free/文本侧外显 rescore）已被 RECOVER 单件占据——新颖性承重腿=双源动作选择
（门控选择性重解析+按样本调度）及其与 rescore 的耦合（§1.2/§8）。（判据级同族条款——K4 载体形态、K5 非语义槽载体、
K-PS 机制核降级、K-RL 方法命名、K-XOVER 价值窗口——见 §7，不在摘要重复。）

**三角色统一架构**：

```text
门控环（确定性触发电池 + V̂ 调度 + 准入门；TFRL 调参）——唯一调度权
  ├── 统一知识系统（研究主题）：对外一个查询接口，对内自决存量 or 现算——
  │     实体发音库（声学 key→同音候选 value）、T2 音频库（静态粗召回+动态细加工）、
  │     面 key 联邦（语义/情感/说话人/事件/时间锚）、世界知识接口；
  │     现算后端=冻结专家算子池（ASR/emotion2vec/说话人/事件/TTS/DSP，默认不跑、按需调用）；
  │     切片/面装载/融合权重/物化边界 = TFRL 优化的配置空间
  └── omni 裁决核：在"候选区已准入的证据 × 假设集"上裁决与作答
        （三不：不规划〔架构选择〕、不自省发起、不垄断感知——后两项有预检电池背书 §6.1②①）
```

**运行范式**：门控化的**查询-裁决环**——一切动作（重听=查输入流、重切=查知识邻域、
检索=查外部、发音匹配=查发音库）都是对统一知识接口的**假设条件化查询**；何时问、问什么、
问多深由外置确定性门裁决（模型零自省）；一切查询输出落候选区、经准入门才进核上下文
（结构防爆总则）。

**任务三阶段**（三个研究问题簇+一个联合评价面，非时序串行）：

| 阶段 | 核心问题 | 章节 |
|---|---|---|
| 阶段一：谁搜索谁 | query 如何进入知识的地址空间？实体发音库机制核；个性化 | §2 |
| 阶段二：知识如何组织 | key 建模（切片×面×表示）与 value 建模；统一接口与两层绑定；TFRL 任务优化 | §3 |
| 阶段三：知识如何使用 | 门控查询-裁决环：双源触发、定向反思、准入与裁决 | §4 |

**研究纲领：效果优先**——主判据=相对最强基线的效果绝对提升；成本九维记账不设限；等预算/
Pareto 归后期。**Harness 学说**——每个 harness 组件带消融开关+蜕壳条件（model eats
harness）；可吃性分层：感知 harness 会被吃、门控部分被吃、**知识层护城河=带范围的可证伪
命题**：在动态/私域/可审计信息分布上，外置知识对当前冻结核存在正 oracle headroom（参数
边界使然——世界事实晚于训练截止、时效、出处审计；文本域 RAG 在模型规模化中存活=同型
先例而非结构定理），headroom 消失则对应组件蜕壳——**护城河钉在知识层**，恰是研究主题
所在。

**红线**：不修改任何模型参数；不为本任务新训练任何模型；不新增 LLM 代答（最终作答权在
冻结 omni 核）；**克隆边界（第四条）**——音色克隆 enrollment 仅限当前会话内当事说话人的
任务音频、不跨会话留存、克隆输出仅用于内部 key 合成比对、永不生成对外播放语音、不涉第三方
PII 合成（§2.4）。工具级冻结组件（已发布检查点的 ASR/音频向量模型/TTS/判官/DSP/搜索引擎）
可用。**双门前置**：能力预检电池=Stage-2A 第零步（§6.1）；载体判定=先导数据集构造+现有
载体矩阵（§5）。判死永不在无分辨力的载体上宣布（灵敏度前置+回退梯，§5.3/§7）。

## §1 研究背景与问题定义

### §1.1 任务结构与两段式

R2 面向的任务因果链：**音频观测 → 音频语义假设 h（槽型任意：实体/事件/情感/说话人/声学
场景/音乐属性）→ 以 h 为钥匙的知识 → 有依据的回答**。知识检索是两段式：**定位**（key 的
职责——key 是地址不是副本，压缩即抽象，只需保留可判别面）→ **提取解析**（模型对 value 的
职责）。读集实证支撑两段拆分：SpeechRAG 检索侧几乎无损（0.9702 vs 0.9707）而生成端崩溃
（EM 0.3522 vs 0.7514）——定位成功、解析失败；Pi-Serini 的 surfaced 94.7→behavior 58.9
级联——证据在上下文里≠被使用。

### §1.2 音频特有机制与"why now"

**误差面（听错/判错）**：外部检索的 query 依赖可能听错的音频假设——把 Meyer 听成 Mayer，
检回的证据彼此一致、来源可信、条条锚在错误实体上，"多搜"反而把错误假设佐证得更牢
（Omni-DeepSearch A.6 over-search 轨迹；oracle 分解 entity-only 33.76/端到端 43.44/
gold-entity 50.00，仅 Gemini-3-Pro 口径、实体槽证据）。**结构面（同音异形）**：局部声学
片段自身不携带确定身份——ASR 的历史教训是身份由序列上下文与先验知识联合裁定（候选生成+
lattice 解码+LM rescore 的系统级方案）。

由此得本方向的机制核心：**把经典 ASR 三件套（声学模型-发音词典-语言模型）以开放知识系统
重新实例化**——声学 key（冻结编码器）扮演声学模型、实体发音库（声学 key→同音候选 value）
扮演发音词典、**LLM+外部世界知识扮演语义层 LM**（rescore 感知假设：世界上存在 Meyer 会议、
不存在 Mayer 会议）、门控 agent 环扮演解码器；且加入经典 ASR 没有的维度——说话人/情感等
面作为**索引维度**（经典 ASR 把说话人当噪声归一化掉）。**Why now（四使能件交集）**：能做
reasoning 级 rescore 的冻结 LLM（2023+）、成熟冻结专家编码器阵（emotion2vec 等）、agentic
控制范式（音频域 2026 起步）、评测端首次奖励分面理解（读集内〔cut 2026-07-30〕，omni
基准 2025+）；外加三个社区
（ASR 盯 WER/agentic 在文本/omni 做对齐）的目标函数都不指向该交点。类比：RAG 把知识从
LLM 权重外置；本方案把"发音→身份"映射从 ASR 权重外置——**实体层的 RAG-for-ASR，加分面
与 agentic**。具名近邻十七件已一手核验入 §8 矩阵（逐件训练态/信息访问边界；对该线的全称
概括退役；含主载体谱系三件与重扫描二件——RECOVER 单件占前三分量、新颖性承重腿=双源
动作选择，§8）：发音库的结构先行者=PRISM（TTS 逐实体建声学记忆、training-free 但白盒）；
biasing 线已有黑盒自动上下文发现（Siskos 一系）与免重训练关键词检出（WCTC）；GER 线已有
检索增强形态（RAC/DARAG——RAC 为本件内代称、其文未自命名；纯文本后处理、回不到信号）。**十七件无一同时满足全部四分量；RECOVER 单件已占前三——增量
锚在第四分量「双源动作选择」及其与 rescore 的耦合**（§2.3/§8）。2023 时代近邻的
承重前提（模型无法在上下文原生消费候选词典、须把 key 打进内部状态）在 2026 冻结 omni 核
上是否仍成立，本身即 Stage-2A 复现先行的重审对象（§8 重审条款）。

### §1.3 概念词典（件内自足）

**三形式（按被改变的系统对象互斥划分）**：**组织**——知识以什么单元/schema/关系/索引/
版本/出处存在（语料库、chunk/schema、索引、快照）；**供给**——何时取、从哪取、以什么
query 取、取多少、何时停（query 构造器、检索器、规划器、预算/停止策略）；**使用**——已
取回证据如何被接纳/融合/冲突处理/归因/拒用（准入、grounding、仲裁、abstention）。**两道门**：采集门（未见输出，决定买不买调用）≠准入门
（已见输出，决定进不进核上下文）。**四类信息作用**：①外部新信息（研究对象）②对已有观测
的重表达（重听属此类）③潜在知识激发（归 R1/R6）④验证与出处。**知识/记忆二分（作者性
判据）**：世界写的=知识（R2）；系统自己从 episode 写出的 revised lessons=记忆（R3）；
R2 只以 dev 预注册冻结先验消费记忆类信息，在线写入归 R3。**信息角色边界**：主张只覆盖
"外部新信息有边际价值"的实例分布；T1 主载体（深搜线）按构造满足（过滤删除可直答样本），
NB 主载体的信息角色由闭卷探针读数界定（§5.1 污染协议），负类实例由
先导数据集按构造标注（§5.4）。

### §1.4 主张对象、红线与反还原不变量

北极星=system-level 任务能力，作答权在冻结 omni 核。红线四条见 §0。**反还原不变量**
（防"这只是 ASR rescoring"）：①目标函数永不含通用朗读语音 WER（实体/
知识密集集的实体准确率与该集 WER 可入榜）；②动作空间必须含无 ASR 类比的动作（定向重听、
按面重加工、双源比价）且其贡献可消融；③运行时 ASR 是 **harness 实验轴**而非身份——前向
通道 {omni 单通道 vs ASR+omni 双通道} 由实验裁决，系统身份由知识系统+门控环承载（被 TFRL
优化、被消融归因的部分）；**身份与主张分层**：系统身份=通道无关，能力上界主张的承载臂钉
ASR-free（§0）——前者管系统是什么、后者管哪个臂可立哪句话，不同层不互斥。**Harness 学说**：每个 harness 组件登记消融开关+蜕壳条件（核在
预检电池某项超阈值 X 后该组件应可摘除且效果不降——**超阈组件的蜕壳可当期验证；未超阈
组件的条件只登记、本阶段不验证**）；可吃性分层与知识层护城河见 §0/§8。

### §1.5 前置三问分型

**问题一：value 本体在哪（T1/T2，实验可行性分型）**——T1：value 在开放 web/文本（两个
现有主载体）；key 空间归搜索引擎，杠杆只在 query 侧；T2：value 本体是音频/受控库（锚数据
集与先导数据集）；key 表示才是可设计对象。跨分型不互推。**问题二：key 用什么表示**——由
冻结编码器联邦决定，选型判据=面的不变性/区分性需求（§2.4）。**问题三：什么装进 key、什么
装进 value**——key=可被检索的信息面（定位面设计），value=被检回内容的承载形态与合同
（组织层对象——形态服从使用端合同，但"如何被使用"的机制归使用层，§3.4/§6.2 三层接口）。

### §1.6 双门前置

**门一（能力门）**：模型是否具备预期的工具调用/裁决能力不作假设——能力预检电池=Stage-2A
第零步（§6.1），**测量并路由**：核的选择与前向通道配置由读数决定，且预检不过有明确后果
（探针不稳→探针系信号禁用、双源主张记待定；裁决能力不过→裁决核公理不成立、回 owner
重议核选择——路由全表见 §6.1/§7 K-Gate）。**门二（载体门）**：是否有现成数据集承载
验证——逐阶段判定（§5）：阶段三 T1 载体存在但方向性（先分析基线再扩展）；阶段二非语义面
主张无现成载体（先导数据集构造，§5.4）；**能力上界主张（NB）的战场载体身份已冻结**（四件套见
§5.1；判据数值待 Stage-2A 第零步余量检定后预注册，预注册前 K-NB 不判）。两门的答案都进报告正文，不作
暗默前提。

## §2 阶段一：谁搜索谁——映射、实体发音库与个性化

### §2.1 映射矩阵（读集内选项全景）

| query 模态 | key 空间（value 形态） | 代表工作 | 状态 |
|---|---|---|---|
| 文本 | 文本稀疏/稠密向量 | DPR 2004.04906 原理（key=E_P(标题⊕正文)，value 的确定性函数、单面） | 成熟 |
| 音频→文本 query | 搜索引擎自有 key | AudioRAG 2602.10656、Omni-DeepSearch 2605.08762 | 语音域现役（T1） |
| 文本 | 音频段向量（adapter 对齐） | SpeechRAG 2412.16500 | 研究线（T2） |
| 语音 | 语音向量 | SpeechDPR 2401.13463 | 研究线（T2） |

### §2.2 T1 的映射瓶颈与多假设 query

T1 上唯一可行路径=音频理解→文本 query→搜索引擎，瓶颈在 query 构造建立在可能听错的假设上。
杠杆=**多假设 query 构造**：候选假设并行发查、检索结果反向佐证假设（corr(e,h)，§6.3）。
跨域先例（红线内、确定性）：OK-VQA 的 ArticleNet 配方（内容词∪检测器标签→1/2 词组合枚举
→top-1 文章→规则抽句），语音同构=ASR 内容词∪面标签。

### §2.3 机制核：实体发音库

**构造**：从知识源拉实体清单→G2P/TTS 合成标准音（"国标发音"参考系）+**口音变体族**
（主要口音原型，方言学文献记录的系统性音变=世界知识）→冻结编码器产声学 key→库。key 为
**多假设 N-best 式**（不在建库时定案身份）。**查询**：疑似听错 span 的声学表示→检回同音/
近音候选实体集（value）→**世界知识 rescore 裁定**（哪个候选在世界中真实存在且语境相符）。
**范围钉死**：实体/术语层——通用逐字转写归冻结 ASR 工具（反还原不变量①）；中文同音字
密度使库价值更高。**与具名近邻的 prior-difference（逐篇矩阵见 §8）**：结构先行者
PRISM（EMNLP 2023）已做"TTS 逐实体→声学 key-value memory→推理期 kNN"且 training-free，
但需白盒读取 encoder/decoder 隐状态——在 API-only 冻结 omni 核上不可运行；且无世界知识
rescore、无口音变体/个性化轴、非门控动作空间的一员。本库增量=合取（收窄口径）：**API-only 黑盒声学
key × 与声学假设耦合的世界知识 rescore〔文本侧闭表 rescore 已被 RECOVER 占据——本方案的
rescore 服务于双源裁决、与重听动作耦合〕× 门控查询动作（按样本双源选择——新颖性承重腿）
× 口音/个性化 key 族**——
发音库在此定位为 agentic 搜索/工具调用与使用的能力建设组件，机制核身份由合取承载。GER
检索增强形态（RAC/DARAG）为纯文本后处理、回不到信号；本方案反思时握原始音频重注意权
+发音库+世界知识。**检索层对照阶梯（入 K-PS 域）**：字面/别名匹配 → G2P/音素编辑距离 →
PRISM 式合成语音记忆（白盒参照上界）→ 冻结声学 key（本方案）——**阶梯首级=门控前实验（带中止规则）**：冻结黑盒声学 key
的同音候选命中率在同预算下不优于 G2P/Double-Metaphone 编辑距离基线→机制核改挂"语音学
检索+世界知识 rescore"、声学 key 退可选（§0 已具名；中止规则预注册）。**两条近邻自证的
必要性证据（D2 源核）**：PRISM 纯声学索引臂实体错误改善而整体 WER 崩溃（作者归因缺语言
语境）——声学 key 需要语言/世界侧裁决者；BR-ASR 最好配置的检索结果 58.4% 仍为同音干扰
（按其 D2 复原式口径；原文公式不可复算）——读集内该线最强训练实现仍未把同音裁决从嵌入
空间分离出来，恰是世界
知识 rescore 的空位。**术语消歧**：PRISM 文中的 "rescore"=束搜索内的分数回退机制，
与本方案的世界知识 rescore（外部事实裁决感知假设）非同一构念。**钳形风险与价值窗口**：
API-only 边界下本方案的注入通道即 prompt——大词表端有全表注入灾难先例、小词表端有
in-context 注入击败声学记忆的先例（两侧均见 §8）——机制核的价值窗口须由词典规模扫描
（DICT-SCALE 臂，§6.2/§7 K-XOVER）实证存在，不预设。

### §2.4 个性化三件套（声学空间被说话人扭曲的对策）

①**对偶选型**：发音面 key 用说话人不变性编码器（对齐损失丢说话人信息在此恰是 feature），
说话人面 key 用区分性编码器（ECAPA 类）——同一"缺陷"在两个面分别是 bug 与 feature；
①′**归一化前置梯级**：更廉价的说话人归一化/会话内对比归一化先行，仅当其在口音分层上
失敏且克隆 key 有独立增益时才升级到③——P13N 臂序即此升级阶梯的实验化；
②**变体族 key**（静态层，见 §2.3）；③**查询期个性化 key 合成**（动态层）：冻结零样本
音色克隆 TTS 以当前说话人会话内音频为 enrollment，把候选实体的标准音与显式口音/音变族
发音合成于当前音色→个性化声学 key→与实际发音匹配（把标准音推进说话人空间，而非把说话人
拉回标准空间）。**机制边界如实**：零样本克隆传递的是音色（及至多泛化韵律），发音变体来自
显式 G2P/音变模型（§2.3 变体族）而非克隆——克隆不携带该说话人的个人发音习惯，个人发音
档案归 R3；辅以会话内对比归一化。**克隆的伦理与授权边界**：enrollment 音频仅限当前会话内当事说话人的任务音频、
不跨会话留存（留存即入 R3 且需另行授权）、克隆输出仅用于内部 key 合成比对、永不生成对外
播放的语音内容、不涉第三方 PII 合成——**已升 §0 红线第四条**，并写入 authorization 合同（§9）。**R2/R3 界线**：
会话内瞬态说话人画像=R2；跨会话个人发音档案（revised lessons）=**R3 第一用例**。
**范围**：同语言口音变异可解；跨方言系统出界。

### §2.5 阶段一实验落点

A1（gold-entity ceiling，实体槽实例）与 A1′（gold-evidence 双读数：naive/masked+泄漏
占比——A-OKVQA 实测天真增益 60–71% 是答案泄漏）把映射损失与使用损失分开；发音库检索层
读数（同音候选命中率）独立报告；多假设 query 为供给侧 BASELINE VARIABLE。

## §3 阶段二：知识如何组织——key/value 建模与 TFRL 任务优化

### §3.1 文本域组织演进（D2 源核版）

**原理基座（pre-2024 时效例外）**：RAG 2005.11401 确立**外挂非参数记忆原理**——参数记忆
（生成器权重，原文中 BART 是联合微调的，"冻结生成器"是常见误读）与非参数记忆（稠密索引）
分离，索引可整体热替换：原文实测换任领导人索引后，与新索引同期的问题答对率 70%/68%、答出
错配旧答案的仅 12%/4%（82 题单模板单模型探针、同编码器同 schema 整索引替换，边界如实）；
它还在 2020 年就试过并放弃了"不检索"机制（null-document 三种实现全无增益），且观察到模型
用固定文档做 **no-op 检索伪装不检索**——该失效形态本方案在 §6.5 主动检出。DPR 2004.04906
确立稠密检索：两个训练对齐的编码器把文档与 query 映入同一空间、近邻即检索；其 key 是
value 的确定性函数、每 value 恰一个单面 key——"为同一 value 造多个信息不同的 key"要到
2024 年图/摘要索引一系才出现。ROME 2202.05262 证明参数中的事实**可直接编辑**，但编辑后
模型会编造貌似合理而无证据的新事实——知识外置的根本理由在**证据与出处**，不在可更新性。

**2024 年后的演进**：GraphRAG 2404.16130 在索引期用 LLM 预构建实体图+社区摘要，把跨文档
聚合前移到组织期——这是 **value 侧的层次化**（评测管线内没有摘要级 key 匹配，key 侧升级
被论文列为 future work）；其主语料之一是约 1M token 的 **Podcast 转写**——图组织已在口语
转写文本上验证过，但声学/副语言面零进入 key 或 value，文本域的组织升级止步于转写层。
HippoRAG 2405.14831 用名词短语图+PPR 实现**在线单跳成本**的多跳关联（省的只是在线侧、
离线索引反而更贵——成本从查询期搬到索引期）；其 uncertainty-based ensemble（阈值触发概念
面与稠密面分数融合）是文本域"多面 key+权重融合"的先例；其错误归因给出关键量化：**48% 的
失败源于 query 侧 key 只保留实体、丢弃上下文信号**——静态时刻决定保留什么，就在静态时刻
埋下失败。LightRAG 2410.05779 把索引产物换成逐节点/逐边 (K,V) 对、双层 key+双路 query
路由（构建成本无对比数字；D2 证据权重降级——directness 维度被删且被注释数字显示其上全面
落后朴素 RAG）。Pi-Serini 2605.10848 只调 BM25 的 k1/b 两参+扫检索深度，就把 surfaced
证据召回推到 94.7–95.8%——**组织升级的收益必须对着调优稀疏基线验证**；其调参方向明确归因
于长文档域，短 passage 语料只搬程序不搬数值；其 surfaced 94.7→previewed 73.6→behavior
58.9 级联是"检索召回不转化为使用"的独立证据。**记忆支线**（A-MEM 2502.12110/MemRL
2601.03192/Decocted 2604.04373）组织的是系统自产经验，按 §1.3 二分归 R3，此处只借四条
纪律的形状：逐条效用记账、蒸馏修正优于原始记录（revised lessons）、检索相关性提高时任务
效果非单调、对称调参（headline 不得只给自家臂调参）。

### §3.2 视觉域组织演进（D2 源核版）

Wiki-LLaVA 2404.15406 用两层**串行** key（冻结 CLIP 图像向量匹配 wiki 标题、再由
Contriever 以问题检 600 字符 chunk），并自测出两个对本方案关键的读数：带检索反而净负
（26.4 < 无检索微调基线 28.5，且检索条数增加单调劣化），以及**微调的能力代价——
MME-Perception 从 1513.3 跌到 802.8（−47%）**，是"不动参数"红线最有力的跨域证据。
EchoSight 2407.12735 把第一跳换成同模态图像向量 key（击败图像→实体名文本路线：检索 R@1
13.3/36.5 vs 3.3），并**对同一 section 并置视觉面与多模态面两个 key、以全局常数 α=0.5
线性融合**——多面 key 概念在视觉域 2024 年已落地；其 oracle 三级阶梯相对实测的可恢复余量
达 48.1 个百分点。VAM 2605.16481 是 training-free 的在线层次视觉记忆，**已实现跨模态多面
key 与 query 面路由的工作代码**（planner 按 sources⊆{frame,event,summary} 选面）——但
**无融合规则（两面分数的组合从未指定）、零消融，且其 Limitations 自陈缺副语言/音频态面**。
GranuRAG 2605.15019 的"两级证据"实为两份 value 无条件拼接（scene 级 key 只在构造附录、
评测管线未运行），作多粒度意识定位、不作多层 key 证据。MemLens 2605.14906 给出**面特化的
最强实证**：单一词面 BM25 key 在时序检索轴登顶（62.50）而在实体消歧轴垫底（18.03），34
个系统跨类型相关性低——"key 的面决定它能检回什么"有了直接证据；同时其冻结骨干保
abstention（77.27/68.18）vs RL/LoRA 记忆后训练把 abstention 摧毁至 9–22%，是 TFRL 的又一
支持读数。（本段 VAM/MemLens/MementoGUI 属记忆类载体，按 §1.3 二分只作组织/供给形式的
形状借用。）**空位结论**：多面 key+面路由**概念已被占**（EchoSight/VAM）；读集内仍空的是
**音频/副语言面、query 自适应的确定性融合规则、面级消融**三处——语音域 O-config 臂的
增量钉在此三处。

### §3.3 语音域现状

检索线三篇：组织 schema（版本/出处/冲突/引用/abstain）逐字段为零；每 value 一个单向量
单面 key。agentic 线两篇：无持久组织、开放 live web、无快照无落盘（golden_path 仅实体名
链、480/640，trace/* 160 条无该字段——本地实测）。图/层次索引、多面 key、多粒度、面级
消融：语音域读集内全部缺席。

### §3.4 阶段二研究内容：key/value 建模三问 + 统一接口 + TFRL 优化

**问一：key 如何建模**——三子维设计空间：**切片**（单元边界/尺度：定长窗/VAD/说话人轮次/
事件边界/多尺度；VAM 的 Otsu 自适应边界=training-free 在线切片先例；专家模型的窗长需求使
切片按面而异）×**面装载**（哪些信息面进地址空间：语义/副语言/说话人/事件/**时间锚**——
时序不是独立灾难，分解为 key 面/出处字段/动作区间参数）×**表示**（冻结编码器选型；每面
过**可检索性前置检定**——emotion2vec 类非检索目标训练，不过检定的面不入对照；近邻实证：
Siskos 线更换现成文本 embedder 在 Earnings21 上使增益塌 69–81%〔TED-LIUM 上仅约 24%，
载体相关〕，检定非空转）。key 为
多假设式（§1.2 结构面）。

**问二：value 如何建模**——value=被检回内容的承载形态建模（组织层：形态决定使用层能做
什么；使用机制本身归 §4/USE 层），形态（标签/句子/语音段/
图）服从使用端合同：冻结核要能解析（omni 核可原生消费音频态 value——对文本核级联的预测
优势）、准入门要能判断（出处+佐证标记）、判据要能审计（时间锚+内容 hash）、**动态层要能
再加工（保留原始可切片材料）**。value 合同一页纸预注册，非实验轴。

**问三：任务端到端优化（TFRL，身份两档制）**——key/value 建模空间的配置（切片策略/
面组合/融合权重/候选宽度 N/**物化边界**）以任务效果为目标做 training-free 优化；
training-free=零模型参数更新，控制器轻量策略允许在交互中更新。**档 A（离线策略标定，
入合同）**：dev 上 reward-guided 配置搜索、冻结后进 test（ASR 史上 LM 权重/beam 调优=该
方法论四十年先例）；如实定位为 derivative-free 配置优化，**必设等预算优化器对照**
（random search/Bayesian/evolutionary 同预算——赢不过随机搜索的优化器不立方法主张）。
**档 B（contextual bandit，RL 身份承载形态）**：运行期按实例状态选动作/配置——状态=
触发电池读数向量（§6.3 state），动作=对统一知识接口的查询族，reward=离线标定的
delta_E；探索策略、预算、credit assignment 与离线/在线边界——骨架已给（§6.3 档B形式化
块），实验臂=B-adapt（§6.2）、判据=K-RL（§7），数值与协议余项 authorization 前收口
（§9 义务）。**方法身份由档 B 承载；档 A 单独存在时不以 RL 名义立方法主张。**占位：任务
奖励驱动的知识组织优化在读集内无人做（最近邻 MemRL 的 utility-Q 属记忆维度；
AutoML-for-RAG 类占位补扫义务）。

**统一知识接口与两层绑定**：系统只有一个可查询对象——知识系统对外回答查询、对内自决
**存量 or 现算**（能力池=接口的现算后端：冻结算子默认不跑、按需调用）；**物化边界（哪些
预提取进 key、哪些留按需现算）=早/晚绑定线=TFRL 优化变量**。检索架构=**静态粗召回**
（粗切片+稳定多面 key→候选邻域）+**动态细加工**（查询条件化的再切片/再取面，仅对候选
邻域）；长音频输入超出工作上下文且被反复查询时即"知识化"入 T2 库——双空间在此统一。

**实验重构（O-config 臂族）**：incumbent 配置（单向量平铺定长切，读集现状）vs 任务优化
配置（档 A 搜出）vs random-search@equal-budget（同空间等预算随机搜索——优化器不赢随机
搜索则不立方法主张）；切片子维先用
检索层读数（K5-r，AR@k 型）廉价筛选；优化配置臂的任何调参须给 incumbent 配置臂等预算
（对称调参纪律）；O-config 臂主锚 SLUE-SQA-5
（Spoken-SQuAD 派生自 SQuAD，DPR 实测调优 BM25 在其上全面反赢稠密 68.8 vs 51.6，语义面
易饱和）；O 臂占实验资源小头预注册。

## §4 阶段三：知识如何使用——门控查询-裁决环

### §4.1 文本域供给/使用演进（D2 源核版，压缩）

### §4.4 阶段三研究内容：门控查询-裁决环

**底盘继承与门控化**：ReAct 环（动作=对统一知识接口的查询）+ Reflexion 式反思——但按
**定向反思统一律**约束：**反思环有效 iff 注入假设条件化的新证据**（纯语言自省/无条件重
表达/无假设取证三者皆死——Agent-Omni 0.00、2606.28864 垫底、A.6 有害与 NAP/ARC 冠军的
有效重查在此统一）。读集内全部音频 agentic 系统都是自由生成环（trained 支的
Speech-Hands 亦以 SFT 学仲裁而非模型外计算的门）——**门控化（training-free×模型外计算
×双源动作）的 agent 环即空位**。

**双源触发电池（模型零自省，全部外置确定性信号）**：

| 感知列（触发 RE_RESOLVE） | 知识列（触发 SEARCH） |
|---|---|
| 探针实体槽离散度（核 N 采样=其 lattice） | 答案槽探针离散度（无检索态） |
| 前置工具自报置信度（若双通道配置） | 验证式反查失败（候选答案廉价定向验证，gapCorr） |
| 声学质量先验（DSP） | 结构性问题先验（dev 标定的类别基率表） |
| 知识侧验证失败（实体查无此物） | 实体-属性覆盖缺口（问题问音频中不存在的属性） |

对冲："自信幻觉"由**验证优先**兜底（答案承重槽即使探针一致也过一次廉价验证）。触发=三元
决策：**路由**（槽型-面路由表：实体事实→web、发音歧义→发音库、视觉指涉→图搜、音频本体
→T2 库）+**构造**（多假设 query）+**深度**（验证式单查→全量检索→多跳，成本排序级联）。
**触发门质量自身为必报读数**：双混淆矩阵（听错触发对 TTS 最小对 gold；知识触发对先导
数据集负类 gold）——"校准先验判取"这一跨域机制（CTA 一系）的可测性由先导负类首次解锁
（现有载体无负类、不可直测）。

**核的角色（三不+一是）**：不规划、不自省发起、不垄断感知（对齐损失挤掉副语言信息——
**核非全能感知者公理**，项目内部经验+公开测量补扫义务）；**是候选裁决者**：在准入后的
"假设×证据"上裁决与作答——验证易于生成，这是核的强项，能力假设被压到最小且可预检。
RE_RESOLVE 分面路由：语义面→音频段重递核（真重听）；副语言面→专家工具对区间再加工、
符号化输出递核。"第几步重听"=一等设计变量（KV 干预证据显示注入存在有效窗口）。

**结构防爆四机制**：单默认通道（每任务一条最廉价前向）+中控按需调度+**一切查询输出落
候选区、经准入门才见核（总则）**+知识层摊销。**前向通道=harness 实验轴**：{omni 单通道
vs ASR+omni 双通道} 由实验裁决（语义理解准确率），如实报告；蜕壳条件登记。

### §6.3 方法合同（五元组，统一接口版）

```text
state_t   = { H_t 多假设槽集（N-best 式，含 agree(h)）, E_t 已准入证据（corr(e,h)、出处、
              时间锚）, b_t 分维记账余额, 动作历史 A_{1..t-1} 与候选答案漂移 }
action_t  ∈ 对统一知识接口的查询族：{ RE_RESOLVE(区间,面), RE_SLICE(邻域,粒度,面),
              SEARCH(q,库), ADMIT/REJECT(e), ANSWER, STOP/ABSTAIN }
V̂ 估计量族（信号分层=A4a/A4b 差分的定义所在）：
  A4a: V̂_gen(SEARCH(q)|s_t)=α2·gapCorr(E_t,ĥ_t)+α3·nov(q|A_{1..t-1})   ←无感知不确定性输入
  A4b: V̂_aud=V̂_gen+α1·(1−maxAgree(H_t))；V̂(RE_RESOLVE|s_t)=β1·disp(H_t)+β2·(1−audCons(ĥ_t))
  准入: V̂(ADMIT(e)|s_t)=γ1·corr(e,ĥ_t)+γ2·srcQual(e)−γ3·confl(e,E_t)
  再切片: V̂(RE_SLICE(邻域,粒度,面)|s_t)=δ1·gapCorr(E_t,ĥ_t)+δ2·(1−menuCov(邻域))
    ——menuCov=该候选邻域内已尝试的（粒度,面）组合占预注册再加工菜单的比例（确定性计数；
    菜单=authorization 预注册）；δ 权重与 α/β/γ 同批 dev 标定。§6.4 所称"确定性策略"即
    本式+policy 阈值规则（**档 A 形态无第二套机制**；档 B 的种子化探索按可重放口径另行
    覆盖，见块末）。
  可实现定义：maxAgree=采样候选答案语义槽众数占比；disp=1−maxAgree；audCons=已执行重呈现
  中首选假设复现比（无重呈现=1）；corr(e,h)=槽值重叠（实体槽=字符串/别名匹配、类别槽=
  类别及别名表匹配）；gapCorr=1−max_{e∈E_t}corr(e,ĥ_t)（只按首选假设计，不从证据侧反推
  假设全集后验）；nov=与历史 query 最大重叠之补（扩展为（动作类型,时间区间）对）；srcQual
  =预注册白名单查表；confl=同一语义槽取值冲突计数。时序合法性：全部输入仅依赖 t 步及以前
  观测；实际回报仅离线标定不进在线决策。探针仪器声明：逐步候选答案探针为 A4a/A4b 两臂
  共用仪器（同频同额计费，A4a 的 V̂_gen 不读取），差分中探针成本抵消。触发电池（§4.4
  两列）为估计量族的传感器层——本版已接入 disp/maxAgree/gapCorr 三路；**其余五路信号
  （工具自报置信度/声学质量先验/实体存在性验证/类别先验表/属性覆盖缺口）的估计量接入
  形式与权重列入 §9 义务**，接入前它们只作门控预筛的独立阈值信号、不进 V̂。
policy    : argmax_a V̂(a|s_t)；max_a V̂ ≤ τ 时 ANSWER/STOP；**跨动作族同尺度合同**：各族
  V̂ 分量先对离线 delta_E 统一校准（同一标定集、同一目标量纲）再入 argmax，未过校准的
  分量不入决策（§6.5 标定读数=该合同的检定面）；τ/α/β/γ/δ 与融合权重、候选
  宽度 N、切片配置=TFRL 档 A dev 标定（禁 test gold）；**再加工菜单=authorization 预注册
  后冻结的常量**（menuCov 的分母，不进 dev 标定——其内容选定发生在预注册前）；硬上限=
  工程护栏只记录。
transition: 一切查询输出先落候选区，仅 ADMIT 进核上下文；RE_RESOLVE/RE_SLICE 更新假设与
  邻域；一切写入带出处与时间锚。
档B形式化: 对象=contextual bandit（状态 s_t 如上，动作=查询族，reward=离线标定的
  delta_E 代理）；策略=V̂ 之上的 ε-greedy/UCB 族（探索率与预算 authorization 前预注册）；
  随机性种子化且全程 trace——§6.4 确定性硬约束对档 B 按"给定种子可重放"口径覆盖；
  credit assignment=终局效用经离线标定分解至步级动作族（协议入 §9 义务）；档 B 相对
  档 A 的增益由 B-adapt 臂承载（§6.2）、判据=K-RL（§7）。
```

取值预注册；近邻残余数不代充本核余量，§5.1/§5.3）。
**判别力条款**：A1 与 A0 皆近地板且差值低于余量=核能力缺失（gold 假设都救不动），不判
杠杆死、直接走 §5.3 回退梯——"杠杆死/载体无分辨力/核能力缺失"三分。

- **K1a（通用调度）**：A4a vs 效果最强固定策略（阶梯扫至成本不低于 max(A4a,A4b)，取效果
  最高档×选定 re-resolve 档；并列论文 SOTA 臂、random-matched-cost 与
  serial-composition 固定臂〔载体=NB 主载体，§6.2〕），paired delta 95%
  下置信界 ≤0 → 调度类杠杆判死。matched-cost 不显著低于 A4a → 读数标 `ALLOCATION_
  UNPROVEN`；自适应臂成本超阶梯预注册倍数 → `COST_DISPARATE`（仅在阶梯无法扩至成本可比
  时非空转）。
- **K1b（双源独立性=合取条件）**：①A4b−A4a paired delta 95% 下置信界 >0 ∧ ②标定后 β
  权重与零可区分；任一不满足 → 音频特有主张判死、按 §8 路由 MERGE。配对成本可比：探针
  两臂共用仪器抵消；A4b 成本超 A4a 预注册倍数（core calls/retrieval hops/audio seconds
  三维）→ `COST_DISPARATE`，不得单独支撑独立主张。
- **K-NB（能力上界判据；统计口径与 K1a 同型）**：NB 主载体上，主张臂（运行时 ASR-free）
  vs incumbent（ASR+biasing-GER，§8 分组合同实例化；对手入判边界=§5.1 整合载体条款）的实体准确率与任务效用 paired delta
  95% 下置信界 ≤0 → 能力上界主张判死，降级"理解任务限定的知识增强"；若 FC 双通道参照臂在
  NB 主载体上使主张臂不及（不及口径同下）→ 同样降级为"增强"并如实改判（能力上界主张
  只能由 ASR-free 臂承载）。载体身份已冻结（§5.1）；数值（SESOI/power）以 Stage-2A 第零步
  余量检定为输入预注册，预注册前不判。**跨载体口径**：K-NB 判死权仅在 NB 主载体——对入判组（①②与⑤〔预注册〕⑥〔重实现后〕），
  paired delta 逐组计算、多重性校正仅施于判死方向的比较族；组④ trained 上界的正面交锋钉
  LibriSpeech+Rare5k 作**强制对照读数**：主张臂不及 trained 上界（不及=paired delta 95%
  下置信界 ≤0，与判死族同式但不入其多重性校正、施于对照方向）→能力上界主张改判"增强"
  并如实报差距（跨信息边界对手、不携判死权；该载体上仅预注册实体子切片准确率入读数、
  通用 WER 为 READOUT_ONLY——反还原不变量①）。
  **对称调参与成本旗**：incumbent 各**入判**组（边界=§5.1）在不低于主张臂的调优预算下
  实例化（对手弱配置不入判）；主张臂成本超预注册倍数（core calls/retrieval hops/audio
  seconds 三维）→标 `COST_DISPARATE`——旗不判死、不进主判据（效果优先纲领下的可证伪性
  保障）。**"上界"口径**：主张臂=预注册配置族的最优臂、incumbent=各**入判**组最强臂
  （sup-vs-sup 对照），配置族授权前冻结、多重性按本节末校正。
- **K-PS（阶段一机制核判据）**：PS-abl 消融显示发音库贡献在困难实体切片上的 paired delta
  95% 下置信界 ≤0 → 发音库降级为工程组件（不承载机制核主张）；P13N 三臂在口音分层上逐级
  无增益 → 对应个性化机制（变体族/克隆 key）逐个降级。降级不判方向死——机制核主张回落到
  双源调度与组织优化两支柱。
- **K2（over/under 双向）**：over-search 事件=最终答错 ∧ t>t*（首个当步候选正确步）存在
  SEARCH；判定输入=已落盘答案与 rank/hash 轨迹；判官抽样复核（抽样框=候选 episode、输入
  不含检索正文、CI 对象=事件率、抽样率与协议预注册）；如实标注为事件率估计非内容级全量。
  A4b 未相对最优固定档降低该率（非劣界预注册）→ 调度杠杆判死。under-call 对偶读数（§6.5）
  同报，不单独判死。
- **K3（复制）**：次载体上按预注册 replication criterion 判方向一致（无分辨力的轻微负值
  不算翻转）。
- **K4（准入门；载体形态前置）**：A3 未降 Knowledge-error 或 type-D 增多 → 判死留 R5/R8。
  前置：准入价值集中于长文/多 claim 任务（Self-RAG：ASQA −14.0 vs 短答 −2.9），短答载体
  上仅当 correct→wrong 基数过检定③ 且证据密集子桶一并为负才生效，否则记
  `PENDING_CARRIER_FORM`。
- **K5（组织优化两级）**：前置㈠锚上非语义槽 query 占比 ≥ 下限、㈡incumbent 配置
  （单面单向量 key）与调优稀疏基线的
  检索层读数距天花板有余量（不过则不判死、回 owner）。K5-r=检索层报告读数（AR@k，含调优
  稀疏与深度对等，按面分层，不携判死）；K5-t=档 A 优化配置相对 incumbent 与
  random-search@equal-budget（同空间等预算）无任务效用/coverage 增益 → 组织优化不立主张、回落实验合同角色（判死权仅在
  K5-t，且仅在具备非语义槽需求的载体上生效，否则 `PENDING_CARRIER`）。
- **K-Gate（门一判据；①–④ 四条路由，⑤为配置输入，§6.1）**：②探针稳定性不过阈 → 探针系
  信号禁用、A4b 记 PENDING_CAPABILITY；③候选裁决不过阈 → 裁决核公理不成立、回 owner
  重议核；④核裸语义差距超阈 → K-NB 降级理解任务限定；①丢失面清单为空的面 → 组件登记
  蜕壳条件并作摘除对照。
- **K-PS↔K-NB 关系条款**：两判据载体独立（K-PS 在 SLU/W1 网格与先导口音层；K-NB 在 NB
  主载体），互不传染悬置；**NB 主载体上的 PS-abl 整合运行=READOUT_ONLY、不入 K-PS 判定
  （K-PS 判定输入仅取其判据载体）**；**联合出口**：K-PS 判死 ∧ K-NB 成立 → NB 主张保留但机制归因如实
  改挂知识系统的其余组件（面联邦/T2 库/世界知识 rescore），发音库退为工程件；K-PS 成立 ∧
  K-NB 判死 → 发音库作为组件主张保留、能力上界主张放弃。
- **K-RL（方法身份判据）**：B-adapt 臂上档 B−档 A paired delta 95% 下置信界 ≤0 → RL
  身份不立、方法命名回落 reward-guided 配置优化（方向不判死，档 A 结论保留）。
- **K-XOVER（机制核价值窗口判据）**：DICT-SCALE 扫描中发音库检索相对 in-context 注入的
  crossover 不存在于目标词典规模区间 → 机制核动机在该载体判空、按 §5.3 回退梯路由（与
  K-PS 联动：窗口存在而 K-PS 判死 → 机制核改挂语音学检索+世界知识 rescore）。**目标词典
  规模区间定义**：主载体知识源构造的实体清单规模的预注册包络——"全表"=该载体知识源全量
  实体清单、下限锚=先导诊断集实体数（现成刻度锚：ConEC 逐场清单约 100–2000 词、Fox 展开
  3066 unigram），数值随 power 预注册冻结；预注册前与 K-NB 同步不判。
- **非劣性读数（MMAU/SLU 行）**：非劣界预注册，READOUT_ONLY——不携判死权，只作主张矩阵
  的符号验证。**READOUT_ONLY 家族**：H 行、VF-abl、蜕壳检验、A5、A6、NB-④ 对照行、NB 主载体上的
  PS-abl 整合读数同属（无判死权；A6 兼 K1a 的 A1 缺位替补输入；组④ 载体的通用 WER 为
  读数级 READOUT_ONLY；NB-④ 为家族内唯一携改判权的读数——改判≠判死）——判死族多重性校正不含 READOUT_ONLY 读数。
- 多杠杆×多集×多分桶按预注册 multiplicity correction（Holm/max-T，复用 W1 统计基建；
  分桶相关性如实建模——近邻教训：只改实体词的 oracle 亦改善非实体桶，独立性假设不成立）。

## §8 管辖界线与独立性
