# R2 开题报告：语音任务中的知识系统——门控 agent 底盘上的 key/value 建模、组织与使用

## §0 一页摘要

**方向陈述（三层归位）**：**研究主题=知识**——语音任务中知识的 key/value 建模、组织、
供给与使用，及其基于任务效果的 training-free 端到端优化（TFRL）；**底盘=继承自文本域的
成熟 agent 架构**（ReAct/Reflexion/DeepAgents 谱系），我们的动作是把它**门控化**；
**战场=语音任务谱系**（从音频理解、口语问答到外部知识深搜，六族任务矩阵，§5.1）。

**核心主张（新基线，三臂可判）**：在实体/知识密集的语音任务上，**"语音内容知识 + 冻结
omni 核"可以替代"专用 ASR + biasing/GER"成为新的系统范式基线**——omni 核出原生语义
能力，知识系统补核的三个已知短板（实体：发音库+世界知识；副语言：面 key 联邦；长时程：
T2 库），门控环把两者缝合。判定=三臂对照：omni 裸核（下界）/ ASR+biasing-GER
（incumbent，必须赢的对手）/ omni 核+知识系统（主张臂）。

**三角色统一架构**：

```text
门控环（确定性触发电池 + V̂ 调度 + 准入门；TFRL 调参）——唯一调度权
  ├── 统一知识系统（研究主题）：对外一个查询接口，对内自决存量 or 现算——
  │     实体发音库（声学 key→同音候选 value）、T2 音频库（静态粗召回+动态细加工）、
  │     面 key 联邦（语义/情感/说话人/事件/时间锚）、世界知识接口；
  │     现算后端=冻结专家算子池（ASR/emotion2vec/说话人/事件/TTS/DSP，默认不跑、按需调用）；
  │     切片/面装载/融合权重/物化边界 = TFRL 优化的配置空间
  └── omni 裁决核：在"候选区已准入的证据 × 假设集"上裁决与作答
        （三不：不规划、不自省发起、不垄断感知——各有预检电池背书）
```

**运行范式**：门控化的**查询-裁决环**——一切动作（重听=查输入流、重切=查知识邻域、
检索=查外部、发音匹配=查发音库）都是对统一知识接口的**假设条件化查询**；何时问、问什么、
问多深由外置确定性门裁决（模型零自省）；一切查询输出落候选区、经准入门才进核上下文
（结构防爆总则）。

**任务三阶段**（三个研究问题簇+一个联合评价面，非时序串行）：

| 阶段 | 核心问题 | 章节 |
|---|---|---|
| 阶段一：谁搜索谁 | query 如何进入知识的地址空间？实体发音库机制核；个性化 | §2 |
| 阶段二：知识如何组织 | key 建模（切片×面×表示）与 value 建模；统一接口与两层绑定；TFRL 任务优化 | §3 |
| 阶段三：知识如何使用 | 门控查询-裁决环：双源触发、定向反思、准入与裁决 | §4 |

**研究纲领：效果优先**——主判据=相对最强基线的效果绝对提升；成本九维记账不设限；等预算/
Pareto 归后期。**Harness 学说**——每个 harness 组件带消融开关+蜕壳条件（model eats
harness）；可吃性分层：感知 harness 会被吃、门控部分被吃、**知识层结构上吃不掉（世界事实
晚于训练截止、时效、出处审计——文本域 RAG 在模型规模化中存活即证）——方向护城河钉在
知识层**，恰是研究主题所在。

**红线**：不修改任何模型参数；不为本任务新训练任何模型；不新增 LLM 代答（最终作答权在
冻结 omni 核）。工具级冻结组件（已发布检查点的 ASR/音频向量模型/TTS/判官/DSP/搜索引擎）
可用。**双门前置**：能力预检电池=Stage-2A 第零步（§6.1）；载体判定=先导数据集构造+现有
载体矩阵（§5）。判死永不在无分辨力的载体上宣布（灵敏度前置+回退梯，§5.3/§7）。

## §1 研究背景与问题定义

### §1.1 任务结构与两段式

R2 面向的任务因果链：**音频观测 → 音频语义假设 h（槽型任意：实体/事件/情感/说话人/声学
场景/音乐属性）→ 以 h 为钥匙的知识 → 有依据的回答**。知识检索是两段式：**定位**（key 的
职责——key 是地址不是副本，压缩即抽象，只需保留可判别面）→ **提取解析**（模型对 value 的
职责）。读集实证支撑两段拆分：SpeechRAG 检索侧几乎无损（0.9702 vs 0.9707）而生成端崩溃
（EM 0.3522 vs 0.7514）——定位成功、解析失败；Pi-Serini 的 surfaced 94.7→behavior 58.9
级联——证据在上下文里≠被使用。

### §1.2 音频特有机制与"why now"

**误差面（听错/判错）**：外部检索的 query 依赖可能听错的音频假设——把 Meyer 听成 Mayer，
检回的证据彼此一致、来源可信、条条锚在错误实体上，"多搜"反而把错误假设佐证得更牢
（Omni-DeepSearch A.6 over-search 轨迹；oracle 分解 entity-only 33.76/端到端 43.44/
gold-entity 50.00，仅 Gemini-3-Pro 口径、实体槽证据）。**结构面（同音异形）**：局部声学
片段自身不携带确定身份——ASR 的历史教训是身份由序列上下文与先验知识联合裁定（候选生成+
lattice 解码+LM rescore 的系统级方案）。

由此得本方向的机制核心：**把经典 ASR 三件套（声学模型-发音词典-语言模型）以开放知识系统
重新实例化**——声学 key（冻结编码器）扮演声学模型、实体发音库（声学 key→同音候选 value）
扮演发音词典、**LLM+外部世界知识扮演语义层 LM**（rescore 感知假设：世界上存在 Meyer 会议、
不存在 Mayer 会议）、门控 agent 环扮演解码器；且加入经典 ASR 没有的维度——说话人/情感等
面作为**索引维度**（经典 ASR 把说话人当噪声归一化掉）。**Why now（四使能件交集）**：能做
reasoning 级 rescore 的冻结 LLM（2023+）、成熟冻结专家编码器阵（emotion2vec 等）、agentic
控制范式（音频域 2026 起步）、评测端首次奖励分面理解（omni 基准 2025+）；外加三个社区
（ASR 盯 WER/agentic 在文本/omni 做对齐）的目标函数都不指向该交点。类比：RAG 把知识从
LLM 权重外置；本方案把"发音→身份"映射从 ASR 权重外置——**实体层的 RAG-for-ASR，加分面
与 agentic**。具名近邻（占位补扫义务，§9）：contextual biasing（需每句预给候选表、训练
进解码器、单面）、GER/生成式纠错线（LLM 在 N-best 上纠错——回不到信号、无世界知识环）、
lattice 上的 spoken term detection（词层）、检索增强 ASR。

### §1.3 概念词典（件内自足）

**三形式（按被改变的系统对象互斥划分）**：**组织**——知识以什么单元/schema/关系/索引/
版本/出处存在（语料库、chunk/schema、索引、快照）；**供给**——何时取、从哪取、以什么
query 取、取多少、何时停（query 构造器、检索器、规划器、预算/停止策略）；**使用**——已
取回证据如何被接纳/融合/冲突处理/归因/拒用（准入、grounding、仲裁、abstention）。**两道门**：采集门（未见输出，决定买不买调用）≠准入门
（已见输出，决定进不进核上下文）。**四类信息作用**：①外部新信息（研究对象）②对已有观测
的重表达（重听属此类）③潜在知识激发（归 R1/R6）④验证与出处。**知识/记忆二分（作者性
判据）**：世界写的=知识（R2）；系统自己从 episode 写出的 revised lessons=记忆（R3）；
R2 只以 dev 预注册冻结先验消费记忆类信息，在线写入归 R3。**信息角色边界**：主张只覆盖
"外部新信息有边际价值"的实例分布；主载体按构造满足（过滤删除可直答样本），负类实例由
先导数据集按构造标注（§5.4）。

### §1.4 主张对象、红线与反还原不变量

北极星=system-level 任务能力，作答权在冻结 omni 核。红线三条见 §0。**反还原不变量**
（防"这只是 ASR rescoring"）：①目标函数永不含通用朗读语音 WER（实体/
知识密集集的实体准确率与该集 WER 可入榜）；②动作空间必须含无 ASR 类比的动作（定向重听、
按面重加工、双源比价）且其贡献可消融；③运行时 ASR 是 **harness 实验轴**而非身份——前向
通道 {omni 单通道 vs ASR+omni 双通道} 由实验裁决，系统身份由知识系统+门控环承载（被 TFRL
优化、被消融归因的部分）。**Harness 学说**：每个 harness 组件登记消融开关+蜕壳条件（核在
预检电池某项超阈值 X 后该组件应可摘除且效果不降——本身可验证）；可吃性分层与知识层护城河
见 §0/§8。

### §1.5 前置三问分型

**问题一：value 本体在哪（T1/T2，实验可行性分型）**——T1：value 在开放 web/文本（两个
现有主载体）；key 空间归搜索引擎，杠杆只在 query 侧；T2：value 本体是音频/受控库（锚数据
集与先导数据集）；key 表示才是可设计对象。跨分型不互推。**问题二：key 用什么表示**——由
冻结编码器联邦决定，选型判据=面的不变性/区分性需求（§2.4）。**问题三：什么装进 key、什么
装进 value**——key=可被检索的信息面（定位面设计），value=检索到的内容如何被使用（形态
服从使用端合同，§3.4）。

### §1.6 双门前置

**门一（能力门）**：模型是否具备预期的工具调用/裁决能力不作假设、只作测量——能力预检电池
=Stage-2A 第零步（§6.1），核的选择与前向通道配置由读数决定。**门二（载体门）**：是否有
现成数据集承载验证——逐阶段判定（§5）：阶段三 T1 载体存在但方向性（先分析基线再扩展）；
阶段二非语义面主张无现成载体（先导数据集构造，§5.4）。两门的答案都进报告正文，不作暗默
前提。

## §2 阶段一：谁搜索谁——映射、实体发音库与个性化

### §2.1 映射矩阵（读集内选项全景）

| query 模态 | key 空间（value 形态） | 代表工作 | 状态 |
|---|---|---|---|
| 文本 | 文本稀疏/稠密向量 | DPR 2004.04906 原理（key=E_P(标题⊕正文)，value 的确定性函数、单面） | 成熟 |
| 音频→文本 query | 搜索引擎自有 key | AudioRAG 2602.10656、Omni-DeepSearch 2605.08762 | 语音域现役（T1） |
| 文本 | 音频段向量（adapter 对齐） | SpeechRAG 2412.16500 | 研究线（T2） |
| 语音 | 语音向量 | SpeechDPR 2401.13463 | 研究线（T2） |
| 音频/文本混合 | 混合向量 | WavRAG 2502.14727 | 研究线（T2） |
| **实体音频 span** | **声学形式（多假设）** | **本方案实体发音库（§2.3）** | 提案 |

检索表征线三篇深读结论（数字经 LaTeX 源核对，D2 条目在册）：SpeechDPR top-20 19.73%
（级联 19.94%、集成 28.88%；未训练语音表征 0.04%——不可检索；gold passage 下 reader 上限
仅 11.17 FF1）；SpeechRAG 检索无损/生成崩（上引）、高 WER 区间端到端反超（45% WER：
0.7106→0.9952）；WavRAG 零训练 embedder 地板（R@1 0.3407/0.0675）、top-2→3 反降
（0.6408→0.5129）。三篇全有训练环节→方法论基线；**key 全部单向量单面、每 value 恰一 key**。

### §2.2 T1 的映射瓶颈与多假设 query

T1 上唯一可行路径=音频理解→文本 query→搜索引擎，瓶颈在 query 构造建立在可能听错的假设上。
杠杆=**多假设 query 构造**：候选假设并行发查、检索结果反向佐证假设（corr(e,h)，§6.3）。
跨域先例（红线内、确定性）：OK-VQA 的 ArticleNet 配方（内容词∪检测器标签→1/2 词组合枚举
→top-1 文章→规则抽句），语音同构=ASR 内容词∪面标签。

### §2.3 机制核：实体发音库

**构造**：从知识源拉实体清单→G2P/TTS 合成标准音（"国标发音"参考系）+**口音变体族**
（主要口音原型，方言学文献记录的系统性音变=世界知识）→冻结编码器产声学 key→库。key 为
**多假设 N-best 式**（不在建库时定案身份）。**查询**：疑似听错 span 的声学表示→检回同音/
近音候选实体集（value）→**世界知识 rescore 裁定**（哪个候选在世界中真实存在且语境相符）。
**范围钉死**：实体/术语层——通用逐字转写归冻结 ASR 工具（反还原不变量①）；中文同音字
密度使库价值更高。**与具名近邻的差异**：biasing 需每句预给候选表且训练进解码器，本库从
知识自动构造、检索式、冻结；GER 回不到信号、无世界知识，本方案反思时握原始音频重注意权
+发音库+世界知识。

### §2.4 个性化三件套（声学空间被说话人扭曲的对策）

①**对偶选型**：发音面 key 用说话人不变性编码器（对齐损失丢说话人信息在此恰是 feature），
说话人面 key 用区分性编码器（ECAPA 类）——同一"缺陷"在两个面分别是 bug 与 feature；
②**变体族 key**（静态层，见 §2.3）；③**查询期个性化 key 合成**（动态层）：冻结零样本
音色克隆 TTS 以当前说话人会话内音频为 enrollment，合成"这个人会怎么念候选实体"→个性化
声学 key→与实际发音匹配（把标准音推进说话人空间，而非把说话人拉回标准空间）；辅以会话内
对比归一化。**R2/R3 界线**：会话内瞬态说话人画像=R2；跨会话个人发音档案（revised
lessons）=**R3 第一用例**。**范围**：同语言口音变异可解；跨方言系统出界。

### §2.5 阶段一实验落点

A1（gold-entity ceiling，实体槽实例）与 A1′（gold-evidence 双读数：naive/masked+泄漏
占比——A-OKVQA 实测天真增益 60–71% 是答案泄漏）把映射损失与使用损失分开；发音库检索层
读数（同音候选命中率）独立报告；多假设 query 为供给侧 BASELINE VARIABLE。

## §3 阶段二：知识如何组织——key/value 建模与 TFRL 任务优化

### §3.1 文本域组织演进（D2 源核版，压缩）

原理基座：RAG 2005.11401=外挂非参数记忆原理（BART 联合微调，"冻结生成器"是误读；索引热
替换 70/68/12/4，82 题单模板边界；2020 已试并弃"不检索"机制且发现 no-op 检索伪装）；DPR
=稠密检索原理（key 单面、value 确定性函数）；ROME 2202.05262=参数中事实可直接编辑但改后
编造无据事实——外置理由在证据/出处轴。演进：GraphRAG 2404.16130（索引期图+社区摘要=
value 侧层次化；key 匹配是 future work；主语料之一为约 1M token Podcast 转写——图组织已在
口语转写验证、声学/副语言面零进入）；HippoRAG 2405.14831（在线单跳成本多跳、离线更贵；
uncertainty ensemble=文本域多面 key 融合先例；48% 失败=query 侧 key 丢上下文）；LightRAG
2410.05779（双层 key+双路路由；构建成本无对比；D2 证据权重降级）；Pi-Serini 2605.10848
（只调 k1/b+扫深度→surfaced 召回 94.7–95.8%——组织收益必须对调优稀疏基线验证；参数值
长文档域限定、只搬程序）。记忆支线（A-MEM/MemRL/Decocted）归 R3，只借形状：效用记账、
蒸馏修正（revised lessons）、相关性↑效果非单调、对称调参纪律。

### §3.2 视觉域组织演进（D2 源核版，压缩）

Wiki-LLaVA 2404.15406（两层串行 key；检索净负自测 26.4<28.5；微调致 MME-Perception
−47%=**"不动参数"最有力跨域证据**）；EchoSight 2407.12735（同模态图像 key 击败图像→

### §3.3 语音域现状

### §3.4 阶段二研究内容：key/value 建模三问 + 统一接口 + TFRL 优化

**问一：key 如何建模**——三子维设计空间：**切片**（单元边界/尺度：定长窗/VAD/说话人轮次/
事件边界/多尺度；VAM 的 Otsu 自适应边界=training-free 在线切片先例；专家模型的窗长需求使
切片按面而异）×**面装载**（哪些信息面进地址空间：语义/副语言/说话人/事件/**时间锚**——
时序不是独立灾难，分解为 key 面/出处字段/动作区间参数）×**表示**（冻结编码器选型；每面
过**可检索性前置检定**——emotion2vec 类非检索目标训练，不过检定的面不入对照）。key 为
多假设式（§1.2 结构面）。

**问二：value 如何建模**——value=检索到的内容如何被使用的建模，形态（标签/句子/语音段/
图）服从使用端合同：冻结核要能解析（omni 核可原生消费音频态 value——对文本核级联的预测
优势）、准入门要能判断（出处+佐证标记）、判据要能审计（时间锚+内容 hash）、**动态层要能
再加工（保留原始可切片材料）**。value 合同一页纸预注册，非实验轴。

**问三：任务端到端优化（TFRL）**——key/value 建模空间的配置（切片策略/面组合/融合权重/
候选宽度 N/**物化边界**）以任务效果为目标做 training-free 优化。**档 A（入合同）**：dev
上 reward-guided 配置搜索，冻结后进 test（ASR 史上 LM 权重/beam 调优=该方法论四十年
先例）；**档 B（扩展）**：运行期按 query/类别自适应配置选择。占位：任务奖励驱动的知识
组织优化在读集内无人做（最近邻 MemRL 的 utility-Q 属记忆维度；AutoML-for-RAG 类占位
补扫义务）。

**统一知识接口与两层绑定**：系统只有一个可查询对象——知识系统对外回答查询、对内自决
**存量 or 现算**（能力池=接口的现算后端：冻结算子默认不跑、按需调用）；**物化边界（哪些
预提取进 key、哪些留按需现算）=早/晚绑定线=TFRL 优化变量**。检索架构=**静态粗召回**
（粗切片+稳定多面 key→候选邻域）+**动态细加工**（查询条件化的再切片/再取面，仅对候选
邻域）；长音频输入超出工作上下文且被反复查询时即"知识化"入 T2 库——双空间在此统一。

**实验重构（O-config 臂族）**：incumbent 配置（单向量平铺定长切，读集现状）vs 任务优化
配置（档 A 搜出）vs random-config（同空间随机采样——优化器须赢过随机搜索）；切片子维先用
检索层读数（K5-r，AR@k 型）廉价筛选；O2 任何调参给 O1 等预算；O 臂主锚 SLUE-SQA-5
（Spoken-SQuAD 派生自 SQuAD，DPR 实测调优 BM25 在其上全面反赢稠密 68.8 vs 51.6，语义面
易饱和）；O 臂占实验资源小头预注册。

### §4.4 阶段三研究内容：门控查询-裁决环

**底盘继承与门控化**：ReAct 环（动作=对统一知识接口的查询）+ Reflexion 式反思——但按
**定向反思统一律**约束：**反思环有效 iff 注入假设条件化的新证据**（纯语言自省/无条件重
表达/无假设取证三者皆死——Agent-Omni 0.00、2606.28864 垫底、A.6 有害与 NAP/ARC 冠军的
有效重查在此统一）。读集内全部音频 agentic 系统都是自由生成环——**门控化的 agent 环
即空位**。

**双源触发电池（模型零自省，全部外置确定性信号）**：

| 感知列（触发 RE_RESOLVE） | 知识列（触发 SEARCH） |
|---|---|
| 探针实体槽离散度（核 N 采样=其 lattice） | 答案槽探针离散度（无检索态） |
| 前置工具自报置信度（若双通道配置） | 验证式反查失败（候选答案廉价定向验证，gapCorr） |
| 声学质量先验（DSP） | 结构性问题先验（dev 标定的类别基率表） |
| 知识侧验证失败（实体查无此物） | 实体-属性覆盖缺口（问题问音频中不存在的属性） |

对冲："自信幻觉"由**验证优先**兜底（答案承重槽即使探针一致也过一次廉价验证）。触发=三元
决策：**路由**（槽型-面路由表：实体事实→web、发音歧义→发音库、视觉指涉→图搜、音频本体
→T2 库）+**构造**（多假设 query）+**深度**（验证式单查→全量检索→多跳，成本排序级联）。
**触发门质量自身为必报读数**：双混淆矩阵（听错触发对 TTS 最小对 gold；知识触发对先导
数据集负类 gold）——M3 机制位由先导负类解锁。

**核的角色（三不+一是）**：不规划、不自省发起、不垄断感知（对齐损失挤掉副语言信息——
**核非全能感知者公理**，项目内部经验+公开测量补扫义务）；**是候选裁决者**：在准入后的
"假设×证据"上裁决与作答——验证易于生成，这是核的强项，能力假设被压到最小且可预检。
RE_RESOLVE 分面路由：语义面→音频段重递核（真重听）；副语言面→专家工具对区间再加工、
符号化输出递核。"第几步重听"=一等设计变量（KV 干预证据显示注入存在有效窗口）。

**结构防爆四机制**：单默认通道（每任务一条最廉价前向）+中控按需调度+**一切查询输出落
候选区、经准入门才见核（总则）**+知识层摊销。**前向通道=harness 实验轴**：{omni 单通道
vs ASR+omni 双通道} 由实验裁决（语义理解准确率），如实报告；蜕壳条件登记。

### §6.3 方法合同（五元组，统一接口版）

```text
state_t   = { H_t 多假设槽集（N-best 式，含 agree(h)）, E_t 已准入证据（corr(e,h)、出处、
              时间锚）, b_t 分维记账余额, 动作历史 A_{1..t-1} 与候选答案漂移 }
action_t  ∈ 对统一知识接口的查询族：{ RE_RESOLVE(区间,面), RE_SLICE(邻域,粒度,面),
              SEARCH(q,库), ADMIT/REJECT(e), ANSWER, STOP/ABSTAIN }
V̂ 估计量族（信号分层=A4a/A4b 差分的定义所在）：
  A4a: V̂_gen(SEARCH(q)|s_t)=α2·gapCorr(E_t,ĥ_t)+α3·nov(q|A_{1..t-1})   ←无感知不确定性输入
  A4b: V̂_aud=V̂_gen+α1·(1−maxAgree(H_t))；V̂(RE_RESOLVE|s_t)=β1·disp(H_t)+β2·(1−audCons(ĥ_t))
  准入: V̂(ADMIT(e)|s_t)=γ1·corr(e,ĥ_t)+γ2·srcQual(e)−γ3·confl(e,E_t)
  可实现定义：maxAgree=采样候选答案语义槽众数占比；disp=1−maxAgree；audCons=已执行重呈现
  中首选假设复现比（无重呈现=1）；corr(e,h)=槽值重叠（实体槽=字符串/别名匹配、类别槽=
  类别及别名表匹配）；gapCorr=1−max_{e∈E_t}corr(e,ĥ_t)（只按首选假设计，不从证据侧反推
  假设全集后验）；nov=与历史 query 最大重叠之补（扩展为（动作类型,时间区间）对）；srcQual
  =预注册白名单查表；confl=同一语义槽取值冲突计数。时序合法性：全部输入仅依赖 t 步及以前
  观测；实际回报仅离线标定不进在线决策。探针仪器声明：逐步候选答案探针为 A4a/A4b 两臂
  共用仪器（同频同额计费，A4a 的 V̂_gen 不读取），差分中探针成本抵消。触发电池（§4.4
  两列）为估计量族的传感器层。
policy    : argmax_a V̂(a|s_t)；max_a V̂ ≤ τ 时 ANSWER/STOP；τ/α/β/γ 与融合权重、候选宽度
  N、切片配置=TFRL 档 A dev 标定（禁 test gold）；硬上限=工程护栏只记录。
transition: 一切查询输出先落候选区，仅 ADMIT 进核上下文；RE_RESOLVE/RE_SLICE 更新假设与
  邻域；一切写入带出处与时间锚。
```

## §7 击杀判据（定义=本版件内自足；数值=authorization 前 power analysis 预注册）

**灵敏度前置检定**：任何判死只在载体过检定后有效——①A1（trace/* 不可构造子集由 A6 替补）
−A0 ≥ 预注册最小可检余量；②固定档曲线斜率非零；③correct→wrong 样本基数 ≥ 下限。
**判别力条款**：A1 与 A0 皆近地板且差值低于余量=核能力缺失（gold 假设都救不动），不判
杠杆死、直接走 §5.3 回退梯——"杠杆死/载体无分辨力/核能力缺失"三分。

- **K1a（通用调度）**：A4a vs 效果最强固定策略（阶梯扫至成本不低于 max(A4a,A4b)，取效果
  最高档×选定 re-resolve 档；并列论文 SOTA 臂与 random-matched-cost），paired delta 95%
  下置信界 ≤0 → 调度类杠杆判死。matched-cost 不显著低于 A4a → 读数标 `ALLOCATION_
  UNPROVEN`；自适应臂成本超阶梯预注册倍数 → `COST_DISPARATE`（仅在阶梯无法扩至成本可比
  时非空转）。
- **K1b（双源独立性=合取条件）**：①A4b−A4a paired delta 95% 下置信界 >0 ∧ ②标定后 β
  权重与零可区分；任一不满足 → 音频特有主张判死、按 §8 路由 MERGE。配对成本可比：探针
  两臂共用仪器抵消；A4b 成本超 A4a 预注册倍数（core calls/retrieval hops/audio seconds
  三维）→ `COST_DISPARATE`，不得单独支撑独立主张。
- **K-NB（新基线判据）**：实体/知识密集集上主张臂未达 ≥ incumbent（ASR+biasing-GER）的
  实体准确率/任务效用 → 范式替代主张判死，降级"理解任务限定的知识增强"。
- **K2（over/under 双向）**：over-search 事件=最终答错 ∧ t>t*（首个当步候选正确步）存在
  SEARCH；判定输入=已落盘答案与 rank/hash 轨迹；判官抽样复核（抽样框=候选 episode、输入
  不含检索正文、CI 对象=事件率、抽样率与协议预注册）；如实标注为事件率估计非内容级全量。
  A4b 未相对最优固定档降低该率（非劣界预注册）→ 调度杠杆判死。under-call 对偶读数（§6.5）
  同报，不单独判死。
- **K3（复制）**：次载体上按预注册 replication criterion 判方向一致（无分辨力的轻微负值
  不算翻转）。
- **K4（准入门；载体形态前置）**：A3 未降 Knowledge-error 或 type-D 增多 → 判死留 R5/R8。
  前置：准入价值集中于长文/多 claim 任务（Self-RAG：ASQA −14.0 vs 短答 −2.9），短答载体
  上仅当 correct→wrong 基数过检定③ 且证据密集子桶一并为负才生效，否则记
  `PENDING_CARRIER_FORM`。
- **K5（组织优化两级）**：前置㈠锚上非语义槽 query 占比 ≥ 下限、㈡O1 与调优稀疏基线的
  检索层读数距天花板有余量（不过则不判死、回 owner）。K5-r=检索层报告读数（AR@k，含调优
  稀疏与深度对等，按面分层，不携判死）；K5-t=档 A 优化配置相对 incumbent 与 random-
  config 无任务效用/coverage 增益 → 组织优化不立主张、回落实验合同角色（判死权仅在
  K5-t，且仅在具备非语义槽需求的载体上生效，否则 `PENDING_CARRIER`）。
- **K-Gate（门一判据）**：预检④（核裸语义 vs ASR 实体差距）超阈 → K-NB 主张降级；预检①
  丢失面清单为空 → 对应面联邦组件登记蜕壳条件并作摘除对照。
- 多杠杆×多集×多分桶按预注册 multiplicity correction（Holm/max-T，复用 W1 统计基建）。
