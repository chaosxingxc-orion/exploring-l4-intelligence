# Agentic calibration coder codebook v3

Use only the shared source bytes and coder-visible contract. Code every assigned paper; do not infer
labels from selection, project preference, prior discussion or another coder.

`REFERENCE` records evidence without moving a source-domain protocol or claiming runnable parity.
`BORROW_PROTOCOL` requires an explicit source-to-speech/omni translation, preserved decision
structure, exact locators, a rejection condition and an observable rejection outcome.
`REPRODUCTION_CANDIDATE` requires a closed task, dataset revision and split, official repository and
revision, entrypoint, access regime, license/terms, evaluator or ground truth, local asset state and
locators. A blocker or missing field means the label cannot be used.

Agentic direct scope requires both a decision and an action/tool path around a generic frozen core.
Specialized system cores and trained controllers cannot enter the direct agentic route. Paper-level
K/S/M labels may be multiple, but every experiment cell has one primary intervention attribution.

Submit all 56 responses before agreement or adjudication is revealed. Empty empirical object arrays
must retain an explicit absence reason, and every evidence-bearing object must reference a declared
source locator.
