本轮终点固定为 `AGENTIC_RC2_CODER_READY_NOT_DISTRIBUTED`。RC2 只完成方法合同、已知候选只读闭合、
exact independent-review manifest；不运行 coder、agreement、研究模型、API、benchmark metric、复现或
prototype。Stage-1B v5 与 320-work union 保持不可改写。当前完成的是首次提交前 P0 泄漏修复；
owner 已授权一次本地 no-push commit 与 commit-bound 独立方法复审提交，coder 仍未分发。

专用 Duplex 模型任务不进入研究路线。FDB-v2 仅作为一篇盲校准排除边界；FDB-v3 不再占 sentinel；
Audio MultiChallenge 仅作 instrument support。

继续存在但只能编码为 specialized-system exclusion。

## 3. 输出合同

Reviewer-visible package 保留完整 calibration manifest、prior claim links、具名完整 codebook、candidate
readiness 与治理合同。Coder-visible package 只允许 source bytes、label-hidden assignment、blank packet、
response schema、agreement rules、中性 codebook 与中性 claim-template view。递归 scanner 拒绝选择理由、
origin/link、readiness、problem route 与具名预期标签。两名 coder 共用一个 content bundle hash；身份、
prompt、process provenance 与 submission receipt 独立绑定，不能改变共享内容字节。

每名未来 coder 对 56 篇分别输出 paper labels；有实证实验时再输出 cells、observations、paired
comparisons、dataset graph、claim decisions、translation/compatibility decisions、source locators 与
review event。`agentic_scope` 与 cell 的单一 primary intervention 均为强类型 agreement critical path。

候选 readiness 对每项统一登记 official source、paper/repo revision、license、dataset/protocol、entrypoint、
access、evaluator、local state、specialized-model dependency、最强 blocker、deviation ledger、translation
与 rejection condition。所有候选 fail closed，`primary_selection` 与 `fallback_selection` 均保持 withheld。

## 4. 候选角色

1. AudioGenie-Reasoner：直接方法首要候选；本地 repo 已 pin，MMAU-mini/MMAR 已 pin；仍是
   `CANDIDATE_NOT_ANCHOR`，依赖、remote planner、adapter 与 evaluator 尚未闭合。
2. AudioToolAgent：task-matched nearest prior；是 external orchestration prior，不自动等同 reward-guided
   control；官方 repo HEAD 已核对，但 license、local materialization、API/model 与 exact setup 未闭合。
3. Audio2Tool：本地 speech tool-action/evaluator carrier；只允许 revision-bound allowlist loader，不能成为
   方法复现 anchor。
4. MMAU-mini、MMAR：validation carriers，只冻结 task/data/revision/evaluator readiness，不运行 benchmark。
5. LongShOTAgent、Active Perception Agent；VISUALSKILL、XSkill、MMSkills、Anything2Skill、
   RESOURCE2SKILL；M2A、Mem-Gallery、Mem2ActBench：默认 transfer analogues，必须通过 translation 与
   rejection gate。
