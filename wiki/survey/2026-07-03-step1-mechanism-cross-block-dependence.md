## B0 axis statement (constructor)

M2 occupies axis (a): changing q0. The killed object is Gibbs tilting of a SINGLE FIXED q0 under a given separable R, with qstar_product proving isolation is a no-op exactly when the base is a product measure. In long-form streaming ASR the base is neither fixed nor a product: block t's distribution is q0(·|x_t, ŷ_{<t}), conditioned on the decoder's own committed hypotheses, so the joint law Π_t q0(·|x_t, ŷ_{<t}) is a correlated chain whose per-block factors depend on realized history — qstar_product's product-base hypothesis fails identically, and no lane relitigation is involved because the claim degenerates EXACTLY to the killed no-op at the context-free boundary (q0(·|x,h) ≡ q0(·|x)): it generalizes the killed theorem rather than contradicting it. Context isolation replaces q0(·|x_t, ŷ_{<t}) with q0(·|x_t) — a base-measure change that moves the per-block oracle ceiling BEFORE any tilt is applied; no reward tilt appears anywhere in the claim, and the ceiling-separation quantity ε (committed-error lock-in mass, part iii below) contains neither β nor spread, so it is invisible to gain = β·KL(q0‖q*) ≤ spread²/(8β), which conditions on a fixed q0. This is P4's own admission made constructive — conditioning as a first-class q0-changing operator, with a published formal template (D1-07: conditioning = Bayesian posterior movement) — and it is the destructive dual of M3's support injection: carried erroneous context REMOVES effective support (D1-08's support-constraint logic run in reverse). The composite selection-feedback corollary (the selector's output at block t is injected into block t+1's conditioning state, coupling axis b into axis a) has no representation in the killed formalism, where selection is terminal: the C1 pipeline that was adjudicated on 7/02 contained no cross-block pathway at all.

### Formal statement attempt

SETUP. Let a frozen model define a conditional family q0(·|x,h) over transcripts y ∈ 𝒴, where x is an audio block and h ∈ 𝒴* ∪ {∅} is prompt-carried history (no weights change; scope-fence IN). Fix a stream x_1,…,x_T and per-block verifiable rewards R_t : 𝒴 → {0,1} (exact match; the joint reward Σ_t R_t is DELIBERATELY separable so the entire delta lives in the base measure, not in R — no M1 content). A context policy π sets the conditioning state: π^self commits a hypothesis chain and sets h_t = ŷ_{<t} (commit-then-continue: all N block-t candidates share the committed h_t, matching deployed streaming decoders); π^iso sets h_t = ∅; π^ctrl sets h_t = z_t (irrelevant text, token-length matched to π^self's context). Best-of-N block value: V_N^π(t) = E[max_{i≤N} R_t(y_t^{(i)})], y_t^{(i)} iid ~ q0(·|x_t, h_t) given h_t. Write p_t(h) = q0({y : R_t(y)=1} | x_t, h) and let μ_t be the law of the committed history under π^self.

CLAIM (context lock-in moves the oracle ceiling). (i) V_N^self(t) = E_{h∼μ_t}[1 − (1−p_t(h))^N] ≤ 1 − (1 − E_{μ_t} p_t(h))^N, with equality iff p_t(h) is μ_t-a.s. constant [Jensen; p ↦ 1−(1−p)^N is concave]. (ii) If E_{μ_t}[p_t(h)] ≤ p_t(∅) (A1, error amplification on average — an EMPIRICAL premise, measured not assumed), then V_N^self(t) ≤ V_N^iso(t) for every N. (iii) If μ_t(L_t) = ε_t > 0 where L_t = {h : p_t(h) = 0} (A2, lock-in mass) and p_t(∅) > 0, then lim_{N→∞} V_N^self(t) ≤ 1 − ε_t < 1 = lim_{N→∞} V_N^iso(t): the asymptotic ORACLE CEILINGS strictly separate by ε_t — a quantity containing neither β nor any reward spread — and no per-block sampling or tilting budget under π^self closes it. This is a ceiling statement (axis a), not a hit-cost statement (axis c). (iv) Degeneracy check: if the family is context-free, μ_t-dependence vanishes, V_N^self = V_N^iso = V_N^ctrl, and the claim collapses to the qstar_product no-op — the killed theorem is recovered exactly at the boundary where its product-base hypothesis holds; it is NOT of the form exp(a+b)=exp(a)·exp(b) because no Gibbs tilt appears: two different base measures are compared, one non-product. (v) Selection-feedback corollary (couples axis b to axis a): if the committing selector at block t improves in expected committed reward and p_{t+1} is stochastically increasing in committed-history correctness (A1-monotone), then V_N^self weakly increases at every subsequent block — the value of closing the C1 realized-vs-headroom estimation gap COMPOUNDS across blocks under π^self, whereas under π^iso it is exactly per-block additive. Proof burden: (i)–(iv) are elementary (mixture order statistics); (v) needs a monotone-coupling argument; the WER-valued (non-binary) extension needs a stochastic-dominance premise and is left open. Proving is post-GO work per timebox discipline; the T-part's value is the template (family q0(·|x,h) as first-class operator, ceiling separation with no β/spread, killed no-op as the boundary case, compounding corollary) — exactly what P4's what-would-overturn column requests.
