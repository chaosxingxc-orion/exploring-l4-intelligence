## B0 axis statement (constructor)

This lane occupies axis (b) — estimating R — and only that axis. The killed theorems (gain = beta*KL(q0||q*) <= spread^2/(8*beta); qstar_product) bound the value headroom of selection on a fixed q0 under a GIVEN reward R; they say nothing about the fidelity with which a deployed, label-free selector can ESTIMATE R, which the committed C1 artifact shows is the binding constraint (oracle +0.042 WER [0.029, 0.056] @ N=8 significant; label-free MBR null at every N; ~10% of headroom realized). M5 does not reduce to the killed object on any of its three coordinates: (i) q0 is fixed — every arm selects strictly within the same 8-candidate pool sampled once from the frozen model, and the oracle-in-pool ceiling is numerically identical across all arms in every analysis below; (ii) no new reward component is introduced and no context isolation is performed — the target functional is the same WER-reward R throughout; (iii) the claimed gain is a reduction of the realization gap (estimator risk), which is bounded above by the oracle headroom and therefore can never contradict the spread lens. The T-part is a Hoeffding/Condorcet aggregation bound plus an information-set separation (a single-shot proxy is a measurable function of the current item only; the accumulating selector conditions on past pools), which is not an algebraic relabeling of the Gibbs identity and does not invoke exp(a+b)=exp(a)exp(b) anywhere. The one genuinely new degree of freedom — cross-item evidence about recurring lexical types — exists precisely because deployment-time R is not reference-free computable from a single item, the exact gap the 7/02 verdict left standing as "estimating R".

### Formal statement attempt

SETTING. A frozen policy q0; a session stream of items t=1..T with unknown references; per item a pool Y_t of N i.i.d. candidates from q0(.|x_t); reward R_t(y) = -WER(ref_t, y). A single-shot label-free proxy is any measurable sigma(x_t, Y_t) (MBR utility, self-certainty, internal confidence). An accumulating selector is sigma_M(x_t, Y_t, M_{t-1}) where M_{t-1} is any label-free functional of past pools/picks. Both select an index WITHIN Y_t, so for every selector, realized gain <= oracle-in-pool headroom (ceiling unchanged — axis-b ontology pinned).

THEOREM CANDIDATE (cross-occurrence identifiability of rare types; finite form). Let w* be a rare lexical type (train-corpus frequency <= f0) occurring in the references of m >= 2 items T_w of the stream. Assume: (A1, support) each pool in T_w contains a candidate carrying w* with probability p_pool > 0, independently across items given w*; (A2, mode-at-truth margin) conditional on w* and across items in T_w, the per-item probability that a pool's consensus-2 rare-token set contains w* exceeds the corresponding probability for every FIXED wrong variant v != w* by margin gamma > 0 (acoustic realizations vary across items, so misrecognitions decorrelate while the true form recurs verbatim); (A3, retrieval) the memory keys occurrences of the same type across the session with recall 1 (exact rare-token match suffices in the ASR case). THEN: (1) the accumulated consensus-2 memory contains w* after m occurrences with probability >= 1 - exp(-2 m gamma^2) (Hoeffding on the margin count); (2) the memory-dominant within-pool selector attains expected excess reward over ANY single-shot proxy of at least Delta = p_act * E[per-token WER value], where p_act = P(w* in pool AND single-shot pick misses w* AND w* in memory) — a strictly positive, measurable quantity; (3) under shuffled memory (A3 broken by permuting sessions), the memory term is independent of w* and the expected excess is <= 0; (4) STRICT SEPARATION: if I(R_t ; M_{t-1} | x_t, Y_t) > 0 — which (A1)-(A2) imply through the recurring-type channel — then no measurable function of (x_t, Y_t) alone attains the Bayes risk of sigma_M; the class of single-shot reference-free proxies is uniformly dominated. NON-TAUTOLOGY: the content is an aggregation/estimation bound plus an information-set separation; it does not tilt q0, adds no reward component, never exceeds the oracle ceiling, and reduces to no instance of exp(a+b)=exp(a)exp(b) under any separability assumption. ## Refuter (prosecution; defends the 7/02 null)

### R1 tautology check

No direct collapse — the pinned ontology (fixed q0, fixed R, gain ≤ headroom) is deliberately outside the killed box, so B0 does not strike it a priori. BUT the tautology has an exact session-level analog that the strongest T-part cannot dodge for free: WER is separable across utterances (per-item reward) and, given fixed q0, per-utterance candidate pools are conditionally independent — so the session-level Gibbs optimum factorizes into per-utterance optima, exp(Σaₜ)=Πexp(aₜ), the qstar_product algebra lifted to the session product space. Cross-utterance accumulation therefore adds NOTHING over the best per-utterance proxy unless per-utterance reward posteriors are coupled through a shared latent (speaker lexicon/channel/topic); the T-part is non-tautological exactly and only on that coupling residual — whose in-house measured incidence is 3/144 dev positions (2.1%, the constructor's own structural_null_diagnostic). Two further degeneracies: (i) if 'single-item proxy' is allowed to condition on the observable session prefix — which any deployed streaming proxy can — then the comparison class contains every accumulation scheme as a member F(pool_t, prefix_t), and 'accumulation beats the best single-shot proxy' is definitionally false/vacuous; the only non-vacuous reading is 'beats MBR specifically', an engineering claim, not a theorem. (ii) Any provable identifiability/consistency statement of the targeted form ('accumulated cross-item evidence improves reward-proxy fidelity') reduces to empirical-Bayes shrinkage across items sharing a latent (Robbins 1956; James–Stein) — a relabeled textbook result. This mirrors P2 verbatim: 'the machine-checked halo covers only trivial algebra' — the provable part is 1950s empirical Bayes; the interesting part (the coupling premise) is an empirical assumption, not a theorem.
