### R1 tautology check

R1 verdict: NO on the letter, YES on a substitute degeneracy. Honest concession first: the pinned ontology genuinely dodges P1 — M5 makes no decomposition-adds-headroom claim, so it does not collapse to exp(a+b)=exp(a)·exp(b); axis (b) is real because the killed theorems assume R is given (prereg §1). But the T-part target ('conditions under which accumulated cross-item evidence provably improves reward-proxy fidelity over any single-item proxy, stated finitely') has its own collapse: its strongest provable form is a textbook hierarchical-Bayes / Rao-Blackwell pooling lemma — if per-item label-free signals are conditionally independent given an identifiable shared session latent θ (speaker lexicon / error profile) that is informative about R, then the pooled estimator has lower risk than any single-item estimator. This is (i) classical sequential estimation, no new mathematics; (ii) circular in exactly the P5 pattern ('gain only from new non-degenerate rewards' → here 'fidelity gain only from an informative shared latent' — the hypothesis IS the conclusion); (iii) an instance of P6 verbatim: 'credit assignment — the existence of a separable, verifiable per-block observable — is the whole hard problem ... the formalism simply ASSUMES it as a hypothesis.' The 'over ANY single-item proxy' quantifier is false in general: if utterances are conditionally independent given (audio, model), the single-item sufficient statistic already contains everything and past items add nothing — so the theorem MUST assume cross-item coupling, and when that coupling is instantiated concretely on this data the only candidate is recurring rare lexical items, which is M3's axis-(a) object and the cache-LM occupied cell. The identifiability escape additionally requires proxy errors independent across items; archive claim C3 (wiki/survey/2026-06-26-survey-rewards-eval.md, in-archive, delta=duplicate) pre-adjudicates the opposite: self-consistency pseudo-rewards are 'self-confirming' — errors correlate with the model's prior, breaking the independence identifiability needs. Also note the anti-Goodhart data-processing bound: memory is a function of past (pool, label-free signal) tuples; if the stored credit source is MBR utility, whose selection value is measured null at every N, accumulation can only amplify per-item correlation through cross-item redundancy — and the redundancy surface is measured in-house at 2.1% (see R3).
