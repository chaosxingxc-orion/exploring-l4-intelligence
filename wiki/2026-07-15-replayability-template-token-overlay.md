# 可回放模板 token 覆盖层

**取代范围（仅此一节）**：模板 §4「状态 token 与放行门槛」中涉及最强否定性结论的行——
`NO_DIRECT_MATCH_WITHIN_LOGGED_SCOPE` 一词**停用**（第三轮复审裁定其把「查询被记下」偷换为
「结果宇宙被完整审阅」；该词的历史使用被裁为 reviewer 诱导的善意用词,不追溯）。

**现行规则（RESP-02 §3.3,身份索引制）**：

1. 否定性结论**必须按身份索引**,不存在全局 token；每个身份的合法 token 以
   `RESP-02 §3.3` 表 + 合同修正案 №1 为准（如 strict-I2 = `NO_DIRECT_MATCH_AMONG_RETAINED_RECORDS`
   @记录集版本;I4 = `METHOD_FAMILY_OCCUPIED; INSTANTIATION UNDERSEARCHED; PREDICTIVE CONTRIBUTION
   NOT YET SHOWN`）。
2. 任何否定性结论必须带**强制伴随 token**：`SEARCH_RESULT_UNIVERSE_UNAVAILABLE`（round-1 范围）/
   `SCIENTIFIC_SATURATION_NOT_ASSESSABLE`,并钉定记录集版本与已知集外压力。
3. round-2 起,`WITHIN_PROTOCOL` 类措辞仅当该轮可回放协议（raw capture + 结果宇宙 + 筛选轨迹）
   全量执行后方可使用。
4. 机器执行面：P0-R8 校验器（`scripts/integrity/p0r8_state_gate.py`）对热层与新文档 fail-closed
   扫描;本模板与 Decision-Log 等历史/引文文件按范围豁免,但**新产出的 response/bundle 一律受检**。

模板 §0–§3、§5–§7（提交规则、replay bundle 结构、五级证据等级、双审、签署、给执行 AI 的指令）
**全部继续有效**。
