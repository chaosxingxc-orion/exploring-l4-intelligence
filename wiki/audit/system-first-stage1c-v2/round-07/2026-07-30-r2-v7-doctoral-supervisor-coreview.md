2. **唯一能分离"量"与"分配"的臂被移出主判据。** §5.3 把 `random-matched-cost（等成本随机调度）`

### MAJOR-2（§3.4 O 臂 + §7 K5 + §7 灵敏度前置；来源=变化 (a)+(d) 阶段二有界 + 多面 key 升主）
### 新增的 K5 没有可适用的分辨力前置，且其载体结构性地无法驱动 O2 赖以立论的非语义面

**问题。** 本件对 K1–K4 的最大制度成就是"判死永不在无分辨力的载体上宣布"（round-05 MAJOR-B
关闭点）。K5 是 v7 新增的第五个判据，它**继承了该前置的量词但继承不到它的检定**，并且它的载体
被本件自己的两处声明判定为无法激发 O2 的关键变量：

1. **三条检定在 K5 的载体上有两条不可构造。** §7 的检定①=`A1 − A0 ≥ 最小可检余量`，A1 是
   gold-entity + gold-path ceiling，只存在于 Omni-DeepSearch（`golden_path`）；检定②=固定预算档
   曲线斜率非零，`(5,1)/(10,3)/(15,5)` 是主载体的 retry 档。而 K5 的载体是
   **Spoken-SQuAD / SLUE-SQA-5**（§3.4 第 3 项、§6.1 O 行、§7 K5 三处一致声明"仅 T2"）——两个
   锚上既无实体路径 gold、也无该 retry 预算结构。只有检定③（correct→wrong 样本基数）可移植。
   于是"任何 K 判死只在载体通过检定后有效"这句全域量词对 K5 **形式满足、实质空转**。
2. **回退梯同样只覆盖主载体。** §5.4 的四级梯全部是 Omni-DeepSearch→AudioRAG 的载体替换路径，
   K5 失敏时无出口。
3. **更根本：O2 的立论变量在其载体上没有需求。** O2 的假设是"单向量把语义/副语言/说话人/场景
   各面压扁是检索失效的装载根源"，其对照力量来自**非语义面**（emotion2vec 一类的副语言面、
   audio2vec 一类的场景面）。而本件自陈：(i) 情感/副语言型外部知识**载体缺位**（§0、§1.1、
   §3.4 诚实声明、§9 调研待办四处），(ii) 因此"情感面 key 只做检索层读数，不做任务层主张"。
   两个锚是朗读/TTS 态的事实型口语 QA，其 query 的判别槽是语义槽。**结果：O2 在其唯一载体上
   只有语义面能动，而 K5 却完全定义在任务效用上**（"O2 相对 O1 …无任务效用/answer-bearing
   coverage 增益 → 装载升级不立研究主张"）。一个 K5 空值因此无法区分三件事：多面 key 无价值 /
   锚上无非语义需求 / 多出来的面只带来了检索噪声。
4. **后果不对称。** §3.4 与 §7 都写"K5 判死不伤主线"，这在**资源**意义上为真；但在**结论**意义上
   不为真：一个近乎注定的 K5 空值会被记入"装载升级不立研究主张"，即 owner 刚签认的阶段二有界
   研究内容会以一次无分辨力的读数被判死。这正是 round-05 MAJOR-B 所防的形态，在新臂上复现。

**v6 对照。** v6 无 K5、组织轴=FIXED，故无此洞；v6 的 assay-sensitivity 前置与其被保护的 K1–K4
共用同一载体，量词与检定同域。v7 扩了域、没有扩检定。

**建议修复。**
(a) 为 K5 立**独立分辨力前置**，至少两条：① 锚数据集中"判别槽为非语义槽"的 query 占比 ≥ 预注册
下限（若无法达到，K5 不得触发判死）；② O1 在该锚上的检索层读数（R@k）距天花板有预注册余量
（否则语义面已饱和，多面 key 无处发挥）。
(b) 把 K5 拆成两级：**检索层 K5-r**（O2 能否检回 O1 检不回的目标 value，按面分层报告——这是当前
载体唯一支持的判定）与**任务层 K5-t**（须在具备非语义槽需求的载体上才生效，在此前记
`PENDING_CARRIER`）。这与 §3.4 已写的"情感面只做检索层读数"完全同构，只是把同一纪律施加到判据上。
(c) §5.4 回退梯补一句 K5 载体失敏的出口（与梯④同型：不得宣布判死，回 owner）。

### MAJOR-3（§1.3 信息角色边界 vs §4.4/§4.5/§5.2；来源=变化 (b) 假设槽型泛化）

**问题。** 续79④ 把主张边界从槽型改挂**信息角色**，并写明"答案纯由音频决定的实例留在实验里
