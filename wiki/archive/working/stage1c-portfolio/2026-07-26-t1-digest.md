## Compression note
Each JSONL row packs one paper's PRIMARY experiment configuration; where a paper reports multiple benchmarks under the same frozen core + arm (e.g. AudioProcessBench's MMAU-Pro/MMAR/MMSU pool, or TalTech's/VISA's shared MMAR-1000), the benchmark ladder is compressed into `headline_numbers` rather than exploded into one row per benchmark. Papers with genuinely distinct frozen-core-x-arm configurations across benchmarks (e.g. Audio-Mind's MMAR vs MSU-Bench frontends) still report both numbers in one row's `headline_numbers` field for compactness; this is a deliberate compression, not a missing-data gap, and is flagged in `issues` in the manifest.

## Recurring cross-paper field facts anchored in this table (with row pointers)
1. **No scalar reward acts as an inference-time controller in the entire audio/omni corpus** except the disqualified train-time cases (2602.13685, 2603.05231, 2602.00846-RM-training, 2606.19341-TAURA) — every deployed decision is either an LLM classification or a hand-set scalar (rows: 2602.10656, 2509.21749, 2604.14520, 2604.09121/2605.29430, 2605.28192, 2510.11454, 2407.09886, 2603.17822, 2606.07264, 2605.28480, 2511.02834, 2605.08762, 2512.16978, 2512.23646).
2. **"Agentic loses to direct readout" is task-conditioned, not a law** (row 2511.02834 OmniInstruct −3.6; row 2512.23646 GPT-4o-brain 68.7<72.08; row 2605.28480 matched-AGR −8.4/−3.0; contrast with the MMAR-1000 agent track topping the direct-readout track by +11.07 Rubrics — TalTech 69.83 vs VISA-reported best direct 58.76, two papers, one leaderboard; VISA's own lift is +7.47).
3. **Verification-signal quality compresses sharply into selection utility, and can even invert rank** (row 2606.09925: 51.5pt step-spread → 9.5pt chain-spread, rank inversions; row 2606.04730: strongest signal wins one task while destroying two others; row 2607.13347: judge policies can be net-negative relative to doing nothing at all).
4. **Consensus/MBR is the empirically dominant, and often free, signal component** (row 2606.04730: MBR costs 0 model calls and 0% spurious-candidate selection; row 2606.09925: MV beats BoN for every real critic).
5. **Abstain/Tie calibration is a near-universal failure mode of LALM judges** (row 2606.24648: 18-19% Tie-accuracy on Style/Emphasis vs human 85.3/76.0, rising to 35-43% on Age/Gender where humans themselves fall to 38.7 on Age; row 2604.25591: abstention measured via AURAC but never deployed as policy anywhere in the corpus).
6. **Token-level metrics under-report wrapper gains on speech** (row 2605.29430: S²ER 19.73→4.16 while MER only 14.44→13.28; row 2605.28480: MMAR-Rubrics +6.9 vs accuracy-axis +1.5, ~4.6x the gap).
