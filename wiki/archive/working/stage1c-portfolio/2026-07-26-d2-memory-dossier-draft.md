### 2607.00685 — M2 Note: Continual Evolution of Vision Language Models via Mistake Notebook Learning (AMAP/Alibaba; arXiv:2607.00685v1, 1 Jul 2026, cs.MA)

**方法面（method surface）**：MECHANISM (§3.1-3.3). An external, editable memory M of triplets (s,g,e): s = subject (10-50-word domain+problem-type+solution-method label), g = guidance (a distilled 'mistake-to-guidance' checklist with explicit applicability conditions and anti-patterns), e = multimodal embedding of s(+)g computed by Qwen3-VL-Embedding. Two roles over ONE frozen core: a Tuning Model (solver) and a Tuner Model (supervisor); both are API/inference-only, NO weight updates anywhere ('context optimization', Eq.1: M* = argmax_M E[R(pi_theta(z))], z = (q,i) (+) Ret((q,i),M)).
READ PATH: cosine similarity of the query embedding E(q,i) against note embeddings, top-K with a relevance floor alpha (Eq.2; defaults K=1, alpha=0.4). Retrieved note is concatenated as ADVISORY context, plus a system-prompt read-gate ordering the solver to first declare the guidance 'applicable / partially applicable / irrelevant' and use only applicable parts (Appendix A.2 RAG-Enhanced System Prompt).
WRITE PATH: for each failed item, the Tuner runs sigma (subject extraction, Eq.3), phi (guidance synthesis from the failed trajectory, Eq.4), then an edit action a_k in {add, merge} (Eq.5); merges rewrite the subject and fuse guidance, preventing fragmentation.
COMMIT GATE: batch-level post-verification with rollback (Eq.6-7, Alg.1 line 16): rerun THE SAME batch under M'_i; accept iff Acc(B_i|M'_i) >= Acc(B_i|M_i), else roll back. Described as 'accept-if-improves ... monotonic non-degradation at the batch level' and as an implicit regularizer on notebook growth (§3.3(4)).
REWARD (§3.2): binary gold-match when labels exist; otherwise LLM-as-a-Judge binary verdict. Both instantiations are used, but the paper never ablates judge-reward vs gold-reward.
DECISION RIGHTS EXERCISED: write (add/merge), commit/rollback, read admission (alpha, top-K), and a soft per-item use/ignore right at read time. NOT exercised: candidate selection (single generation, no best-of-N), stopping, abstention, budget allocation.
TASKS: 6 VLM benchmarks (MMMU_val, MathVista, MMStar, RealworldQA, AI2D, ChartQA); backbones Qwen3-VL-8B-Instruct, Qwen3-VL-Plus, GPT-5.4. Two regimes: supervised (notebook built on train split, frozen for test) and test-time scaling (notebook evolves online during test).

Cross-model evolving (Plus as Tuner, 8B as solver): avg 76.6 (+2.3), MathVista +5.1, RealworldQA +3.9. CoT+M2Note 78.4 vs CoT-only 77.6. Cost approx $3-7 vs '>$500' for RL/DPE self-evolving baselines; memory stays tiny (28-50 entries in Table 1, up to 61-67 in the batch-size sweep and transfer tables; 261-462 tokens/guidance)【复核更正 wf_5f1f5801】.
GATE ABLATIONS. Write gate (Table 2): w/o post-verification MMMU_val 65.7 -- BELOW the 67.1 vanilla -- vs 68.4 with the gate; MathVista 76.2 vs 77.3. Read gate (Table 5): Naive-use 76.2/67.8/64.1 vs applicability-Judgment 77.3/68.4/63.9. Retrieval threshold sweep (Fig.3c): alpha=0.4 best, alpha=0.8 effectively disables the notebook and degrades accuracy; K robust but K=1 kept 'to reduce the risk of hallucinations'. **自述与显见局限**：STATED (§6 Limitation): the mechanism only works 'when mistakes exhibit recurring structure'; best in narrow domains (math) with stable abstractions; 'in broad domains with long-tail visual diversity, relevant notes can be harder to retrieve, and mismatched guidance may introduce misleading context or amplify hallucinations, making continual evolution less stable'. Authors name two directions: stronger abstraction + a more reliable post-update verification strategy, and 'enriching notes beyond text (e.g., reference images, tool-use traces, structured checklists)'.
EVIDENT (not stated): (a) the write gate is oracle-dependent -- it needs a scored batch, i.e. gold labels or a judge, and Table 2 shows that removing it makes the system NET NEGATIVE on MMMU; the label-free judge variant is never separately evaluated, so the gate's behaviour under a noisy reward is unmeasured. (b) The gate is batch-aggregate: a note that fixes 2 items and poisons 1 is committed; there is no per-note attribution, no eviction, no decay, no usage accounting. (c) No poisoning/adversarial threat model at all -- the only failure mode considered is 'unhelpful note', not 'hostile or distribution-shifted writer'; the accept-if-improves rule is a utility gate, not a provenance gate. (d) Cross-model transfer is lossy and can be NEGATIVE (Table 4: 8B-evolved notebook applied to Qwen3-VL-Plus gives MMMU_val -1.1); authors concede 'cross-model transfer is not always risk-free'. (e) Retrieval is content-semantic only; nothing in a note records the CONDITION under which the failure occurred. (f) K=1 means no multi-note aggregation and no conflict arbitration between contradictory notes. (g) Gains on the strongest backbone shrink to +0.8 avg (GPT-5.4), so headroom is anti-correlated with core strength (they say so: 'stronger backbones make fewer mistakes and require fewer notebook entries').

**改进空间（方向级台阶）**：Direction-level steps that remain OPEN on top of this work:
1. ACOUSTIC KEYING. The note key is a text/vision embedding of the query. For speech-omni, the recurring-failure structure is often not semantic but CONDITIONAL (this speaker/accent, this SNR, this codec, overlapped speech, this prosodic register). An open step is a two-part key -- (semantic subject) x (acoustic condition descriptor) -- with retrieval conditioned on measured or verbalized acoustic conditions, so a note reads 'under low-SNR far-field speech, this core drops final consonants; verify numerals by re-asking'. Their own §6 direction (2) ('enrich notes beyond text') is the door; they only imagine reference images.
2. BLACK-BOX-LEGAL WRITE GATE. Replace the gold/judge batch reward with signals our deployment actually has: consensus concentration over resampled candidates, judge MARGIN between top-2 candidates, self-verification vote rate. The paper proves the gate matters (Table 2, ungated writes go below vanilla) but never tests a gate built from unlabeled signals -- that is the exact untested step. Caveat: the full Table 2 picture shows this gate value is benchmark-specific (decisive on MMMU for both backbones; matched or slightly beaten by the ungated variant on MathVista/MMStar under Qwen3-VL-Plus, and on 8B/MMStar) -- worth stating precisely for anyone designing a black-box-legal replacement gate.【复核更正 wf_5f1f5801】
3. PER-NOTE CREDIT + LIFECYCLE. Move from batch accept/rollback to per-note counterfactual attribution (hold-out-one-note reruns), plus usage counters, decay, and eviction, so the notebook can be audited and shrunk rather than only merged.
4. POISONING DEFENCE. Introduce an explicit adversarial-write model: quarantine window, provenance fields (which core, which condition, which reward evidence), multi-sample corroboration before promotion, and rollback keyed to the writer rather than to the batch.
5. CROSS-INSTANCE MEMORY. Their Table 4 is the only negative-transfer datapoint in this trio (not run in any of the three papers read; surface = D2 corpus, 3 papers, cut 2026-07-26). Open: what makes a note core-agnostic? Condition-scoped notes (keyed to acoustic regime, not to a model's idiosyncratic error) are a candidate answer, and a transferability gate -- re-specified in legal signals as 'accept a foreign note only if, on a locally held-out CALIBRATION split we own, consensus concentration / judge margin improves post-injection' (an offline one-time calibration split is legal; a test-item-scored batch is not) -- is an obvious untried mechanism.【复核更正 wf_5f1f5801】
6. MISSING DECISION RIGHTS. No stop, no abstain, no budget. A memory that also carries 'in this regime, abstain / escalate' entries is unoccupied surface.

**资产完备度**：No code, data, or checkpoint release is stated anywhere in the paper (no repository URL, no availability section). **域界定**：TEXT+VISION only (VLM). No audio, no speech, no omni. TRANSFERS to speech-omni: the whole control-plane skeleton is modality-agnostic -- external editable note memory, embedding retrieval with a relevance floor, reflection-generated writes, accept-if-improves commit/rollback, and the read-time applicability judgment all operate on text context around a frozen core and are fully black-box legal (no weights, gradients, hidden states, or logprobs anywhere). DOES NOT TRANSFER: the retrieval key. Their multimodal ablation (Table 3) shows image+text embedding beats text-only (77.3/68.4/63.9 vs 75.5/66.6/59.1), i.e. the modality-native key is load-bearing -- and for speech there is no equivalent off-the-shelf acoustic-condition key in their design. Also non-transferring: the labeled-batch reward assumption (our deployment has no test-item gold), and the assumption that failure structure is domain/concept-shaped rather than condition-shaped. Cross-modality generalization claims are out of scope; treat this strictly as a transfer lens for an audio-omni instance.

**备注**：Field-fact tests: (i) no scalar reward acts as a controller here either -- the binary reward is a WRITE-ADMISSION test on an aggregate batch, not a per-step control signal, consistent with the campaign's prior finding; (ii) the paper is a clean instance of 'agentic wrapper on frozen core beats RL at 1/100 cost' but the wins are small (+0.8 to +2.3 avg) and shrink with core strength; (iii) their Table 5 read-gate is functionally an evaluator applied ON TOP of retrieval -- the same margin-arbiter posture our program wants, but implemented as a prompt instruction, never as a scored comparison.

### 2605.28192 — Agentic Active Omni-Modal Perception for Multi-Hop Audio-Visual Reasoning (MOV-Bench + AOP-Agent; SJTU; arXiv:2605.28192v1, 27 May 2026, cs.AI)

**方法面（method surface）**：TWO ARTIFACTS. (A) MOV-Bench: 519 human-verified multiple-choice questions over FineVideo, requiring integration of temporally dispersed evidence across BOTH audio and visual streams; 5 themes (causal/referential/relational/hypothetical/intent), 2/3/4 hops (295/138/86, mean 2.60 hops), 15 video categories, mean duration 240.26 s, 36.42% longer than 5 min. Built by LLM synthesis (Qwen3.5-Plus) from ASR transcripts + visual events + LLM-constructed audio events, then a LANGUAGE-ONLY filter (drop anything a text LLM answers without the video; 2240 -> 802 via DeepSeek-V4-Flash) then human verification (-> 519) for answer correctness, question naturalness, cross-modal grounding (§2.2.2, App.B).
(B) AOP-Agent: training-free, open-source-only agentic wrapper on a FROZEN Omni-LLM (all agents share one backbone unless stated).
MEMORY CONSTRUCTION (§3.2, App.D.4): ASR-timestamp segmentation (FunASR) into fine clips; adjacent clips merged into mid-level segments (merge threshold G_max=30 s, max 120 s, 2.5 s overlap), downsampled in resolution. For each mid-level segment an Omni-LLM emits a STRUCTURED record: visual keypoints K^v, AUDIO keypoints K^a, retrieval keywords K^w, and a segment description D_{V,i}; a global summary D_V is synthesized from all segment descriptions. Audio keypoints are natural-language ('A low, sustained, electronic musical tone plays throughout the segment'; the prompt asks for 'speech intention, emotion, sound events, environment sounds, and audio-only evidence that may not be visually obvious', Fig.9). Memory-construction temperature is 1.0 'to encourage diverse video descriptions' (App.C.2).
READ PATH: five observation tools over the hierarchy (App.D.2) -- description-based dense retrieval (cosine over BGE-M3 embeddings, Eq.2-3), keyword BM25 over K^w (Eq.4-5), keypoint hybrid over K^v and K^a with lambda mixing dense and BM25 CHOSEN BY THE PLANNER (Eq.6-7), neighbor temporal expansion with planner-chosen radius r (Eq.8), fine-grained drill-down into child clips (Eq.9).
CONTROL LOOP (§3.3, App.D.3): Planner A_P(Q, M_W, D_V) -> (P_cur, P_fut) picks the tool and its arguments plus a stated future plan; tools return O_t which is unioned into Evidence Memory M_E; Reflector A_R(O_t, M_E, P_cur) -> (S_S, R_r, D_r) assigns each candidate segment a DISCRETE relevance score in {0, 0.5, 1, 1.5, 2} with written scoring rubric, writes reflection feedback R_r explaining what is missing, and emits the control decision D_r in {continue, replan, answer}; Reasoner A_A(M_E, M_W, D_V) emits answer + predicted_option + confidence + evidence list. Working memory M_W = {P_past, P_fut, R_r}.
DECISION RIGHTS EXERCISED: allocate (tool + granularity + dense/sparse mix + neighbor radius), select/rank (reflector segment scores), repair (replan), STOP (reflector 'answer'; hard cap on rounds). NOT exercised: ABSTAIN -- the Reasoner prompt says 'You must select one of the provided options. Do not reject all options without selection' (Fig.14). No candidate resampling / best-of-N, no scalar reward.
EFFECT SIZES (Tables 1-4, Fig.5). MOV-Bench direct inference: Qwen3-Omni-Instruct 52.79 overall (62.43 short -> 45.50 long; 4-hop 51.16); Qwen3-Omni-Thinking 55.49 overall but 44.19 on 4-hop; MiniCPM-o 4.5 53.18; Qwen2.5-Omni-7B 46.63. **自述与显见局限**：STATED (Limitations section): benchmark scale is small (519) and LLM-synthesized questions 'may still be less diverse and natural than fully human-labeled data'; the multi-round loop adds inference overhead; 'hallucination and error propagation remain critical challenges' and 'although the reflector can partially mitigate error propagation, the overall accuracy is still constrained by the quality of the hierarchical omni-modal memory base and the reliability of the underlying OmniLLM'; the memory base 'is not streaming-friendly, as it relies on a multi-level offline construction process', limiting smart-glasses / live-streaming use. Their Appendix E.2 failure case is explicitly a MEMORY-POISONING case: the memory base contains a hallucinated cue ('someone shouts for everyone to stop'), the agent over-interprets the unsupported cue, infers a wrong causal relation, and answers wrongly -- they conclude it 'highlights the need for stronger hallucination detection and evidence verification'.
EVIDENT (not stated): (a) WRITES ARE COMPLETELY UNGATED -- every keypoint/description is committed from a SINGLE Omni-LLM pass at temperature 1.0, with no verification, no resampling, no consensus, no confidence field, no provenance, and no rollback; the only defence is prompt-level 'Do NOT hallucinate events outside this specific timeframe'. This is the direct cause of their own failure case. (b) Memory is strictly EPISODIC and per-video: nothing survives the question; there is no cross-instance or cross-session store, so the system re-learns nothing about which cues this core habitually mis-describes. (c) Audio is preserved only as TEXT -- retrieval indexes BGE-M3 text embeddings and BM25 over verbalized keypoints, so any acoustic property the core fails to verbalize (SNR, channel, speaker identity/turn, overlap, prosodic contour, codec artifacts) is unrecoverable downstream. (d) Segmentation is ASR-driven, so non-speech audio evidence has no independent temporal index. (e) Reflector relevance scores are single-shot LLM ratings on a 5-level scale, never calibrated, never validated against gold evidence spans; no ablation isolates 'scoring' from 'stop decision'. (f) No abstention right, by prompt construction. (g) The gain is backbone-dependent to the point of vanishing: +0.38 on Qwen2.5-Omni-7B vs +9.83 on Qwen3-Omni-Instruct. (h) No cost accounting in tokens/wall-clock against direct inference despite acknowledging overhead.

**改进空间（方向级台阶）**：Direction-level steps that remain OPEN on top of this work:
1. GATE THE MEMORY WRITE. Their poisoning failure is unforced: keypoint extraction is a single stochastic pass. Open step: resample segment descriptions K times and commit only fields with cross-sample agreement; attach a per-field confidence and provenance (segment id, sampling agreement, extraction prompt version); quarantine low-agreement fields so retrieval can down-weight rather than trust them. **方法面（method surface）**：MECHANISM (§III). That asymmetry should be stated explicitly in any cost table we publish.
R6 -- OVER-OBSERVATION IS REAL. AOP-Agent's rounds sweep degrades past 5 (60.85 -> 59.79 MOV-long; 38.24 -> 36.47 OVB-long). More retrieval is not monotonically better; a stopping right is a defence against our own memory.

NET POSITION FOR THE D2 CHARTER

The charter's four questions map cleanly onto what this trio settles and what it leaves. External memory designs for frozen cores: OCCUPIED in two distinct shapes (durable abstracted note store; per-episode structured evidence hierarchy). Write gating against poisoning: only a UTILITY gate exists (accept-if-improves, oracle-dependent), no provenance/adversarial gate anywhere, and the one omni system with an audio-bearing memory has NO gate and demonstrably poisons itself. Acoustic keying: entirely open -- every key in the trio is text, and the only audio-native fields are verbalized keypoints that discard the condition. Black-box-legal signals for gating writes/reads/abstention: the estimator ranking is now measured for ALLMs and the winners are consensus-shaped and legal (or trivially legalizable), but they have been wired ONLY to a fixed inference-mode router, never to a memory write, a memory read, or an abstention policy. The unbuilt step this trio makes concrete is a single sentence: a condition-keyed, provenance-carrying note store whose writes are admitted by consensus-and-margin statistics rather than by a label oracle, whose reads are gated by the same statistics, and which owns an abstain entry -- evaluated with same-backbone direct-inference controls and cost-annotated AURAC. Level discipline holds: this is a direction map, not an innovation lock, and no novelty verdict is implied.
