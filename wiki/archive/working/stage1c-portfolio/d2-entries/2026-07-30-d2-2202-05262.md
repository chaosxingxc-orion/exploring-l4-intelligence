## 1. 方法本质

ROME 分两步：先用**因果中介分析**（causal mediation analysis，承 Vig et al. 2020 / Pearl 2001）做
**causal tracing**——跑三遍网络（clean / 把主语 token 的 embedding 加 `ε~N(0;ν)` 噪声的 corrupted /
corrupted 但把某个 `h_i^{(l)}` 强制恢复为 clean 值），用 indirect effect
`IE = P_{*,clean h}[o] − P_*[o]` 量化每个隐状态对该事实预测的因果贡献；结论是因果效应集中在
**(i) MLP 模块、(ii) 中间若干层、(iii) 主语最后一个 token** 这三维交点（Figure 2），并另设"切断 MLP
的改图干预"验证低层效应依赖后续 MLP（Figure 3）。第二步把该定位落到权重：把
`W_proj^{(l)}` 视为**线性联想记忆**（`WK≈V`），用闭式的**秩一更新** `Ŵ = W + Λ(C^{-1}k_*)^T` 插入一
条新 (k_*, v_*)，其中 `k_*` = 主语末 token 处 MLP 非线性后的激活（对 50 条随机前缀取均值）、
`v_*` = 在"最大化 `o*` 概率 + 对『{subject} is a』提示的 KL 正则（论文称 **essence drift** 控制）"两项
目标下优化出的向量；`C = KK^T` 由 Wikipedia 样本预估的未中心化协方差预缓存。GPT-2 XL 的干预层取
**第 18 层**（MLP 因果效应中心），单次编辑在 A6000 上约 **2 秒**（附录 C.5）。

**"难以更新"是谁的结论——判定：不是 ROME 的。** ROME 的摘要原句是这些关联"correspond to
localized, **directly-editable** computations"，结论段原句是"demonstrate the **feasibility** of direct
manipulation of computational mechanisms in large pretrained models"。ROME 是**参数编辑成功**的正面
结果（Table 4：GPT-2 XL 综合分 S=**89.2**、GPT-J S=**91.5**，同时保住泛化与特异性，而所有对比方法至少
牺牲其一）。因此 R2 第 285–286 行"难以更新"一句**不是 ROME 的结论**，属后续文献（大规模/序列编辑、
涟漪效应一类）的口径，本读集内无该类论文承重 → **张冠李戴成立**。

## 2. 定位：它能锚什么、不能锚什么

**它能锚三件事**（皆有 ROME 原文句可引）：

1. **参数化事实存储是有结构、可寻址的**——localized factual association hypothesis 三维定位
   （MLP / 中层 / 主语末 token）。这是 R2 那句话的前半，成立。
2. **参数里的事实天生就是 key-value 形态**，且 key 与 value 语义分工明确：`k_*`=主语的检索头、
   `v_*`=被召回的属性内容头。这与 R2 §1.5"key 是检索头、value 是内容头，两者必须拆开"的核心概念
   **同构**，且是**参数侧**的先例（R2 现在只用 DPR 举外置侧的例）。ROME 甚至给了 key 的**多前缀取均值**
   构造（式 4，50 条长度 2–10 的随机前缀）以求 key 对上下文鲁棒——这是"同一 value 的 key 该怎么造"
   的一个具体答案。
3. **单事实参数编辑的代价与形态**：一次编辑一条事实（论文自述"it only edits a single fact at a time,
   and it is not intended as a practical method for large-scale model training"）；且**编辑是有向的**——
   "The iconic landmark in Seattle is the Space Needle"与其反向句**分开存储**，要同时改需**两次编辑**。

**它不能锚"知识必须外置"——除非换论据。** 按"难以更新"路径锚，与 ROME 自身结论相反。但 ROME §3.6
Limitations 末句提供了一条**它自己说的**、方向正确的论据：

> "Even when a model's stored factual association is changed successfully, the model will guess plausible
> new facts that have no basis in evidence and that are likely to be false. **This may limit the usefulness
> of a language model as a source of facts.**"

即：外置的理由不在"改不动"，而在**改动成功也没有出处、模型仍会编造无证据支撑的相邻事实**——这落在
**出处/证据轴**，恰好对上 R2 §3.3 反复点的组织 schema 缺字段（provenance、冲突标记、引用支持、
abstain）。建议 R2 改按这条锚。次级论据两条同样出自 §3.6：单事实粒度+有向存储的**每事实更新成本**；
以及"logical / spatial / numerical 知识未被研究、属性向量空间结构理解不完整"的**适用面窄**声明。

## 4. DFS 四问

**① 方法是什么？** 因果中介分析（clean/corrupted/corrupted-with-restoration 三跑 + indirect effect）
把事实召回定位到"中层 MLP × 主语末 token"，再把该层 `W_proj` 当线性联想记忆做闭式秩一更新插入新
(k_*, v_*)，其中 v_* 由"目标概率最大化 + essence-drift KL"优化得到。全流程**无需训练任何辅助网络**，
与需要 hypernetwork 训练的 KE/MEND 形成成本对照。

**② 局限是什么？**（全部为论文 §3.6 自述，非我方推断）一次只改一条事实、明确"不作为实用大规模方法"；
编辑**有向**（正反向须两次编辑）；未研究逻辑/空间/数值知识；属性向量空间结构理解不完整；**即使编辑成功，
模型仍会编造无证据支撑、且很可能为假的相邻新事实**。另有两条我方从数字读出的局限：zsRE 的 specificity
不敏感（论文自承），以及人评显示流畅度有其指标未捕捉的退化。

**③ 改进空间在哪？** 论文自己把"扩到多事实同时编辑"外包给 MEMIT（`meng2022memit`，正文两处显式指路），
说明规模化是当时的公开缺口；"编辑成功但无出处仍编造"这一条则**没有**参数侧解法被提出——它天然指向
外置证据+归因，也就是 R2 的地盘。essence-drift KL 只用了单一探针提示（"{subject} is a"），可扩为多面探针。

**④ 可借鉴什么？**（对 R2 最实质的一问）**(a) 评价套件形状**：ES/PS/NS + Fluency + Consistency 五维 +
调和均值 S，且 NS 的负例**刻意取潜空间近邻**——这套"必须同时报特异性/退化项，否则退化方法夺冠"的纪律
可直接搬到 R2 §6 评价层（KE-CF 的 ES 99.9 / NS 6.9 / S 18.1 就是反例证据）。**(b) key 构造**：多随机前缀
取均值以求 key 的上下文鲁棒性，对应 R2 O 臂"同一 value 多面 key"的具体做法。**(c) 干预定位方法论**：
"先用因果度量定位、再在被定位处做最小干预、并用干预结果反向确认定位"（Figure 5 的 layer×token 扫描与
Figure 2 的热图相互印证）——这个"定位→干预→回证"闭环是 R2 若要论证"某个环节是瓶颈"时可复用的论证
结构，比单点消融强。

### 深读后新增的、R2 应该知道的事实

1. **ROME 是参数编辑的正面结果，不是负面结果。** 引用它论证"外置"时若不加限定，等于把自己的
   pre-2024 原理基座建在一个方向相反的结论上——这是一个会被评审一击命中的点，优先级最高。
2. **ROME 提供了 R2 key-value 教义的参数侧同构先例**（`k_*`=主语检索头、`v_*`=属性内容头，
   `W_proj` 作线性联想记忆）。R2 §1.5 现在只有 DPR 一个外置侧例证；补上 ROME 这一侧后，
   "key/value 必须拆开"从一个 RAG 工程约定升格为**参数与外置两侧共有的结构事实**，论证强度提升。
3. **ROME 的 key 是"多前缀均值"**（50 条长度 2–10 随机前缀）——即 key 表示刻意求"对上下文不敏感"。
   R2 §3.3 讲语音域"每个 value 只有一个单向量 key、只服务一个匹配面"时，可用这条对照说明
   "key 该被主动设计"而非被动取一次编码。
4. **CounterFact 的 neighborhood 负例是 SPARQL 取潜空间近邻，不是随机抽样**；论文明说随机抽样
   （zsRE 做法）测不出 bleedover。R2 §5.1 批 Omni-DeepSearch-640"无负类"时，这是一条现成的
   **负类构造方法论**：负例要取"最容易被误伤的近邻"，不是取"无关样本"。
5. **"只报 efficacy 会让退化方法夺冠"有硬数字**：KE-CF ES 99.9 / NS 6.9 / GE 383.0 / S 18.1；
   MEND-CF ES 100.0 / NS 5.5 / S 14.9。R2 §6 评价层若设 gold/oracle 类上界行，须同时设退化项列。
6. **人评抓到了自动指标没抓到的退化**（ROME 一致性 1.8× 优于 FT+L，但流畅度反而略差）。
   R2 依赖三 LLM judge 的评测设计应记入这条：单一自动判官族可能系统性漏掉某一维退化。
7. **成本对照可直接引用**：ROME 单编辑 ≈2 s、零训练；KE/MEND 推理 ~100 ms 但需 hours-to-days 训练。
   这是"参数路线 vs 外置路线"成本记账的一个 pre-2024 锚点，与 R2 §6.5 九维成本向量的
   "只报告不设限"口径相容。
8. **适用面声明**：ROME 只覆盖 (s, r, o) 三元组式事实，**明确未覆盖逻辑/空间/数值知识**。R2 若用它
   泛化到"知识"整体，须自行加范围限定词。
