## 1. 方法本质

RAG 把一个预训练 seq2seq 生成器（BART-large，406M，论文称 **parametric memory**）与一个稠密向量索引
（2018-12 Wikipedia、100 词不重叠切段、21M 段、FAISS HNSW MIPS，论文称 **non-parametric memory**）组合成一个
把取回文档当**隐变量**并边缘化的概率模型，然后**端到端联合微调**（Figure 1 题注原文："We combine a pre-trained
retriever (Query Encoder + Document Index) with a pre-trained seq2seq model (Generator) and **fine-tune
end-to-end**"）。**生成器不是冻结的**：§2.4 明确"jointly train the retriever and generator components"，且
"keep the document encoder (and index) fixed, **only fine-tuning the query encoder BERT_q and the BART
generator**"——冻结的是 **document encoder 与索引**（理由是刷新索引的代价，对照 REALM），附录 G 记可训练参数
626M，其中 BART 占 406M。**RAG-Sequence** 用同一篇文档生成整个序列，`p(y|x) ≈ Σ_z p_η(z|x)Π_i p_θ(y_i|x,z,y_<i)`，
解码需对每篇文档各跑一次 beam search 再补前向（"Thorough Decoding"，或用 "Fast Decoding" 近似）；
**RAG-Token** 每个 token 可抽不同文档，`p(y|x) ≈ Π_i Σ_z p_η(z|x)p_θ(y_i|x,z,y_<i)`，可直接塞进标准 beam
decoder；分类任务（目标长度 1）下两者等价。检索是**无条件的**：每 query 必检、固定 top-K（训练 k∈{5,10}，
测试按 dev 选：QA 用 RAG-Token 15 篇 / RAG-Sequence 50 篇，生成任务 10 篇），**没有触发、没有停止、没有准入门**。

## 2. key-value 定位

- **key**：`BERT_d(z)` 的 [CLS] 稠密向量，来自 DPR 已发布 bi-encoder 检查点（该检查点带 NQ+TriviaQA 检索监督），
  **本文不训练它**；索引=单个 FAISS HNSW MIPS 索引，附录 G 记为 "21M **728** dimensional vectors, consisting of
  15.3B values"。⚠️ DPR 原文 d=**768**；两文不一致（21M×728≈15.3B 内部自洽，故疑为 RAG 附录笔误）。
  标 `UNVERIFIED`，R2 若需维度以 DPR 为准。
- **value**：取回的 100 词文档原文，与输入 `x` **直接拼接**后送进 BART（§2.3 "we simply concatenate them"）。
  无出处字段、无版本、无冲突标记、无引用归因、无 abstain。
- **key 与 value 的关系**：key = 编码器对同一 value 文本的确定性函数；**每个 value 恰好一个 key、单面**。
  RAG **不是**"key 与 value 装载不同信息"的先例。
- **可替换性的真实边界**：§4.5 "Index hot-swapping" 证明的是**整索引替换**（同编码器、同 schema、同源
  Wikipedia dump 的 2016 vs 2018 两版），不是"任意外部库可换"。
- **query 侧的可学部分只有 key 空间的 query 端**：`BERT_q` 被微调，`BERT_d` 与索引冻结——即"把 query 拉进
  已固定的 key 空间"，而非重建共同空间。这与 R2 §1.5 问题二的可行动作（红线下只能用已发布检查点）恰好同型。

## 4. DFS 四问

**方法**：把"世界知识"从生成器参数里搬到一个可独立替换的稠密向量索引，用隐变量边缘化把检索接进 seq2seq 的
可微训练环，两种边缘化粒度（per-sequence / per-token）覆盖"单文档答案"与"多文档拼合答案"两类需求。
运行时的全部自由度只有两项：调 K，与换索引。

**局限**：(a) 检索无条件、无预算、无停止、无准入——不存在任何"这次值不值得检"或"这条证据信不信"的决策；
(b) 增益的归因不干净——generator 与 query encoder 同时被微调，"外挂记忆有用"与"多训了 626M 参数"在
主表里无法分离（Table 6 的冻结检索器行只分离了**检索器是否可学**，没分离生成器）；(c) 附录 F/H 自陈两种
静默失效（null document 机制无效、story generation 上检索塌缩），说明该框架下"库是否真在起作用"不可由主指标判读。

**改进空间**：把运行时那两项自由度（K、索引）从固定超参升级为**按实例的决策**，就是 2024 年后整条自适应/
定价谱系的起点；把 Table 6 的"冻结 vs 可学检索器"对照换成"冻结全栈 + 外显控制面 vs 固定档"，就是 R2 的
杠杆一形态。RAG 自己留下的两个未做的实验位（"检索是否改变了答案"的逐次判定、"答案不在任何取回文档中却答对"
的比例）都可直接确定性离线计算。

**可借鉴**：① `parametric memory / non-parametric memory` 二分与 `index hot-swapping` 的实验形态——R2 §6.4
的复放合同（pin 索引/日期、落盘文档 ID）本质是把 hot-swapping 从"演示"升成"审计装置"；② "答案不在任何取回
文档中却答对" 的确定性统计量，可直接搬去做 R2 §1.3 第③类信息作用（潜在知识激发）的离线拆分；③ Figure 3
的"取回文档数扫描"作为固定档阶梯的报告形态。

### 5.2 深读后新增的、R2 应该知道的事实

1. **「学会不检索」在 2020 年就被试过并放弃**（附录 F "Null Document Probabilities"）：作者实现了 REALM 式
   null document 的三种变体（可学 null 文档 embedding / 静态可学 bias / 小网络预测 logit），**均无增益故删除**；
   并观察到 Open MS-MARCO 上模型对"不太可能从检索受益的问题"**学会总是取回同一批固定文档**，即退化成
   **no-op 检索**而不是不检索。→ 支持 R2 §4.5「明确不研究部署期 need-detection 通用检测器」的取舍，同时给出
   R2 应预期并主动检出的一种失效形态：**no-op 检索伪装成"不需要检索"**。R2 §6.5 的 answer-bearing coverage
   与 §6.4 的 rank/hash 轨迹恰好是它的检出装置，建议在 §4.5 或 §6.5 就地引这条 pre-2024 先例。
2. **检索塌缩（Retrieval Collapse，附录 H）**：在 story generation 上检索器塌缩成与输入无关的固定文档，
   generator 学会忽略它们，**RAG ≡ BART**。→ 组织/检索可以在主指标不报错的情况下**整体失效**；这是 R2 §6.3
   "知识源与索引不静默变化"与 §3.4 O2 构建的 pre-2024 直接先例。
3. **"更多不一定更好"的数量维 pre-2024 锚**（Figure 3）：测试期增加取回文档数时，**RAG-Sequence 单调改善，
   RAG-Token 在 10 篇处达峰后下降**；MS-MARCO 上 k 增大 Rouge-L 升而 Bleu-1 降（**指标间符号冲突**）。
   → R2 §4.1 把"更相关≠更好"的来源记给 Decocted 2604.04373（2026）；**数量维**的非单调与指标符号冲突
   在 2020 年即有。建议 R2 在 §4.1 或 §6.5 加一句 pre-2024 锚，并注意：R2 的固定档阶梯（§5.3）向上扫档时
   必须**逐指标**报符号，不能只报主指标。
4. **调优稀疏基线会赢的 pre-2024 锚就在 RAG 自己的消融里**（Table 6）：换成 BM25 检索器后 NQ 大幅下降
   （43.5→29.7），**但 FEVER 上 BM25 反而最好**（75.1/91.6 > 学习检索 74.5/90.6），作者归因为 FEVER claim
   高度实体中心、适合词面匹配。→ 与 R2 §3.4「对照臂必须含调优的稀疏基线（Pi-Serini 教训）」同构，可加
   pre-2024 锚。**同时是一条警告**：Table 6 的"冻结检索器"对照是**训练期冻结 vs 联合训练**，与 R2 红线下
   "全栈冻结 + 外显控制面"不同型，其掉分幅度（NQ −5.7 / −2.8）**不可**当作 R2 方案的效果预期。
5. **潜在知识激发（R2 §1.3 第③类信息作用）在 2020 年已有量化与机制证据**：NQ 上 **11.8%** 的正确作答
   发生在"没有任何取回文档含答案"时；Figure 2 的 document posterior 分析显示 Jeopardy 生成中首 token 后
   后验变平、BART 单独就能补完书名，作者结论是"非参数记忆帮助**引出**参数记忆中已有的具体知识"。
   → R2 §1.3 把第③类划给 R1/R6 是合理的边界，但本条说明：**检索带来的增益里有一份不是外部新信息**，
   R2 的 `delta_E` 与 A1′ 若不拆这一份，"外部知识的边际价值"会被系统性高估。RAG 给出的拆分统计量
   （"答案不在任何取回文档中却答对"的比例）是确定性、离线、无需 judge 的，建议直接纳入 R2 §6.5 合理性层。
6. **口径瑕疵（非承重）**：附录 G 把索引写成 "21M **728** dimensional vectors, consisting of 15.3B values"
   （21M×728≈15.3B，内部自洽），与 DPR 原文 d=**768** 冲突。标 `UNVERIFIED`，疑为 RAG 附录笔误；R2 引维度
   以 DPR 为准。另：eprint 内 `tables/main_results.tex`（`tab:benchmark`）是**未被 `\input` 的死文件**，其
   "Per-token + Frozen" 等行**不在论文中**，任何 R2 引用不得取自该文件。
