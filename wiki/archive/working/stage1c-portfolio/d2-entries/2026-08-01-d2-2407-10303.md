## 2. 方法本质

### 2.1 底座：冻结 transducer + 可训 BiLSTM context encoder + 交叉注意力 biasing adapter

本篇不新造架构，而是在既有 cross-attention neural biasing 范式（CLAS 系）上改两处工程细节。
底座机制（`2_contextual_asr.tex` §2.2，L36–52）：

1. 每个偏置词/短语 `c_j` 经 **BiLSTM context encoder** 编成定长嵌入 `c_j^e = BiLSTM(c_j)`
   （L38）；特设 `c_0` 为 *no-bias* 选项、其嵌入硬连线为全零（L34、L40）。
2. 编码器某层输出 `h_t^enc`（或 predictor 的 `h_{u-1}^pred`）作 **query**，`C^e` 同时作 key 与
   value，走多头点积注意力得 `A^enc = MHA(q=H^enc, k=C^e, v=C^e)`（L44），注意力输出
   `b_t^enc = (a_t^enc)^T · C^e`（L46）。
3. **写回**：`ĥ_t^enc = h_t^enc + b_t^enc`（L50），修改后的表示**继续喂给下一编码器层或 joiner**
   （L52）。

配置（`4_experiments.tex` L17–18）：BiLSTM context encoder **2 层、128 维隐状态，跨全部
biasing 模块共享**；每个 biasing adapter = **4 头、128 维**点积注意力层 + 必要投影层；全部
biasing 模块合计 **3.7%–6.7%** 的 transducer 参数量（71.5M × [3.7%, 6.7%] ≈ **2.6M–4.8M**）；
**ScaledAdam，30 epochs**。作者另报两条负结果（同 L17）：**用独立 context encoder 或改用 BERT
作 context encoder 均无改善**——这是一条对 R2 有用的顺带读数（偏置 key 的语义容量不是瓶颈，
见 §9 第 6 条）。

### 2.2 贡献一：early context injection（把注入点从末层前移到编码器中段）

论证（`3_proposed.tex` §3.1 L4）：既有工作只注入编码器**最终**输出，缺陷是
"the contextualization of a frame `ĥ_t^enc` has no impact on the other frames, as they are edited
essentially independently from one another"；若注入到更早的层，"it may have far-reaching impacts
on the model's internal states via its self-attention mechanism"。即**机制主张=让偏置信息经过
后续自注意力层的跨帧传播**，而非逐帧独立编辑。

主模型注入点=**第 9 层与第 15 层（末层）**（`4_experiments.tex` L17，编码器共 15 层）。
**predictor 侧仍只在最终输出偏置**（`3_proposed.tex` L8，理由=predictor 常为 LSTM 或无状态
n-gram 前馈网络）。

作者预先反驳计算开销质疑（`3_proposed.tex` L6）：一次 context lookup 的量级与一层编码器对
数百帧做自注意力相当，故"this overhead is negligible"——该定性主张与其自表数字的张力见 §4.4。

### 2.3 贡献二：text perturbation（**训练期**数据增强，非推理期机制）

诊断（`3_proposed.tex` L41 + Table 1）：训练集上模型早已过拟合，含**至少一个被误识稀词**的
句子只占 **29.38%（LibriSpeech）/ 4.42%（SPGISpeech）**——只有这部分句子在训练时才可能真正
从"含 ground-truth 稀词的上下文"里获益，其余句子的 biasing 模块学不到"要去查上下文"。

手段（`3_proposed.tex` L48–50 + `4_experiments.tex` L10）：以 **< 200 条手工语言学规则**
（例 `"ein"↔"ane"`、`"s"↔"z"`，**覆盖全部 26 个英文字母**；`1_introduction.tex` L37）对稀词
生成同音异拼替代，按**最大匹配**替换（例 `"lee"→"li"`，即使 `"e"↔"a"` 也匹配也不取）；
**以概率 p=0.2 逐稀词随机扰动，且在 reference transcription 与 context 两侧同时替换**
（`1_introduction.tex` L37 举例：把 "Klein" 在转写与上下文中同时改成 "Klane"）。

效果（Table 1，同 `3_proposed.tex` L41）：含被误识稀词的句子占比由 **29.38% → 90.13%
（LibriSpeech）**、**4.42% → 36.37%（SPGISpeech）**。

**机制归属必须钉死**：扰动只发生在**训练期**。推理期模型参数不变、测试上下文不扰动、无额外
计算。因此本贡献 **100% 落在 R2 边界的训练侧**，其推理期形态为零——这既意味着"不能作
training-free 先例"，也意味着"其语言学规则集本身可以被 training-free 地挪作他用"（见 §6
可借鉴 (b)、§8 HG-RA-2）。

### 3.2 信息访问=**读写双向白盒**，比只读白盒离 API-only 更远

R2 §8 的"信息访问"列区分黑盒 / prompt 级 / 白盒。本篇的位置必须写准：

- 它不只**读**编码器第 9 层的中间激活作 query，还要把注意力输出**加回该层并让其继续前向**
  （`ĥ_t^enc = h_t^enc + b_t^enc`，`2_contextual_asr.tex` L50–52）。这是对内部状态的**写**操作。
- 因此部署要求是：可取任意中间层张量 + 可在层间插入自定义模块 + 可端到端反传梯度到该模块。
  任何 API-only 部署（含 llama.cpp/vLLM/HTTP 端点）都不满足。
- 与读集内其它白盒件的相对位置：PRISM 改写 beam-search 解码环（解码期白盒）、WCTC-Biasing
  中间层读+写回（**同型**）、RECAST 读 decoder state 并接管解码环。本篇与 WCTC-Biasing 同为
  **编码器内部读写**，但 WCTC-Biasing 免重训练、本篇需 30 epochs——**本篇是读集内"训练态×
  白盒深度"双维度都最远离 R2 边界的近邻之一**。

## 6. DFS 四问

**方法**：在**冻结**的 Zipformer stateless transducer 之上训一组轻量偏置通路（共享 BiLSTM
context encoder + 逐注入点 cross-attention adapter，合计 3.7%–6.7% 参数、30 epochs），把上下文
的注入点从"仅编码器末层"前移到"编码器第 9 层 + 末层"，让偏置信息经后续自注意力跨帧扩散；
并在**训练期**用 < 200 条手工同音异拼规则以 p=0.2 同时扰动 reference 与 context，把"含误识
稀词、因而真能从上下文获益"的训练句占比从 29.38% 抬到 90.13%，强迫偏置通路学会依赖上下文。

**局限**（十条，全部源内可核）：

- (i) **非 training-free 且非 API-only**：30 epochs 训练 + 编码器中间层**读写**（§3.1/§3.2）。
- (ii) **真实上下文载体上不成立**：ConEC/Earnings-21 总 WER 10.40 输零训练 SF 10.29、U-WER 输、
  PRODUCT 输到连"不加偏置"都不如；vanilla NB 更在四项上净负于不加偏置（§4.3）。
- (iii) **头条 60%/25% 只在 test-other N=500 一格复现**；N=1000/test-clean 三列全输 SF（§4.2）。
  增益随偏置表规模衰减，而真实上下文正是大表。
- (iv) **成功载体的上下文全部 gold 派生**（LS/SPGI 的上下文由 reference 稀词构造），唯一非
  gold 派生的载体即失败载体（§3.3）。
- (v) **超参选型面只报 test 集，源内无 dev 声明**（§3.4）。
- (vi) **"overhead negligible" 与自表 +31%~+38% 墙钟不符**（§4.4）。
- (vii) **无任何自适应门**：上下文逐句无条件注入，无 no-context 分支、无准入过滤、无按不确定性
  触发。`c_0` 零嵌入的 *no-bias* 选项是注意力**内部的软出口**，不是可读出、可标定、可外显阈值化
  的门——源内对其无任何消融或读数。
- (viii) **不可复现**（§5）。
- (ix) **未作 oracle headroom 记账**，尽管其**自家前作**同载体同骨干的 oracle 9.69 已发表，且
  提纲显示 oracle 对照曾在计划内又被舍弃（§5 第 4 条）。
- (x) **p 只扫 {0.1,0.2,0.4}**，p=0.4 的 B-WER 更优被"平衡"理由弃用，但未给加权准则（§4.5）。

**改进空间**（本篇留下的、R2 可占的空位）：

1. **准入/门控**：ConEC 的失效形态（U-WER 纯损、PRODUCT 倒亏、vanilla NB 全面净负）就是
   "无条件注入的稀释代价"。本篇**同载体、同骨干**已经把 NO / 零训练 SF / trained NB /
   trained NB+早注入+TP 四臂全部跑齐，缺的恰是**第五臂：逐句（或逐实体类）决定注不注、注哪些**。
   注意 PRODUCT 与 PERSON 的符号相反（PRODUCT 倒亏 24.4% 余量、PERSON 取走 30.9%），说明门控
   信号即使只有"实体类"这一粗粒度也可能有效——这是一个成本极低的可证伪起点。
2. **偏置表规模自适应**：作者**自己**把"缩短偏置表"列为 future work（`1_introduction.tex` L35
   "light-weight algorithms may be applied to shorten the biasing lists, which can be a future
   work"；`5_conclusions.tex` 重申 "shortening the biasing lists or reducing the sensitivity of
   contextual ASR models to the distractors"）。**即"选择注入什么"是本篇作者公开承认的未解问题**
   ——R2 在该分量上的独立性不必靠"没人做过"，而可以直接引其自认。
3. **把 text perturbation 从训练期搬到推理期**：其作用机制是"制造不看上下文就答不对的样本"。
   在 training-free 设置下的对偶是：用**同一套规则集**在推理期生成同音异拼候选，作
   (a) 检索/匹配的 query 扩展，或 (b) **一致性探针**——若模型对原拼写与扰动拼写给出同一假设，
   说明它没在听声学证据，该假设的置信应被下调。这把一个纯训练期技巧改造成 R2 的**模型外
   标量门信号源**，是本篇最可移植的一条，且不需要原规则表（规则形态在源内已给足样例）。
4. **oracle 余量记账**：R2 在 Earnings21/ConEC 上应报"取走 oracle 余量的百分比"而非相对增益。
   本件已给出三个现成基准点（SF 16.7%、本篇 1.4%、B-WER 侧 16.2%/19.3%）。

**可借鉴**：

- (a) **同骨干、同载体、按信息边界分层的现成 incumbent 阶梯**：
  `NO → 零训练 SF → trained NB → trained NB+早注入+TP`（本篇 Table 3）
  `+ 合成上下文 SF（10.08）+ Fox 共享表 SF（10.22）+ ConEC oracle（9.69）`（前作 Table 2），
  全部在 **Earnings-21 = R2 主载体**上、全部用同一 71.5M Zipformer transducer 与同一评测协议
  （fstalign + Whisper normalizer）。这是 R2 §8 组①③④分组合同要的形状，且**自带一个"训练
  不敌零训练"的读数**——不需要 R2 自己制造。
- (b) **< 200 条覆盖 26 字母的手工同音异拼规则**：零成本、零训练、可离线执行、可完全自建的候选
  生成器形态，直接对接 R2 §2.3 的发音库/异拼候选通道（原表不可得，须自建，但规则形态与"最大
  匹配替换"策略在源内已明示）。
- (c) **注入位置的非单调性**（单点中层 > 单点末层；4 点 < 2 点）：一个跨方法可迁移的先例——
  "注入更多不等于更好"在**白盒深层**也成立，与 R2 在 prompt 层观察到的稀释代价同构。
- (d) **U-WER/B-WER 显式帕累托刻度**（p=0.4：B-WER 更优 14.7%、U-WER 回退）：R2 四层评价里
  "稀词/实体增益不得以常词代价换取"的现成刻度盘，且 §4.3 的 oracle 分析已证明**常词侧余量
  恒为 0**，故常词回退在该载体上永远是纯损。

## 8. 2026 重审条款预置

提案 §8 的通用重审条款针对"2023 时代近邻"。本篇为 2024 件、且属 round-16 指认的载体谱系，
故按篇预置**三条具名重审对象**，Stage-2A 复现先行时逐条重审、结论回写本条目：

1. **HG-RA-1（早注入前提在冻结 omni 核上的存活）**。本篇的承重前提是
   *「上下文必须被写进声学编码器的中间状态、经自注意力跨帧扩散，逐帧独立编辑末层是不够的」*
   （`3_proposed.tex` L4）。该前提与 WCTC-Biasing 的"须在声学编码器内 biasing"反主张**同向**，
   共同构成 R2 API-only 红线的最强技术性反对。
   **重审问句**：在冻结的 Qwen3-Omni-30B 上、以原生上下文通道消费候选词表时，该前提是否仍成立？
   **判定后果**：若不成立 → 本篇与 WCTC-Biasing 的这一分量共同失效，R2 的 API-only 红线代价
   显著下降；**若仍成立 → R2 必须在 §1.4 显式记账"红线换来的性能上限损失"，并在 §5.3 回退梯里
   预置白盒回退档**。两个分支都必须写进 prior-difference 记账，不得只留有利分支。
2. **HG-RA-2（真实上下文失效的归因分解：噪声轴 × 规模轴）**。本篇同骨干上给出了两组对照：
   gold 派生上下文（LS/SPGI，本篇全胜或近全胜）vs 真实上下文（ConEC，败给零训练 SF）；以及
   偏置表规模 N=100/500/1000 的单调衰减（§4.2）。**但两者从未正交分解**——ConEC 的失败究竟是
   "上下文含误导性干扰"（ConEC 论文自举 GE 财报 "Aviation and Renewables" 例）还是"表太大"，
   源内无法判定。
   **重审设计**：R2 在 Earnings21 上主张门控准入时，**必须自带噪声轴 × 规模轴的二维分解**
   （固定表规模变噪声比例 / 固定噪声比例变表规模），否则即复制本篇的归因缺口，本条目判其
   效应量不可归因于门控。
   **判定后果**：若在冻结 omni 核上真实上下文注入**不再净负**，R2 的准入门从"必要项候选"
   降为"优化项"，须如实回写 §8 与 §4.4 的门位主张。
3. **HG-RA-3（oracle 余量记账的强制继承）**。本篇未对其自家前作已发表的同载体 oracle（9.69）
   作 headroom 记账，只报相对基线增益；提纲 `plan.txt` 显示 oracle 对照曾在计划内又被舍弃。
   **重审约束**：R2 在 Earnings21/ConEC 上的**任何**数字，若不同时给出"取走 oracle 余量的
   百分比"，本条目判其继承了本篇的记账缺陷，该数字不得作为效应量上报。本件已给出三个现成
   基准点（总 WER：SF 16.7%、本篇 1.4%；B-WER：SF 16.2%、本篇 19.3%）。
   **附加约束**：ConEC oracle 是**gold 对齐的事后替换**（用 gold 决定哪些词该替换成什么），
   属 R2 §6.3 "test gold 禁入 controller" 覆盖的 oracle 类；它只能作**上界刻度**，
   **不得**作为任何主张臂或对手臂参与 K-NB 判定。

## 9. 深读后新增的、R2 应该知道的事实

1. **R2 的主载体上已经存在一条完整的、同骨干的公开阶梯，且其顶点不是训练方法**。在
   Earnings-21 上、同一 71.5M SPGI-训练 Zipformer transducer、同一评测协议下：
   `ConEC oracle 9.69 < Fox 共享表 SF 10.22 < 零训练 SF（真实上下文）10.29 < 本篇 trained 10.40
   < 不加偏置 10.41 < vanilla trained NB 10.66`（合成上下文 SF 10.08 单列，因其上下文 gold 派生、
   非同信息边界）。**R2 无须自建这条阶梯，但必须按信息边界分组呈现它，且不得把 10.40 说成上界。**
2. **U-WER 侧的余量恒为零，这给了 R2 一把免费的稀释代价尺**。ConEC oracle 按构造只替换实体词，
   故其常词 WER 与"不加偏置"相同（8.71）。推论：**该载体上任何注入方法的 U-WER 回退都是纯损、
   没有对价**。现成读数：SF −0.01pp（约平）、本篇 −0.05pp、vanilla NB **−0.22pp**。R2 的门控
   准入臂可以直接把"U-WER 回退量"作为无争议的代价指标，无需新定义。
3. **"无条件注入净负"在语音域、真实上下文、R2 主载体上得到第三个独立数据点**。此前 R2 §8 的
   双侧证据合同引的是 RECAST（全表注入 82.5 vs 裸 19.6）与 RAG-Boost（raw-RAG 15.09→32.98），
   两者都在 LLM/SLM 栈上、且都不是 R2 主载体。本篇的 vanilla NB 在 Earnings-21 上四项净负于
   不加偏置（10.66/8.93/26.44/24.85 vs 10.41/8.71/26.02/24.25）——**同载体、传统 transducer 栈、
   真实上下文**，是该合同最贴身的一点。同时它落在"注入接口类型"的第三类（编码器内部加性写回，
   既非 prompt 拼接也非解码期分数插值），可用于回答 §8 登记的待判问题
   "注入接口类型决定稀释代价"。
4. **本篇给出"gold 派生上下文 → 真实上下文"的受控降级刻度**：同方法（SF）、同骨干下，
   10.08 (8.62/23.43) → 10.29 (8.70/24.84)，即总 WER 退 0.21pp、B-WER 退 1.41pp（交叉核件
   Table 2 行 2 vs 行 4）。**任何在 LibriSpeech 式合成偏置协议上取得的增益，迁移到真实上下文时
   须按此量级折价**——这条对 R2 的组④对照载体（LibriSpeech+Rare5k）与主载体（Earnings21）之间
   的口径换算是直接可用的。
5. **一条会削弱 R2 "冻结强核"叙事的反向读数，必须成对登记**：交叉核件 ConEC Table 2 行 8，
   **Whisper (large, 1550M)、零上下文、零偏置**，在同一 Earnings-21 上得
   **7.98 (6.94/17.43)**——**总 WER 与 B-WER 双双优于上述全部偏置结果，包括 oracle 9.69/18.72**。
   **口径警告（必须同时引用）**：(a) 模型规模差 21.7 倍（1550M vs 71.5M）；(b) Whisper 侧未加
   任何上下文，故这不是"上下文无用"的证据，而是"骨干能力可以压过上下文机制"的证据；
   (c) ConEC 论文用 WhisperX 对齐、假设与参考均过 Whisper normalizer，与 transducer 行是否
   完全同口径，源内未逐项声明；(d) ConEC 论文同页自述：Whisper large 在需要专门知识的实体类
   （PERSON 28.9、ORG 19.6、GPE 17.0、PROD 18.7、FAC 21.6）上"remains challenging with WERs
   greater than 15%"，而 Whisper **base**（74M，与其模型同量级）**并未**胜过不加偏置的
   transducer（14.67 vs 10.41）。
   **对 R2 的净含义**：这条同时**支持**"冻结强核 + 知识层"的路线（大冻结核的裸底比小模型加
   训练偏置更高），又**收窄**了知识层可主张的余量（大核的总 WER 余量已被吃掉大半，剩下的
   headroom 集中在实体类）。R2 §0 的"知识层护城河=带范围可证伪命题"条款应把这条列为
   **具名反向先验**，与 PRISM 的 LOC 反向读数并列。
6. **两条顺带的负结果，对 R2 的 key 设计有直接约束**（`4_experiments.tex` L17）：
   (a) **用独立 context encoder（而非共享）无改善**；(b) **用 BERT 替换 BiLSTM 作 context encoder
   无改善**。作者在被注释掉的原稿里写下了解释（`2_contextual_asr.tex` L20 注释行）：
   "The encoder has most likely learned to encode the pronunciation."
   **含义**：在该范式下，偏置 key 的有效信息是**发音**而非语义，语义容量（BERT）不是瓶颈。
   这直接支持 R2 §2.3 "机制核=实体发音库"的选择，且是一条来自**反对阵营内部**的支持性读数
   （其被注释掉说明作者未公开承诺，引用时须标注为"源内注释行、非正文主张"）。
7. **"缩短偏置表"是本篇作者公开承认的未解问题**（`1_introduction.tex` L35、`5_conclusions.tex`）。
   R2 在"选择注入什么/注入多少"分量上的独立性主张，可以从"读集内无人占据"（弱量词、易被新
   文献击穿）升级为"该领域的直接先例作者自己把它列为 future work"（强、可引、时间稳定）。
8. **注入点非单调性是跨接口层可迁移的先例**（Table 4：单中层 9 = 4.25 优于单末层 15 = 4.33；
   四点 4.19 劣于两点 4.00）。R2 此前的稀释代价证据全在 prompt 层（RECAST/RAG-Boost/Siskos）；
   本篇把同一形状的非单调性搬到了**白盒深层**，说明"更多注入 ≠ 更好"不是 prompt 接口的偶然
   性质。可作 §4.1 "更相关 ≠ 更好"的第二类接口证据。
9. **本篇的墙钟数字是 R2 预算章可直接引的接口成本刻度**：5.3 小时 test-other、单张 V100、
   beam=4，不加偏置 2.6 分钟 → 两点注入 3.4 分钟（**+30.8%**）→ 四点注入 3.6 分钟（**+38.5%**），
   偏置表 N=500。作者称此为 "negligible"；R2 引用时**必须携带比例而非形容词**。
