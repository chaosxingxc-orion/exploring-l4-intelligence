## §1 方法本质

OmniAgent 把长视频/omni 理解形式化为 POMDP，让**同一个 omni 模型**既感知又推理又行动，
通过迭代的 **Observation-Thought-Action（OTA）** 循环按需向环境索取原始媒体。核心架构是
**易失感知（transient percept $\mathcal{E}_k$）与持久文本记忆（$\mathcal{M}_k$）的严格
分离**：每一轮策略 $\pi_\theta$ 把上一轮返回的原始媒体蒸馏成一段结构化文本观测 $O_k$
写入 $\mathcal{M}_k$，随后环境**把原始媒体从上下文里物理删除**（替换为
`[MEDIA OMITTED - Refer to Observation]` 占位并保留时间戳），使上下文开销与视频时长
解耦。动作空间恰为四个：$a_{\text{frames}}(s,e,n)$ 取区间内 $n$ 帧、
$a_{\text{audio}}(s,e)$ **取该区间的音频段**、$a_{\text{clip}}(s,e)$ 取带同步音频的
连续片段、$a_{\text{answer}}(y)$ 作答并终止。环境 $\Omega$ 只做 ffmpeg 级原始媒体抽取
（音频统一解码为 16 kHz PCM S16LE 单声道并用 ffprobe 校验区间对齐），**一切语义感知
由策略本体完成，无任何外部专家模块、无检索、无知识库**。策略经**两阶段训练**得到：
(i) **Agentic SFT**——用 Gemini-3.0-Pro 在环境里做 best-of-N 成功导向探索，产出 58K 条
轨迹（含自纠错轨迹以免 teacher-forcing 偏置），经"结果验证 + GPT-4o 理性审计（5 分
Likert，≥3/5）"双阶段质控；(ii) **Agentic RL**——在 SFT 阶段 best-of-N 失败的难题上做
GRPO，并用自研的 **TAURA**（Turn-aware Adaptive Uncertainty Rescaled Advantage）以
逐轮 token 熵为连续权重把轨迹级 advantage 重分配到轮级，解决多轮 GRPO 的 advantage
homogenization。推理期的控制规则写在 prompt 里：**必须输出一个 0.0–1.0 的 `confidence`
字段（"Confidence Gatekeeper"），只有 confidence ≥ 0.9 才允许发出 answer，否则继续
取证，除非环境 `[NOTICE]` 提示 FINAL STEP**；prompt 另有"同一动作+区间不得请求两次，
但鼓励换模态或更高密度重查同一区间"的新颖性约束、"在 think 字段主动寻找反驳当前主假设的
证据"的反确认偏置要求、以及针对 ASR 的"不得为迁就假设而改写或推测词语"。

## §2 六字段方法卡（对齐 R2 §2.1 格式）

| 字段 | 内容 |
|---|---|
| **组织** | **无外部知识组织；有回合内持久文本记忆。** $\mathcal{M}_k=(O_0,\text{OTA}_1,\dots,\text{OTA}_k)$ 是**单实例、单回合**的推理迹，跨题即弃；没有语料库、索引、快照、跨实例记忆或版本。有一条真实的组织机制：**媒体清洗式上下文重写**——非破坏性地删除历史消息里的 image/video/audio 条目，替换为保留了精确时间戳的文本占位（帧动作保留全部采样时间戳，音频/clip 动作保留请求区间头），使媒体开销为常数阶。有出处约定：prompt 强制在 observation 与 think 中以 Full Evidence ID 前缀标注每条发现（如 `[Frames 10.0s-12.0s (num=5)]`）——这是三篇里**唯一**存在的 provenance 规范。无冲突标记字段、无来源质量分级、无 abstain 支持。 |
| **供给** | **训练出来的自适应策略 + prompt 内的固定阈值门 + 时长缩放的硬上限。** 每轮策略自回归产出 $(O_k,T_k,A_k)$，动作类型与参数（区间、帧数）由策略选定；停止由两条规则共同决定：**(1) confidence ≥ 0.9 才允许 answer**（prompt 常数阈值，作用在策略自报的标量上）；(2) 硬上限 $K$ 随时长缩放（SFT 期 $K\in[5,32]$、RL 期 $K\in[5,10]$，测试时可扫到 52），触达时 `[NOTICE] FINAL STEP` 强制绕过阈值作答。SFT 期还注入随机化物理约束以促探索（帧数 $n\in[30,60]$ 步长 2、clip 时长 $\in[30,60]$s 步长 2、**音频时长 $\in[150,300]$s 步长 10**）。**没有外部知识动作，因此不存在感知/知识两侧的预算分配。** |
| **使用** | 无准入门、无仲裁、无 abstain。每轮取回的媒体**无条件**进入上下文，由同一策略蒸馏成 $O_k$ 后原媒体被清除——即"使用"与"蒸馏"合并在策略内部，不可分离、不可审计为独立模块。prompt 层有三条弱使用规范：反确认偏置（think 里主动找反驳主假设的证据）、ASR 保真（不得为迁就假设改写词语）、证据 ID 可溯源前缀。**均为 prompt 级要求，无标量、无阈值、无 admit/reject 统计**；论文未报任何"某条观测是否改变了答案"的度量。 |
| **changed vs held-constant** | **changed：策略参数本体。** 基座 Qwen2.5-Omni-7B 经 Agentic SFT（58K 轨迹、2 epoch、lr 1e-5、bs 64、16×A100）+ Agentic RL（GRPO+TAURA、150 步、group size 8、lr 1e-6、clip 0.30/0.20、global bs 256、64×A100、无 KL 无熵正则、DAPO token-level loss + clip-higher）。SFT 语料来自 LongVideo-Reason / Video-Holmes / VSI-Train-10k / LongVALE / MultiHop-EgoQA 的 train split。**held-constant：环境算子（纯 ffmpeg，确定性）。** 训练期另用两个外部大模型：Gemini-3.0-Pro 作轨迹 teacher、GPT-4o 作理性审计判官（均只在数据合成期，不在推理期）。**对 R2 而言：红线 1（不改参数）与红线 2（不为本任务新训练）双双违反。** 红线 3（不新增 LLM 代答）**合规**——答案由同一个 omni 策略发出，无第二个 LLM 代答，这是三篇里唯一红线 3 合规的一篇。 |
| **runtime-visible vs gold-only** | runtime-visible 且**实际进入控制**：策略自报的 `confidence` 标量（阈值 0.9 门控 answer）、剩余步数 `[NOTICE]`、环境诊断错误码（`Err.TS_OOB` / `Err.INVALID_JSON` 等，允许策略在记忆里承认失误并自纠）、动作+区间的历史（"不得重复同一动作+区间"）、视频 META（duration/fps/has_audio；`has_audio=false` 时 `get_audio` 被**禁止**）。**逐 token 熵**是 runtime 可计算量，但**只在训练期用于 TAURA 的信用分配，不在推理期充当控制器**。gold-only：MCQ 正确性、Temporal IoU、MRA——训练期作 verifiable reward，推理期不可见（合规）。Gemini-2.5-Pro 的 fork-step 标注与 GPT-4o 的理性审计属离线分析/数据构造，不进推理。 |
| **数据/基线/指标/成本** | 数据：10 个基准 × 3 类。视频理解 VideoMME / VSI-Bench / MLVU / Minerva / LVBench；**音视频 DailyOmni / WorldSense / OmniVideoBench**；时序定位 **LongVALE / VUE-TR**。时长覆盖数十秒到 2 小时以上。指标：MCQ accuracy、Temporal IoU、MRA（与 verifiable reward 同口径）。基线：主基线为直答 Qwen2.5-Omni-7B（$\Delta$ 全部相对它报告），另横比闭源（GPT-4o / Gemini-1.5-Pro / Gemini-2.0-Flash / Gemini-2.5-Pro，灰显）、开源 agentic（LongVT / Zoom-Zero / VITAL / Video-CoM）、thinking（Video-R1 / Open-o3 / VideoRFT / LongVILA-R1）、非 thinking 一大批。成本：**记账相对充分（三篇里最好）**——报平均帧数（203 / 201.6）、平均轮数（8.5–12.5，按时长分层）、轮/小时密度、wall-clock latency（100 样本 LVBench 子集）、GPU 数（1 vs 4×A100），并画 accuracy-vs-frames 的 Pareto 图。**仍缺**：token 计数、API 费用、训练成本摊销、CI/多 seed/显著性检验。 |

## §4 DFS 四问

**方法**：把 omni 视频理解形式化为 POMDP，让单一 omni 策略在 OTA 循环内以四个原语
（取帧 / **取音频段** / 取带音的 clip / 作答）按需索取原始媒体，用"持久文本记忆 + 原始
媒体即时清除"把上下文开销与时长解耦；策略经 Agentic SFT（58K teacher 轨迹）+ Agentic RL
（GRPO + TAURA 熵驱动轮级信用分配）习得；推理期以自报 confidence ≥ 0.9 的固定阈值门控
"继续取证 vs 作答"，另有时长缩放的硬轮数上限。

**局限**：(a) **必须训练**——SFT 16×A100 + RL 64×A100，且 teacher 是 Gemini-3.0-Pro、
审计是 GPT-4o；这套主动感知能力是被蒸馏/强化进参数的，不是 training-free 控制面能得到的；
(b) **动作空间里没有任何外部知识动作**——环境只做 ffmpeg 抽取，无检索、无 web、无知识库，
所以"何时该去外部找知识"这一决策类别整体缺席；(c) 停止阈值 0.9 是 prompt 里的**魔数**，
无标定、无灵敏度分析、无校准检验（自报 confidence 的可靠性未被测量），也没有"该停没停"
的混淆矩阵；(d) 无准入门——取回的媒体无条件进上下文，且"使用"与"蒸馏"被合并进策略内部
不可分离消融；(e) 媒体清除是不可逆的信息瓶颈，$O_k$ 漏记的细节永久丢失，论文未量化该
损失；(f) 两处训练退化（Standard SFT 伤 LVBench、Vanilla GRPO 伤 DailyOmni）说明该路线
在音视频轴上脆弱；(g) 大部分增益来自 SFT 而非 RL（§3.5），TAURA 的净贡献仅 +1.5~+1.9；
(h) 无 CI、无多 seed、无显著性；时长分层准确率非单调而正文称"稳定"；(i) fork-step 标注
用 Gemini-2.5-Pro 做 oracle，熵-关键性相关性的独立性存疑。

**改进空间**：把 0.9 阈值换成可标定的价值估计量并给校准曲线；把感知动作与外部知识动作
放进**同一个**预算竞争里（本篇的整条空缺）；把"蒸馏"从策略内部剥离成可消融的准入/压缩
模块；量化媒体清除的信息损失；补 CI 与 seed 方差；在 training-free 设定下复现多少主动
感知能力（论文未做该消融——"不训练、只靠 prompt 走同一环境"这一臂缺失，正是 R2 的
天然切入点）。

**可借鉴**：环境算子契约（ffmpeg 两段式 seek、音频 16 kHz PCM S16LE 单声道、ffprobe
区间校验、越界 `-sseof` 回退、`Err.*` 结构化诊断码）→ R2 `RE_RESOLVE_AUDIO` 的确定性
实现规范；**媒体清除 + 保留时间戳的上下文重写协议** → R2 长回合上下文管理（纯确定性，
不需 LLM）；"同一动作+区间不得重复请求，但鼓励换模态/换密度重查" → R2 `nov(q)` 项在
**音频区间**维度的直接类比（R2 目前的 `nov` 只按 query 词面/实体重叠定义，可扩展为
"(动作类型, 区间) 对的新颖性"）；**Full Evidence ID 前缀的可溯源约定** → R2 §3.4 第 2 项
出处 schema 的现成写法；**逐轮熵 ↔ 决策关键性（79.2%）** → R2 §6.2 `disp(H_t)` 与
`maxAgree` 一族信号的动机论据（须标注它是训练期信用分配的证据，不是推理期控制的证据）；
**test-time scaling 曲线 + 实际轮数饱和**这一报告形式 → R2 §5.3"固定档阶梯向上扫至
成本可比"的呈现模板。

## §5 R2 威胁面判定

### (a) 是否已做"部署可见信号估计外部证据动作边际价值"或"感知 vs 知识不确定性的动作分配"

**外部证据动作的边际价值估计：否（该动作类别不存在）。感知/知识两侧的动作分配：否
（只有感知一侧）。但"部署可见标量 + 固定阈值门控继续取证 vs 作答"：是——这是本批唯一
真正压到 R2 量词的事实。**

具体：`Confidence Gatekeeper` 要求策略每轮输出一个 0.0–1.0 的标量，`"0.9" Behavioral
Rule` 规定只有该标量 ≥ 0.9 才允许 `answer`，否则继续取证（除 FINAL STEP 强制作答）。
这在结构上就是"部署可见标量 + 阈值 → 继续/停止"的控制器。但与 R2 的估计量族有四处
本质差别：
1. **量的性质不同**：它是策略**自报的置信度**（"证据是否足以定论"的自评），不是对
   **某个候选动作的前瞻边际价值**的估计；R2 的 $\hat V(a\mid s_t)$ 是 per-action 的，
   本篇的 confidence 是 per-state 的单值，无法在两个候选动作之间做 argmax。
2. **无外部动作可比**：门控的两侧是"继续感知"与"作答"，不含"去外部搜"。R2 的核心是
   `RE_RESOLVE` 与 `SEARCH` 之间的分配——本篇结构上无从表达。
3. **阈值来源不同**：0.9 是 prompt 里的常数，无标定协议、无 dev 集选型、无灵敏度分析、
   无校准曲线；R2 的 $\tau$ 与 $\alpha/\beta/\gamma$ 要在 dev 上离线标定并预注册。
4. **产出该标量的策略是训练出来的**：自报 confidence 的可用性来自 58K SFT 轨迹 + RL；
   在**冻结未训练**的核上，自报置信度是否还有分辨力，本篇不回答（这正是 R2 A4b 的
   可研究空间，也是本篇缺失的臂）。

**必须更新的 R2 空位断言（读集内量词）——按承重排序**：

1. **§4.3 第 1 点"读集内没有任何一处 scalar reward 充当推理期控制器（37 行音频/omni
   语料场级事实）"——必须重写，这是本批最高优先级的量词修复。**
   字面上"scalar **reward**"仍成立（本篇的 verifiable reward 只在训练期）。但隔离评审
   会立刻指出：**一个自报标量 + 固定阈值就是推理期标量控制器**，靠"reward vs
   confidence"的词义差别守住断言是脆弱的，属于 §gate-oracle 谱系里典型的"量词被更强
   实例击穿"形态。建议改写为可辩护的精确式，例如：
   > 读集内没有任何一处**对外部知识动作的前瞻边际价值估计**充当推理期控制器；最接近的
   > 是 NAP/OmniAgent 的自报置信度 ≥0.9 停止规则——但其动作空间纯感知（无外部知识
   > 动作）、阈值为 prompt 常数（无标定/无校准读数）、且产出该标量的策略经 58K Agentic
   > SFT + Agentic RL 训练（红线 1/2 不合规）。
   这一改写**不削弱** R2 的主创新，反而把 A4b 的识别对象讲得更准（见下 (c)）。
2. **§4.4 机制位表需增一行或改注**：现表 8 行机制全按"外部知识供给"轴组织，因此
   "语音域状态"列对本篇不可判定。建议在表下加一条限定语：该表的量词范围为
   **外部知识供给/使用轴**；感知供给轴在 omni 视频域已出现自适应轮数分配（NAP，训练态）
   与 test-time scaling 饱和曲线，跨轴不得互推。
3. **§4.3 定位结论"文本/视觉域 2023–2026 的整个'自适应→定价'跃迁在语音域尚未发生"** →
   须加轴限定。**在外部知识轴上成立**；在**感知轴**上，NAP 已完成"自适应触发"这一步
   （按自报置信度决定继续感知 vs 作答，并有 test-time scaling 与轮数饱和的实证），
   只是尚未"被定价"（无成本-价值归一、无按类别预算再分配）。不加限定的原句会被判失真。
4. **§4.4 M7（oracle/headroom 报告行）"唯一 oracle 行=Omni-DeepSearch 实体分解"** →
   仍成立（本篇无 gold-evidence/oracle 臂）。但本篇提供了另一类上界读数：
   test-time scaling 上界（$K$ 6→52，53.4→59.6）与"实际轮数饱和 11.7"——建议 R2 §5.3
   把这一形式列为"预算扫描曲线"的已发表模板（与 oracle 行并列，不混为一谈）。
5. **§3.3 组织轴"语音域读集内全部缺席"** → 基本成立但须加一条例外：NAP 有
   **回合内持久文本记忆 + 媒体清除的上下文重写协议 + Evidence-ID provenance 约定**。
   这不是外部知识组织（无库、无索引、无跨实例），但"出处 schema 逐字段为零"这句在本篇上
   **不成立**——它是三篇里唯一有 provenance 前缀规范的。建议 §3.3 把"逐字段为零"的量词
   限定在检索表征线三篇 + 外部知识 agentic 线，并如实注明 NAP 的 provenance 约定
   （对 R2 有利：§3.4 第 2 项有了现成写法）。

### (b) 调度/编排决策是训练的、prompt 自由生成的、还是确定性规则的

**三者混合，且是三篇里唯一含训练的一篇**：
- **训练**（承重）：动作类型与参数（哪个区间、取几帧、换哪个模态）由 $\pi_\theta$ 产出，
  该策略经 Agentic SFT（58K 条 Gemini-3.0-Pro best-of-N 轨迹，GPT-4o 理性审计 ≥3/5 过滤）
  + Agentic RL（GRPO + TAURA 熵驱动轮级 advantage 重标定）习得。**这是 R2 红线 1/2 的
  直接违反面**。
- **确定性规则**：`confidence ≥ 0.9` 阈值门（prompt 常数）、`has_audio=false` 时禁用
  `get_audio`、"同一动作+区间不得重复请求"、$K$ 随时长缩放的硬上限、FINAL STEP 强制作答、
  环境的 ffmpeg 算子与 `Err.*` 诊断码。
- **prompt 自由生成**：$O_k$ 的内容、$T_k$ 的 gap analysis 与反驳假设检查、confidence
  的具体取值（由策略自由产出，虽被阈值消费）。

**对 R2 的含义（重要）**：本篇证明"感知动作调度"这条路在**训练态**下可行且效果显著
（时序定位 3.5→36.5）。R2 主张的是**同一决策类别在 training-free 下用确定性估计量做**，
因此 NAP 不是竞争者而是**上界参照与对立设定**：它给出"训练能达到什么"的参照，而 R2 的
命题是"不训练能拿到多少"。建议 R2 §5.3 把 NAP 列为"训练态上界参照（不可作臂、红线 1/2
不合规）"，并在 §7 的最强反方栏补一条：**近地板基线（Qwen2.5-Omni 时序定位 3.5–5.7）
被训练抬到 36.5–39.1 这一事实，支持"地板可能是能力缺失而非调度缺失"的对立解释**——
这与 EChO 条目 §5e 指出的"本核在 MMAR 68.70 但在 Omni-DeepSearch 6.56"是同一担忧的
两个独立证据，R2 §5.4 的灵敏度前置检定必须能区分这两种解释，否则回退梯不可判。

### (c) NAP 重点：active perception 与 R2 的 RE_RESOLVE 是什么关系；A4b 独立性受什么影响

**结论：NAP 已占据"重听/重看作为一等推理动作"这一方法位。R2 不能再把
`RE_RESOLVE_AUDIO` 本身当作新颖单元；A4b 的独立性主张必须显式重定位到"双源分配"上。
做完这一重定位后，A4b 的独立性在读集内仍然成立。**

**占据到什么程度（逐项对齐 R2 §6.2）**：

| R2 元素 | NAP 是否占据 | 依据 |
|---|---|---|
| `RE_RESOLVE_AUDIO` 作为一等动作 | **是，完全占据** | $a_{\text{audio}}(s,e)$ 是四个动作原语之一；$a_{\text{clip}}(s,e)$ 带同步音频；prompt 明写"鼓励换模态或更高密度重查同一重要区间（如 get_audio 后再 get_clip）" |
| 重听的**区间/粒度**可选 | **是** | 区间 $[s,e]$ 与帧数 $n$ 由策略选定；粗到细的时间二分策略写在 prompt 的 STRATEGIC INSPECTION GUIDELINES 里 |
| 由不确定性触发重听 | **部分** | 触发量是自报 confidence（<0.9 就继续取证），不是假设集离散度 `disp(H_t)`；无"首选假设在重呈现中被复现的比例"（`audCons`）这类度量 |
| 多假设并行 + 用证据反过来佐证哪个假设为真 | **否** | prompt 只要求"主动寻找反驳当前**主**假设的证据"，是单主假设的反确认，不是 R2 §2.4 的多假设 query 构造与 $corr(e,h)$ 佐证结构 |
| 听错/判错假设导致**相关但错误的外部证据** | **否，且结构上不可能** | 无外部检索，证据永远来自同一段媒体；R2 §1.2 的核心失效模式在本篇无法发生。prompt 里有一条最接近的东西："ASR 时不得为迁就假设而改写或推测词语"——承认了听错风险，但处置是提示约束，不是机制 |
| `RE_RESOLVE` **与外部检索竞争同一预算** | **否，整体缺席** | 动作空间无外部动作；$K$ 只在感知动作之间分配 |
| 训练-free | **否** | 红线 1/2 违反 |

**A4b 独立性受到的具体影响与建议改写**：

- **受损的表述**：R2 §1.2 的"正确的动作不是继续搜外部，而是回头重听音频（re-resolve
  audio）。于是产生 R2 的核心决策问题"这一段，若被读成"重听动作是 R2 提出的"，会被
  评审以 NAP 直接反驳。**须加一句如实的占据声明**：重听作为一等推理动作已由
  NAP/OmniAgent（2606.19341，训练态、纯感知动作空间）与 CoFi-Agent（Interspeech 2026
  ARC，见 EChO 条目 §5c 的线索，全文未获取）占据；R2 的新颖单元不在动作原语的存在性。
- **仍然成立的独立性**：R2 §6.1 的 A4b 定义已经是
  "A4a + 感知不确定性路由（$\alpha_1$ 项 + RE_RESOLVE 动作 + **双源动作选择**）"，
  §8 的独立性行也已写为"把感知不确定性路由进**获取决策**"。**这个定义在 NAP 面前是
  站得住的**——NAP 没有获取决策（无外部获取），因此它的感知不确定性无处可路由。
  但当前文字把三样东西打包在一个括号里（$\alpha_1$ 项 / RE_RESOLVE 动作 / 双源选择），
  读者会误以为 RE_RESOLVE 的存在本身也是被主张的新颖性之一。
  **建议改写 A4b 的括号为承重分层**：
  > A4b = A4a + **双源动作选择**（在 `RE_RESOLVE` 与 `SEARCH` 之间用同一预算做
  > argmax）+ 感知不确定性信号入获取决策（$\alpha_1$、$\beta_1$、$\beta_2$ 项）。
  > **`RE_RESOLVE` 动作原语本身不作新颖性主张**（已被 NAP 占据，训练态；R2 的实现为
  > 冻结 DSP/感知工具的确定性重呈现）；被主张的是**该动作与外部知识动作在同一价值尺度
  > 上被比较**，且全过程 training-free、决策量外显可标定。
- **§8 独立性判据表建议增一行**（"支持独立"侧）：
  | 支持独立 | 判定载体 |
  |---|---|
  | 双源（感知/知识）动作在同一价值尺度上竞争，读集内无先例 | §6.2 动作空间同时含 `RE_RESOLVE_AUDIO` 与 `SEARCH(q)`；NAP 只有感知侧、AudioRAG/Omni-DeepSearch 只有知识侧 |
  同时在 MERGE 触发侧建议增一行：**若 A4b 的效果全部可由"只是多重听了几次"解释**
  （即把 A4a 的 re-resolve 固定档向上扫至与 A4b 等重听次数后差分消失），则音频特有主张
  判死——这是 NAP 逼出来的一个新的、必要的归因对照臂（现行 §5.3 的
  random-matched-cost 只匹配总成本，不匹配**重听次数**）。**建议把
  "re-resolve-count-matched 固定档"补入 §5.3 对照臂清单**，这是本次深读产出的最具体的
  实验设计修补。
- **一条对 R2 有利的推论**：NAP 的 test-time scaling 显示"实际轮数在 $K=52$ 时饱和于
  11.7"，即**训练出来的策略自己就会停**；而 Agent-Omni 的自由生成 `is_final` 在 MELD 上
  多跑 40.6% 却零增益（见该条目 §3.5）。两者对照给出一个干净的谱：**训练态能自适应停、
  prompt 自由生成不能**。R2 的命题正是插在这两点之间的第三种可能——**不训练，但用确定性
  阈值规则**。这个三点谱建议写进 §4.3 或 §4.5 作为主研究问题的定位图，它比现行文字更
  直接地说明 R2 填的是哪个格子。

### (d) 红线关系与可搬组件

**红线三条逐条**：
1. **不修改冻结核参数** → **违反**。Qwen2.5-Omni-7B 的参数被 SFT + RL 改写。
2. **不为本任务新训练任何模型** → **违反**。58K 轨迹 SFT（16×A100）+ GRPO/TAURA RL
   （64×A100）；另用 Gemini-3.0-Pro 作 teacher、GPT-4o 作审计判官（仅数据合成期）。
3. **不新增 LLM 代答** → **合规，且是三篇里唯一合规的一篇**。答案由同一个 omni 策略
   通过 $a_{\text{answer}}$ 发出，无第二个 LLM 代答。
   **结论**：NAP 的任何效果数字（DailyOmni 64.8、LongVALE 39.1 等）**不可作为 R2 的
   可达目标或臂**，只能作**训练态上界参照**；其"单模型自持作答权"的架构取向反而与 R2
   红线 3 同向，可在 §1.4 引作支持性先例（"读集内已有工作把作答权保持在单一 omni 核内"）。

**可搬组件（红线内，全部为确定性/工程层）**：
- **音频重呈现算子契约**：ffmpeg 两段式 seek（关键帧粗定位 + 精确解码）、音频统一
  16 kHz PCM S16LE 单声道、ffprobe 校验返回波形与请求区间严格对齐、边界越界的
  `-sseof` 回退。→ 直接作 R2 `RE_RESOLVE_AUDIO` 的实现规范，保证 `audCons` 的
  重呈现是确定性且可复算的。
- **媒体清除 + 时间戳保留的上下文重写协议**（非破坏性重写、`[MEDIA OMITTED - Refer to
  Observation]` 占位、帧动作保留全部采样时间戳、音频/clip 动作保留请求区间头）。
  → R2 多轮回合的上下文管理，纯确定性、不需 LLM，且天然产出可审计的动作-区间轨迹。
- **动作新颖性约束**："同一动作 + 同一区间不得请求两次；鼓励换模态或提高密度重查同一
  区间"。→ R2 §6.2 `nov` 项的扩展定义：从"query 词面/实体重叠的补"扩为
  **"(动作类型, 时间区间) 对的新颖性"**，使 `nov` 在 `RE_RESOLVE` 上也有定义
  （现行 `nov` 只对 `SEARCH(q)` 有定义，这是 R2 估计量族的一个实际缺口）。
- **Full Evidence ID 前缀的可溯源约定**（observation 与 think 都必须前缀证据 ID）。
  → R2 §3.4 第 2 项"音频锚定的出处 schema"的现成写法。
- **结构化环境诊断码**（`Err.TS_OOB`、`Err.INVALID_JSON`）+ 允许策略在记忆中承认失误
  并自纠。→ R2 工程护栏 + A5 扰动臂的错误注入接口。
- **报告形式**：test-time scaling 曲线（$K$ 扫描 + 实际消耗饱和值并列）、
  accuracy-vs-frames Pareto 图、时长分层的 turns / turns-per-hour / accuracy 三行表。
  → R2 §5.3 固定档阶梯与 §6.5 效率记账层的呈现模板。
- **动机论据（非组件）**：逐轮熵与决策关键性的 79.2% 正相关。→ 支持 R2 `disp(H_t)` /
  `maxAgree` 一族信号的合理性；**必须标注**它是训练期信用分配的证据、由 Gemini-2.5-Pro
  标注 fork step 得到，不得当作"熵可作推理期控制器"的效果证据。

**不可搬**：Agentic SFT / Agentic RL / TAURA / verifiable reward 训练环
（红线 1/2）；Gemini-3.0-Pro teacher 与 GPT-4o 审计（本任务的数据合成 = 为任务训练的
组成部分）；训练出来的 confidence 自报能力（在冻结核上的分辨力未知，属 R2 待测量而非
可搬）。

### (e) 是否提供新载体/基线数字

**提供 5 个新载体，但没有一个可作 R2 载体；提供两组高价值基线数字，其中一组是对
R2 主载体选择的最强反方证据。**

- **新载体**：DailyOmni、WorldSense、OmniVideoBench（音视频理解）、LongVALE、VUE-TR
  （音视频时序定位）。**全部不可作 R2 载体**：均为视频/音视频理解与定位，答案完全由
  提供的媒体决定，**外部知识对实例级答案无边际价值**——落在 R2 §1.3 信息角色边界之外。
  另注：本篇是 video-first 的，音频只是三个媒体算子之一，DailyOmni/WorldSense/
  OmniVideoBench 的"omni"指音视频联合，不含外部知识轴。
- **可用处**：LongVALE / VUE-TR 的**时序定位**任务形态可作 R2 `RE_RESOLVE` 有效性的

- **基线数字组二（最强反方，必须纳入 R2 §5.4/§7）**：**同一个冻结 omni 核在时序定位上
  只有 3.5–5.7（近地板），经 58K SFT + RL 后升到 36.5–39.1（约 6–10 倍）。**
  这是"近地板读数可能反映**任务形态级能力缺失**、而非可被 training-free 控制面修复的

  A0 且都近地板，则为能力缺失，**直接走 §5.4 梯③/④，不得宣布任何调度类判死或胜出**。
