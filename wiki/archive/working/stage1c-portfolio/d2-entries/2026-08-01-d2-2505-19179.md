## 1. 方法本质

BR-ASR 把 contextual biasing 的**规模瓶颈重构为一个跨模态检索问题**：不再把整张 bias list
塞进 SpeechLLM 的提示或 bias encoder，而是先用一个**训练出来的语音-偏置对比检索器**从至多
200k 条的词库里裁出 top-K 候选，再把这 K 条交给一个**本来就会消费 bias list 的 contextual
ASR 后端**。三个构件：

**(a) speech-and-bias 对比学习检索（§2.2.1，L148–161）**。把 CLAP 改造成"语音↔偏置词"对齐：
`X̂ = Pool · E_s(X)`、`b̂ = E_b(b)`（Eq. `clap:proj`，L156），损失 `L = 0.5*(l_a(S)+l_b(S))`，
其中 `S = τ(X̂ · b̂ᵀ)` 为点积相似度、`τ` 为**可学习温度**（Eq. `clap:loss`，L157）。负例
按 CLAP 做法从 `B_total \ B_sentence` 里随机取 `N_neg` 条（L161）。两条偏置编码支路
（§2.2.2，L172–181）：**AcousticBias** 先把偏置词 TTS 合成为音频再过同一语音编码器
（`E_b(b) = E_s(TTS(b))`），把语音与偏置词投到**同一声学空间**；**TextualBias** 直接用
SpeechLLM 自带的 LLM 抽文本特征（`E_b(b) = LLM(b)`），此时 `E_s(·) = Projection ·
Speech-Encoder(·)`。长度失配由池化解决，报了两种：AdaAvgPool（同 CLAP）与
**AttnPool**（`X̂ = Linear · Σ_{T'}(Attention(H))`，L192）。

**(b) 动态课程调度同音 hard negative（§2.2.3，L195–216）**。先用 G2P 生成音素串，按
**音素级 Levenshtein 距离**构同音集：`H_i = {h_j | Lev(p_i,p_j) ≤ θ, h_j ∈ B\{b_i}}`
（L200–202），阈值 `θ=2`（L203）。同音负例采样比按 **sigmoid 课程**推进：
`α_n = α_min + (α_max−α_min)·(2/(1+e^{−γn}) − 1)`（L205–207），`n` 为训练步数；实参
`α_min=0.01, α_max=0.5, γ=0.05`（L259）。另加一项正则
`L_total = L + λ Σ_{h_j∈H_i} ‖b_i − h_j‖²₂`（Eq. `loss_reg`，L211–215），`λ=0.1`（L261），
论文自述目的是"To further disperse homophone in training"（L210）。

**(c) 检索结果接 contextual ASR 后端（§2.1 + §3.1.2）**。后端形式化为
`P(y_{i+1}|X,y_{1:i},B) = C-ASR(φ(X), y_{1:i}, ψ(B))`（Eq. `casr`，L137–139），`ψ(·)` 既可以是
文本提示（"Related bias words are b1, b2, …"，L143）也可以是专用 bias encoder。BR-ASR 只
把 `B` 换成 `B_retrieval`，不动后端权重。检索侧用 **FAISS**、向量预归一化 +
`METRIC_INNER_PRODUCT`（L263），每后端一个**固定的 retrieval threshold**：
Prompt-QwenAudio=50、BiasEncoder-QwenAudio=50、Prompt-SLAM-ASR=**10**（L264）。

**一句话定位**：BR-ASR 是"**训练一个语音→偏置词的检索器 + 一道确定性 top-K 截断**"，
门控信号是连续相似度、门的形状是**固定 K**（无自适应阈值、无 no-retrieval 分支）；所有
"要不要用这条候选"的裁决被推给下游那个**已经被训练过消费 bias list** 的后端。

## 2. 训练态与信息访问边界

### 2.1 retriever 端到端训练，编码器冻结的理由是防遗忘

§2.2.2 标题即 "Frozen Encoding Priors"，原句（L166）：

> "To prevent catastrophic forgetting and ensure feature consistency, we **fully freeze**
> speech/bias encoding network `E_s , E_b`"

训练预算（L258）："we use AdamW with a maximum learning rate of 1e-4 warmup ratio of 0.05 and
**train the network for 10 epochs with 960h data**"。温度 `τ` 初始化 0.007、上限裁剪 100
（L257）。

**可训练面到底是什么，源里未逐项列出**——这是一处必须声明的欠规约。按 L156/L180/L192/L255
可推：AttnPool 的 Attention+Linear、TextualBias 路径里"inherited from SpeechLLMs"的
projection（L255 只说"reused"，未说是否解冻）、可学习温度 `τ`。**极端情形**：
AcousticBias+AdaAvgPool 那一行里，两个编码器冻结、AdaAvgPool 无参数、且源码 L252–253 的
注释掉行写着"And there is no more projection layer mentioned in Eq. 1"——若该注释代表实现，
则该行**几乎只有 `τ` 可训**，而它恰是表 2 里最差的一行（B-WER 12.4）。R2 若把 BR-ASR 引作
"trained retrieval 上界"，须把这条欠规约记进比较合同：**"训练量"在其内部各行之间相差极大，
不能当成一个均质的训练态对手**。

### 2.2 后端只有 Qwen-Audio / SLAM-ASR 两族，且其 bias 消费端各自训练过

摘要（L72）与结论（L402）分别写"allows seamless integration of the retrieved candidates into
**diverse ASR systems without fine-tuning**"、"enables **plug-and-play integration with diverse
systems**"；引言（L128）更进一步写"when integrated with **third-party ASR systems**, it
consistently improves rare-word recognition without architectural modifications"。

**实证边界如实**（§3.1.2，L242–247）：

| 后端 | 出处 | 其 bias 消费端的训练态（原文） |
|---|---|---|
| Prompt-QwenAudio | 复现自 `gong2024contextual`，backbone 换 Qwen-Audio **unchat** 版 | "is **trained** using the bias size between 20∼80"（L245） |
| BiasEncoder-QwenAudio | 同上 | "is **trained** using the bias size between 50∼1000, and the bias encoder is initialized from `gte-large-en-v1.5`"（L246） |
| Prompt-SLAM-ASR | 直接复用 `yang2024ctc`（CTC-filter 论文）的预训练件 | "we **reuse the pre-trained** Prompt-SLAM-ASR，where the **training bias size is 5 on average**"（L247） |

即：**"多种下游 ASR"= 2 个 SpeechLLM 族、3 个具体系统，且 3 个全部是已在 bias list 上训练过
的 contextual ASR**；"third-party"只落在 **1 个**复用件（Prompt-SLAM-ASR）上。"without
fine-tuning"的准确读法是**"接入检索插件不需要再微调后端"**，不是"任意冻结 ASR 都能插"。

**更硬的一条**：每个后端的 retrieval threshold（50/50/**10**，L264）与该后端**训练期的
bias size 分布**对齐——SLAM-ASR 训练期均值 5 条，所以只喂 10 条。**这是"plug-and-play"的
直接反证：插件必须按后端训练分布调 K。** 对 R2 的意义见 §4/§6。

### 2.3 信息访问：编码器冻结 ≠ 黑盒

BR-ASR 的检索器**复用 SpeechLLM 自己的语音编码器**（`E_s(·) = φ(·)`，L171），TextualBias
支路还要复用**该 SpeechLLM 的 LLM 部分**取文本特征、并复用其 projection（L178–180、L254–255）。
因此它需要对后端做**白盒前向读取**（编码器输出 `H`、投影层），只是不改权重。**信息访问边界
= 白盒组件复用 + 训练适配层**，与 API-only 差两级。这一点 §8 矩阵行原写法「训练 retriever
（编码器冻结）」只覆盖了训练态、未覆盖白盒性，须补（见 §5）。

### 2.4 AcousticBias 变体依赖 edge-tts（单一在线音色）

§3.1.2 原句（L250）：

> "we firstly synthesized all bias words from the database `B_total` using **`edge-tts`**
> with the **default voice "en-US-AnaNeural"**"

`edge-tts` 是微软 Edge 在线 TTS 服务的第三方封装（源里以脚注 URL 形式给出，无版本、无
模型标识）。由此有三条对 R2 直接承重的边界：

1. **可复现性**：200k 条偏置词的声学 key 依赖一个**外部在线服务**且无版本钉死，索引不可
   逐位重建；
2. **说话人/口音单一**：单一默认女声美音，声学 key 族**零口音变体、零说话人变体**；
3. **论文自己测出了它的代价**：§3.3（L376）"we adopt TextualBias, as textual inputs **avoid
   the domain mismatch between synthesized and real speech**, and are more robust to OOV
   words"——最终 SOTA 配置（B-WER 2.8/7.1）走的是 **TextualBias**，不是 AcousticBias。

**换言之：BR-ASR 是"单音色 TTS 声学 key 打不过文本 key"的一手实测证据。** R2 §2.3 发音库
的设计（G2P/TTS 标准音 **+ 口音变体族** + 多假设 N-best key）恰是对这一失败模式的回应，
本篇应被引作**该设计的动机证据**，而不只是竞品。

### 3.2 表 1（`tab:main`）主结果，LibriSpeech test-clean/-other

格式 `test-clean/test-other`。BR-ASR 的 SOTA 行（Prompt-QwenAudio + Bias Retrieval）：

| N | \|B_sentence\| | 100 | 500 | 1000 | 2000 |
|---|---|---|---|---|---|
| WER | 1.1/2.6 | 1.2/2.7 | 1.2/2.7 | 1.2/2.7 | **1.2/2.8** |
| B-WER | 1.2/3.7 | 2.3/6.1 | 2.4/6.3 | 2.6/6.6 | **2.8/7.1** |

裸 Prompt-QwenAudio（无检索）：N=100 时 WER 1.3/3.5、B-WER 2.4/6.4；**N=500 崩塌**
（WER **22.4/27.8**、B-WER **32.1/39.1**）；N≥1000 记 `X`。论文归因（L346）：
"suffers **catastrophic failure (at N≥100)** due to **LLM hallucinations**, and unreliable
results for N≥1000 due to **exceeded context limits**"。Prompt-SLAM-ASR 同型：N=100 即
WER 7.4/17.9、B-WER 24.8/44.1，N≥500 记 `X`。

**对 R2 最承重的一条（论文未点破）**：Prompt-QwenAudio 的**训练期 bias size 是 20∼80**
（L245），而检索阈值恰取 **50**（L264）——**检索所做的，很大程度是把后端从
训练分布外（N=500/1000/2000）拉回它的训练工作点（≈50 条）**。因此"+BR 相对裸 Prompt 降
80–92% B-WER"是**对一个被推出训练分布的后端**测得的增益，**不是**对一个健康基线的增益。
R2 若把"ASR+biasing-GER"incumbent 实例化为这类臂，须按 §8 分组合同**在各自训练工作点上**
运行，否则等于挑弱实现称胜。

**与传统 SOTA 的真实胜负（论文未如实概括）**：USTR-CT 在 **N=100 / 500 / 1000 三档
B-WER 上全面优于 BR-ASR**（2.0/4.4、2.2/5.6、2.5/6.3 对 BR 的 2.3/6.1、2.4/6.3、2.6/6.6），

指标定义（§3.1.1 脚注 L228–232）：`Recall@X` = 达到 X% 召回时的**平均检索条数**
`N̄_retrieval`；`Recall#X` = 每句检索 X 条时的召回率。

**两条被本次深读逐格测出的、必须随协议移植一起声明的口径问题**：

- **表头箭头方向错**：`Recall_B@99` 列标 `(↑)`（L323），但按脚注它是"达 99% 召回所需的
  平均条数"，**越小越好**，而表体加粗的正是最小值 32.8。**引用该协议时须把该列改标 (↓)。**
- **两个 Recall 的公式如实排版后无法产生表中数值**：`Recall_B = Σ|B_sentence| / Σ|B_retrieval|`
  （L234）、`Recall_H = Σ|H_sentence| / Σ|B_retrieval|`（L237）——**分子未取与检索结果的交集**。
  若逐字执行，`|B_retrieval|=50` 而每句 oracle 偏置词只有个位数，比值应在个位数百分比，
  绝不可能是 97.3–99.9%。**可复原的意图**：`Recall_B#50 = |B_sentence ∩ B_retrieval| /
  |B_sentence|`（真召回）、`Recall_H#50 = |H_sentence ∩ B_retrieval| / |B_retrieval|`
  （检索结果中同音干扰的占比，实为查准侧的假阳率）。**R2 若采纳该读数，必须用复原式重述，
  不能照抄论文公式。**

**课程学习的真实代价/收益（论文只讲收益）**：开课程后 `Recall_H#50` 大降
（Acoustic 99.9→69.3、Textual 91.3→58.4）、B-WER 降（8.6→7.4、7.9→7.1），
但 **`Recall_B@99` 同时上升**（32.8→42.2、38.7→47.3），即**达到同样召回需要多检回约 9–10 条**。
这是一条**干净的"精度换预算"曲线**，对 R2 准入门的预算记账直接可用。

## 4. DFS 四问

**方法**：训练一个 CLAP 式的语音↔偏置词双塔检索器（两个编码器全冻结、只训池化/投影/温度），
用音素编辑距离 ≤2 构造同音 hard negative 并按 sigmoid 课程逐步提高其采样比、外加一项嵌入
空间正则，把 200k 级词表在 FAISS 上裁到固定 top-K，再喂给一个**已被训练成会消费 bias list**
的 contextual ASR 后端；后端权重不动。

**局限**（按对 R2 的承重排序）：

1. **不是 training-free，也不是 API-only**——10 epochs × 960h 的对比训练（L258），且检索器
   必须复用后端自己的语音编码器（与 TextualBias 下的 LLM/projection）做白盒前向（L171/L180/L255）。
   R2 的 API-only 冻结核上**两条都不成立**。
2. **"多种下游 ASR"的实证边界=2 族 3 系统，且 3 个全部 bias-trained**，"third-party" n=1
   （L242–247）；**且 K 必须按后端训练期 bias size 调**（50/50/10，L264）——直接反证
   "plug-and-play"。
3. **headline 增益的参照系是被推出训练分布的后端**（训练 20∼80 条、测试喂 500/1000/2000 条），
   崩塌被论文归因于"LLM hallucinations / exceeded context limits"（L346）而非分布外操作。
4. **单语料单语言、训练评测同源**（§3.5），零跨域证据。
5. **多处数字口径不一致/不可复算**（§3.4 表，共 8 条），其中 45%、17.1%、80% absolutely、
   10.2%、32%、23% 六条不得转引；0.3% WER 退化与 93/91% retrieval accuracy 两条在源中无出处。
6. **传统 SOTA 在 N≤1000 的 B-WER 上仍优于本方法**，且 N=1000 档加粗标注错误（§3.2）。
7. **正则项符号与陈述目的相反**：Eq. `loss_reg`（L211–215）在总损失上**加** `+λ‖b_i−h_j‖²₂`，
   最小化它会把同音词嵌入**拉近**；而 L210 自述目的是"further **disperse** homophone"。
   要实现"分散"应取负号或改成 margin/hinge 形式。**这是一处方法层符号错误，复现前必须裁定。**
8. **课程调度的时间尺度可疑**：`γ=0.05` 且 `n` = 训练步数（L208/L259）时，
   `α_n` 在约 100 步内即饱和到 ≈0.49（e^{−5}≈0.0067），相对 10 epochs × 960h 的总步数
   等同于"前 100 步 warmup、其余全程固定 0.5"，**"课程"实质退化为常数**。源码 L260 有一条
   注释掉的作者自注："`gamma=1e-5 is better, after 1epoch training`"——与该判断一致
   （γ=1e-5 时约 10 万步才达 0.46）。**引用其课程设计时须声明 γ 的量纲/取值存疑。**
9. **缺关键消融**：`θ=2` 未扫；retrieval threshold K（50/10）未扫，因而**"检索多少条"这个
   最直接的预算-精度旋钮全篇没有曲线**；无"不检索但给全表"的公平对照（该格记 `X`）；
   无 oracle 检索上界臂（`N=|B_sentence|` 列可近似充当，但未被如此使用）。
10. **成本记账不完整**：只报 FAISS 查询 20ms/500ms；200k 条 edge-tts 合成、编码器前向、索引
    构建、以及注入 K 条候选后后端提示变长的解码开销**均未记账**。

**改进空间**（R2 可占的台阶）：

- 第 9 条缺的 **K 扫描曲线**恰是 R2 准入门的核心读数。BR-ASR 已经提供了半条：表 2 显示同音
  课程会把 `Recall_B@99` 从 32.8 推到 42.2（多检 ≈10 条换 1.2 pp B-WER）。R2 只要把 K 从
  固定常数换成**由可标定标量驱动的自适应准入**，就能在同一坐标系里画出 BR-ASR 没画的那条曲线。
- 第 7 条的符号错误指向一个更根本的替代：**同音消歧不必在嵌入空间里做**。BR-ASR 花了一整个
  课程 + 一项（符号可疑的）正则去把同音词在嵌入空间推开，代价是检索效率下降；R2 的路线是
  **保留同音簇作为 value、把裁决推到解码期的世界知识 rescore**——即把"哪个候选在世界中真实
  存在且语境相符"当作裁决依据，而不是要求声学空间自己分得开。BR-ASR 的
  `Recall_H#50` 58.4%（最好一行仍有近六成检索结果是同音干扰，L333）**正是"声学空间分不开"
  的量化证据**，也是 R2 该设计的最强动机数。
- 第 4 条：把同一协议搬到第二语料/第二语言即是现成增量；中文同音字密度使 R2 §2.3 的
  "库价值更高"论断在此有直接的对照可做。

**可借鉴**（四条，按可移植度排序）：

1. **同音负例的集合构造法 → R2 发音库负例/候选族设计（最高价值）**。`H_i = {h_j | Lev(p_i,p_j)
   ≤ θ}`、θ=2、G2P 音素串（L200–203）是一个**零训练即可执行**的确定性构造：R2 不需要它的
   sigmoid 课程（R2 无训练），但**同一个集合在 R2 里换了角色**——在 BR-ASR 里它是"要被推开的
   负例"，在 R2 发音库里它正好是**"同音候选 value"本身**（§2.3："检回同音/近音候选实体集
   (value)→世界知识 rescore 裁定"）。**同一构造，相反用途**：BR-ASR 训练时花力气消除的混淆，
   R2 在检索时刻意保留、把消歧推给世界知识。这条对偶关系应当写进 R2 §2.3 的 prior-difference，
   它比"我们不训练"更能说明机制差异。θ=2 与 G2P 管线可直接充当 R2 §2.3 检索层对照阶梯里
   **"G2P/音素编辑距离"那一级的具名实现**（R2 draft L198–200 已预留该级）。
2. **`Recall_H#K` 这一读数直接可用**。R2 §2.5（draft L220–221）已要求"发音库检索层读数
   （同音候选命中率）独立报告"但未定义指标；BR-ASR 给了名字、给了取值范围（58.4%–99.9%，
   表 2）、并给了它与 B-WER 的联动方向。**建议 R2 直接采用 `Recall_H#K` 作为该读数的正式定义
   （用 §3.3 复原式，不用论文原公式），并把 58.4% 记作"trained 上界在 LibriSpeech 上的参照值"。**
   同时采用 `Recall_B@99`（改标 ↓）作为准入门的**预算侧**读数。
3. **`Recall_B@99` 的"达标所需条数"形式是一个比 top-K 精度更好的门控预算指标**——它把
   "为了不漏，得放多少条进来"变成一个可比数，正是 R2 准入门要报的量。
4. **单音色 TTS 声学 key 的失败是一手证据**（§2.4）：TextualBias 在全部三项指标上优于
   AcousticBias，论文自陈原因是合成音与真实语音的域失配。R2 发音库的口音变体族 + 查询期
   个性化 key 合成（§2.4）应把这条引作**动机证据**；反过来，R2 也因此**必须**在自己的发音库
   上报同样的对照（单音色 key vs 变体族 key），否则会重蹈同一失配。

## 6. R2 增量变量核验：delta 确实缺席吗（逐项引证）

R2 在该行主张的新增变量共两条（建议补至四条）。逐条到原文里找反证：

**① 「零训练」——BR-ASR 确实有训练。CONFIRMED_ABSENT。**
直接引证：L258 "we use AdamW with a maximum learning rate of 1e-4 warmup ratio of 0.05 and
**train the network for 10 epochs with 960h data**"；L157 温度 τ 为**可学习**参数、L257 给其
初值与裁剪上限；L192 AttnPool 含 `Attention` 与 `Linear` 两组参数。全篇**无任何 training-free
配置**、无"不训练检索器"的对照臂。**缺席确认。**（唯一需声明的灰区：冻结的是两个编码器，
可训练面在源中未逐项列出，见 §2.1；但"存在训练"这一事实无歧义。）

**② 「同音裁决交世界知识 rescore 而非训练」——BR-ASR 的同音裁决完全在训练侧。CONFIRMED_ABSENT。**
直接引证：其同音消歧的**全部**手段是 (a) 训练期负例采样比的 sigmoid 课程（L204–207）与
(b) 嵌入空间正则 `λΣ‖b_i−h_j‖²₂`（L211–215）——**两者都只在训练时生效，推理时不存在同音
裁决步骤**。全文检索：无 rescoring、无 LLM 复核候选、无外部知识源、无"哪个候选在世界中真实
存在"一类判据；参考文献侧的 `mybib.bib` 亦无知识库/世界知识条目参与本方法（其 RAG 相关引用
DOC-RAG/LA-RAG/GEC-RAG 均出现在 §1 的**被区分对象**位置，L96）。
**唯一需要如实记的近似物**（不构成占据）：L351 把 BiasEncoder+BR 的稳定性归因于
"the **secondary text processing** that effectively disambiguates homophones"——这是**后端
bias encoder（`gte-large-en-v1.5` 初始化、且经过训练）在文本侧的二次处理**，仍是训练态组件，
**不是**推理期的世界知识 rescore。**缺席确认，且该近似物应写进 R2 的 prior-difference
记账**（它说明"把同音消歧推到检索之后"这一**位置**已有先例，R2 的独立性须落在
"**推到推理期、由冻结核 + 世界知识裁决、且零训练**"，而不是"首次把消歧后置"）。

**③ 「API-only 黑盒」（建议新增）——BR-ASR 需白盒。CONFIRMED_ABSENT。**
L171 "As a well-trained speech encoder is available in SpeechLLMs, **we reuse the speech
encoder** `E_s(·) = φ(·)`"；L178 TextualBias "we also directly employ **the same LLM backend**
to extract textual bias features"；L255 "the same **projection inherited from SpeechLLMs** is
reused"。三处都要求对后端内部前向的读取权。**缺席确认。**

**④ 「后端无须 bias-trained」（建议新增）——BR-ASR 三后端全部 bias-trained。CONFIRMED_ABSENT。**
L245/L246/L247 逐条引证见 §2.2 表。**缺席确认。**

**反向自检（避免过度主张）**：本篇**确实占据**了以下 R2 可能想主张的面，R2 不得再声称首创——
(a) 语音→偏置词的**跨模态检索**本身；(b) **200k 级**词表上的可扩展检索与 20ms 级查询延迟；
(c) 用**音素编辑距离**构造同音混淆集；(d) 检索层与 ASR 解码**解耦**（"decoupling bias
retrieval from ASR decoding"，L402）。R2 在这四点上是**继承者**，增量只能挂在 §6 的四条
delta 合取上。

## 7. 2026 重审条款（预置）

R2 draft L674–676 的 2026 重审条款目前只指向"2023 时代近邻"。**BR-ASR 虽为 2025 件，但其
承重前提同样落在重审面内**，本条目预置三款：

**重审款 R-BR-1（承重前提：长候选表不可被原生消费）**。BR-ASR 的全部动机建立在 §1 的三条
断言上（L91–93）："(1) Excessive prompt length induces **LLM hallucinations** …；(2) Increased
computational complexity from lengthy prompts degrades inference efficiency；(3) Bias list is
limited to **dozens of entries**"，其**唯一实证**是 Prompt-QwenAudio 在 N=500 的崩塌
（22.4/27.8，表 1 L297）。但该后端是 **Qwen-Audio unchat 版**（2023 代、L244）且**训练期
bias size 仅 20∼80**（L245）——崩塌与其说是"SpeechLLM 无法原生消费长候选表"，不如说是
**分布外操作 + 该代模型的上下文长度限制**（论文自陈 N≥1000 是 "exceeded context limits"，L346）。
**重审对象**：在 Qwen3-Omni 级冻结长上下文核上，直接把 top-K（K=50/200/1000/全表）候选放进
上下文，测 B-WER 与幻觉率。**触发后果**：若长上下文原生消费不崩，则"检索是必要的"这一动机
在 R2 的边界上失效，**R2 的检索层主张须改挂成本/延迟/预算而非精度**，且 §8 分组③"trained
retrieval 上界"的威胁度须下调。**重审时点**：Stage-2A 复现先行第零步（能力预检电池，
draft §6.1）——该臂可与门一（能力门）合并跑，零额外载体成本。

**重审款 R-BR-2（效率数字的可继承性）**。20ms / 7GB / 8GB 三个数是**建立在 SpeechLLM 内部
编码器输出（4096 维）之上的 FAISS flat 索引**的性质（L263、L392）。R2 在 API-only 边界下
若改用黑盒可得的表示重建索引，**维度、可分性、索引大小与召回全部变化**，三数不可继承。
**重审对象**：R2 自建声学 key 索引的 `Recall_B@99` / 查询延迟 / 显存，须与 BR-ASR 的
32.8–47.3 条 / 20ms / 8GB 同表并列并声明表示不同源。

**重审款 R-BR-3（协议口径的复原式）**。若 R2 选用 LibriSpeech+Rare5k 作 NB 载体，
`Recall_B` / `Recall_H` 必须用 §3.3 的**复原式**而非论文原式，且 `Recall_B@99` 列改标 (↓)；
本条目所列 §3.4 的六条不可复算数字**永久列入不得转引清单**。**重审对象**：载体选定件
（draft §9 盘点收口）须逐条确认已采用复原式。

## 8. 深读后新增的、R2 应该知道的事实

1. **BR-ASR 的 headline 增益参照系不健康**：其对比对象 Prompt-QwenAudio 训练期 bias size
   20∼80，而被喂 500/1000/2000 条。"降 80–92% B-WER"里有相当部分是**把后端拉回训练工作点**。
   R2 的 §8 分组合同（"不得挑弱实现称胜"）在这里有一个具体的落点：**incumbent 分组③的
   BR-ASR 臂必须在其自身工作点（K≈50）上运行，不能借用论文的崩塌基线。**
2. **传统方法在中小 N 上仍赢**：USTR-CT 的 B-WER 在 N=100/500/1000 三档全面优于 BR-ASR，
   BR-ASR 只在 N=2000 反超（§3.2）。"trained retrieval 是上界"这一定位**只在大词表区成立**；
   R2 若在小 N 区做实验，真正的对手是传统 CT 线而非 BR-ASR。
3. **"检索多少条"这个旋钮全篇没有曲线**（K 固定 50/50/10，无扫描）——这是 R2 准入门可以
   干净占据的空位，且 BR-ASR 自己的表 2 已经给了半条曲线的坐标系（`Recall_B@99` 上升 ≈10 条
   换 1.2 pp B-WER）。
4. **最好一行仍有 58.4% 的检索结果是同音干扰**（表 2 末行 `Recall_H#50`，L333）。即：
   **训练一个专门的同音课程之后，声学/文本空间依然分不开近六成同音混淆。** 这是 R2
   "把同音裁决交给世界知识 rescore 而非要求嵌入空间自己分开"最强的一手动机数，应直接入
   R2 §2.3。
5. **单音色 TTS 声学 key 打不过文本 key，论文自陈原因是合成音-真实音域失配**（L376）。
   R2 发音库的口音变体族/个性化 key 合成因此不是锦上添花而是**对已知失败模式的必要对策**；
   同时 R2 必须自证其变体族确实消除了该失配（单音色 vs 变体族对照臂）。
6. **同音集构造在两篇里角色相反**：BR-ASR 把 `Lev(p_i,p_j)≤2` 的集合当作**要被推开的负例**，
   R2 把同一集合当作**要被检回的候选 value**。这条对偶是 R2 §2.3 prior-difference 里比
   "我们不训练"更锋利的表述，建议采纳。
7. **方法层存在一处符号错误与一处调度尺度疑点**（正则 `+λ‖b_i−h_j‖²` 与"disperse"目的相反；
   γ=0.05 使课程约 100 步饱和，作者自己的注释掉行写"gamma=1e-5 is better"）。R2 引用其
   课程设计时须声明这两点；若 Stage-2A 要把它作为对照臂复现，**这两处必须先裁定**。
8. **`00README.json` 与 eprint 内容注记**：源包内 `mybib.bib`（31KB）与 `template.bbl`
   已随件落盘，BR-ASR 的完整引文图可**离线**展开，无需再次触网——若 R2 要沿其引用做一层
   BFS（Phoneme-RAG / CTC-filter / Dual-NAM / VQ-RAG / DB-NNLM / USTR-CT / PRISM 线），
   题录已在本地可得。
