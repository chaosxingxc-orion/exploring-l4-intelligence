## 1. 方法本质

本篇**不是方法论文**，是**零样本（训练无关）测试期扩展在 LVLM 上的第一份系统实证研究**：
13 个 instruction-tuned 模型（Qwen2.5-VL 7/32/72B，Qwen3-VL 2/4/8/32B，InternVL-3.5 2/4/8/38B，
Molmo2 4/8B）× 9 种 TTS 方法 × 6 个基准，总算力开销约 **$6,000**，全模型 max token length 统一
**1,024**。九种方法用统一形式实现——在 question 与 post-prompt 之间插一段 `think-prompt`：
CoT、S-CoT、Plan-and-Solve、Self-Consistency（10 采样，T=0.8，top-p 0.95）、Self-Aggregation
（4 候选）、Self-Refinement、Describe-Answer、CCoT、Prompt Repetition；其余均贪心解码；答案抽取
失败时追加一次 `answer-only` 二次前向兜底。三条结论：(1) **小而能干**的 instruction-tuned 模型
获益最大（与 LLM 文献相反）；(2) **算力超过必要量时 LVLM"失焦"**——TTS 在纯感知任务上**降分**；
(3) **视觉接地是前置的**——图像注意力早期见峰随后衰减，并用 image-KV-cache dropping 做因果验证。
论文自己给出的边界处置建议是：**"substantial compute can be saved by identifying whether a task
actually requires test-time scaling, for example by training a simple binary classifier."**（未实现）

## 2. 三轴定位

**门控信号是什么**：**没有实现任何门控信号**。本篇测量的是 regime 边界，不建门。它识别出的判别
变量是**任务类型标签（推理型 vs 感知型）**，由基准/类目归属**先验给定**，**不是实例级不确定性
信号**。唯一的实例级旋钮是 token 预算（1,024 vs 300），且作为**全局上限**施加、非逐实例。
它提出的门是一个**训练的二分类器**——从未构建。

**决策规则训练还是规则**：不适用——研究中的"规则"都是全局配置选择（用哪种方法、token 上限多少）。
论文建议的规则是**训练**（binary classifier）；研究内**不存在任何自适应逐实例规则**。

**作用在哪道门**：**严格说两道门都不是**。TTS 是**内部生成算力**，不是证据获取，因此它位于 R2
两道门的**上游**——是对生成的预算分配决策，不是对采集或准入的决策。它与 R2 直接相关的机制接触点
只有一处：**Describe-Answer 与 CCoT 在形态上是"获取型"的**（先生成一个中间表示——caption /
scene graph——再注回 prompt），而这两个方法是全篇最稳定垫底的方法。也就是说，"**把已持有观测重
表达后注回上下文**"这一族在视觉域**输了**——这是本篇唯一直接对 R2 的 re-resolve / 重呈现动作类
说话的位置（详见 §5）。

## 3. 主实验数字（LaTeX 源核对）

### 3.0 任务分型（必须原样搬运，不得改写）

论文的分型在**基准与 MMStar 类目两级粒度**上给出，**全部在视觉域内**：
- **推理型**：WeMath（数学）、LogicVista（逻辑）。
- **感知型**：RealWorldQA（"a perception benchmark focused on spatial understanding"）、
  A-OKVQA（"also a perception benchmark"）。
- **混合**：MMStar（"serves as both a perception and a reasoning benchmark"）、
  HallusionBench（"both a perception and visual reasoning benchmark, designed to evaluate
  hallucination"）。
- **MMStar 六类目的显式二分**（Supp §`supp:mmstar_categorical_perception_degrade`）：
  感知向 = **coarse perception / fine-grained perception / science & technology**；
  推理向 = **instance reasoning / logical reasoning / mathematics**。
  ⚠ 把 science & technology 划入"感知向、几乎不需推理"是**有争议的归类**，R2 不应默认继承。

6. **Token 预算（Table 2 `tab:token_budget`，Δ = score@300 − score@1024）= 反向验证**：
   截短思维链**帮助感知、伤害推理**。Qwen3-VL-4B S-CoT RealWorldQA **+3.79** vs WeMath **−14.89**、

7. **闭源核对照（Supp `tab:gpt5.2`）**：GPT-5.2 coarse perception 基线 76.29 → CoT 73.50、
   Self-Refinement **69.70**；fine-grained 58.54 → Self-Refinement 58.10；RealWorldQA 73.59 →
   Self-Refinement **71.90**。论文措辞："less pronounced for GPT-5.2, but in some cases, still
   causing degradation." 即**边界在前沿模型上仍在，只是被削弱**。
8. **机制证据（Fig.4 `fig:attn` + Fig.5 `fig:dop_kv_cache`）**：图像注意力早期见峰随即衰减，对
   已生成 token 的注意力上升并最终主导（连**逐 token 的最大图像注意力上界**也稳步下降）。因果
   干预：每数据集取 **300 随机样本**，在生成步 **{20, 50, 100, 200, 300}** 处把图像 token 的
   Key/Value cache 从**所有层**整体删除后继续生成——早期删除明显掉分，**约 200 步之后删除图像
   几乎不影响准确率**（对应节省 ≈**125 GFLOPs**（WeMath / HallusionBench / MMStar）、
   ≈**325 GFLOPs**（LogicVista））。
9. **"重表达族"垫底**：Describe-Answer 与 CCoT 是全表最稳定垫底的两法。例：Qwen3-VL-32B
   Describe-Answer MMStar **70.20** vs 基线 72.66，其 math 类目 **61.05** vs 基线 71.42（−10.37）；
   Qwen2.5-VL-72B Describe-Answer MMStar 66.78 vs 68.65、HallusionBench 72.66 vs 74.97；
   Qwen2.5-VL-7B CCoT A-OKVQA **83.32** vs 基线 87.77（该表最差格）。
10. **judge 校验（Supp `tab:judge_validation`）**：LLM judge–GT 76.4% vs VLM–GT 75.9%，
    judge–VLM 一致 94.3%，judge–human 83.3%，human–GT 69.5%（250 样本 / 5 名标注者 / 各 50）。

## 4. DFS 四问

**方法**：在"模型规模 × 方法 × 任务类型"三维上系统绘制训练无关测试期算力的 regime 图，并用注意力
动态 + 因果 KV 删除解释**为什么**多算力伤害感知（视觉接地前置 + 漂移到自生成文本上）。

**局限**：(i) **纯视觉，零音频**——主文与附录**通篇不含** audio / speech / acoustic / omni 任一词
（已穷举检索确认）；(ii) 任务分型是**基准/类目标签**，不是可测量的逐实例信号，**无法直接充当控制器
输入**；(iii) science & technology 归为"感知向"这一归类可疑，且它驱动了部分类目级叙事；
(iv) 只有全局 token 上限（1,024 vs 300），无逐实例预算；(v) 提出的补救（训练二分类器）**从未构建
或评估**；(vi) 除采样类方法外每格单次运行，无 seed / 置信区间；(vii) LLaVA-OneVision-7B 与
SmolVLM2-2.2B 因 instruction-following 失败被排除（Supp `supp:model_failures`），该**选择性排除
部分地制造了 Takeaway 1**（"能干的模型获益最大"），论文虽披露但未量化其影响。

**改进空间**：整个门是空的。从"哪个信号能预测收益"到"逐实例预算"全部未占。更关键：**无人检验
任务类型标签能否被实例级不确定性统计量替代**——而这正是 R2 的 α1 项所在。

**可借鉴**：(a) **受害侧协议**——报告推理型基准时必须并列一个**纯感知基准**，并把混合基准按类目
解剖，使符号翻转在同一模型/同一方法内部可见（R2 的音频类目分桶可直接照搬）；
(b) **减预算 Δ 表**（Δ = score@短 − score@长）作为廉价、模型无关的"这类任务想要更少算力"探测器；
(c) **因果 KV 删除**作为证据必要性探针——其音频类比（"在第 k 步删掉音频 KV"）能直接回答"第 k 步
之后重听还有没有用"；(d) 论文的收束口号"靠判定任务是否需要算力来省算力"就是 R2 论点的跨模态同构。

## 5. R2 定位句核查

**R2 §4.2 原句（L416-417）**：
> "regime 边界（2606.28864）：额外测试时算力对推理型任务有利、对纯感知任务有害——获取策略必须
> 按任务类型分层。"

**判定：实证半句 CONFIRMED（且证据强于 R2 所暗示）；框定半句 CORRECTED。**

- **CONFIRMED 部分**：实证结论完全成立，且支撑面比 R2 引述的更宽——RealWorldQA（Table 1）
  + 第二个纯感知基准 A-OKVQA（Supp）+ MMStar **类目级**同模型同方法符号翻转（Supp）
  + **反向实验**（截到 300 token 反而**帮助**感知、**伤害**推理，Table 2）+ InternVL-3.5
  与 Molmo2 系列复现 + GPT-5.2 上被削弱但仍在。五路互证。
- **CORRECTED 1（概念词越界）**：本篇的杠杆是**内部推理算力，不是获取**。全篇不获取任何外部证据。
  R2 写"**获取**策略必须按任务类型分层"，论文支持的是"**推理期算力预算**必须按任务类型分层"。
  照现有措辞会跨越 R2 自己 §1.3 的章界（供给形式 vs 内部计算）。
- **CORRECTED 2（bullet 归属）**：R2 §4.2 把它归在"**被门控的获取**"标题下。本篇**不建任何门**，
  明确把门留给未来工作（"for example by training a simple binary classifier"）。它应作为
  **regime 边界 / 负迁移证据**条目单列，而非门控机制条目。

**建议改写**：
> "regime 边界（2606.28864，**纯视觉域、无音频**）：额外**推理期算力**对推理型任务有利、对纯感知
> 任务有害——RealWorldQA/A-OKVQA/InternVL-3.5 三路复现 + MMStar 类目级双向验证 + 300-token 截断
> 反向验证；**按任务类型分层的预算判据在视觉域已被实证，但该文不建门（自陈应留给一个训练的
> 二分类器）**。R2 把它读作对获取预算的**类比**，不承载对获取的效果证据。"

### 深读后新增的、R2 应该知道的事实（重点：对"感知 vs 知识不确定性"二分的支持与挑战）

1. **零音频——直接回答本次任务的关键提问**：穷举检索 `main.tex` + `supplementary.tex`，
   **audio / speech / acoustic / omni 出现次数为 0**。所有"感知"任务都是**视觉**的（空间理解、
   粗/细粒度视觉感知、图像幻觉）。所以"它的'感知任务上多算力有害'是否包含音频感知"——**不包含**。
   R2 **不得**把它引作关于音频感知的证据；这是一条**迁移未经检验的跨模态类比**，与 R2 §9 的
   H5 withheld 纪律（跨域只借形状不承载效果）一致。
2. **它支持 R2 二分的方式，与 R2 的二分并非同一划分——必须分清**：论文的划分是**任务类型**
   （答案是否需要审慎推演），R2 的划分是**不确定性类型**（我的不确定来自听不清还是不知道）。
   两者是不同的分区，不可等同。论文实证说的是：**当答案由感知本身决定时，追加生成算力有害，
   因为模型漂移到自生成文本、不再回读图像**（前置注意力 + KV 删除双证）。翻译进 R2 词汇，这是
   一条关于 **R2 §1.3 第②类信息作用（对已有观测的重表达）**的陈述，**不是**关于第①类（外部新
   信息）的陈述。R2 §4.2 目前把它与 ToolGate/FOVEA（第①类的门）并列，模糊了这个区别。
3. **最直接相关、且是"挑战"而非单纯"支持"的一条**：全篇最字面地实现"把已持有观测重表达后注回
   上下文"的两个方法——**Describe-Answer**（先给图像详细 caption，再 caption+图像+问题一起作答）
   与 **CCoT**（先抽 scene graph，再 graph+图像+问题一起作答）——**恰是全表最稳定垫底的两法**，
   包括在它们本来要帮的感知基准上（Qwen2.5-VL-7B CCoT A-OKVQA 83.32 vs 基线 87.77；Qwen3-VL-32B
   Describe-Answer MMStar 70.20 vs 72.66、math 61.05 vs 71.42）。
   **R2 的 re-resolve 动作结构上属于这一族**（不引入外部新信息，只重呈现已有观测）。视觉域证据是：
   **固定的、无条件的观测重表达是净负的**。这不反驳 R2 的设计（R2 的 re-resolve 以感知不确定性
   信号为条件，且 A4b−A4a 差分正是能查出它有害的臂），但推出三条必须写进 R2 的推论：
   - R2 **应当预期无条件重听臂会输**；因此 A4a 中"re-resolve 为固定档，从 {0, 每题至多 1 次前置
     重听} 中按 dev 最优选定"这一设定需注意：本篇预测该固定档偏弱甚至有害。这**对 R2 的可识别性
     有利**（A4b−A4a 缺口更大），但 R2 必须**如实报告 dev 选中 0 的情形**，不得让固定档意外成为
     承载 R2 正向主张的臂。
   - R2 的主张必须始终是**条件价值**（"感知不确定性高时重听有价值"），**永不可**表述为无条件
     ("重听有价值")——后者的视觉类比已被实证为假。
   - R2 应把这两法列为**跨域反例先例**，写进 prior-difference 记账：跨域已试过"无条件重呈现"
     并失败，R2 的差异只能挂在"被信号门控"上。
4. **前置化结论给重听设了一条"截止线"——R2 §4.5 目前只管"选哪个动作"、不管"在第几步"**：
   图像注意力早期见峰后衰减，且因果干预显示**约 200 生成 token 之后整体删除图像几乎不影响准确率**。
   若音频类比成立，**在长推理链后段重听将是惰性的**——冻结核此时已停止回读感知输入、在自己的文本
   上推理。于是"**何时**重听（是否必须在链条承诺之前）"上升为 R2 动作调度的一等设计变量。
   这是一条**廉价可验的预测**：R2 可在自己载体上做同型探针（在第 k 步 mask/删除音频 KV 或音频
   token，测准确率随 k 的曲线），从而把"重听的有效窗口"变成可报告的事实。
5. **预算非单调是双向的、且按任务类型定向**：与 Omni-DeepSearch 的 (5,1)/(10,3)/(15,5) 饱和相比，
   这里测的是**反方向**——把预算从 1,024 砍到 300 token **改善**感知（Qwen2.5-VL-72B
   Self-Refinement RealWorldQA **+10.07**、Qwen3-VL-4B S-CoT **+3.79**）同时**摧毁**推理
   （WeMath −15.06、LogicVista −13.84）。"花得越多越好"不只是**饱和**为假，而是**符号翻转**为假。
   R2 预算章可把它作为视觉域的孪生证据（并注明是生成算力轴，非获取轴）。
6. **模型强度交互——R2 不可假定自身核落在良性区**：小而能干的模型 TTS 获益最大（Qwen3-VL-2B
   WeMath 35.46 → 64.25），而**感知受害在较老/指令遵循较弱的族上更重**（Qwen2.5-VL 7B/32B 在
   RealWorldQA 上九法全负；InternVL-3.5 4B/8B/38B 六法全负），在 GPT-5.2 上被削弱。R2 的载体是
   冻结 30B 级 omni 核，处在两种效应同时活跃的区间；且 R2 **不应**把"小模型获益最大"这一结论
   引作自身核规模选择的依据（不同模态、不同指令遵循画像）。
