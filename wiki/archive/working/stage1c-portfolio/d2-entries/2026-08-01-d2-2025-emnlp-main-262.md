## 2. 「首个系统性实证分析」覆盖什么（**任务下达的第一个承重点**）

**主张逐字（摘要，第 5187 页）**：

> "Our study provides the **first systematic empirical analysis of the modality gap and alignment mechanisms in LSLMs**, offering both theoretical and methodological guidance for future optimization."

**引言的两处同族主张（第 5188 页）**：

> "We systematically reproduce and quantify this discrepancy across various LLM backbones and training strategies, and, **for the first time, empirically reveal the underlying mechanisms behind the performance difference**."
> 贡献 (3)：> "We provide the **first empirical evidence** that targeted interventions on speech representations can improve speech input performance on challenging cases."

**主张的自我限界（Related Work §2.2，第 5188 页）——本件须与摘要并置引用**：

> "Previous work has systematically analyzed the **modality gap phenomenon** and shown that it persists across a wide range of multimodal models (Liang et al., 2022). This gap largely arises from **the cone effect**…"
> "In the field of **speech translation**, the modality gap has also been a subject of investigation. Evidence suggests that this gap can emerge during the early phases of fine-tuning (Han et al., 2023)… This representational divergence was empirically quantified using the **cosine similarity between speech and text embeddings**, confirming a substantial gap (Fang and Feng, 2023)."

### 2.3 覆盖面（三）：方法学的三层堆栈

**第一层 —— 粗粒度（序列级），§4.1（第 5191 页）逐字**：

> "we employ two similarity metrics, denoted in a unified manner as `f^(·)(x, y)`… (cos: cosine similarity, d: Euclidean distance): `f^(cos)(x,y) = x⊤y/(‖x‖‖y‖)`, `f^(d)(x,y) = ‖x−y‖₂`."
> "For each layer l, we first compute the **mean representation over the sequence dimension** for both modalities: `h̄_l^s = (1/T_s) Σ_i h_{l,i}^s`, `h̄_l^t = (1/T_t) Σ_j h_{l,j}^t`"

配对构造逐字：> "Given a set of N speech-text query pairs `{(x_i^s, x_i^t)}_{i=1}^N`, where `x_i^s` denotes the speech input and `x_i^t` **its corresponding text transcription**"（5191）→ **文本侧输入是同一条语音的转写**，两侧内容严格配对；Figure 3 显示两路都带同一 `System Prompt`。

模态差距的操作化定义逐字（§4.3，5191）：> "We quantify the modality gap as the drop in benchmark scores between text and speech inputs, as: **`GAP = M^t − M^s`**, where `M^t` and `M^s` are overall benchmark scores obtained from text and speech inputs, respectively."
层平均标量：> "`f̄^(·) = (1/L) Σ_{l=1}^L f_l^(·)(h̄_l^s, h̄_l^t)`"

**第二层 —— 细粒度（token 级），§5.1–5.2（第 5192–5193 页）逐字**：

> "At each layer l, we construct a **token-wise similarity matrix `A_l^(·) ∈ R^{T_s×T_t}`**, defined as: `[A_l^(·)]_{i,j} = f^(·)(h_{l,i}^s, h_{l,j}^t)`"
> "for each text token j, we identify the index of the speech frame with maximal similarity or minimal distance as: `i*_j = arg max_i [A_l^(cos)]_{i,j}` if `f^(·) = f^(cos)`; `arg min_i [A_l^(d)]_{i,j}` if `f^(·) = f^(d)`"
> "To verify the presence of monotonicity in these alignments, we use the **Spearman rank correlation coefficient** between text token indices and their aligned speech frame indices as the evaluation metric."

**Alignment Path Score（APS）定义逐字（§5.2，5193）**：

> "Based on the observed token-level alignment patterns, we propose the **Alignment Path Score (APS)** to quantify the strength of speech-text alignment at the token level. Specifically, APS is defined as:
> **`APS^(·) = (1/(L × T_t)) Σ_{l=1}^L Σ_{j=1}^{T_t} [A_l^(·)]_{i*_j, j}`**
> where L denotes the number of layers, T_t is the number of text tokens, and `[A_l^(·)]_{i*_j, j}` represents the **maximal similarity (or minimal distance) along the alignment path for each token**."

→ **APS 是「沿最优对齐路径的、逐层逐 token 平均的极值」**，与序列级标量 `f̄` 的差别是：前者在 token 对齐后取极值，后者在序列均值后取相似度。**两者都有 cos 与 d 两个版本。**

**第三层 —— 干预（因果探针），§5.3（第 5193 页）逐字**：

> "However, **correlation does not necessarily imply causation.** To further investigate whether the token-level alignment mechanism **causally** affects the speech understanding ability of LSLMs, we conducted a series of **targeted intervention experiments**."
> "we first used the APS path to identify the **three speech tokens with the lowest alignment scores (bottom3)** as well as **all tokens along the alignment path (All)**. We then applied two types of interventions: (1) **Angle projection**, where the selected speech token embeddings were **projected to have the same direction as their corresponding text token embeddings**; and (2) **Length normalization**, where the **norm of the speech token embeddings was scaled to match that of the corresponding text tokens**."

→ **任务下达提到的「Alignment Path Score / angle-projection / length-norm interventions」三项全部 CONFIRMED，逐字如上。**

### 2.4 覆盖面（四）：评测载体

## 3. 关键发现（逐字 + 复算）

### 3.1 前置：模态差距的规模与两因分解（§3.3，第 5190 页）

**逐字**：

> "For the data shown in Figure 2, on average, LSLMs exhibit a **25% performance decline on speech inputs relative to their base models on text**. This decline can be attributed to two factors: (1) **fine-tuning–induced erosion of reasoning and generation capabilities, with an average drop of 8.79%**; and (2) **suboptimal speech–text alignment, with an average drop of 16.46%**. Given the variety of model sizes and tuning methods evaluated, **this trend appears general**."

**Figure 2 三档柱（本件已与 Table 2 交叉核对，见 §1）**：

| 配置 | 微调前·文本输入 | 微调后·文本输入 | Δ₁（微调侵蚀） | 微调后·语音输入 | Δ₂（模态错位） |
|---|---|---|---|---|---|
| Qwen2.5-1.5B \| Full | 61.7 | 54.9 | −6.8 | 45.6 | −9.3 |
| Qwen2.5-1.5B \| LoRA | 61.7 | 55.3 | −6.4 | 39.7 | −15.6 |
| Llama3.2-3B \| Full | 65.8 | 53.0 | −12.8 | 38.1 | −14.9 |
| Llama3.2-3B \| LoRA | 65.8 | **66.7** | **+0.9** | 36.1 | **−30.6** |
| Qwen2.5-7B \| Full | 77.3 | 59.2 | −18.1 | 48.3 | −10.9 |
| Qwen2.5-7B \| LoRA | 77.3 | 70.0 | −7.3 | 51.0 | −19.0 |
| Llama3.1-8B \| Full | 72.4 | 53.6 | −18.8 | 44.5 | −9.1 |
| Llama3.1-8B \| LoRA | 72.4 | **71.4** | **−1.0** | 49.1 | **−22.3** |

**本件复算（三条，全部为承重的单位口径更正）**：

1. **Δ₁ 的算术平均 = (6.8+6.4+12.8−0.9+18.1+7.3+18.8+1.0)/8 = 70.3/8 = 8.79** ✓
   **Δ₂ 的算术平均 = (9.3+15.6+14.9+30.6+10.9+19.0+9.1+22.3)/8 = 131.7/8 = 16.46** ✓
   → **论文写的「8.79%」与「16.46%」实为【绝对百分点（pp）】，不是相对百分比。**
2. **两者之和 = 25.25 pp**，即论文所称的「25% performance decline」**同样是 25.25 pp**。
   验证其不可能是相对值：微调前文本均分 = (61.7+61.7+65.8+65.8+77.3+77.3+72.4+72.4)/8 = **69.3**；微调后语音均分 = (45.6+39.7+38.1+36.1+48.3+51.0+44.5+49.1)/8 = **44.05**；相对降幅 = 25.25/69.3 = **36.4% ≠ 25%**。
   → **「25% 下降」是 25.25 pp，相对降幅实为 36.4%。**
3. **对比**：§5.3 的 "improving by **7.52%**"（Llama3.1-8B）与 "**4.19%**"（Qwen2.5-7B）**是相对百分比**（见 §3.4 复算）。
   → **本篇在两节之间对 "%" 的用法不一致**（§3.3 = 百分点；§5.3 = 相对百分比）。**R2 引用这三个数（25 / 8.79 / 16.46）时必须写作「百分点」，否则会把效应量夸大约 1.44 倍。**（本件复算，标为承重更正。）

**两条表面之下的读数（本件新增，论文未讨论）**：
- **LoRA 与全参数微调的两因结构完全相反**：LoRA 的文本能力几乎不掉（Δ₁ ∈ [−7.3, +0.9]，两个 Llama 配置甚至 ≈0），但模态错位极大（Δ₂ ∈ [−30.6, −15.6]）；全参数微调则相反（Δ₁ ∈ [−18.8, −6.8]，Δ₂ ∈ [−14.9, −9.1]）。**8 个配置中，LoRA 的 Δ₂ 全部大于同骨干的全参数 Δ₂；全参数的 Δ₁ 全部大于同骨干的 LoRA Δ₁。无一例外。**
- → **「总下降 25 pp」在两种微调法下由完全不同的成分构成**，把两者平均成一个数会掩盖这一结构。这条对 R2 的意义见 §6。

### 3.2 关键发现（一）：**深层方向对齐、幅度发散**（§4.2，第 5191 页）

**摘要逐字（第 5187 页）**：

> "At the coarse-grained level, representations of speech and text in **deeper layers are found to be increasingly aligned in direction (cosine similarity), while concurrently diverging in magnitude (Euclidean distance)**."

**正文逐字（§4.2，第 5191 页；Figure 4 无数值层，本件只引文字）**：

> "For cosine similarity, **all models demonstrate a consistent increase as the network depth grows**, indicating **progressively stronger alignment** between speech and text representations in deeper layers. Moreover, **later training checkpoints consistently yield higher similarity scores across all layers**, reflecting improved cross-modal alignment as training advances."
> "In contrast, **Euclidean distance gradually increases in the shallow layers and accelerates in the deeper layers**. While **models with more extensive training tend to exhibit slightly lower Euclidean distances overall**, the **upward trend with increasing depth remains consistent**, suggesting **growing representational magnitude divergence despite directional convergence**."
> "These trends suggest that deeper layers and extended training foster improved alignment in **representational direction** (cosine similarity), while **preserving modality-specific distinctions in magnitude** (Euclidean distance). This alignment pattern **could facilitate effective multimodal integration while preserving essential characteristics of each modality**."

**外部验证（Qwen2-Audio，附录 B.2，第 5201 页）逐字**：

> "The observed layer-wise similarity dynamics, characterized by **an increase in cosine similarity and a concurrent upward trend in Euclidean distance with network depth**, are **highly analogous** to the phenomena identified in our primary experiments."

→ **该现象在自训 8 件 + 外部 1 件（三阶段训练范式）上均成立**，是全篇最稳的一条读数。

**本件记录的一处叙述张力（见 §7 I-3）**：§4.2 把幅度发散**正面定性**为 "preserving essential characteristics of each modality"，但 §4.3 的回归给出的欧氏距离斜率**为正**（`y = 0.42x + 8.72` 等）——**即欧氏距离越大、模态差距越大**。两处对同一量的价值判断方向相反。

### 3.3 关键发现（二）：**表示相似度与模态差距的线性相关**（§4.3，第 5191–5192 页）

**Figure 5 的四条回归式（文本层逐字抽取，第 5192 页）**：

| 面板 | 自变量 | 回归式 | R² |
|---|---|---|---|
| Full Fine-tune | Cosine Similarity（层平均） | `y = −11.67x + 21.00` | **0.39** |
| Full Fine-tune | Euclidean Distance（层平均） | Llama: `y = 0.42x + 8.72` / Qwen: `y = 0.20x + 6.47` | **0.53 / 0.27** |
| LoRA Fine-tune | Cosine Similarity（层平均） | `y = −63.53x + 69.82` | **0.75** |
| LoRA Fine-tune | Euclidean Distance（层平均） | Llama: `y = 1.44x + 16.27` / Qwen: `y = 0.60x + 2.84` | **0.88 / 0.64** |

**正文 Key Findings 逐字（第 5192 页）**：

> "Under LoRA fine-tuning, a **strong linear relationship** is observed between cosine similarity and GAP (**R² = 0.75**), suggesting that **better cross-modal alignment leads to smaller performance disparities**. Although Euclidean distance shows a weaker correlation overall, it becomes more pronounced within specific model families (**R² = 0.64 for Qwen and R² = 0.88 for Llama**)."
> "For full-parameter fine-tuning, the same trend persists but with **reduced strength**: **R² = 0.39** for cosine similarity, and **R² = 0.53 and 0.27** for Euclidean distance in Llama and Qwen, respectively."

**作者给出的机制解释逐字（§4.3 Analysis，第 5192 页）**：

> "The stronger correlations observed in LoRA-tuned models may stem from the **constrained low-rank adaptation, which preserves the integrity of pretrained text representations while facilitating targeted speech-text alignment**. In contrast, full fine-tuning grants more representational flexibility, **potentially introducing overfitting that weakens this correlation**. Consequently, representation similarity serves as a **more reliable predictor of modality performance under LoRA than under full-parameter fine-tuning**."

**本件记录的三条限界**：
- **回归点 = 检查点**（"Each point corresponds to a **model checkpoint**"，5192）。每个配置 5 个检查点，故 LoRA 面板的样本量约为 4 配置 × 5 检查点 = **20 点**（余弦面板合并 Llama 与 Qwen；欧氏面板按族分开各约 10 点）。**论文未报样本量、未报置信区间、未报 p 值。**
- **同一模型的不同训练步不是独立样本**（沿训练轨迹强自相关），**R² 因此不是跨模型泛化的度量**；论文未讨论。
- **余弦面板的斜率为负、欧氏面板为正**，两者方向自洽（相似度高→差距小；距离大→差距大），但**这与 §4.2 把幅度发散称为「保留模态特性」的正面定性存在张力**（见 §7 I-3）。

### 3.4 关键发现（三）：**自发的单调 token 级对齐**与 APS（§5.1–5.2，第 5192–5193 页）

**观察逐字（§5.1，第 5192 页；Figure 6 为热力图，本件只引文字）**：

> "Across **all models and training paradigms**, we consistently observed that the token-wise similarity matrix typically exhibits **extreme values along a nearly monotonic path**. As shown in Fig. 6, with the increase in text token index, there is a **monotonic alignment path in the speech frame sequence** along which the similarity (or distance) values are locally maximized (or minimized). **This monotonic path does not strictly align with the main diagonal, but reflects the actual temporal alignment structure between speech and text modalities.**"

**统计量化逐字（§5.1，第 5193 页）**：

> "At the final training epoch across all models, the **average Spearman coefficient is 0.85 for cosine similarity and 0.70 for Euclidean distance**. The proportion of tokens with **perfectly identical alignment paths under both similarity measures is 0.59**, indicating substantial consistency in the alignment results."

**机制定性逐字（§5.1 Mechanism Analysis，第 5193 页）**：

> "The widespread emergence of this monotonic pattern suggests that the model **not only aligns modalities globally, but also spontaneously learns a soft, monotonic alignment between speech frames and text tokens at the token level**. Importantly, this alignment pattern **emerges automatically in end-to-end speech-text alignment tasks**, reflecting the model's ability to capture and map the temporal structure of speech to the semantic structure of text in a robust manner."

**APS 与 GAP 的回归（Figure 7 的四条回归式，文本层逐字抽取，第 5194 页）**：

| 面板 | 自变量 | 回归式 | R² | 对应的序列级 R²（§3.3） |

| Full Fine-tune | APS (cos) | `y = −10.34x + 18.72` | 0.37 | 0.39（略降） |
| Full Fine-tune | APS (d) | Llama: `y = 0.29x + 7.22` / Qwen: `y = 0.11x + 6.25` | 0.53 / **0.15** | 0.53 / 0.27（Qwen 明显降） |
| **LoRA Fine-tune** | **APS (cos)** | `y = −63.86x + 63.04` | **0.81** | 0.75（**升**） |

**正文逐字（§5.2，第 5193 页）**：

> "As shown in Figure 7, **LoRA-trained LSLMs yield higher R² values for both cosine (0.81 vs. 0.75) and Euclidean APS (0.72 vs. 0.64 for Qwen; 0.95 vs. 0.88 for Llama)** compared to previous baselines, indicating **stronger linear correlations with GAP**. The stronger correlation between APS and GAP highlights that **fine-grained, token-level alignment is the key mechanism underlying LSLM speech understanding**."

**本件记录（承重）**：**「APS 比序列级指标更强」这一主张只在 LoRA 侧成立**。全参数侧 APS(cos) 从 0.39 **降到** 0.37、APS(d) 在 Qwen 上从 0.27 **降到** 0.15。**正文用 "similar to…with both showing low R² values" 一句带过这两处下降**，未指出 Qwen 侧几乎腰斩。→ 见 §7 I-4。

**外部验证（Qwen2-Audio，Table 9，第 5202 页）**：

|---|---|---|---|

For LoRA fine-tuned models, applying angle projection to either the Bottom3 or All alignment-path tokens **consistently improves results**. **本件逐格复算（四条，全部核对通过）**：

### 3.6 干预纠正的两类错误（§5.3 + 附录 A.4，第 5194 / 5197 页）

**逐字**：

> "These corrections fall into two categories: (1) **resolving semantic misunderstandings from misinterpreting spoken content**, and (2) **rectifying factual errors despite correct semantic parsing**."
> （A.4）"The first category involves the resolution of semantic misunderstandings arising from the spoken input. For example, in **Case 1**, the model initially **misinterprets the spoken entity \"Brittany\" as \"Britain\"**, leading to an irrelevant answer. Similarly, **Case 2** shows an **erroneous entity recognition** from the speech input."
> （A.4）"The second category addresses **factual errors that occur even when the initial semantic parsing of the spoken query is correct**. In **Case 3** and **Case 4**, the model demonstrates a correct understanding of the question's topic but **fails to produce factually accurate or complete answers**."
> （A.4 结语）"indicating that such interventions can enhance multimodal alignment and enable **more reliable knowledge retrieval from speech input**."

**四个案例（Tables 4–7，第 5199–5201 页）**：

| Case | 问题 | 参考答案 | 语音输入的错误 | 错误类型 |
|---|---|---|---|---|
| 1 | "What do they speak in Brittany?" | "Breton." | 把 `Brittany` 听成 `Britain`，答英语/威尔士语/盖尔语 | **实体误听**（语义误解） |
| 2 | "Who is Sean Hannity?" | "An American talk show host and conservative political commentator." | 转成 "Shawn Hanity"，答成"演员与喜剧演员" | **实体误听**（语义误解） |
| 3 | "What's the biggest wasp?" | "Asian giant hornet." | 语义解析正确，答成 "tarantula hawk wasp" | **事实错误** |
| 4 | "Where does the story of American Horror Story: Murder House take place?" | "Los Angeles, California." | 语义解析正确，答成"虚构小镇 Harmony / 新奥尔良法国区" | **事实错误** |

**这四个案例的承重意义（本件判定）**：Case 3 与 Case 4 的**同一模型在文本输入下答对**（Table 6：文本 "The largest wasp in the world is the **Asian giant hornet**." ✓；Table 7：文本 "…takes place in **Los Angeles, California**." ✓），**在语音输入下答错，且错误不来自听错**（问题被正确解析）。→ **这是「同一参数、同一知识、换输入模态即读不出来」的一手案例证据**，也正是 R2 §1.7 L5 线所指的「参数知识不可稳定读取」的直接实例。**但须同时记录其证据强度：四个案例是【定性挑选的代表例】，论文未给该两类错误的比例、未给案例的抽样规则。**

## 6. DFS 四问

### 6.1 方法核心

把「端到端 LSLM 在语义理解上不如 ASR+LLM 级联」这一现象，**拆成一个可测量的表示层机制问题**：先把性能差距操作化为 `GAP = M^t − M^s`（同一模型、同一内容、只换输入模态），再用**三层递进的观测堆栈**去解释它——**序列级**（逐层的方向相似度与幅度距离，及其层平均值与 GAP 的线性回归）→ **token 级**（token-frame 相似度矩阵上的自发单调对齐路径，及沿路径的 **Alignment Path Score**，其与 GAP 的回归更强）→ **干预**（沿路径对最差三个或全部语音 token 做角度投影/长度归一，检验相关是否带因果）。核心科学主张只有两句：**深层的跨模态对齐是「方向收敛、幅度发散」**；**token 级对齐质量（APS）比序列级相似度更能预测模态差距，且对它的定向干预能部分收窄差距。**

### 6.2 自述局限（Limitations 全节逐字，第 5195 页）

> "**Generalizability of Findings.** Our main experiments focus on a **specific set of architectures and alignment frameworks**. Although Appendix B reports consistent phenomena across external LSLMs, **broader validation on larger models and fundamentally novel alignment strategies remains necessary**."
>
> "**Scope of Data and Tasks.** Our evaluation centers on **English, single-turn dialogue with synthetic speech**, which may limit the applicability of the findings to **other languages, multi-turn conversations, and noisy real-world inputs**."
>
> "**Post-hoc Nature of Interventions.** Our intervention strategies are **applied post hoc at inference time and serve primarily as analytical probes** of token-level alignment. An important direction is to **integrate these insights into training** to explicitly optimize cross-modal consistency and improve speech-input performance."

**自述局限之外、本件逐表核对新增的七条（论文未列）**：
- (i) **单位口径不一致（承重）**：§3.3 的 25 / 8.79 / 16.46 是**百分点**，§5.3 的 7.52 / 4.19 是**相对百分比**，两节均写作 "%"（§3.1 复算 3 与 §3.5 复算 2）。

### 6.3 改进空间

按与 R2 的相关度排序，逐条给出论文中的可证伪抓手：

1. **「事实错误」与「听错」的比例从未被测量**：§5.3 把干预纠正的错误分成两类（语义误解 / 事实错误），却只给了 4 个挑选的案例，**无比例、无抽样规则、无标注协议**。**把这两类在 sd-qa 上做一次带标注的分类统计**，就能把「语音输入下参数知识读不出来」从案例级证据升为分布级证据——这是本篇留给 L5 线的最直接的空格。
2. **APS 只在最优路径上取极值，丢弃了整个矩阵的其余信息**：`[A_l]_{i*_j, j}` 只取每列极值。路径的**离散度**、**次优路径的竞争强度**、**逐层路径的稳定性**均未进入指标。
3. **干预只有两个几何算子、两个作用域**：角度与模长是嵌入的两个自由度的极端形式（完全对齐 / 完全匹配），**无插值强度参数**（如按 α 部分投影）、**无按层选择**（干预作用在哪一层未在正文声明，见 §7 I-5）。
4. **Bottom3 优于 All 这一现象未被解释**：Table 1 中 Bottom3 在 4 个 LoRA/Full 配置中 3 个优于 All；这暗示「过度干预有害」，但论文只说 "more robust gains"，未做 Bottom-k 的 k 扫描。
5. **合成语音的天花板**：训练与评测语音全部为 CosyVoice 合成且经 WER<0.1 过滤，**真实语音上的 GAP 结构未知**；Limitations 自列。
6. **相关性的因果强度有限**：干预实验只在 **1 个子集（sd-qa）× 4 个配置**上做，且 length normalization **8 格中 7 格为负**——即两个几何算子中有一个整体有害。**"causally affects" 这一措辞的证据面比它听起来窄。**

### 6.4 R2 可借鉴部分

1. **`GAP = M^t − M^s` 这一操作化定义**是本篇最干净的一件工具：**同一模型、同一内容、只换输入模态**，得到一个不依赖任何外部基线的标量。R2 若要在 §1.7 L5 线上给出「语音模态读不出参数知识」的量化读数，**这是一个可直接复用的、零额外训练的测量协议**（只需一次文本输入臂）。
2. **两因分解（微调侵蚀 vs 模态错位）的三档柱设计**（微调前文本 / 微调后文本 / 微调后语音）把两种降级来源分离。R2 若在冻结核上做同类诊断，第一档柱恒定（无微调），**分解退化为单因**——这本身就是「冻结核路线避开了第一因」的一条现成论据。
3. **序列级 → token 级 → 干预的三层递进**是一个可移植的机制论证模板：相关（弱） → 更细粒度的相关（更强） → 定向干预（因果探针）。R2 的机制章节可采用同一递进纪律。
4. **外部验证的最小充分形式**（附录 B）：先在 4 件不同对齐范式的公开 LSLM 上验现象存在（Table 8），再在其中 1 件上重跑全部三层分析（B.2）。**这是「自训模型上的结论是否泛化」的一种低成本证明结构。**
5. **「同一模型文本对、语音错」的案例格式**（Tables 4–7 的六行结构：Question / Reference / Text Input / Speech Input / 各干预输出）是一份**可直接复用的定性证据模板**，且它天然把「听错」与「知识读不出」分开呈现。
6. **Bottom-k 定向干预的思路**（只动最差的少数单元、而非全体）与「作用域收缩即免疫」的读数同向（对照 ConEC row 3 vs row 4、iKnow-audio 的 log-sum-exp 融合）——**本篇给出了该规律在表示层的一个实例**。

### 8.3 可信度小结（不作方向性裁定）

- **可直接引用的强项**：`GAP = M^t − M^s` 的操作化定义与 Table 2 的 8 配置 × 5 检查点全表；§5.1 的路径单调性标量（0.85 / 0.70 / 0.59）与 Table 9 的外部复现；Table 8 的四件外部 LSLM 全部呈正 GAP（8.09 / 15.65 / 6.51 / 13.30）；Table 1 与 Table 10 的干预格全表；Cases 1–4 的定性证据。这五组均有表体直接支撑、无跨表冲突（Table 2 的单点录入错误已在 I-1 中定位并给出正确值）。
- **引用时必须带限定的**：「25% / 8.79% / 16.46%」（**须改写为百分点**，否则效应量被夸大约 1.44 倍）；「APS 相关性更强」（**须写明只在 LoRA 侧**，全参数侧两处下降）；「干预可改善」（**须写明从不闭合差距**，最好一格仍差 3.97 pp、外部件仅 +0.91 pp）；「first systematic empirical analysis」（**须写明范围限于 LSLM 模型族**，多模态与语音翻译的模态差距分析被作者自列为在先工作）；「causally affects」（**须写明证据面 = 1 子集 × 4 配置，且两个算子中一个整体有害**）。
- **不应作为承重引用的**：Figure 4 / 6 / 8 / 9 的任何目视读数（无数值层）；Table 2 中 Qwen2.5-1.5B\|LoRA\|4000 的 Text-MMSU 单元格（I-1，应用复算值 ≈51.97 或直接回避）；干预实验的层位设定（I-5，全文未报）；「两类错误」的相对比例（论文只给挑选案例）。
- **本件对 R2 最直接的两条**：①**`GAP` 协议与两因分解可直接复用**——在冻结核路线上第一因（微调侵蚀）恒为零，分解退化为单因，这本身是一条现成的路线论据；②**Case 3 / Case 4 是「同一参数、同内容、换模态即读不出知识」的一手案例证据**，正对应 R2 §1.7 L5 线的核心命题，**但其证据级别是案例级、非分布级**，R2 引用时须如实标注并把「比例测量」列为该线的遗留义务。
- **遗留核对义务（有网络时）**：①对官方 PDF 目视复核 Table 1 / 2 / 3 / 8 / 9 / 10 与 Figure 5 / 7 的全部承重数字，并补齐 Figure 4 / 8 / 9 的曲线读数；②核实本 id 是否另有 eprint/预印本版本以升一档证据等级；③核实是否有随后释出的代码/检查点（本篇正文无任何发布声明）；④**读 SALAD（2510.13632）全文，核实 R2 draft 转述的「文本能力遗忘 + 跨模态错位」二分与本篇「fine-tuning erosion + suboptimal alignment」二分的对应关系是否成立**——该对应目前只基于 R2 draft 的一句话摘述，属待核项。
